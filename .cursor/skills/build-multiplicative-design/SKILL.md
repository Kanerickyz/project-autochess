# 构筑乘法效应设计

## Overview

策略深度来自**构筑**：多件独立组件简单联动后产生远超相加的指数收益。

**公式**：`A（基础值）× B（乘数因子）= 指数收益`

- **A** = 事件源 / 基础输出或基础触发（能稳定发生的那一头）  
- **B** = 放大组件（易伤、加速循环、转化、反制、复制、连锁等）

优秀构筑不是堆最强单体，而是找能互为乘数的组件。框架源自行业「构筑乘法效应」摘要，已映射到本项目载体（技能·站位·增益，非标签羁绊）。

## 本项目边界（必读）

| 定稿 | 含义 |
|------|------|
| **主题羁绊** | 八主题上场凑人触发团队层；见 Notion Doc ID `feature-unit-theme-bonds`（指针 `Documents/Features/UNIT_THEME_BONDS.md`）；**必须**复用 `EffectSpec` / `EffectResolver`，禁止另写一套 Buff |
| 构筑深度载体 | **单位内建技能 + 槽位站位 + 增益卡 + 主题羁绊**（+ 装备/消耗品若已入规格） |
| 效果统一管线 | 战斗增益与主题团队层经 `EffectSpec` / `EffectResolver`；触发经 `CombatEventBus` |
| 内部流派不对外 | 内部可用「坚韧 / 冲锋」等称呼；八**主题名**可对玩家；勿与内部流派名混用 |

本 skill 里审查乘法时：主题层当作**弱身份开关 / 弱 B**，须与单位技能**分轴**；不要把「凑 N 人」写成与技能同轴再乘。

## 何时用 / 不用

**用**：新技能组合、站位杠杆、增益/装备邻接、流派样板、构筑成型节奏与反制空间、平衡批跑解读「某一构筑统治」时。

**不用**：单点改攻血且无联动意图；纯 UI/美术；已明确否决的种族羁绊方案展开。

## 三分法（设计构筑）

```text
定义收益上限（乘数因子）
  + 制造门槛/成本（空间 · 时序 · 状态）
  + 限定风险/约束（脆弱 · 独占 · 反差弱点）
```

## 角色分工

### `game-designer`（功能）

负责：**选哪类乘数、门槛形态、反制可读性、验收观察点**。不写具体点数。

交付检查：

1. 标明 **A（基础输出/触发）** 与 **B（乘数）** 各是什么组件  
2. 门槛属于空间 / 时序 / 状态哪一类（可组合）  
3. 对手或环境如何打断（脆弱点、资源独占、反差弱点至少一类）  
4. 玩家在观战里能否看出「联动兑现了」（对照 Notion Doc ID `feature-combat-feedback`，指针 `Documents/Features/COMBAT_FEEDBACK.md`）

### `balance-designer`（数值）

负责：**幅度、叠层、软硬顶、成型时间、集中度**。不借调参发明新玩法维度。

交付检查：

1. 乘数有启动阈值 / 衰减 / 硬顶，避免开局满碎甲或无限循环  
2. 转化类：垃圾资源转化价值 ≤ 核心资源直取价值  
3. 复制/叠层：高成本 + 可打断；无限叠层视为高危  
4. 用数据盯：**成型时间**、**Build 集中度**（胜场占比、核心件选取率、有/无该链胜率差；批跑为启发式 AI，不当真人胜率）  
5. 单乘数统治时下调顺序：**先压 B**（硬顶/幅度/完整度）→ **再收启动频率** → **再抬规格内已有门槛的数值旋钮**；若需**新门槛形态**则停手退回 `game-designer`

## 快速参考：六类乘数因子（B）

| 类型 | 核心思路 | 设计要点 |
|------|----------|----------|
| **削减/易伤** | 降抗/降防让基础伤害指数放大 | 叠层或战末生效；物魔削减勿完美同 Build；避免抗性暴穿负无穷 |
| **频率/循环** | 加快出手或降行动成本 | 概率/消耗打断白嫖无限循环；每回合次数软硬顶或疲劳 |
| **资源转化** | 废牌/杂资源→核心资源 | 定转化率；转化件占席位/格位/槽位制造机会成本 |
| **反制/反伤** | 吃伤害或吃行动换输出/控 | 区分扛爆发 vs 扛高频；反伤通常低于主动但可含百分比成长 |
| **复制/叠加** | 复制核心单位/效果或叠低效状态 | 高稀有/一次性成本；边际递减；无限叠=危险 |
| **范围/连锁** | 单体扩 AOE 或击杀重置链 | 单次连锁次数上限；AOE 衰减；击杀/暴击/命中等触发要分流派 |

## 快速参考：构筑门槛

| 门槛 | 核心思路 | 注意 |
|------|----------|------|
| **空间/位置** | 乘数绑定稀缺格、相邻、前后排 | 强迫牺牲其他构筑的最优站位/装位 |
| **时序/阶段** | 仅中后期或 N 回合后兑现 | 核心件高费/高稀有；前期弱、有存血风险 |
| **状态/前置** | 低血、怒气、叠 N 层才开环 | 前置宜难逆转；失败有明确惩罚或资源浪费 |

## 快速参考：风险与约束

| 约束 | 核心思路 | 注意 |
|------|----------|------|
| **脆弱性/单一性** | 乘数链易被点杀/控打断 | 定破绽（核心 Buff/核心单位）；攻速→缴械减速，技能→沉默/魔抗 |
| **资源独占** | 乘数吃稀缺通用资源 | 逼抢万用装/稀有卡/槽位；启用某构筑可削弱其他万用装收益 |
| **反差型弱点** | 最强时暴露对立短板 | 极致输出难带有效防御；后排爆发需扎堆→怕 AOE |

## 本项目对照示例（A × B）

| A（基础值） | B（乘数） | 载体 |
|-------------|-----------|------|
| 法伤技能基础量 | 「易伤/降抗」类技能或增益 | 技能 + 增益卡 |
| 前排承伤单位 | 受伤触发回血/加攻的联动链 | 技能 + 站位（前排） |
| 单次普攻/技能命中 | 邻格/同列触发额外效果 | 站位吸附 + 技能目标规则 |
| 击杀事件 | 重置或扩散（有次数顶） | 技能触发 + 硬顶 |

## Common Mistakes

| 错误 | 改正 |
|------|------|
| 写成含糊「法师羁绊 -20% 魔抗」却不走统一管线 | 主题成形效果须可表达为 EffectSpec；点数归 balance-designer |
| 只有 B、没有门槛与破绽 | 补空间/时序/状态门槛 + 至少一类约束 |
| 数值直接定稿塞进功能文 | 功能归 game-designer；点数归 balance-designer |
| 用另套脚本实现「团队羁绊 Buff」 | 必须走 EffectSpec / EffectResolver |
| 主题层与单位技能同轴叠乘 | 主题层做弱身份开关；与听亡/挨打等内建轴分轴 |
| 无限击杀重置无上限 | 明确每次行动连锁次数顶 |
