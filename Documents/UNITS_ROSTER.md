# 角色汇总（UNITS_ROSTER）

> 由 `tools/generate_units_roster.py` 生成；流派按技能主触发/机制自动推断，可在脚本 `ARCHETYPE_OVERRIDES` 手工覆盖。
> **功能规格**（友方角色 / 敌方角色 / 生成的代理角色；生命、攻击、移动）见 [Features/UNITS.md](./Features/UNITS.md)；本文是角色内容一览。

## 说明

- **Tier / cost**：商店角色 `cost` 通常等于 `tier`；高 Tier 需多次进入商店解锁。
- **商店池**：`resources/shop/dev_shop_pool.tres` 的 `character_pool`；token 与占位敌人不入池。
- **流派标签**：召唤 / 受伤 / 地图 / 商店 / 开战 / 死亡 / 友亡 / 击倒；设计向分类，未写入 `.tres`。

## 流派索引

### 召唤（11）
- 友方召唤、被召唤、死亡/友亡生成 token
- 蟋蟀（T1）、马（T1）、驯兽师（T2）、蜘蛛（T2）、母羊（T3）、鹿（T3）、绵羊（T3）、蝎子（T4）、公鸡（T5）、火鸡（T5）、苍蝇（T6）

### 受伤（9）
- 受伤时触发（含反伤、自 buff、友伤计数）
- 枪手（T2）、孔雀（T2）、刺豚（T2）、熊（T3）、河豚（T3）、骆驼（T3）、象（T3）、狼獾（T4）、大猩猩（T6）

### 地图（3）
- 格子燃烧等地形效果
- 余烬鼠（T3）、灰烬萨满（T4）、火塘守卫（T5）

### 商店（6）
- 购买 / 出售 / 升级等商店阶段联动
- 河狸（T1）、鸭子（T1）、鱼（T1）、水獭（T1）、猪（T1）、鸽子（T1）

### 开战（8）
- 战斗开始时的伤害或 buff
- 蚊子（T1）、螃蟹（T2）、史莱姆（T2）、狼（T3）、犰狳（T4）、豹（T4）、野猪（T5）、鳄鱼（T5）

### 死亡（5）
- 自身死亡时 buff 队友或全场伤害（非召唤）
- 蚂蚁（T1）、火烈鸟（T2）、刺猬（T2）、獾（T3）、猛犸（T6）

### 友亡（1）
- 友方死亡时自身成长（非召唤）
- 鲨鱼（T5）

### 击倒（2）
- 击杀敌人时触发
- 河马（T4）、犀牛（T5）

### 其他（4）
- 未归类或复合机制
- 刺客（T2）、炸弹人（T2）、战车（T2）、皇后（T5）
