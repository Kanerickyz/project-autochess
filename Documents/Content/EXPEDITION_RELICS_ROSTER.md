# 远征圣物库（EXPEDITION_RELICS_ROSTER）

> Content · **【草案】非定稿** · 2026-11-04  
> 功能共识见 [DesignNotes/EXPEDITION_RELICS_CONSENSUS.md](../DesignNotes/EXPEDITION_RELICS_CONSENSUS.md)（正式 Feature 待授权）。  
> **本篇写**：圣物内容池——分 Tier、名称、效果草案、乘轴与风险。  
> **本篇不写**：定点数 / 百分比；事件文案库；池权重表；完整 Feature 规则正文。  
> 构筑审查参照项目内「构筑乘法」习惯：圣物优先作 **B（乘数）**；主题层仅弱放大且**不改主题人数**。

## 1. 分档原则

| Tier | 身份 |
|------|------|
| **1** | 早期可安心带的弱 B / 薄规则；门槛低、破绽小；单独不够赢 |
| **2** | 中段成型件；要空间 / 时序 / 状态之一或带可读代价；能改某一构筑味道 |
| **3** | 稀有强规则；高机会成本或反差弱点；忌无限循环与「视同多凑主题人数」 |

事件三选一池如何按层偏抽高档 → 留给数值，本表不定。
