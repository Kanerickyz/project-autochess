# 角色技能库（UNIT_ABILITIES_ROSTER）

> Content · 实时主路径 · 2026-10-13  
> 功能规则见 [Features/UNIT_ABILITIES.md](../Features/UNIT_ABILITIES.md)；友方兵种见 [UNITS_ROSTER.md](./UNITS_ROSTER.md)。  
> **本篇写**：独立技能内容池——名称、触发、效果草案、相对强度标注。  
> **本篇不写**：定点数 / 百分比；挂载到哪只兵种（另表未定时可空）；玩家可见流派标签。  
> **【As-Is】** 下列技能**尚未**写入 `resources/abilities/`、也**未**挂到 realtime 单位；主路径仍表现为无主技能。

## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 技能与角色 | **技能库独立**；设计条目时不绑兵种。挂载（自带技能单位 / 附魔池 / 白板）另步 |
| 强度 | 按 Feature 频率档 + 幅度（小/中/大）+ 持续 + 目标广度等简评；综合档为 **偏弱 / 中庸 / 偏强**（相对，非数值定稿） |
| 持续默认 | 本场临时（技能层不承担「整局越爬越强」；局间单位成长另议） |
| 小队范围 | 触发听其他友方；文案用「友方…时」；不对外挂「小队」标签 |
| 流派 | 不对外；下表「内部备注」仅给策划，不上玩家 UI |
| 内部设计语「成长」 | 听友方事件 → 给**自己**叠本场属性（如阵亡喂自身、上场喂自身）。**废弃**并列内部名「同仇」；坚韧/冲锋仍为愿景内部样板 |
| 生成代理 | 占人口、本场临时、默认无主技能；复制体按**基础身体弱一档**，忽略本场临时层 |

## 2. 强度标注读法

| 列 | 含义 |
|----|------|
| 频率 | 一场一次 / 偶尔多次 / 高频 / 条件稀有 |
| 小队 | 是否小队范围触发（听其他友方） |
| 综合 | 相对预算档；留给数值填空后仍可回调 |

## 4. 生成代理（本库约定摘要）

与 Feature §6 对齐，本库生成类技能一律遵守：

1. 代理本场临时，结算清场；不进牌库、不可再打出。  
2. **占用人口**。  
3. **无主技能**；不继承「再生成代理」类效果。  
4. **残影 / 分身**：属性取持有者配置底（基础身体）的弱一档比例，**不含**本场临时层。  
5. **义士应召**：固定弱模板，不是死者复制。

具体比例与只数留给数值。

## 5. 未收录（本版不做进库）

| 想法 | 原因 |
|------|------|

| 移动时 / 回合存活触发 | 实时主路径不用 |
