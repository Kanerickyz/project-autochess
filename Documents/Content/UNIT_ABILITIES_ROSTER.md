# 角色技能库（UNIT_ABILITIES_ROSTER）

> Content · 2026-10-15  
> 功能规则见 [Features/UNIT_ABILITIES.md](../Features/UNIT_ABILITIES.md)；友方角色见 [UNITS_ROSTER.md](./UNITS_ROSTER.md)。  
> **本篇写**：技能内容池——名称、触发、效果草案、相对强度。  
> **本篇不写**：定点数 / 百分比；玩家可见流派标签。挂载（**1 技能 ↔ 1 角色**）见 [UNITS_ROSTER.md](./UNITS_ROSTER.md) §6。  
> **【资源】** 本篇技能条目均有 ability 资源；**三十七人** 1:1 挂载已绑（见角色库 §6）。援军呼应为 `ally_deploy_self_atk_small`（OnFriendSummoned）。


## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 技能与角色 | 内容池按条目设计；**交付挂载 1:1** 见角色库 §6 |

| 强度 | 频率档 + 幅度（小/中/大）+ 持续 + 目标广度；综合 **偏弱 / 中庸 / 偏强**（相对） |
| 持续默认 | 本场临时 |
| 小队范围 | 触发听其他友方；文案用「友方…时」；不对外挂「小队」标签 |
| 流派 | 不对外；内部备注仅策划用 |
| 生成随从 | 本场临时、不占准备座位、默认无主技能；每次触发按技能生成（无每角色本场累计上限）；复制体按基础身体弱一档，忽略本场临时层 |
| 本批不含 | 商店买/卖/升级；移动时；开战全队大加成；战斗内喂食；完整技能复制/吞咽 |

## 2. 强度标注读法

| 列 | 含义 |
|----|------|
| 频率 | 一场一次 / 偶尔多次 / 高频 / 条件稀有 |
| 小队 | 是否听其他友方事件 |
| 综合 | 相对预算档 |
| 挂载 | 唯一主挂角色（显示名） |

## 4. 生成随从（本库约定摘要）

1. 随从本场临时，结算清场；不进牌库、不可再打出。  
2. **不占**准备角色座位。  
3. **无主技能**；不继承「再生成随从」类效果。  
4. **残影 / 分身**：取持有者基础身体弱一档，**不含**本场临时层。  
5. **义士应召**：固定弱模板，不是死者复制；**仅**友方角色死亡触发，随从/代理死亡不触发（防连环生成）。  
6. **不设**每角色本场随从累计上限；每次触发按该技能 `spawn_count` 生成。

具体比例与只数留给数值。
