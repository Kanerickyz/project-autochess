## 1. 召唤统领（工作名）

| 项 | 内容 |
|----|------|
| 机制名 | 召唤统领 |
| 显示名 | 召唤统领（资源 `giant_knight`；原铁甲统领占位已改名） |
| 节点 | 本幕 Boss 遭遇 |
| 攻击方式 | 近战溅射 |
| 足迹 | 逻辑 2×2 |
| 一动 | 召唤 / 移动 / 出手三选一（见 Features） |
| 开场跟班 | **无** |
| 衍生小兵 | 复用 **枯骨**（`skeleton`）基础身体 → 敌方代理；无主技能 |
| 实现资源 | `resources/units/realtime/giant_knight.tres`（`is_boss_leader`、2×2、`summon_unit`=枯骨） |
| 开场 | `rt_wave_boss` 仅首领；Boss 节点预算不填杂；**前排水平居中**落座 |
| 数值 | 生命 **75** / 攻击 **15**；小兵上限 3 / 每动召 1 / Boss `steps_per_turn=1`；攻距与溅射 1.5 |
| 召唤体 | 枯骨壳；战中强制可移动（`steps_per_turn≥2`、攻距≥1、无部署等待） |

### 数值填空（交 balance；本表只列旋钮）

| 旋钮 | 说明 |
|------|------|
| 生命 / 攻击 | 超高单体威胁档 |
| `steps_per_turn` | 可动但极慢（仅移动策略用） |
| 攻距 / 溅射半径 | 功能上可略宽于普通近战一档 |
| 场上衍生小兵硬上限 | 必填；防拖时与堵路 |
| 单次召唤只数 | 低额度（1 只枯骨壳，或一小撮更弱） |
| 枯骨壳相对商店枯骨 | 可同底或再弱一档 |
