## 1. 召唤统领（工作名）

| 项 | 内容 |
|----|------|
| 机制名 | 召唤统领 |
| 显示名 | 召唤统领（资源 `giant_knight`；原铁甲统领占位已改名） |
| 节点 | 本幕 Boss 遭遇 |
| 攻击方式 | 近战 AOE 溅射 |
| 足迹 | 逻辑 2×2 |
| 一动 | 召唤 / 移动 / 出手三选一（见 Features） |
| 开场跟班 | **无** |
| 衍生小兵 | `summon_pool`：**T4 精锐枯卫** / **T5 霸卫**（随机）；保留主技能；禁止再召唤 |
| 实现资源 | `giant_knight.tres` + `boss_minion_t4.tres` / `boss_minion_t5.tres` |
| 开场 | `rt_wave_boss` 仅首领；Boss 节点预算不填杂；**敌方半场后方水平居中**落座 |
| 数值 | 生命 **100** / 攻击 **50**；小兵上限 3 / 每动召 1 / 召后冷却 **3** 次首领行动 / Boss `steps_per_turn=1`；攻距 1.5 / 溅射按资源 |
| 召唤体 | T4 精锐枯卫 **攻10/血10**、T5 霸卫 **攻12/血12**（均不低于 10）；战中强制可立即接敌 |
| 召唤上限 | 场上存活 ≤ **3**；整场战斗累计召唤 ≤ **3**（`summon_max_alive` / `summon_max_total`） |

### 数值填空（交 balance；本表只列旋钮）

| 旋钮 | 说明 |
|------|------|
| 生命 / 攻击 | 超高单体威胁档 |
| `steps_per_turn` | 可动但极慢（仅移动策略用） |
| 攻距 / 溅射半径 | 功能上可略宽于普通近战一档 |
| 场上衍生小兵硬上限 | 必填；防拖时与堵路 |
| 单次召唤只数 | 低额度（1 只枯骨壳，或一小撮更弱） |
| T4/T5 随从相对友方同档 | 高于普通杂兵；可带主技能 |
