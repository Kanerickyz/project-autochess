---

## 1. 口径

| 项 | 规则 |
|----|------|
| 计数 | 仅**已入座**；按角色种类（`unit.id`）去重；同 id 多份只计 1 |
| 兑现 | 持有该徽章 **且** `count(绑定职业) ≥ N` |
| 持续 | 默认**本场遭遇**（开战挂上 / 状态本场有效）；非招募小药水式永久攻血 |
| 叠算 | 同职低档与 ×5 可并存；效果叠加 |
| 同盟 | 「各点数 +1」对已满足条件的职绑徽章生效（含 ×5） |
| 广度变体 | **本版花名册不做**（五军合契等另案） |
