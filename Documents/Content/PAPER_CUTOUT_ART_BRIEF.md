> **状态：Run 战场已接入。** 场景背景与 8 个角色造型（蓝 / 红各一）由效果图编辑、二次创作而来，见 §6–§7。

## 1. 风格一句话

**Aged paper cutout doodle / 旧纸剪贴涂鸦风**：像泛黄卡纸上手绘小纸片拼成的微缩战场——扁平剪纸、大色块、清晰剪影、轻微歪斜手工感；质朴俏皮略粗糙，手游清晰度优先。

## 4. 贴纸技术要点（单位与场景纸片通用）

### 4.1 三层结构（由外到内）

1. **接触阴影**（可选独立层或烘焙进底）：短、柔、偏下或偏一侧；强化「贴在纸上」；勿长投影、勿硬边。
2. **米白剪纸边**：轮廓外一圈略不规则的米白/淡黄边；宽度相对角色身高约 **4–8%**；允许轻微缺口/磨损，禁止完美矢量描边。
3. **深炭墨线 + 内部平涂**：墨线贴在色块外缘内侧；粗细自然变化；内部蜡笔/马克笔平涂，少量铅笔排线与随性涂鸦。

### 4.2 材质与纹理预算

| 允许 | 禁止 |
| --- | --- |
| 纸张纤维、局部褪色、轻微污渍 | 写实皮肤/金属、塑料感、厚重 3D |
| 蜡笔/马克笔大色块 | 复杂渐变、PBR、体积光 |
| 少量铅笔排线、随性涂鸦 | 过密排线、满屏噪点 |
| 轻微歪斜、手工裁切感 | 重复平铺纸纹、夸张折痕 |
| 扁平剪纸层叠 | 过度规整矢量、对称到「印刷品」 |

### 4.3 角色造形约定

- **大头小身体**（约头:身 = 1 : 1～1.2）；全身剪影在棋盘尺度仍可辨。
- **突出**头盔 / 披风 / 盾 / 武器；细节集中于此，躯干保持大色块。
- **阵营色明确**：钴蓝 = 我方布料；砖红 = 敌方布料；盔甲统一米白暖灰，不靠盔甲分阵营。
- 站姿略歪、武器角度可随意，但轮廓必须一眼分出 archetype。

## 5. 场景分层（Run 战场环境）

竖屏、我下敌上；视觉为「中央开阔纸面 + 左右纸片边界」。逻辑格网仍由程序绘制/驱动；本简报只定**环境贴纸层**。

| 层（由后到前） | 内容 | 备注 |
| --- | --- | --- |
| L0 纸基 | 泛黄卡纸底 + 极轻纤维/污渍 | 整板一块或九宫可平铺但**禁止**明显重复纹 |
| L1 地面点缀 | 稀疏草叶涂鸦、小石点、浅苔色排线 | 中央通道更干净；勿铺满 |
| L2 边界远景 | 左右较淡的树簇/岩块纸片 | 可略小、略褪色 |
| L3 边界近景 | 左右更饱和的树/岩层叠 | 形成「舞台边框」，中央留空给单位 |
| L4 单位贴纸 | archetype 贴纸 + 接触阴影 | 见 §6 |
| L5 UI/反馈 | 血条、攻血标、高亮等 | **不在本简报范围**；保持现有可读，勿被纸纹淹没 |

**构图原则**：细节集中于**角色**与**左右场景边界**；中央战场保持开阔低干扰，保证单位剪影与阵营色可读。

## 6. 角色造型与兵种映射

8 个造型，每个蓝（我）/ 红（敌）各一张。造型只管外观，不绑定技能。敌方资源 id 去掉 `enemy_` 前缀后共用同一张表；未登记的 id 落到 `spear`，场上不出现无图单位。

| 造型 | 剪影要点 | 兵种（资源 id） |
| --- | --- | --- |
| `shield` 盾卫 | 尖盔 + 十字竖盾 + 短剑 | knight、spike_shield、rune_plate、relic_aegis、mirror_warden |
| `archer` 弓手 | 兜帽 + 反曲弓 + 箭囊 | archer、crossbow、horsebow |
| `axe` 重斧 | 厚甲 + 双刃大斧 | barbarian、maul、giant_knight、valkyrie |
| `captain` 披风剑 | 大披风 + 举大剑 | mini_pekka、hunter、rider |
| `spear` 投枪 | 敞盔 + 举标枪 + 小盾 | spear_goblin、echo_spear（默认造型） |
| `musket` 火铳 | 羽毛宽檐帽 + 长火铳 | musketeer |
| `banner` 旗鼓 | 高旗 + 腰鼓 | banner、dirge_horn、wardrum |
| `skeleton` 亡灵 | 骷髅 + 破兜帽 + 锈剑 | skeleton、goblin、gravewright、soulcaller |

召唤代理也须显式映射：bus、ram、token_thick_copy → `shield`；token_ember → `spear`；chick、slime_split、token_weak、token_weak_copy、zombie_fly → `skeleton`。

改映射只改 `resources/ui/paper_unit_art.tres`；`unit_art_catalog_test_runner.gd` 校验 realtime / enemies / tokens 下每个单位都有显式映射。

## 7. 资产与制作流程

```text
art_source/paper_cutout/          # 源图，.gdignore
  concept_reference.jpg           # 效果图
  arena_background.jpg            # 去掉士兵、收窄树林的空场景
  units_sheet_a.jpg               # 盾卫 / 弓手 / 重斧 / 披风剑（蓝）
  units_sheet_b.jpg               # 投枪 / 火铳 / 旗鼓 / 亡灵（蓝）
assets/sprites/paper_cutout/
  env/arena_background.jpg
  units/unit_<造型>_{blue,red}.png
```

- 源图由图像生成以效果图为参考编辑而来；角色画在纯品红底上。
- `tools/process_paper_cutout_art.py` 抠掉品红底、每格只留最大连通块、裁边，红版只把钴蓝布料换成砖红，蓝红剪影一致。
- 米白纸边与墨线都画在贴图里；运行时只加脚下短接触阴影。
- 背景按铺满缩放；左右树林约占原图宽度 15%，棋盘压进树林内缘 40%，其余作为两侧留白。

## 8. 可读距离规则

| 距离 / 情境 | 必须可读 | 可牺牲 |
| --- | --- | --- |
| 竖屏全板（单位占格约拇指盖大小） | 阵营色（蓝/红布料）、大件（盾/斧/披风/弓） | 面容、纹章细节、排线 |
| 半板 / 聚焦观战 | 造型辨认（八类互不混淆） | 纸纤维、污渍 |
| 色盲 / 降饱和 | 剪影形状区分造型；阵营除颜色外可靠朝向分区（我下敌上） | 单靠色相的装饰 |
| 重叠 / 混战 | 米白边帮助分离单体；阴影勿糊成一团 | 多层树丛细节 |

**剪影验收口诀**：缩小到约 **48–64 px 高** 仍能分出盾、弓、大斧、披风、标枪、火铳、旗鼓、骷髅，且能分蓝红。

## 10. 禁止项（汇总）

- 写实、塑料、厚重 3D、复杂渐变  
- 过密排线、满屏噪点、重复纸纹、夸张折痕  
- 过度规整矢量、完美对称描边冒充手作  
- 用盔甲色代替阵营色；蓝红布料不清晰  
- 中央战场堆满装饰导致单位难认  
- 本切片扩做 UI 全套、音效、玩法脚本
