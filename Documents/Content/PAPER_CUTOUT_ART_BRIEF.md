# 旧纸剪贴涂鸦风 — 美术规范

> Content · 纸片单位与战场美术  
> 主题约束见 [GAME_VISION.md](../GAME_VISION.md)；兵种名单见 [UNITS_ROSTER.md](./UNITS_ROSTER.md)。

**本文件制定后续制作与验收标准，并未修改原素材。** 下述线宽、占比与色值为建议锁定的生产参数，不是对旧图逐像素测量的结论。现有图集可继承画布、锚点和文件顺序；角色比例与纸边需逐项复核。

风格一句话：**Aged paper cutout doodle / 旧纸剪贴涂鸦风**——泛黄卡纸上手绘小纸片拼成的微缩战场；扁平剪纸、大色块、清晰剪影、轻微歪斜手工感；手游清晰度优先。

---

## 1. 计量口径

- 所有像素数以 **256×256** 最终单帧为基准；原生 **512** 工作稿全部乘 2。旧 512 图集为重采样放大，不能视为原生高精度稿。
- **身高 H**：脚底接触线至裸头/头盔顶部；排除羽毛、角、旗、武器、纸边与特效。兜帽计入头部。
- **总轮廓**：角色、装备及纸边的联合外接矩形；粒子和投影另算。
- 标注宽高的占比均相对 256 画布，头部占比单独相对 H。
- 自动外接矩形检测可用 **Alpha≥128** 排除抗锯齿杂点；同时必须检查所有 **Alpha>0** 像素未被裁切。

## 2. 画布、尺寸与锚点

| 项目 | 规格 |
|------|------|
| 最终帧 | 256×256，RGBA PNG，sRGB，真实透明 |
| 推荐工作稿 | 原生 512×512 分层稿，最终缩小一次输出 |
| 脚底锚点 | 左上原点 `(128,224)`，归一化 `(0.5,0.875)` |
| 静态脚底容差 | 接触点距 y=224 不超过 2px；脚底平面不可被纸边代替 |
| 静态安全范围 | 所有可见内容位于 x∈[16,240)、y∈[16,240) |
| 普通步兵 H | 144–160px，约画布高 56%–63% |
| 普通步兵总轮廓高 | 通常 168–192px，约 66%–75% |
| 普通步兵总轮廓宽 | 通常 144–192px，约 56%–75% |
| 枯骨 H | 112–124px；保留小型炮灰感 |
| 余烬 H | 120–136px；靠黑斗篷与橙色核心辨认 |
| 重装步兵 H | 148–164px；靠肩宽、盾牌和躯干体积显重 |
| 骑乘单位总轮廓 | 高 176–200px、宽 192–216px，骑手头部与步兵头部大小相近 |
| 长武器/高旗总轮廓 | 宽、高均不得超过 224px；优先改变持握姿态 |

不得为了容纳高旗或武器而缩小整个人。优先收拢装备角度、折弯旗面或调整姿势；仍放不下时使用独立装备层或更大动画帧，并明确登记例外。

所有新动画可统一升级到 **384×384**，锚点设为 `(192,288)`，把原 256 帧放在 `(64,64)` 位置，角色像素尺寸保持不变。不得混用帧尺寸而遗漏元数据。

## 3. 比例与剪影

| 项目 | 标准 |
|------|------|
| 步兵头身比 | 约 2.4–2.8 头身；头部高度占 H 的 36%–42% |
| 造型分区 | 头、躯干、脚腿三个大体块；手脚适度放大 |
| 兵种主识别 | 每个角色一个第一识别物、最多两个辅助特征 |
| 独立部件间隙 | 需要保持分离的轮廓间隙至少 4px，缩至 50% 后仍可辨认 |
| 同阵营变化 | 保持基础材质和配色；用头饰、姿态、武器区分 |
| 朝向 | 沿用当前正面偏右四分之三视角；以现有游侠、盾卫、骑手作视角参照 |

透视需统一头盔顶面可见程度与脚掌方向。具体摄像机角度以项目内参照截图为准，不从生成图反推精确度数。后续多方向素材需使用同一相机参照。

## 4. 描边、纸边与占比

| 层级 | 256 基准 | 占画布边长 | 用途 |
|------|--------:|----------:|------|
| 主体外轮廓深褐线 | 3–4px，局部 2–5px | 约 1.2%–1.6% | 最稳定、最清楚的轮廓 |
| 大部件分界线 | 2–3px | 约 0.8%–1.2% | 盾与身体、头盔与脸等 |
| 内部纹理线 | 1–1.5px | 约 0.4%–0.6% | 少量皱褶、板甲刻痕；允许缩小时消失 |
| 米黄纸边 | 常态 3–5px，局部最多 6px | 约 1.2%–2.0% | 深褐轮廓外侧的旧卡纸截面 |
| 纸边加外线 | 常态总宽 6–9px | 约 2.3%–3.5% | 作为整体视觉负担检查 |

线宽沿长弧缓慢变化，每约 12–24px 可出现一次可见粗细变化；避免逐像素抖动。轮廓可以有铅笔或干刷缺口，但武器尖端、脸、手脚接合处需保持辨识。纸边不是固定距离的光滑描边，不得出现统一纯白光环；毛边起伏以 1–2px 为主，不加周期锯齿。

纸边是视觉厚度，不用纸边像素面积占比作为硬验收值；复杂轮廓会天然增加面积。单位内部关键缝隙可以不包完整米黄边，避免弓弦、链条附近被厚纸边糊住。

## 5. 画法、纹理与配色

固定风格词：水粉手绘、旧卡纸剪贴、深褐不规则笔触、克制干刷、颜料厚薄变化、轻微纸纤维、简洁大色块、夸张头身、清晰装备剪影。

| 项目 | 标准 |
|------|------|
| 上色层级 | 每种材质以基础色、暗部、少量亮部为主；避免碎片化渐变 |
| 纹理范围 | 干刷与磨损集中在约 10%–20% 的可见色块区域，作为目测指导 |
| 纹理尺度 | 主要干刷斑块 3–8px；不依赖全图高频噪点制造手绘感 |
| 金属 | 灰褐平涂＋少量短亮痕；不做镜面反射 |
| 皮革/布料 | 哑光大色块，皱褶服务体积，不均匀堆满全身 |
| 骨骼/旧纸 | 骨色偏浅、纸边偏黄褐，深线隔开，避免融成一个轮廓 |
| 阵营色 | 可见主体面积约 20%–30%，优先放披风、头巾、盾面等大块位置 |
| 光源 | 统一画面左上柔光，阴影向右下；不改变不同角色的光向 |

建议生产色板：轮廓 `#4A3228`，最深暗部 `#30251F`，纸边 `#D6BD88`，纸边亮部 `#E7D4A8`，骨色 `#E8D6AD`，铁色 `#79766D`，皮革 `#855735`，友方蓝 `#315F9B`，敌方砖红 `#A14C40`。允许笔触产生色差，但材质中间色保持一致。

禁止：矢量式光滑黑线、纯白贴纸框、照片拼贴纹理、全身均匀颗粒、金属高光过亮、满身纹章和小铆钉、依靠微小符号辨认兵种。阵营还需用旗形、底座标记或 UI 辅助，不能只依靠红蓝差别。

## 6. 特殊角色与状态

| 类型/角色 | 美术规则 |
|-----------|----------|
| 盾卫 / 刺盾 / 禁卫 | 塔盾高直矩形 / 明显尖刺圆盾 / 王权盾徽和金色头盔；灰度剪影下也应不同 |
| 游侠 / 弩手 / 火铳 | 弓的弧线 / 弩的横向结构 / 枪的长直管；持握点清楚 |
| 骑手 / 骑弓 | 猛兽的低身冲锋剪影 / 马与侧射弓剪影；分别设置身体、坐骑、骑手、武器层 |
| 旗手 / 大剑 / 标枪 / 巨锤 | 武器高度不可驱动身体缩放；必要时装备独立层 |
| 链枷 | 链条视觉宽至少 2–3px，链间镂空可简化；静态轮廓收拢，挥击使用扩展动画帧 |
| 石甲 | 大块符文板甲；硬化状态另做叠加层，保持身体尺寸 |
| 余烬 / 召魂 / 残影 | 火焰、魂火、残影拖尾拆为独立特效；静态造型仍有明确实体剪影 |
| 血僧 / 命卫 / 铁心 / 愈修 | 念珠与拳形 / 宝石护甲 / 心形胸甲 / 修士帽与杖；回血特效不要画进常驻底图 |
| 号手 / 鼓手 | 号角外扩方向与鼓的圆形正面形成不同轮廓 |
| 掘墓 / 猎手 / 蛮斧 | 铲 / 弯刃＋皮毛帽 / 角盔＋巨斧，避免都变成普通战士 |
| 圣骸 / 禁卫 | 空甲与遗赠感 / 王权与厚重感，避免共用相同盾与头盔剪影 |
| 药师 / 奥术 | 药匣与绿药瓶 / 尖顶法帽＋法书＋镶宝珠金杖；勿与火铳、游侠远程剪影混淆 |
| 召唤物 | 独立 ID、尺寸档、静态图与动画；弱复制可以减装备，但不得只靠低透明度表示 |

描边与纸边宽度按共同素材尺度保持一致，不随坦克增粗或小型单位任意减半。若小单位纸边过重，可使用范围内较小值。战斗中的生命/攻击成长默认不放大整个人，以免单位遮挡规则失控。

## 7. 分层、动画、特效

- 保留干净完整的整身静态 PNG；另存头、躯干、前后手、前后腿、武器、盾/旗、披风、特效分层源稿，骑乘追加坐骑身体和四肢。
- 活动关节下方预留 6–10px 遮盖余量；仅在可见剪贴边缘做纸边，关节接缝不要出现双重厚纸框。
- 同一角色所有动画固定身体尺度与根节点。行走和待机可上下起伏，但导出的根锚点保持 `(128,224)`；扑击位移由游戏统一处理。
- 动画起步清单：待机、移动、攻击、受击、死亡；数量按表现需要设计，不给未制作的动画占位图冒充完整资源。
- 弓箭、弩矢、枪口火焰、子弹表现、伤害数字、状态图标、阵营底环独立资源；角色底图不包含 UI。
- 地面阴影由引擎独立绘制，柔和短椭圆、低透明度，不能把投影烘焙在角色透明底图内。选中轮廓独立渲染，不改原纸边。
- 默认静态不加大范围辉光。状态效果不能持续盖住武器、脸或阵营大色块。

## 8. 图集、文件与引擎交付

| 项目 | 规范 |
|------|------|
| 当前静态图集 | 4 列×7 行，1024×1792，28 角色各 1 帧，顺序沿用原名册 |
| 裁切 | 256×256，外边距 0，格间距 0；本图集已有格内透明留白 |
| 后续动画 | 每角色独立图集或明确分页；不得把 28 角色帧当动画顺播 |
| 命名 | `unit_<stable_id>_<direction>_<action>_<frame>.png`；显示名与 `stable_id` 分开维护 |
| 必要元数据 | `schema_version`、`unit_id`、`display_name`、`direction`、`action`、`frame_index`、`frame_rect`、`canvas_size`、`pivot_px`、`fps`、`loop` |
| 选配元数据 | 身高档、武器挂点、特效挂点、来源、版本、例外说明 |
| 自动裁边 | 默认关闭；如必须裁边，保存原画布和裁切偏移，重建同一根锚点 |
| 打包采样 | 重打包时每张内容外扩色 2–4px 并保留透明间隔；不可改变逻辑 `frame_rect` 和锚点 |
| 采样/压缩基线 | 平滑采样、无损；在目标手机上检查缩放和图集串色，再选择压缩与 mipmap 方案 |

左上坐标统一记录 `pivot=(128,224)`。若导入系统使用左下归一化坐标，对应 `(0.5,0.125)`。保留已有 Godot 导入说明；引擎具体界面与 API 应在实际项目版本内确认。

视觉轮廓不决定碰撞体。占格、移动、攻击范围与碰撞体使用棋盘逻辑，枯骨与骑手如占同一格，不得按透明 PNG 边界改变占格。渲染排序以地面根节点为准，旗帜和武器的跨格遮挡需要在游戏内验证。

## 9. 手机尺寸与验收

先用**游侠、枯骨、盾卫、旗手、骑手** 5 个代表验证规范，再批量重做。需同时摆到当前棋盘上检查，不只看大图。

1. **256 原尺寸**：轮廓、纸边、材质和 Alpha 边缘干净，无意外透明孔洞、切断装备或散点。
2. **128 缩略图**：兵种、武器、头饰清楚；主轮廓约 1.5–2 屏幕像素，纸边约 1.5–2.5 屏幕像素。
3. **64 缩略图**：作为压力测试，仍能认出阵营和兵种大类，不要求保留甲片细节。若正式游戏长期更小，应另做小尺寸简化版本。
4. 使用浅草、暗土和灰色三种底色检查，避免纸边在浅地面消失或暗色身体融入背景。
5. 灰度及纯色剪影对比相似兵种；阵营色关闭后仍能识别塔盾/刺盾、弓/弩/火铳。
6. 同角色各动作叠加检查：身体体积稳定，脚底不漂移，持握点不穿帮，武器变化符合动作。
7. 脚底接触/单位定位标记留在所属格；头与装备可以投影到邻格，但不可遮死相邻单位的脚底定位信息。选中/目标反馈仍可见。
8. 检查切图矩形、帧数、名称、RGBA、根锚点与文件配套；在目标引擎实际导入并在手机尺寸截图验收。

## 10. 可复用生成提示词

按项目统一规范绘制一个中世纪战棋角色：`[显示名]`；核心识别物：`[一项]`；辅助特征：`[最多两项]`。水粉手绘＋旧卡纸剪贴，2.4–2.8 头身，简洁大体块，深褐不规则轮廓线，克制干刷与颜料厚薄变化，米黄轻微毛边。正面偏右四分之三视角，左上柔光。256×256 最终规格，普通步兵身体高 144–160px，脚底锚点 `(128,224)`，装备与纸边完整位于 16px 安全边以内。外轮廓 3–4px、部件线 2–3px、纸边 3–5px，蓝色阵营大色块 20%–30%。真实透明背景，无文字、无 UI、无底座、无烘焙阴影、无大范围辉光。输出单角色完整造型。
