## 4. 贴纸技术要点（单位与场景纸片通用）

### 4.1 三层结构（由外到内）

1. **接触阴影**（可选独立层或烘焙进底）：短、柔、偏下或偏一侧；强化「贴在纸上」；勿长投影、勿硬边。
2. **米白剪纸边**：轮廓外一圈略不规则的米白/淡黄边；宽度相对角色身高约 **4–8%**；允许轻微缺口/磨损，禁止完美矢量描边。
3. **深炭墨线 + 内部平涂**：墨线贴在色块外缘内侧；粗细自然变化；内部蜡笔/马克笔平涂，少量铅笔排线与随性涂鸦。

### 4.2 材质与纹理预算

| 允许 | 禁止 |
| --- | --- |
| 纸张纤维、局部褪色、轻微污渍 | 写实皮肤/金属、塑料感、厚重 3D |
| 蜡笔/马克笔大色块 | 复杂渐变、PBR、体积光 |
| 少量铅笔排线、随性涂鸦 | 过密排线、满屏噪点 |
| 轻微歪斜、手工裁切感 | 重复平铺纸纹、夸张折痕 |
| 扁平剪纸层叠 | 过度规整矢量、对称到「印刷品」 |

### 4.3 角色造形约定

- **大头小身体**（约头:身 = 1 : 1～1.2）；全身剪影在棋盘尺度仍可辨。
- **突出**头盔 / 披风 / 盾 / 武器；细节集中于此，躯干保持大色块。
- **阵营色明确**：钴蓝 = 我方布料；砖红 = 敌方布料；盔甲统一米白暖灰，不靠盔甲分阵营。
- 站姿略歪、武器角度可随意，但轮廓必须一眼分出 archetype。

## 5. 场景分层（Run 战场环境）

竖屏、我下敌上；视觉为「中央开阔纸面 + 左右纸片边界」。逻辑格网仍由程序绘制/驱动；本简报只定**环境贴纸层**。

| 层（由后到前） | 内容 | 备注 |
| --- | --- | --- |
| L0 纸基 | 泛黄卡纸底 + 极轻纤维/污渍 | 整板一块或九宫可平铺但**禁止**明显重复纹 |
| L1 地面点缀 | 稀疏草叶涂鸦、小石点、浅苔色排线 | 中央通道更干净；勿铺满 |
| L2 边界远景 | 左右较淡的树簇/岩块纸片 | 可略小、略褪色 |
| L3 边界近景 | 左右更饱和的树/岩层叠 | 形成「舞台边框」，中央留空给单位 |
| L4 单位贴纸 | archetype 贴纸 + 接触阴影 | 见 §6 |
| L5 UI/反馈 | 血条、攻血标、高亮等 | **不在本简报范围**；保持现有可读，勿被纸纹淹没 |

**构图原则**：细节集中于**角色**与**左右场景边界**；中央战场保持开阔低干扰，保证单位剪影与阵营色可读。

## 6. Archetype 清单（范围 C · 建议首批）

非整库。每类做 **蓝（我）/ 红（敌）** 各一，共 **8** 张单位贴纸。名称仅为视觉 archetype，不绑定技能 ID。

| ID 建议 | 中文 | 剪影要点 | 蓝版 | 红版 |
| --- | --- | --- | --- | --- |
| `knight_shield` | 骑士盾剑 | 尖盔 + 竖盾（可带简单十字）+ 短剑；盾面大块 | 钴蓝袍 | 砖红袍 |
| `archer` | 弓手 | 侧身弓形 + 箭囊暗示；头巾/兜帽可选 | 钴蓝衣 | 砖红衣/帽 |
| `heavy_axe` | 重斧 | 大双刃斧或宽斧头占剪影；体块略厚 | 钴蓝巾 | 砖红巾 |
| `captain_cape` | 队长披风剑 | **大披风**为第一识别；举剑或持剑；尖盔 | 钴蓝披风（最抢眼） | 砖红披风 |

**制作优先级**：`captain_cape`（阵营旗舰）→ `knight_shield` → `heavy_axe` → `archer`。  
**未列入本切片**：法师、枪兵、召唤物、坐骑、Boss 异形等（需另开合同）。这些 id 继续椭圆回退。

### 6.1 资源 id → archetype（已接线）

`PaperArchetype.from_unit_id` 按子串匹配，先匹配更具体的项。敌我各用对应颜色贴纸。

| 命中子串（小写 id） | archetype |
| --- | --- |
| archer / crossbow / horsebow / musket / hunter | `archer` |
| maul / barbarian / axe | `heavy_axe` |
| giant_knight / valkyrie / banner | `captain_cape` |
| knight / shield / aegis / pekka | `knight_shield` |
| 其余（含空 id） | 无贴纸，椭圆 + 短名 |

## 7. 资产文件命名建议

根目录建议（由 technical-artist 建目录与导入；**本 L0 不创建文件**）：

```text
assets/sprites/paper_cutout/
  env/
    arena_paper_base.png          # 纸基（或 .webp；导入侧决定）
    arena_border_trees_left.png
    arena_border_trees_right.png
    arena_border_rocks_*.png      # 可多片层叠
    arena_ground_doodles.png      # 稀疏草叶；透明底
  units/
    unit_knight_shield_blue.png
    unit_knight_shield_red.png
    unit_archer_blue.png
    unit_archer_red.png
    unit_heavy_axe_blue.png
    unit_heavy_axe_red.png
    unit_captain_cape_blue.png
    unit_captain_cape_red.png
```

约定：

- 前缀 `unit_` / `arena_`；阵营后缀 `_blue` / `_red`。
- 透明底 PNG；**白边与墨线画进贴图**（勿依赖运行时描边冒充剪纸边，除非 TA 合同明确用 shader 且能复现不规则磨损）。
- 单位画布建议正方形，角色脚底略偏画布垂直中心以下，便于锚点对准格心。
- Godot 导入：2D 像素/过滤策略由 TA 定；须保留透明；避免把米白边压成脏边。

## 8. 可读距离规则

| 距离 / 情境 | 必须可读 | 可牺牲 |
| --- | --- | --- |
| 竖屏全板（单位占格约拇指盖大小） | 阵营色（蓝/红布料）、大件（盾/斧/披风/弓） | 面容、纹章细节、排线 |
| 半板 / 聚焦观战 | archetype 辨认（四类互不混淆） | 纸纤维、污渍 |
| 色盲 / 降饱和 | 剪影形状仍分四类；阵营除颜色外可靠朝向分区（我下敌上） | 单靠色相的装饰 |
| 重叠 / 混战 | 米白边帮助分离单体；阴影勿糊成一团 | 多层树丛细节 |

**剪影验收口诀**：缩小到约 **48–64 px 高** 仍能分出「有盾 / 有弓 / 有大斧 / 有大披风」，且能分蓝红。

## 10. 禁止项（汇总）

- 写实、塑料、厚重 3D、复杂渐变  
- 过密排线、满屏噪点、重复纸纹、夸张折痕  
- 过度规整矢量、完美对称描边冒充手作  
- 用盔甲色代替阵营色；蓝红布料不清晰  
- 中央战场堆满装饰导致单位难认  
- 将本简报或参考图路径写成「已入库 / 已实装」
