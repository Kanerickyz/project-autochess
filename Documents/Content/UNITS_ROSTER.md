# 友方角色库（UNITS_ROSTER）

> Content · 2026-10-15  
> 功能规则见 [Features/UNITS.md](../Features/UNITS.md)、[Features/PLAYER.md](../Features/PLAYER.md)；本篇写**显示名、定位、数值草案与主技能挂载**。  
> **本版不写**：被动挂载；敌方 Boss 高威胁位见 [BOSS_ROSTER.md](./BOSS_ROSTER.md) / [Features/BOSS.md](../Features/BOSS.md)。技能效果正文见 [UNIT_ABILITIES_ROSTER.md](./UNIT_ABILITIES_ROSTER.md)，本篇只写挂载关系。  
> **【主题】** 中世纪魔幻（可含亡灵 / 王权 / 魔物佣兵 / 野兽坐骑）；剪影可读优先；显示名宜短（约 2～3 字）。  
> **【1:1 挂载】** 每条主技能恰好挂一名友方；技能池条目见技能库，挂载见 §6。
  
> **【资源】** 可招募友方 **32 人**（含狂战士）已写入 `resources/units/realtime/`（英文 id 见 §4）；§1 旧写「二十五人」为历史稿，以池子与 §6 为准。资源若仍有 `command_cost`，主路径应忽略。


## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 主题包装 | **中世纪魔幻**；允许亡灵、王权、魔物佣兵、野兽坐骑等包装（覆盖旧「友方无魔物、无神话」） |
| 人数 | **三十二名**可招募友方（含血僧/命卫/铁心/愈修等扩展与 **狂战士**）；Boss/随从 token 另计 |

| 快移速 | **快档 2.0 仅骑手**；**骑弓**用中档 1.3 |

本版准备入槽观战，无号令、无遭遇内抽牌。不借推塔。

### 3.3 花费与品阶

| 属性 | 含义 |
|------|------|
| **花费** | 商店买进队伍的金币（`cost`） |
| **品阶** | 商店解锁档 |

评定尺（Content 约定）：身体档 Bb（0 炮灰 / 1 杂兵 / 2 职能 / 3 重身）+ 技能档 Sb（0 空或偏弱 / 1 中庸带 / 2 偏强带）。民兵式 Bb0+Sb0 → 花 1 / 阶 1；否则阶 ≈ Bb，若 Sb≥2 且 Bb≤2 则阶 +1；花费默认阶 1→2、2→3、3→4。**余烬**按特判保持花 2 / 阶 1。
