# 友方角色库（UNITS_ROSTER）

> Content · 2026-10-15  
> 功能规则见 [Features/UNITS.md](../Features/UNITS.md)、[Features/PLAYER.md](../Features/PLAYER.md)；本篇写**显示名、定位、数值草案与主技能挂载**。  
> **本版不写**：被动挂载；敌方 Boss 高威胁位见 [BOSS_ROSTER.md](./BOSS_ROSTER.md) / [Features/BOSS.md](../Features/BOSS.md)。技能效果正文见 [UNIT_ABILITIES_ROSTER.md](./UNIT_ABILITIES_ROSTER.md)，本篇只写挂载关系。  
> **【主题】** 中世纪魔幻（可含亡灵 / 王权 / 魔物佣兵 / 野兽坐骑）；剪影可读优先；显示名宜短（约 2～3 字）。  
> **【1:1 挂载】** 每条主技能恰好挂一名友方；技能池条目见技能库，挂载见 §6。
  
> **【资源】** 可招募友方 **53 人**（含中毒三角 **毒羽** / **蚀刃** / **毒噬**；及散咒 / 葬焰 / 爆爆 / 甲胄师 / 金鼓 / 雷鼓 / 花鼓 / 木鼓 / **幽灵墓地**）已写入 `resources/units/realtime/`（英文 id 见 §4）；§1 旧写「二十五人」为历史稿，以池子与 §6 为准。资源若仍有 `command_cost`，主路径应忽略。


## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 主题包装 | **中世纪魔幻**；允许亡灵、王权、魔物佣兵、野兽坐骑等包装（覆盖旧「友方无魔物、无神话」） |
| 人数 | **五十三名**可招募友方（含中毒三角 **毒羽** / **蚀刃** / **毒噬**）；Boss/随从 token 另计 |
| 技能 | 各挂一条主技能（见 §6）；被动本版不挂 |

| 品阶尺 | **技能触发频率主轴**定默认品阶锚点，综合/广度/生成最多 ±1（频率权重更大；见 §3.3）；面板攻血按三档规则（§3 脚注），不跟品阶分摊；**余烬**保持 **花 2 / 品阶 1** |

本版准备入槽观战，无号令、无遭遇内抽牌。不借推塔。

## 3. 数值草案

长度单位：格；时间单位：秒。字段含义见 Features/UNITS。

评定尺（Content 约定 · **频率主轴**）：

1. **默认锚点**（技能触发可能频率，见 [UNIT_ABILITIES](../Features/UNIT_ABILITIES.md) §7.1 / 技能库频率列）：高频 → 品阶 **1**；偶尔多次 → **2**；一场一次 → **2**；条件稀有 → **2**。

4. **身体**：可玩角色用三档面板（§3 脚注），不跟品阶改攻血。  
5. **花费**默认：阶 1→花 **2**、阶 2→花 **3**、阶 3→花 **4**；**枯骨**花 1；**余烬**特判花 2 / 阶 1；**铁心**保持花 4 / 阶 2（开战囤血幅度特判，未随频率重分改阶）。
