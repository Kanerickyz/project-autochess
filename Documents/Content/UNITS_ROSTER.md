## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 主题包装 | 人类基础军制兵种（盾 / 矛 / 弓 / 斧 / 火枪等）；友方无魔物、无神话包装 |
| 人数 | **十名**友方：在原九职能上**新增**「骑士」（方案乙） |
| 骑士 | 对标皇室战争「野猪骑士」气质 → **高速突袭**近战；略厚于轻步兵；**无**冲建筑 / 推塔 |
| 火枪 | 远程高伤位保留火器风味（幻想特许） |
| 民兵 | 消耗炮灰；**花费 1 / 品阶 1**；**主技能空**（白板对照） |
| 技能 | 九人各挂一条主技能（见 §6）；民兵白板；被动本版不挂；**单位资源槽已绑** |

职能手感可参考外部游戏；本版准备入槽观战，不做圣水式号令与战中出牌。不借推塔。

### 3.1 骑士 vs 轻步兵

| 轴 | 轻步兵 | 骑士 |
|----|--------|------|
| 角色定位 | 高速杂兵 | 高速突袭（略厚冲锋） |
| 移速 | 2.0 | 2.2 |
| 生命 | 2 | 3 |
| 攻击 / 间隔 | 3 / 0.9 | 4 / 0.75 |
| 花费 / 品阶 | 2 / 1 | 3 / 2 |

骑士剪影可读为骑马突击；本版**无骑乘规则**，功能仍是地面高速近战单体。

### 3.2 花费与品阶

| 属性 | 含义 | 备注 |
|------|------|------|
| **花费** | 商店买进构筑库的**金币** | 资源字段 `cost` |
| **品阶** | 商店解锁档 | 高品阶需更多商店进度才会出现 |

- 民兵：**花费 1、品阶 1**。  
- 本版无号令费用；上场人数由准备阶段**本场上场人数上限**约束，落点在**角色座位**上（见 [玩家](../Features/PLAYER.md) / [战斗关卡](../Features/COMBATLEVEL.md)）。

## 6. 主技能挂载（测试用）

> 技能内容池独立设计；本表为挂载层。效果草案与相对强度见 [UNIT_ABILITIES_ROSTER.md](./UNIT_ABILITIES_ROSTER.md)。  
> 流派名仅内部备注，不对玩家 UI 露出。  
> **【单位资源已挂】** 本表技能 id 已写入对应 `resources/units/realtime/*.tres` 的 `ability`；民兵（`skeleton`）为空。

| 兵种名 | 主技能（显示名） | 技能 id（暂定） | 内部体验备注 | 挂载理由（摘要） |
|--------|------------------|-----------------|--------------|------------------|
| 盾兵 | 越挫越勇 | `hurt_gain_atk_small` | 坚韧 | 最高生命，反复挨打叠攻 |
| 骑士 | 锋矢突击 | `combat_start_charge` | 冲锋 | 高速突袭；预布阵吃开战窗（补人吃不到开战） |
| 双手剑士 | 猎杀时刻 | `kill_gain_atk_mid` | 收割 | 单发最高，击杀滚雪球明显 |
| 火枪手 | 穿甲点射 | `crit_extra_damage_mid` | 远程点射 | 远射高单发；**暴击率 25%**（资源 `crit_rate_percent`）使 OnCrit 可读 |
| 链枷兵 | 血怒一击 | `deal_damage_gain_atk_small` | 溅射清杂 | 溅射多次出手，放大清杂叠攻 |
| 斧兵 | 同仇敌忾 | `ally_death_self_atk_mid` | 小队·阵亡 | 均衡近战易活到见队友死 |
| 弓箭手 | 援军呼应 | `ally_deploy_self_atk_small` | 小队·上场 | 后排听友方入场小加攻 |
| 轻步兵 | 散兵余烬 | `death_spawn_pack` | 生成·多体 | 脆杂兵送死后一小群弱代理（不占准备槽；观察强度） |
| 投矛兵 | 绝地反扑 | `death_aoe_mid` | 换人退场 | 更脆，补上易死；死后对**随机敌人**中幅伤害（资源非范围圈） |
| 民兵 | （空） | — | 白板对照 | 纯身体炮灰；有技能炮灰改由轻步 / 投矛承担 |

### 6.1 本轮未挂（技能池仍有）

铁壁反震、以身作则、掩护射击、亡者之志、残影再起、临终分身、绝境增援、义士应召——留待后轮或附魔池，不进本表。

### 6.2 生成代理（挂载侧自检）

本表生成类主技能仅 **散兵余烬**（轻步兵）一条。代理不进牌区、不占准备角色座位；强度靠代理弱化与上场人数上限，不靠人口或号令。
