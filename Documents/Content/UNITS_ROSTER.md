## 1. 范围与共识

| 项 | 结论 |
|----|------|
| 主题包装 | 人类基础军制兵种（盾 / 矛 / 弓 / 斧 / 火枪等）；友方无魔物、无神话包装 |
| 人数 | **十名**友方：在原九职能上**新增**「骑士」（方案乙） |
| 骑士 | 对标皇室战争「野猪骑士」气质 → **高速突袭**近战；略厚于轻步兵；**无**冲建筑 / 推塔 |
| 火枪 | 远程高伤位保留火器风味（幻想特许） |
| 民兵 | 消耗炮灰；**花费 1 / 品阶 1** |
| 技能 | 本版全部无主技能、无被动 |

借自皇室战争的是**职能手感**与 cycle 节奏参考，不是卡面名或机制（圣水、推塔、一卡多体）。

### 3.1 骑士 vs 轻步兵

| 轴 | 轻步兵 | 骑士 |
|----|--------|------|
| 角色定位 | 高速杂兵 | 高速突袭（略厚冲锋） |
| 移速 | 2.0 | 2.2 |
| 生命 | 160 | 320 |
| 攻击 / 间隔 | 95 / 1.1 | 155 / 1.0 |
| 花费 / 品阶 | 2 / 1 | 3 / 2 |

骑士剪影可读为骑马突击；本版**无骑乘规则**，功能仍是地面高速近战单体。

### 3.2 花费与品阶

- **花费**：买进牌库消耗的金币。  
- **品阶**：商店解锁档；高品阶需更多商店进度才会出现。  
- 民兵为消耗兵种：**花费 1、品阶 1**。
