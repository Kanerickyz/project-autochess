# 沙盒、阵容分享与观战录音机

> 功能规格。玩法支柱仍以 [GAME_VISION.md](../GAME_VISION.md) 为准；正式爬塔循环见 [GAME_LOOP.md](./GAME_LOOP.md)；战斗推进见 [COMBAT.md](./COMBAT.md)。  
> **【用户定稿 2026-10-22】** 步进粒度＝行动队列**一动**；「往前」＝**真倒带**战场状态。

## 1. 玩家在做什么

1. 在**远征统计**或**准备阶段**把阵容/布局复制到剪贴板。  
2. 从**主菜单「沙盒」**进入试验场，粘贴后复刻上敌下我布局，点开战。  
3. 在正式战斗与沙盒观战中，用录音机控件：**暂停 / 下一动 / 上一动（倒带）**，并可继续使用既有倍速。

沙盒**不是**第二套远征：无地图、商店、招募、层金；本场胜负不进远征统计。

## 2. 两种剪贴板载荷

同一文本外壳，用是否含敌方块区分。UTF-8 纯文本，带头版本号，便于人读与粘贴。

| 载荷 | 入口按钮 | 必含 | 默认不含 |
|------|----------|------|----------|
| **整局阵容** | 远征统计「复制阵容」 | 友方：单位 id、星级、增益/熔印摘要、友方座位；席位上限 | 敌方、金币、地图、招募短名单 |
| **单场布局** | 准备阶段「复制本场布局」 | 上列友方 **＋** 敌方单位 id（及星/档若有）、敌方座位、遭遇类型（普通/精英/Boss）、Boss 足迹占格若有、**本场随机种子** | 战中才生成的代理角色 |

粘贴识别：

- 仅友方 → 沙盒进入「我方已摆好」；敌方用沙盒默认弱遭遇或再粘贴一场布局。  
- 敌我齐全 → 直接铺满半场。  
- 版本不匹配 / 格式无效 → 短提示，**不清空**场上已有合法布局。

## 3. 沙盒模式

| 项 | 约定 |
|----|------|
| 入口 | 主菜单「沙盒」（在角色库与附魔试验场之间）；与附魔试验场分开 |
| 布局 | 同战斗：上敌下我、双方角色座位 |
| 开战前 | 默认空队 + 弱敌预览；点「粘贴布局」出文本框（可预填系统剪贴板）；双方至少各 1 人方可开战 |
| 开战后天 | 纯观战（不能改阵），与正式战一致 |
| 结束 | 显示本场胜/败后留在沙盒（重开本场 / 再粘贴 / 返回主菜单）；**不**走结局宣告→远征统计 |
| 统计 | **不写入**远征战斗合计账本 |

## 4. 观战录音机【定稿】

正式战斗与沙盒**共用**同一套控件；底栏 Dock，竖屏三键。

| 控件 | 语义 |
|------|------|
| **暂停 / 继续** | 在**动与动之间**冻结或恢复自动推进；暂停优先于倍速 |
| **下一动** | 从暂停（或播放中点按＝先暂停）再完整结算并演出**恰好一动**（队列下一步），然后停住 |
| **上一动** | **真倒带**到上一动结束后的战场状态（含生命、站位、行动队列游标、本场临时层、已生成代理等可观察结果） |
| **倍速** | 保留既有 1×/2×/3×；与暂停并存（第二行或旁路单钮） |

边界：

- 「一动」＝ [COMBAT.md](./COMBAT.md) §7.1 行动队列上当前单位完成靠近+出手（含该动技能尾巴）；**不是**整轮所有人各动一次。  
- 下一动仍播完该动演出，**不**跳过动画瞬跳结果（与战斗观战反馈一致）。  
- 倒带到头：禁用「上一动」并短提示「已到开局」。  
- 进入结算叠层：录音机整组隐藏；焦点只给结算「继续」。  
- 实现可采用「每动后快照」或「同种子从锁阵重演到 N−1」；对外表现须为真倒带，不能只改回合数字。

## 5. 操作入口一览

| 界面 | 控件 |
|------|------|
| 主菜单 | 「沙盒」 |
| 远征统计 | 「复制阵容」（次要；「继续」仍为主 CTA） |
| 准备（正式遭遇） | 「复制本场布局」 |
| 准备（沙盒） | 「粘贴布局」+「复制本场布局」+「开始战斗」 |
| 观战（正式+沙盒） | 上一动 / 暂停·继续 / 下一动（+ 倍速） |

## 6. 玩家可观察验收（轻量）

1. 主菜单能进沙盒并返回。  
2. 统计「复制阵容」后，沙盒粘贴能摆出对应友方（座位大致一致）。  
3. 准备「复制本场布局」后，沙盒粘贴能摆出敌我双方并可开战。  
4. 观战：暂停后自动停；下一动只推进一动再停；上一动能回到上一动结束画面且血量/站位一致。  
5. 沙盒胜负不进远征统计页合计。
