# 游戏基础循环

> 功能规格 · 只谈流程与生命周期，不写具体数值 · 2026-10-12  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [商店](../SHOP_SYSTEM.md) · [增益](../BUFF_SYSTEM.md) · [角色单位](./UNITS.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：商店定价与品阶表、角色攻防数字、技能积木清单、战斗 tick / 伤害公式、换皮与改名。  
> **宏观参照**：杀戮尖塔式「局外 → 开一局 → 地图选路 → 节点 → 回地图 → Boss / 失败」；节点内战斗映射为本作自走棋，**不照搬**对方的卡牌战斗细则。

## 1. 这是什么

**游戏基础循环**规定：玩家从主菜单进入、打完一整局、再回到主菜单的完整生命周期——以及一整局里「地图选路 → 进节点 → 出节点」和战斗节点里「准备 → 自动战斗 → 结算」怎么嵌套。

| 杀戮尖塔宏观 | 本作对应 |
|--------------|----------|
| 主菜单 / 开一局 | 主菜单「开始」→ 新开一整局（第一版不设选初始角色） |
| 幕地图选路 | 幕地图上点选节点前进 |
| 房间战斗 | **自走棋一场**：准备布阵 → 自动战斗 → 结算 |
| 战后选牌 / 营地商店 | **主模式不在战斗胜利后强制进商店**；商店、宝箱、事件等在地图节点上 |
| 击败幕 Boss 通关；战斗失败整局结束 | 清光敌方胜 / 己方全灭败；失败则整局重置 |

**必须分清两种模式**：

| 模式 | 入口 | 在循环里的地位 |
|------|------|----------------|
| **爬塔（主模式）** | 主菜单 → 爬塔场景 | **主循环**：一节点一战；商店在地图商店节点 |
| **线性波次（开发 / 平衡用）** | 直开线性关或沙盒工具 | **工具环**：一关多波，波次之间可进商店；不得写成主循环 |

第一版乐趣仍是：商店构筑 → 手牌布阵 → 开战看联动。胜负以愿景**清波制**定稿为准。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **局外** | 主菜单、设置、沙盒入口；不在某一整局的地图进度里 |
| **一整局** | 从开新局到通关或失败重置的一次爬塔（对应实现里的「Run」） |
| **幕** | 一张爬塔地图 + 本幕 Boss；第一版只有一幕 |
| **节点** | 地图上的一格选择：战斗、商店、休息等 |
| **遭遇** | 进入战斗类节点后的一场自走棋战斗（主模式通常一节点一战） |
| **波次** | 线性开发关里的一波；也用于描述遭遇内部的刷怪节奏。主模式不要把「每波必商店」当成主循环 |
| **线性开发关** | 直开多波关卡的工具模式，用于开发与平衡，不是玩家主入口 |

## 4. 局外生命周期

对照杀戮尖塔「营地 / 主菜单 → 开一局 → 结束回退」：

| 阶段 | 玩家在做什么 | 第一版约定 | 现状 |
|------|--------------|------------|------|
| 主菜单 | 开始游戏、进沙盒、设置、退出 | 主入口只讲爬塔主模式；沙盒 / 线性关标为工具 | **功能已存在**（主菜单可进爬塔与沙盒） |
| 开局 | 点「开始」进入新开一整局 | **不设**选初始角色、难度、种子界面；开局 = 默认起始牌库 + 新地图 | **无选初始**；点开始即新开局 |
| 中途回主菜单 | 放弃本局 | 中途退出 = 本局作废（等同失败重置意图） | 结束界面可回菜单；中途放弃未成主流程文案 |
| 通关 / 失败后 | 再来一局或回主菜单 | 不写局外奖励；失败整局重置后可重开 | **部分存在**（通关 / 失败叠层 → 重开或回菜单） |
| 存档 / 继续 | — | **第一版不做**中途存档；进程结束即本局丢失 | **不存在** |
| 局外成长 | — | **第一版不做**永久解锁、多幕进度 | **不存在**（仅第一幕配置） |

杀戮尖塔「选角色再进一局」→ 本作第一版「主菜单开始 → 直接进入幕地图」。

## 5. 局内生命周期（一整局）

### 5.1 总流程

1. 生成（或加载）本幕地图  
2. 在地图上选可到达节点  
3. 进入节点 → 处理节点内容 → 离开节点回地图  
4. 击败本幕 Boss → 整局通关；任一战斗遭遇失败 → 整局失败并重置  

```mermaid
flowchart TD
  subgraph Meta[局外]
    MainMenu[主菜单]
    Settings[设置]
    Sandbox[沙盒工具]
    MainMenu --> Settings
    MainMenu --> Sandbox
    MainMenu -->|开始一局| NewRun[开新局]
  end

  subgraph RunLoop[局内一整局]
    GenMap[生成幕地图]
    MapSelect[地图选路]
    EnterNode[进入节点]
    LeaveNode[离开节点回地图]
    RunWin[整局通关]
    RunLose[整局失败重置]
    NewRun --> GenMap --> MapSelect
    MapSelect --> EnterNode
    LeaveNode --> MapSelect
    MapSelect -->|Boss已胜| RunWin
  end

  subgraph NodeInner[节点内]
    CombatNode[战斗或精英或Boss]
    ShopNode[商店节点]
    OtherNode[休息事件宝箱献祭等]
    Prep[准备布阵]
    AutoCombat[自动战斗]
    Resolve[结算]
    CombatNode --> Prep --> AutoCombat --> Resolve
    Resolve -->|胜| LeaveNode
    Resolve -->|败| RunLose
    ShopNode -->|购买结束| LeaveNode
    OtherNode -->|交互结束| LeaveNode
  end

  EnterNode --> CombatNode
  EnterNode --> ShopNode
  EnterNode --> OtherNode
  RunWin --> MainMenu
  RunLose --> MainMenu
  RunLose -->|再来一局| NewRun
```

### 5.2 幕与地图选路

| 概念 | 含义 | 第一版约定 |
|------|------|------------|
| 幕 | 一张地图 + Boss | **只有一幕**；通关 = 击败该幕 Boss |
| 地图选路 | 从起点沿连通边前进，每层可选若干节点 | 只能点「当前可达」节点 |
| 神秘节点 | 进入时才揭晓真实类型 | 揭晓后按真实类型处理 |

### 5.3 节点类型

| 节点 | 玩家在做什么 | 离开条件 |
|------|--------------|----------|
| **起点** | 进入即完成 | 自动完成，无战斗 |
| **战斗** | 准备布阵 → 开战看戏 → 看结算 | 胜 → 回地图；败 → 整局失败 |
| **精英** | 同战斗，威胁更高 | 同战斗 |
| **Boss** | 本幕终点战斗 | 胜 → 整局通关；败 → 整局失败 |
| **商店** | 购买角色卡 / 增益卡、刷新 | 结束购买后回地图 |
| **休息** | 恢复类选择（如治疗、整理牌库） | 选完后回地图 |
| **事件** | 选项事件 | 选完后回地图 |
| **宝箱** | 选奖励（如增益） | 选完后回地图 |
| **献祭** | 牌库内技能 / 养成转移类交互 | 完成后回地图 |
| **神秘（?）** | 进入时揭晓为上表某一类型 | 按揭晓类型离开 |

> **献祭**已写入本表（实现侧已有该类型）。细则另切片；本篇只定「它是正式节点类型之一」。

### 5.4 节点进入与离开

- **进入**：仅可选当前可达节点；神秘节点进入时揭晓类型。  
- **战斗类**：进入遭遇 → 准备 → 自动战斗 → 结算 →（胜）完成节点回地图 /（败）整局失败。  
- **非战斗类**：完成交互后回地图。  
- **主模式战斗胜利后直接回地图**，不会被强制塞进商店。

### 5.5 通关与整局失败

| 结果 | 条件 |
|------|------|
| **遭遇胜** | 清光本场全部敌方角色 |
| **遭遇败** | 己方角色全部阵亡（不以基地血条为主轴） |
| **整局通关** | 击败本幕 Boss |
| **整局失败** | 任一战斗遭遇失败 → **整局重置**（牌库、金币、地图进度） |

胜负细节以 [游戏愿景](../GAME_VISION.md) 清波制定稿为准。

## 6. 跨节点持久状态与重置

| 状态 | 跨战斗 / 跨节点 | 整局失败时 |
|------|-----------------|------------|
| 牌库（角色条目、等级、已挂增益） | 保留并可变 | 重置为开局默认 |
| 金币 | 保留 | 重置 |
| 地图进度、已完成节点 | 保留 | 重新生成 / 清空进度 |
| 商店访问次数等推进用计数 | 保留（可影响品阶等） | 重置 |
| 本场战斗临时增益 / 场上实体 | **不**跨战斗保留 | — |
| 友方角色**当前生命** | **跨战斗节点保留**；休息可回复 | 随整局重置 |
| 局外永久解锁 | 第一版无 | — |

> **生命跨节点**：第一版约定场上 / 牌库养成相关的当前生命在战斗节点之间保留，休息节点才有明确回复语义。若改为「每场满血」，休息治疗需另定语义。

## 7. 节点内战斗循环

### 7.1 主模式（爬塔）— 战斗类节点

```text
进入战斗节点
  → 准备（查看牌库/手牌、布阵、点开始战斗）
  → 自动战斗（观看；可加速若已有）
  → 结算（发波次金、清场、判胜负）
  → 胜：回地图选路
  → 败：整局失败 → 重开或回主菜单
```

- **商店不在战斗胜利后自动出现**；要买卡须走地图上的商店节点（或事件 / 宝箱等奖励节点）。  
- 杀戮尖塔「房间战斗」→ 本作「自走棋一场」；对方「战后选牌」→ 本作拆到「地图商店 / 宝箱 / 事件」等。

### 7.2 准备阶段要点

| 玩家 | 系统 |
|------|------|
| 从手牌/牌库选择角色摆上棋盘 | 校验格占用；禁止战斗 |
| 调整站位后点「开始战斗」 | 进入自动战斗 |

愿景目标为每场准备「无放回抽 5 张」；**抽 5 尚未实装**时，现状可能是整库可选——文档与验收须标清，不得把抽 5 写成已完成。

### 7.3 战斗与结算

| 阶段 | 玩家 | 系统 |
|------|------|------|
| 战斗 | 观看（可选加速） | 空闲格刷怪；固定节奏自动战斗；击杀敌人可即时掉金 |
| 结算 | 查看结果 | 发放波次固定收益；清场；敌方全灭 → 胜；己方全灭 → 败 |

战斗内临时增益在波次 / 遭遇结束时清空；牌库养成与跨节点生命见第 6 节。

## 8. 商店在循环中的位置

| 模式 | 商店出现时机 |
|------|--------------|
| **主模式（爬塔）** | **仅地图商店节点**（以及事件 / 宝箱等非战斗奖励，若提供购买或选增益） |
| **线性开发关** | 波次结算之后、下一波准备之前（工具环专用） |

商店「买什么、怎么刷新、满库怎么换」见 [商店文档](../SHOP_SYSTEM.md)。本篇只规定**何时**能进商店。

## 9. 玩家操作与验收（L0）

可观察路径（主模式）：

1. 主菜单能进入爬塔  
2. 地图上能看到可选节点并点选  
3. 战斗节点：能布阵、开战、看自动战斗；胜回地图 / 败出结束界面  
4. 商店节点：能购买后回地图；战斗胜利后**不应**被强制塞进商店  
5. Boss 胜 → 胜利结束；失败 → 牌库 / 金 / 地图进度清掉并可重开  

**非目标（验收不要当缺陷追）**：实时微操、羁绊凑数、基地血条胜负、中途存档、多幕局外成长。

## 附录 A：线性波次工具环

开发 / 平衡用，**不是**主循环：

```text
线性关加载 →（商店）→ 准备 → 战斗 → 结算 → 商店 → 下一波 …
         ↘ 败 → 商店 / 重置构筑 → 再挑战
```

差异要点：线性模式是「一关多波、波波可商店」；主模式是「一节点一战、商店在地图上」。六步职责细节见 [游戏愿景](../GAME_VISION.md)「线性波次」节；实现入口见 `scenes/main/main.tscn`。
