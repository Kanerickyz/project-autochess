> 功能规格 · 只谈地图附魔节点：何时出现、改什么、怎么操作，不写具体数值公式与实现字段 · 2026-10-20

> **攻血（已定）**：熔印者攻、血 = 原料 A、B **当前展示攻血之和**（含星级/增益后的面板）。  
> **【To-Be】** 地图 **附魔节点**内双献祭熔合，产出 **熔印者**（runtime 数值与主技能）；每节点 **至多成功融合 1 次**；可 **跳过**。**【As-Is】** 节点类型与地图颜色已有；进房为占位说明 +「继续」；熔炉 UI、融合服务、runtime 队伍条目 **未实装**。**文档 To-Be ≠ 已实现**。

## 1. 这是什么

**附魔**是地图上的非战斗节点：玩家在「**上方附魔台、下方当前队伍**」的界面里，把 **两名不同队员** 分别放入 **时机格 A** 与 **效果格 B**，预览并在 **产出格 C** 确认后，**永久失去 A 与 B**，得到 **一名熔印者** 加入队伍（队伍净 **−1 人**）。主技能由 A 的触发时机与 B 的效果块 **runtime 缝合**；战斗出手方式（普攻 / 直线攻等）**继承 B**。整房 **只能成功融合一次**；也可 **跳过** 不改队伍直接回地图。

体验骨架：路线赌一口 → 用两名已有队员换一名 **无星级、无法三合一** 的实验体 → 带着新联动继续爬塔。与 **招募**（胜后加人）、**地图商店**（完整养成）分工不同；附魔是 **高风险构筑实验**。

**做**：双献祭熔合、跳过、每节点一次成功融合、只动产出者的 **主技能**（runtime 生成）、被动不参与。  
**不做**：附魔技能池三选一、单目标换技能（旧 MAP 方案已废止）；旧 **献祭** 服务接入主循环；休息 / 宝箱节点。  
**不做**：熔印者参与 **自动三合一**（既不作为计数对象，也不作为同名合成产物）。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **附魔节点 / 熔炉** | 地图上 `ENCHANT` 类型节点；进入后为本篇交互 |
| **时机格 A** | 附魔台上格；拖入一名队员，捐献其主技能 **时机侧**（见 §6） |
| **效果格 B** | 附魔台上格；拖入另一名队员，捐献其主技能 **效果侧**；**战斗壳**整体取自 B |
| **产出格 C** | 确认前预览熔印者；确认后生成队员 |
| **融合** | 销毁 A、B 两名队员，生成 1 名熔印者入队 |
| **熔印者** | 非 Content 二十四人 roster 的友方队员；固定模板身份（如 `fused_enchant`）；显示名 **熔印者**（外观 v1 占位）；**无星级展示** |
| **无星级** | 信息卡与战场 **不显示 1～3 星**；技能数值按 **1 星倍率（×1）** 结算；**不参与** 玩家篇三合一 |

## 5. 表现与布局

### 5.1 进出镜头（功能意图）

与 [招募](./RECRUIT.md) §6.1 同类语义：离开地图层 → 半场滑入拼成一整屏；结束附魔 → 滑出回地图。  
具体缓动留给表现；玩家须能读出「已进入熔炉 / 已离开」。

### 5.2 分区

| 区域 | 内容 | 说明 |
|------|------|------|
| **上区** | 附魔台：格 **A**、**B**、**C**（列 **0 / 2 / 4**，中间各空一格） | 从下区 **拖拽** 队员到 A/B；C 为融合前预览 |
| **下区** | 当前 **队伍** | **不开战**；底栏仅 **融合 / 跳过 / 继续** 三钮 |
| **附魔试验场**（主菜单） | 招募池全员入队 | 下区可 **滚轮或拖拽** 纵向滚动；规则同地图附魔，跳过回主菜单，融合后继续可再熔 |

竖屏：**我上（炉）我下（队）**，与招募（上队下候选）上下对调。

### 5.3 常驻可读信息

阶段标题（如「附魔」）、当前席位占用、融合钮可用 / 不可用原因（缺人、白板、已融合过等）。长按信息卡规则对齐 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2（若该阶段已接信息卡）。

## 6. 交互与缝合规则

### 6.1 原料资格

| 规则 | 说明 |
|------|------|
| A、B **必须是不同** 队伍成员 | 同一人不能占两格 |
| 主技能 **非空** | 白板（无主技能）**不能** 进 A 或 B |
| 主技能 **恰好一条** `EffectSpec` | 见 [角色技能](./UNIT_ABILITIES.md) §3.4；多条 spec 的内容 **不得** 进主路径 |
| 星级 **任意组合** | 例如 **2★ 三合一产物** 与 **1★** 可同时进 A、B；星级只影响原料 **当前攻血/已挂增益**，不改变缝合逻辑 |
| 每节点 | **至多 1 次** 成功融合；成功后融合钮关闭；跳过不消耗「融合次数」 |

### 6.2 缝合（runtime）

从 A 的主技能取 **唯一** `EffectSpec` 的 **时机侧**：

- `trigger`、`condition`（及该 spec 上仅作用于「能否触发」的字段）

从 B 的主技能取 **同一条 spec 约定下的效果侧**：

- `target_selector`、`exclude_owner`、`target_count`、`actions`、`max_triggers_per_combat` 等

生成 **一条** 新的 `EffectSpec`，装入 **新** `AbilityData`：

- **战斗壳**（`can_normal_attack`、`uses_line_attack`、`skip_attack_after_move`、直线伤害字段等）**全部继承 B** 的主技能壳  
- 主技能 **仅含这一条** 合成 spec  

数值与资源均在 **runtime** `duplicate` / 组装；**不** 写入 Content 花名册。

### 6.3 确认融合

1. A、B、C 预览满意 → 点 **融合**。  
2. 从队伍 **移除** A、B（含占位释放）。  
3. 生成 **1 名熔印者** 入队；**占位**默认继承 **A 的座位**（若 A 无座则落到第一个空友方座位；实现须固定序并与玩家篇一致）。  
4. **已挂增益**：A、B 身上 `attached_buffs` **合并** 到熔印者（冲突规则见增益文档）。  
5. 回地图（或先播短确认再回，由表现定）。

### 6.4 跳过

任意时刻可 **跳过**：队伍不变，回地图，节点完成。

### 6.5 队伍为空或无可熔原料

若成员不足 2 人或无人能进 A/B（全白板等）：**只能跳过**。

## 7. 熔印者（产出）

| 项 | 规则 |
|----|------|
| **身份** | 固定模板 `UnitData` 壳（如 `fused_enchant`）；**不是** roster 二十四人之一 |
| **显示名** | **熔印者**；副文案建议含「由两名队员熔合」 |
| **外观** | v1 统一占位剪影；不定立绘 |
| **星级** | **无星级**（UI 不展示星）；内部按 **1 星** 做技能数值倍率（×1） |
| **三合一** | **永不参与** 玩家篇自动三合一：不计入「同名同星」计数，不触发合成，也不因招入第三人而升星 |
| **攻 / 血** | runtime 由 A、B **当前** 攻血（含星级与永久加成后的有效值）按默认公式融合；**默认草案**：各项取两原料 **算术平均后向上取整**（具体系数留给数值） |
| **招募 / 商店** | 不出现在招募候选或商店货架 |

敌阵强度预算对熔印者的计入方式见 [队伍强度抽阵](./ENEMY_SPAWN_BUDGET.md)（实现前在数值侧补一条「按有效面板 + 技能档」）。

## 8. runtime 数据契约（规格）

实现须满足：

1. **队伍条目** 能区分：roster 成员 vs **熔印者**（模板 id + runtime 攻血覆盖 + runtime 主技能）。  
2. 开战、`UnitInstance`、信息卡读技能时：**优先** runtime 主技能，再回退 `UnitData.ability`。  
3. 合成主技能须可通过现有 **EffectResolver** 触发（不另开战斗 Buff 系统）。  
4. 若未来有存档：须能序列化 **配方**（A/B 技能 id 或 spec 指纹 + 融合时星级与攻血快照）或完整 runtime 资源。

模块化建议（实现期）：

- **Run 域** `EnchantFusionService`：校验、缝合、改队伍。  
- **AbilityComposer**（或等价）：`compose_timing(from A spec, effect from B spec) -> EffectSpec`。  
- Content **lint**：主技能 `effect_specs.size() == 1`。

## 10. 验收（功能 · To-Be）

1. 从地图进入附魔：见上炉下队、A/B/C 与融合钮。  
2. 两名有主技能队员填入 A/B，预览 C 可读（时机来自 A、效果来自 B、出手方式跟 B）。  
3. 融合后 A、B 消失，队伍 +1 名熔印者（净 −1 席），占位符合 §6.3。  
4. 熔印者 **无星标**；再获得两名 roster 成员 **不会** 与熔印者触发三合一。  
5. 2★ 与 1★ 作原料可成功融合；白板不能进格。  
6. 同节点第二次融合不可用；跳过则队伍不变。  
7. 下一场战斗熔印者主技能按缝合结果自动触发（经 EffectResolver）。
