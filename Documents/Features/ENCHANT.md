# 附魔（熔炉）

> 功能规格 · 只谈地图附魔节点：何时出现、改什么、怎么操作，不写具体数值公式与实现字段 · 2026-10-20  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [地图与节点](./MAP.md) · [玩家](./PLAYER.md) · [角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · [战斗关卡](./COMBATLEVEL.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：敌阵预算对熔印者的加权公式、镜头秒数、非法组合白名单全表。  
> **攻血（已定）**：熔印者攻、血 = 原料 A、B **当前展示攻血之和**（含星级/增益后的面板）。  
> **【To-Be】** 地图 **附魔节点**内双献祭熔合，产出 **熔印者**（runtime 数值与主技能）；每节点 **至多成功融合 1 次**；可 **跳过**。**【As-Is】** 节点类型与地图颜色已有；进房为占位说明 +「继续」；熔炉 UI、融合服务、runtime 队伍条目 **未实装**。**文档 To-Be ≠ 已实现**。

## 1. 这是什么

**附魔**是地图上的非战斗节点：玩家在「**上方附魔台、下方当前队伍**」的界面里，把 **两名不同队员** 分别放入 **时机格 A** 与 **效果格 B**，在 **产出格 C** 预览熔印者，再向熔炉 **投入 Run 金币** 抬高成功率，最后点 **融合** 做一次熔合检定。主技能由 A 的时机与 B 的效果 **runtime 缝合**；出手方式 **继承 B**。

**【用户新共识 · 熔炉经济】** 每名配方有 **预期投入价 P**（由 A/B **动态**算出）。已投入金币 **G** 未达 **P** 时，融合可能 **失败**——**永久失去 A 与 B**、无熔印者，但 **本节点可换一对原料再赌**；**G ≥ P** 时本次融合 **必定成功**（仍消耗 A、B，产出熔印者）。也可 **跳过** 回地图。每节点 **至多成功融合 1 次**。

体验骨架：路线赌一口 → 用金币与两名队员换一名 **无星级、无法三合一** 的实验体 → 与 **招募**（胜后加人）、**地图商店**（完整养成）分工不同；附魔是 **高风险构筑实验**。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **附魔节点 / 熔炉** | 地图上 `ENCHANT` 类型节点；进入后为本篇交互 |
| **时机格 A** | 附魔台上格；拖入一名队员，捐献其主技能 **时机侧**（见 §6） |
| **效果格 B** | 附魔台上格；拖入另一名队员，捐献其主技能 **效果侧**；**战斗壳**整体取自 B |
| **产出格 C** | 确认前预览熔印者；确认后生成队员 |
| **融合** | 销毁 A、B 两名队员，生成 1 名熔印者入队 |
| **熔印者** | 非 Content 二十四人 roster 的友方队员；固定模板身份（如 `fused_enchant`）；显示名 **熔印者**（外观 v1 占位）；**无星级展示** |
| **无星级** | 信息卡与战场 **不显示 1～3 星**；技能数值按 **1 星倍率（×1）** 结算；**不参与** 玩家篇三合一 |

## 5. 表现与布局

### 5.1 进出镜头（功能意图）

与 [招募](./RECRUIT.md) §6.1 同类语义：离开地图层 → 半场滑入拼成一整屏；结束附魔 → 滑出回地图。  
具体缓动留给表现；玩家须能读出「已进入熔炉 / 已离开」。

### 5.2 分区

| 区域 | 内容 | 说明 |
|------|------|------|
| **上区** | 附魔台：格 **A**、**B**、**C**（列 **0 / 2 / 4**，中间各空一格） | 从下区 **拖拽** 队员到 A/B；C 为融合前预览 |
| **下区** | 当前 **队伍** | **不开战**；底栏见 §5.4 |
| **附魔试验场**（主菜单） | 招募池全员入队 | 下区 **滚轮**、**空白席跟手滚**，或 **左右边条**（棋盘外留白 + 边列外缘）跟手滚；**点在队员中部** 越出容差后 **一律拖**（含竖直上炉 / 换座）；规则同地图附魔，跳过回主菜单，融合后继续可再熔 |

竖屏：**我上（炉）我下（队）**，与招募（上队下候选）上下对调。

### 5.3 常驻可读信息

阶段标题（如「附魔」）、当前席位占用、融合钮可用 / 不可用原因（缺人、白板、已融合过等）。长按信息卡规则对齐 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2（若该阶段已接信息卡）。

### 5.4 底栏操作（【用户新共识】）

| 按钮 | 作用 |
|------|------|
| **投入金币** | 每按一次从 Run 余额扣 **1** 金币，**G += 1**，刷新成功率；**不**掷骰、**不**消耗 A/B |
| **重置** | **免费**；**G = 0**（已投金币不退回 Run）；**A/B 下炉回队**、清空炉位；成功率回到基础值 |
| **融合** | 在 A/B 已就位且本节点尚未成功时，按当前 **G** 与 **P** 做一次熔合检定（见 §6.6） |
| **跳过** | 队伍与金币不变（含本节点已投 **G** 的处理见 §6.6.4），回地图，节点完成 |
| **继续** | 仅在本节点 **已成功融合** 后出现；回地图 |

常驻显示：**预期价 P**、**已投 G**、**当前成功率**、Run **金币余额**；**G ≥ P** 时标为「必成」。

## 6. 交互与缝合规则

### 6.1 原料资格

| 规则 | 说明 |
|------|------|
| A、B **必须是不同** 队伍成员 | 同一人不能占两格 |
| 主技能 **非空** | 白板（无主技能）**不能** 进 A 或 B |
| 主技能 **恰好一条** `EffectSpec` | 见 [角色技能](./UNIT_ABILITIES.md) §3.4；多条 spec 的内容 **不得** 进主路径 |
| 星级 **任意组合** | 例如 **2★ 三合一产物** 与 **1★** 可同时进 A、B；星级只影响原料 **当前攻血/已挂增益**，不改变缝合逻辑 |
| 每节点 | **至多 1 次** **成功**融合；成功后融合钮关闭；**失败不限次数**（可换对再赌）；跳过不消耗成功次数 |

### 6.2 缝合（runtime）

从 A 的主技能取 **唯一** `EffectSpec` 的 **时机侧**：

- `trigger`、`condition`（及该 spec 上仅作用于「能否触发」的字段）

从 B 的主技能取 **同一条 spec 约定下的效果侧**：

- `target_selector`、`exclude_owner`、`target_count`、`actions`、`max_triggers_per_combat` 等

生成 **一条** 新的 `EffectSpec`，装入 **新** `AbilityData`：

- **战斗壳**（`can_normal_attack`、`uses_line_attack`、`skip_attack_after_move`、直线伤害字段等）**全部继承 B** 的主技能壳  
- 主技能 **仅含这一条** 合成 spec  

数值与资源均在 **runtime** `duplicate` / 组装；**不** 写入 Content 花名册。

### 6.3 尝试融合（检定）

前置：A、B 已入炉；本节点尚未成功融合；玩家点 **融合**（**仅此时**掷骰，投币不触发失败）。

**成功**（见 §6.6.3）：

1. 从队伍 **移除** A、B（含占位释放）。  
2. 生成 **1 名熔印者** 入队；**占位**默认继承 **A 的座位**（若 A 无座则落到第一个空友方座位；实现须固定序并与玩家篇一致）。  
3. **已挂增益**：A、B 身上 `attached_buffs` **合并** 到熔印者（冲突规则见增益文档）。  
4. 本节点成功结束；点 **继续** 回地图。

**失败**：

1. **永久移除** A、B（无熔印者）；已投入的 **G 不退回** Run。  
2. 炉位清空；玩家可 **另选两名** 原料再投币、再融合；**节点不结束**，直至成功或 **跳过**。

### 6.4 跳过

任意时刻可 **跳过**：**未在炉上的** 队伍成员不变；炉上 A/B 若存在则 **退回队伍**（与重置下炉一致）。本节点已投入、未在「融合」中消耗的 **G** 是否退回 Run 由数值定稿（**默认：不退回**，与失败一致，避免刷概率）；回地图，节点完成。

### 6.5 队伍为空或无可熔原料

若成员不足 2 人或无人能进 A/B（全白板等）：**只能跳过**。

### 6.6 熔炉经济（【用户新共识】）

#### 6.6.1 预期价 P（动态）

- **P** 在 A、B 均就位且可预览 C 时计算，随换料 **实时更新**。  
- 输入维度（实现期由数值在 Content / 配置中落表，本篇只定结构）：  
  - **时机侧（A）**：`trigger` / `condition` 对应 [角色技能](./UNIT_ABILITIES.md) §7.1 **触发频率分档**（偏高 / 中 / 低）。  
  - **效果侧（B）**：`actions` 类型与幅度（是否生成单位、伤害/治疗量档、目标范围等）。  
  - **原料面板**：A、B 当前展示攻血、星级、已挂增益条数等 **可选加权**（避免同名低星与高星同价）。  
- UI **必须**展示当前配方的 **P** 与 **G**，不必要求玩家手算。

#### 6.6.2 成功率

- 设已投金币 **G**（本配方、本节点本轮重置前累计；仅 **投入金币** 按钮增加）。  
- **基础成功率**（**G = 0** 时尝试融合）：**10%**。  
- **G < P**：`成功率 = 10% + 90% × (G / P)`（线性；**G = 0** 即为 10%）。  
- **G ≥ P**：本次融合 **100% 成功**（仍须点 **融合** 执行；不要求 G 恰好等于 P）。  
- **超投**：**G > P** 不额外加成，仅仍视为必成。  
- **投币** 只改 **G** 与成功率显示；**不** 自动融合、**不** 扣人。

#### 6.6.3 金币

- **投入金币**：每次 **−1** Run 金币、**G += 1**；余额不足时按钮不可用。  
- **融合** 检定成功或失败时，本配方已累计的 **G 清零**（下一轮新配方从 **G = 0**、10% 起算）。  
- 与地图 **商店 / 事件 / 招募** 共用同一 Run 金币池；附魔节点内不另发币。

#### 6.6.4 重置

- **免费**；**G = 0**（已投金币 **不退回** Run）；成功率回到 **10%** 基准展示。  
- **A、B 下炉回队**（若曾在炉上）；炉位空。  
- 不改变本节点「已成功融合」状态（已成功则不可重置到再赌）。

### 6.7 附魔试验场（主菜单）

规则与地图附魔 **一致**（含 **P / G / 概率 / 重置 / 融合**），除非单独标明沙盒：可不扣 Run 金币、失败可不真删队（实现期二选一须在 UI 标明「试验」）。  
底栏额外提供 **随机**：从可熔原料中任选两名不同队员放入 **A / B**（配方变更会清零已投 **G**）；地图附魔节点不显示此钮。

## 7. 熔印者（产出）

| 项 | 规则 |
|----|------|
| **身份** | 固定模板 `UnitData` 壳（如 `fused_enchant`）；**不是** roster 二十四人之一 |
| **显示名** | **熔印者**；副文案建议含「由两名队员熔合」 |
| **外观** | v1 统一占位剪影（画布与二十四人同规格 **305×320**）；不定立绘 |
| **星级** | **无星级**（UI 不展示星）；内部按 **1 星** 做技能数值倍率（×1） |
| **三合一** | **永不参与** 玩家篇自动三合一：不计入「同名同星」计数，不触发合成，也不因招入第三人而升星 |
| **攻 / 血** | runtime 由 A、B **当前** 攻血（含星级与永久加成后的有效值）按默认公式融合；**默认草案**：各项取两原料 **算术平均后向上取整**（具体系数留给数值） |
| **招募 / 商店** | 不出现在招募候选或商店货架 |

敌阵强度预算对熔印者：**有效展示攻血**入身体项；**runtime 缝合主技能**走 `SkillExpectation` 深评分入 α（见 [队伍强度抽阵](./ENEMY_SPAWN_BUDGET.md) §6.1）。

## 8. runtime 数据契约（规格）

实现须满足：

1. **队伍条目** 能区分：roster 成员 vs **熔印者**（模板 id + runtime 攻血覆盖 + runtime 主技能）。  
2. 开战、`UnitInstance`、信息卡读技能时：**优先** runtime 主技能，再回退 `UnitData.ability`。  
3. 合成主技能须可通过现有 **EffectResolver** 触发（不另开战斗 Buff 系统）。  
4. 若未来有存档：须能序列化 **配方**（A/B 技能 id 或 spec 指纹 + 融合时星级与攻血快照）或完整 runtime 资源。

模块化建议（实现期）：

- **Run 域** `EnchantFusionService`：校验、缝合、改队伍。  
- **AbilityComposer**（或等价）：`compose_timing(from A spec, effect from B spec) -> EffectSpec`。  
- Content **lint**：主技能 `effect_specs.size() == 1`。

## 10. 验收（功能 · To-Be）

1. 从地图进入附魔：上炉下队、A/B/C；底栏 **投入金币 / 重置 / 融合 / 跳过**（成功后 **继续**）。  
2. A/B 就位后可见 **P、G、成功率**；换 A 或 B 时 **P** 随配方变化。  
3. **投入金币** 仅增 **G** 与成功率，不扣人、不掷骰。  
4. **G < P** 时融合可失败：A/B 永久消失、无熔印者；可换对再赌；**G ≥ P** 时融合必成。  
5. **重置**：G 清零、A/B 回队；已投金币不退 Run。  
6. 成功后同节点不可再次成功融合；**跳过** 不产出熔印者。  
7. 成功产出：熔印者无星标、三合一不参与；下一场战斗缝合技能经 EffectResolver 触发。  
8. 白板不能进 A/B。
