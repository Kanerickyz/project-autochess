> **【用户新共识 · 2026-11-03】** 货架装备含**护甲与技能类**；共槽、职业固定格数、新角色空装见装备篇。  
> **【边界】** 本功能在**地图商店节点**；表现与招募同屏 Arena 半场（非独立 UnitCardDisplay 卡片屏）。

## 1. 这是什么

玩家进入地图上的**商店**节点后，在「上方己方队伍、下方商店货架」里花金币买消耗品或装备（拖到角色上），并可调整队伍站位，然后离开回地图。分区与招募半场一致（上 `recruit_team` / 下候选·道具行风格）。

| 本篇负责 | 别处负责 |
|----------|----------|
| 地图商店布局、消耗品/装备**货架购买**、刷新、换座 | **地图**：何时出现商店节点、进出回地图 |
| — | **装备**：槽位、挂/拒、详情卸载、队伍暂存、合计护甲、三合一溢出、护甲与「受伤」 |
| — | **招募 / 招募商店**：短名单拿人；小药水 + 旗帜 |
| — | **玩家**：队伍、持久占位、席位上限、装备暂存栏归属 |
| — | **数值**：具体点数（见文末草案表，不定死） |

## 3. 布局与交互

与招募半场分区一致（上队伍、下货架/候选区）：

```text
地图商店（Arena 主路径，同招募草地 / 半场 slide / 金币 HUD）
  上半场：当前队伍角色座位（可换座；短点开详情改装；纸片 _draw_body）
  下半场：商店货架两行（消耗品行 + 装备行；合计 6 格，格数随本次抽签结果浮动；样式对齐招募道具行）
  （队伍级装备暂存栏：可见可拖，版式见装备篇）
  底栏 HUD：刷新货架 / 离开（风格对齐招募 Dock）
```

| 操作 | 结果 |
|------|------|
| 拖消耗品到上半场角色 | 金够则扣金；**单目标魔药**对该成员立刻改永久攻/血；**主题药水**以拖放为确认购买，对当下队伍（含备战）该主题成员各写永久攻/血（无人命中仍扣金清槽）；该槽清空（本版不自动补货） |
| 拖装备到上半场角色 | 金够 **且** 目标有空装备槽 → 扣金挂上、货架槽清空；否则失败不扣金（规则见 [装备](./EQUIPMENT.md)） |
| 短点上半场角色 | 开角色详情（槽位 / 缩略图 / 卸载）；见 [装备](./EQUIPMENT.md) |
| 拖角色换座 | 与准备换座同口径，写回持久占位与落座时间（按下位移超阈值走拖，不触发短点） |
| 长按角色 | 百科介绍卡（不改装）；见 [战斗观战反馈](./COMBAT_FEEDBACK.md) |
| 花金刷新货架 | **整架**按 §3.1 规则无放回重抽 6；扣刷新费 |
| 结束 / 离开 | 回地图，节点完成 |
| 金不足 / 目标非法 / 装备槽满 | 失败，货架保留 |

#### 3.1 货架抽签【用户新共识 · 2026-11-01】

| 项 | 定稿 |
|----|------|
| 槽位数 | 药 + 装合计 **6** |
| 呈现 | **仍两行**：抽中的消耗品上一行、装备下一行；各行格数随本次结果变化（可为 0） |
| 抽签 | 消耗品池 ∪ 装备池合并为候选；按**资源 id**去重后**无放回**随机抽满 6（池不足则有多少抽多少） |
| 唯一 | 同 id 不同时并排 → 同职主题药水至多一瓶；也不会两瓶同款大魔药 / 两件同档护甲 |
| 刷新 | 整架重抽（同规则）；买走槽空、**不**自动补货 |

本版**不做**：单独卖掉装备；商店内买人。

## 4. 消耗品

消耗品为**战斗外永久改属性**（改队伍成员攻/血加成），拖到目标角色后立刻结算。

| 种类（功能） | 效果骨架 | 目标 |
|--------------|----------|------|
| **大生命魔药** | 永久：生命升、攻击降 | 一名队伍成员 |
| **大力量魔药** | 永久：攻击升、生命降 | 一名队伍成员 |
| **稀有消耗品（群伯龙）** | 永久：攻击大幅升、生命降 | 一名队伍成员 |
| **主题药水**（七款） | 永久：该主题成员**展示攻、展示生命各 ×2** | **当下快照**：队伍内（**含备战**）主归该类的成员；拖放到上半场任一角色仅为确认购买 |

#### 4.1 主题药水【用户新共识 · 2026-11-01】

| 项 | 定稿 |
|----|------|
| 货架 | 入地图商店合并候选池（与大魔药、装备一并无放回抽）；**不**进招募道具行 |
| 七款 | 亡灵 / 战士 / 骑士 / 工匠 / 军乐队 / 秘术 / 护卫（与 [主题羁绊](./UNIT_THEME_BONDS.md) 同文） |
| 结算 | 扣金后扫描**当前** `DeckState` 全员（入座 + 备战），对 `theme_bond` 匹配者：以结算当下的展示攻 / 展示生命为基准，各再加等量永久加成（结果为翻倍）；**不做**整局标记、**不**对之后新招自动生效；**不**翻倍护甲装备 |
| 0 命中 | **可买**：金够则扣金、清槽；无人加属性（无效） |
| 交互 | 拖到上半场角色确认；拖放目标**不必**是该主题 |
| 不做 | 战斗内主题光环；招募小药水行；主题类写进道具介绍卡侧栏（瓶身文案写主题名即可） |

**生命归零销毁【用户新共识】**：结算后若该成员展示最大生命 **≤ 0**，立刻从队伍**销毁离队**（腾座）；已扣消耗品金、**不**按出售退金。（主题药水为本版正增益，一般不触发。）

货架抽签见 §3.1（合计 6、无放回、id 唯一）。具体点数见文末草案，规格不定死。

## 5. 装备（购买入口）

装备系统（槽位 0～3、满槽拒绝、详情卸载、队伍暂存、合计护甲、三合一溢出、护甲与「受伤」）见 **[装备](./EQUIPMENT.md)**。本篇只定商店购买入口：

| 项 | 定稿 |
|----|------|
| 货架 | 装备行与消耗品合并抽签（§3.1）；本版货架物为护甲分档（点数见 §7 草案） |
| 购买 | 拖装备到上半场角色：金够且目标有**空装备槽** → 扣金挂上、该货架槽清空；槽满 / 0 槽 / 金不足 → 失败不扣金 |
| 改装 | 短点角色开详情、卸载进暂存、暂存再挂：见装备篇；商店节点内**可写** |
| 可读 | 长按百科附属与头图合计护甲扫读见 [战斗观战反馈](./COMBAT_FEEDBACK.md)；金币图标与招募同格式 |

### 5.1 废止（原 §5.2 等）

下列旧共识**作废**，以实现与验收均不得再采用：

| 废止项 | 原规则 |
|--------|--------|
| 每角色最多一件 | 改为按角色槽上限 0～3（见装备篇） |
| 拖新装随机覆盖 | 旧/新随机留一件、另一件消失不退金 |
| 三合一随机只留一件 | 改为填满产物槽、溢出进队伍暂存（见装备篇） |
| 本版不做单独卸下 | 改为详情可卸载进队伍暂存 |

本版仍**不做**装备单独出售退金（卸载 ≠ 卖金）。

## 6. 验收口径

1. 进入地图商店节点后出现上队伍、下货架半场（Arena，非 UnitCardDisplay 卡片屏）；能结束回地图。  
2. 可拖消耗品到上半场角色：扣金、永久改攻血、槽空；若结算后生命 ≤0 则该角色销毁离队（不退出售金）。  
2b. 主题药水：拖放确认后，当下队伍（含备战）该主题展示攻/生命各翻倍；无人命中仍扣金清槽；之后新招同主题不自动吃。  
3. 货架合计 6 格、两行呈现；进店/刷新为合并池无放回抽满，资源 id 不重复；同职主题药水不同时两瓶。  
3b. 可花金整架刷新；买走不自动补货。  
4. 可买护甲到有空槽角色；槽满拒绝且不扣金；短点详情可见槽位并可卸载到暂存（细则见装备篇验收）。  
5. 有合计护甲时不扣血、不触发「受伤时」；伤害大于护甲时护甲归零且溢出也不扣血；护甲本场可耗尽，装备不销毁，下一场战斗节点开战回满（见装备篇 §8）。  
6. **不再**验收随机覆盖；三合一装备按装备篇 §9。  
7. 上半场可换座并写回持久占位；短点详情与拖换座、长按百科三分离。  
8. 本切片商店内**不能**买角色；招募仍卖小药水+旗帜，不卖本篇货架物。  
9. 招募与商店可见同格式金币展示；背景草地 / 半场 slide 与招募一致。
