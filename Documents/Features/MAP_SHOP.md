## 1. 这是什么

玩家进入地图上的**商店**节点后，在「上方己方队伍、下方商店货架」里花金币买装备（拖到角色上），并可调整队伍站位，然后离开回地图。分区与招募半场一致（上 `recruit_team` / 下候选·道具行风格）。

| 本篇负责 | 别处负责 |
|----------|----------|
| 地图商店布局、装备购买、刷新、换座、护甲与「受伤」边界、转职标签规则 | **地图**：何时出现商店节点、进出回地图 |
| — | **招募 / 招募商店**：短名单拿人；小药水 + 旗帜 |
| — | **玩家**：队伍、持久占位、席位上限 |
| — | **数值**：具体售价 / 权重写入 `.tres`（见 [装备库](../Content/EQUIPMENT_ROSTER.md)） |

## 3. 布局与交互

```text
地图商店（Arena 主路径，同招募草地 / 半场 slide / 金币 HUD）
  上半场：当前队伍角色座位（可换座，写回持久占位；纸片 _draw_body）
  下半场：装备货架 **5 槽**（格样式对齐招募道具行，含价格标）
  底栏 HUD：刷新货架 / 离开（风格对齐招募 Dock）
```

| 操作 | 结果 |
|------|------|
| 拖装备到上半场角色 | 金够且规则允许则扣金，按 §5 挂上；该槽清空 |
| 花金刷新货架 | 从**装备库**重新随机抽 **5** 个（可重复同款）；扣刷新费 |
| 上半场拖角色换座 | 与准备换座同口径，写回持久占位与落座时间 |
| 结束 / 离开 | 回地图，节点完成 |
| 金不足 / 目标非法 / 同职拒装 | 失败，货架保留 |

本版**不做**：单独卖掉装备；商店内买人。

## 4. 货架随机【用户新共识】

- 槽位数：**5**。  
- 池 = [装备库](../Content/EQUIPMENT_ROSTER.md) 全部条目（护甲 + 六职纹章）。  
- 每次填充 / 刷新：对每个槽**独立**从池中随机抽取（**完全打散**，可重复）。  
- 刷新费：见配置 `.tres`（默认沿用 2 金量级，balance 可调）。

## 5. 装备

- **永久**：挂在队伍成员上，跨遭遇保留。  
- **类型**：
  - **护甲**：分档抵挡伤害；每角色护甲槽 **最多 1**。  
  - **转职纹章**：纯标签、**零护甲**；附加一个异职；规则见 §5.3 与 [羁绊](./SYNERGY.md) §2.1。  
- **介绍卡**：主卡（本职）+ 护甲附属（若有）+ 转职列表（额外职）；见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2.1。  
- **UI**：有护甲才显示护甲值图标；金币图标格式与招募一致。

### 5.1 护甲与「受伤」【用户新共识】

护甲在受伤结算中保护生命；**有剩余护甲时本次攻击不扣血**（护甲按受到的伤害扣减，扣到 0 为止；**伤害大于护甲时溢出部分也不扣血**）；**装备不销毁**。护甲仅在**下一场战斗节点开战**时回满，**战斗内不回满**。

| 结算结果 | 「受伤时」类触发 |
|----------|------------------|
| 受击时仍有护甲（含伤害 > 护甲导致护甲归零） | **不**扣血、**不**触发受伤类（仅消耗护甲） |
| 受击时护甲已为 0，扣完仍存活 | 正常扣血；**算**受伤并触发 |
| 受击时护甲已为 0，扣到生命归零 | 只走死亡；**不**触发「受到伤害 / 友方受伤」 |
| 护甲在本场战斗中耗尽 | 本场剩余时间无护甲；离开战斗节点时队伍数据回满；下场开战再同步 |

### 5.2 护甲冲突【用户新共识】

| 场景 | 规则 |
|------|------|
| 已有护甲 + 再拖护甲 | **新替旧**，旧件消失，**不退金** |
| 三合一时多名成员带护甲 | 在护甲候选中**随机留 1** 挂到合成结果，其余消失、不退金 |

### 5.3 转职纹章【用户新共识】

| 项 | 规则 |
|----|------|
| 效果 | 附加**一个**额外职业标签；本职保留；零护甲；不改技能 |
| 与护甲 | **可同挂** |
| 同职 | **拒装**：已有该职标签（含本职）时再拖同职纹章 → 失败、不扣金、货架保留 |
| 件数 | 无硬顶；软顶六职全亮 |
| 三合一 | 合并参与者转职后**按职业去重**全部挂到合成体 |

本版**不做**单独卸下/出售装备入口。

## 6. 验收口径

1. 进入地图商店节点后出现上队伍、下 **5 槽**装备货架；能结束回地图。  
2. 货架每次 / 刷新均从装备库随机 5 件（可重复）。  
3. 可买护甲（每角最多一件，新替旧）；可买转职纹章（异职附加；同职/本职同职拒装）。  
4. 护甲与转职可同挂；介绍卡可读本职 + 护甲 + 额外职。  
5. 有护甲时不扣血、不触发「受伤时」；护甲规则同 §5.1。  
6. 三合一：护甲随机留 1；转职按职去重保留。  
7. 上半场可换座并写回持久占位。  
8. 本切片商店内**不能**买角色；招募仍卖小药水+旗帜，不卖本篇货架物。  
9. 已入座角色的附加职计入羁绊 / 徽章条件（id 去重）。
