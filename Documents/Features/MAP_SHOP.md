## 1. 这是什么

玩家进入地图上的**商店**节点后，在「上方己方队伍、下方商店货架」里花金币买消耗品或装备（拖到角色上），并可调整队伍站位，然后离开回地图。分区与招募半场一致（上 `recruit_team` / 下候选·道具行风格）。

| — | **玩家**：队伍、持久占位、席位上限 |

## 3. 布局与交互

与招募半场分区一致（上队伍、下货架/候选区）：

```text
地图商店（Arena 主路径，同招募草地 / 半场 slide / 金币 HUD）
  上半场：当前队伍角色座位（可换座，写回持久占位；纸片 _draw_body）
  下半场：商店货架（消耗品槽暂定 3 + 装备槽；格样式对齐招募道具行，含价格标）
  底栏 HUD：刷新消耗品 / 离开（风格对齐招募 Dock）
```

| 操作 | 结果 |
|------|------|
| 拖消耗品到上半场角色 | 金够则扣金，对该成员立刻改永久攻/血；该槽清空（本版不自动补货） |
| 拖装备到上半场角色 | 金够则扣金；按 §5 装备规则挂上；该槽清空 |
| 花金刷新消耗品货架 | 在消耗品池内重新随机（可重复出同款）；扣刷新费 |
| 上半场拖角色换座 | 与准备换座同口径，写回持久占位与落座时间 |
| 结束 / 离开 | 回地图，节点完成 |
| 金不足 / 目标非法 | 失败，货架保留 |

本版**不做**：单独卖掉装备；商店内买人。

## 4. 消耗品

消耗品为**战斗外永久改属性**（改队伍成员攻/血加成），拖到目标角色后立刻结算。

| 种类（功能） | 效果骨架 | 目标 |
|--------------|----------|------|
| **大生命魔药** | 永久：生命升、攻击降 | 一名队伍成员 |
| **大力量魔药** | 永久：攻击升、生命降 | 一名队伍成员 |
| **稀有消耗品（群伯龙）** | 永久：攻击大幅升、生命降 | 一名队伍成员 |

**生命归零销毁【用户新共识】**：结算后若该成员展示最大生命 **≤ 0**，立刻从队伍**销毁离队**（腾座）；已扣消耗品金、**不**按出售退金。

货架：若干槽（**暂定 3**），每次从消耗品池**随机**填充；刷新可重复抽到同款。具体点数见文末草案，规格不定死。

## 5. 装备

- **永久**：挂在队伍成员上，跨遭遇保留。  
- **每角色最多一件**。  
- **本版装备**：护甲，分档抵挡伤害（抵挡点数见草案）。  
- **介绍卡**：须能看出该角色是否装备、装备为何。  
- **UI**：有装备才显示护甲值图标（格式对齐攻击/生命图标）；金币图标在招募与商店同格式显示。

### 5.1 护甲与「受伤」【用户新共识】

护甲在受伤结算中保护生命；**有剩余护甲时本次攻击不扣血**（护甲按受到的伤害扣减，扣到 0 为止；**伤害大于护甲时溢出部分也不扣血**，避免被一击穿甲秒杀）；**装备不销毁**。护甲仅在**下一场战斗节点开战**时回满，**战斗内不回满**。

| 结算结果 | 「受伤时」类触发 |
|----------|------------------|
| 受击时仍有护甲（含伤害 > 护甲导致护甲归零） | **不**扣血、**不**触发受伤类（仅消耗护甲） |
| 受击时护甲已为 0，扣完仍存活 | 正常扣血；**算**受伤并触发 |
| 受击时护甲已为 0，扣到生命归零 | 只走死亡；**不**触发「受到伤害 / 友方受伤」 |
| 护甲在本场战斗中耗尽 | 本场剩余时间无护甲；**离开战斗节点**时队伍数据回满（地图/招募立即可读）；下场开战仍会同步一次 |

### 5.2 装备冲突【用户新共识】

| 场景 | 规则 |
|------|------|
| 拖新装备到已有装备的角色 | 在**旧装备与新装备**之间**随机留一件**，另一件消失，**不退金** |
| 三合一时多名成员带装备 | 在**参与合成成员的装备**中**随机留一件**挂到合成结果，其余消失，**不退金** |

本版**不做**单独卸下/出售装备入口。

## 6. 验收口径

1. 进入地图商店节点后出现上队伍、下货架半场（Arena，非 UnitCardDisplay 卡片屏）；能结束回地图。  
2. 可拖消耗品到上半场角色：扣金、永久改攻血、槽空；若结算后生命 ≤0 则该角色销毁离队（不退出售金）。  
3. 可花金刷新消耗品货架；结果可重复。  
4. 可买护甲装备到角色（每角最多一件）；介绍卡与护甲图标可读。  
5. 有护甲时不扣血、不触发「受伤时」；伤害大于护甲时护甲归零且溢出也不扣血；护甲本场可耗尽，装备不销毁，下一场战斗节点开战回满。  
6. 装备冲突与三合一按 §5.2。  
7. 上半场可换座并写回持久占位。  
8. 本切片商店内**不能**买角色；招募仍卖小药水+旗帜，不卖本篇货架物。  
9. 招募与商店可见同格式金币展示；背景草地 / 半场 slide 与招募一致。
