# 战斗状态（Combat Status）

> 功能规格 · 仅**本场遭遇**内生效的可叠层词条 · 2026-10-27；**遗骨** 2026-10-31  
> 相关：[战斗](./COMBAT.md) · [角色技能](./UNIT_ABILITIES.md) · [战斗观战反馈](./COMBAT_FEEDBACK.md) · [增益卡](../BUFF_SYSTEM.md)（Run 持久，**不是**战斗状态）

## 1. 这是什么

**战斗状态**是挂在**战斗内单位实例**上的临时词条（虚弱 / 狂暴 / 中毒 / **遗骨** 等），可叠层；多数参与伤害或回合开始结算，**遗骨**在**死亡时**兑现生成。与商店 **增益卡（BuffCardData）** 区分：增益卡跨遭遇；状态**遭遇结束清空**，不写入队伍成员。

玩家在开战观战时长按单位，信息卡下附属块展示当前状态（与装备附属同 UX）。

## 2. 范围

### 2.1 v1 包含

| 状态 id | 显示名 | 极性 | 规则（叠层上限 **15**） |
|---------|--------|------|------------------------------|
| `weak` | 虚弱 | 负 | 受到**普攻或技能伤害**时，在**护甲计算前**将该次伤害数字 **+1**（不含中毒 tick）。**当次伤害已击杀目标**时不叠加（`ON_DEAL_DAMAGE` 不入场）。每层 +1。 |
| `berserk` | 狂暴 | 正 | **仅普攻** outgoing 伤害，在护甲前 **+1**。每层 +1。 |
| `poison` | 中毒 | 负 | **自己回合开始时**（先于 `ON_ROUND_START` 技能）失去生命 **层数** 点；不走护甲、不吃虚弱。 |
| `relic_bone` | **遗骨** | 正 | 见 §2.3。**不**改伤害数字；死亡时按层数生成骷髅代理。 |

- 叠层：`stacks = clamp(stacks + delta, 0, 15)`。  
- 施加 / 驱散：技能 `EffectSpec` → `EffectAction` `APPLY_COMBAT_STATUS` / `REMOVE_COMBAT_STATUS`（`stat_name` = 状态 id，`value` = 层数，受技能升星倍率）。  
- 实现：实例 `CombatStatusStack`；伤害类状态在伤害管线集中读取；遗骨在**死亡管线**读取；不新增第三套战斗 Bus。

### 2.2 v1 不包含

- 跨遭遇状态、商店购买状态、羁绊计数。  
- 兵种配置「开战自带遗骨层」（本版**仅**战斗中由技能施加；见 §2.3）。  
- 通用净化 / 免疫（除非技能显式 `REMOVE_COMBAT_STATUS`）。  
- 准备阶段状态展示（仅战斗中有状态才出附属块）。  
- 脚下角标（仅长按卡；可后续切片）。

### 2.3 遗骨【定稿 · 用户共识 2026-10-31】

| 项 | 规则 |
|----|------|
| 玩家文案 | 死亡时，生成一具攻击与生命均等于遗骨层数的骷髅。 |
| 来源 | **仅**战斗中经技能 `APPLY_COMBAT_STATUS`（`relic_bone`）施加；**不**做兵种开战自带起手层，**不**做成角色主技能/被动替代品。 |
| 触发 | 持有者走**死亡**管线且当时 `stacks ≥ 1`。Boss **溃散**等非死亡移除**不**触发（见 [Boss](./BOSS.md)）。 |
| 生成 | **一只**骷髅代理：攻击 = **层数**，生命上限与当前生命 = **层数**（例：15 层 → **15/15**；1 层 → **1/1**）。 |
| 代理边界 | 与 [角色技能](./UNIT_ABILITIES.md) §6 一致：本场临时、不占准备座位、**无主技能**、**不带遗骨**（切断连环）。 |
| 空位 | 无可用落子空格则本次生成不执行；有空则生成这一只。 |
| 叠层意义 | 层数决定骷髅**攻/血**，**不**决定生成只数（始终至多 1 只）。 |
| 驱散 / 清空 | `REMOVE_COMBAT_STATUS`、策反清空本场战斗临时状态、遭遇结束清空——与其它战斗状态相同。 |
| 与死亡生成技能 | 可与「死亡时生成」类**技能**同次死亡叠加结算（各自独立）；骷髅再死不继承遗骨。施加遗骨的具体技能名单见 Content，本篇不定挂载表。 |

## 3. 结算顺序

**普攻**（含反打，走 `RealtimeDamagePipeline.resolve_hit` / 旧网格 `from_attack=true`）：

```text
基础伤害 → +狂暴（攻击方）→ +虚弱（受击方，护甲前）→ 护甲 → 扣 HP
```

**技能伤害**（`DEAL_DAMAGE` 等，`from_attack=false`）：

```text
技能伤害 → +虚弱（受击方，护甲前）→ 护甲 → 扣 HP
```

**自己行动轮开始**（`RealtimeCombatSim`）：

```text
中毒 tick（直扣 HP，层数合计）→ 若仍存活 → ON_ROUND_START 技能链
```

若中毒致死：本动**不**触发 `ON_ROUND_START`；行动者从队列跳过，与死亡规则一致。

**死亡时**（进入死亡结算、确认走死亡管线之后）：

```text
……既有死亡时技能 / 同伴「友方死亡」等……
→ 若死者遗骨层数 ≥ 1：尝试生成 攻/血 = 层数 的骷髅代理（无空位则跳过）
```

遗骨与其它「死亡时」效果的相对顺序：与同批死亡技能同一死亡事件内结算即可；实现须稳定可测，本篇不强制插在技能链之前或之后。**遗骨不**参与普攻/技能伤害加减法。

## 4. UI

- `UnitInfoText.INFO_ATTACHMENT_KIND_STATUS`：附属块标题「状态」，正文为规则摘要 + `N 层`。  
- 顺序：装备附属在前，状态附属按 `weak` / `berserk` / `poison` / `relic_bone` 固定序，仅展示层数 &gt; 0 的项。  
- 遗骨摘要示例：「遗骨：死亡时生成攻/血均等于层数的骷髅」。  
- 长按不暂停行动队列。

|----|----------|----------|
| 增益卡 | Run 持久 | 商店 |

## 6. 验收口径（玩家可观察）

- 叠层至 15 不再增加；遭遇结束后状态不再显示。  
- 狂暴只改变普攻扣血，不改变技能伤害数字。  
- 虚弱在「有护甲」时仍先加在进护甲前的伤害数字上（与 MAP_SHOP 护甲规则联测）。  
- 中毒在回合开始技能播报之前扣血；致死则本回合开始技能不播。  
- **遗骨**：战斗中被施加且层数 &gt; 0 的单位死亡后，若有空位，场上出现一只攻/血均等于当时遗骨层数的骷髅；该骷髅无遗骨、无主技能；溃散不生成；开战前单位信息卡无「自带遗骨」（除非本场已被技能挂上）。
