# 队伍羁绊台词（Party Bark）

> 功能规格 · 招募进队时的角色短句气泡 · 2026-10-23  
> 相关文档：[招募](./RECRUIT.md) · [战斗观战反馈](./COMBAT_FEEDBACK.md) · [角色单位](./UNITS.md) · [游戏愿景](../GAME_VISION.md)  
> 内容表见 [Content/UNIT_PARTY_BARKS_ROSTER.md](../Content/UNIT_PARTY_BARKS_ROSTER.md)。  
> **本版不写**：战斗观战中途插播、地图商店冒泡、多句对白树、语音资源表、精确字号像素定死。  
> **【定稿】** 仅**招募阶段**、角色**成功进队**后；纯表现 Flavor；**整局 Run 每条台词最多一次**；首案召魂×残影。  
> **【As-Is】** 见实现与资源；文档定稿 ≠ 未接场景时的旧行为。

## 1. 这是什么

**队伍羁绊台词**规定：当队伍凑齐某组角色时，在**招募界面上区纸片单位**旁弹出短句气泡，加强角色感与同队关系。

它**不是**技能、不是羁绊数值、不走 `EffectSpec` / `CombatEventBus` / 行动内播报。

体验目标：招人瞬间感到「这两人有关系」，而不干扰战斗观战主通道。

---

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 触发阶段与「进队」口径  
- Run 一次频次与重置关系  
- 说话人锚点与气泡表现下限  
- 与招募 / 观战反馈的分界  
- 首案验收口径  

### 2.2 和别处怎么分

| 本篇负责 | 别处负责 |
|----------|----------|
| 何时冒泡、谁说、频次、纯表现边界 | **招募**：招人/替换/重置/快照流程 |
| — | **战斗观战反馈**：技能卡、结果数字、行动者高亮（本系统不占用） |
| — | **Content 花名册**：具体台词与角色 id 组合 |
| — | **技术美术**：气泡贴图与九宫格边距 |

### 2.3 一句边界

本版**只做**招募进队后的短句气泡（表驱动；首条召魂→残影）。  
本版**不做**：准备阶段 / 开战锁阵 / 战斗中途冒泡；地图商店买人冒泡；Boss 胜后（无招募）；弱复制 token 计入组合；流派/小队标签喊话。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **Party Bark / 队伍台词** | 条件满足时的一句 Flavor 台词 |
| **说话人** | 气泡锚点的队伍成员（兵种 id） |
| **所需同队** | 当前队伍须同时拥有的兵种 id 集合（不含战斗代理/弱复制） |
| **进队结算** | 招募/替换（及满员可三合一买入）成功写入队伍之后 |
| **已播标记** | 本 Run 已播过的台词 id；整局持久 |

---

## 4. 触发【设计定稿】

| 项 | 定稿 |
|----|------|
| 阶段 | **仅招募阶段**（含开局招募与胜后招募） |
| 时机 | 一次**进队结算成功之后**（空席加入、满员替换、满员可三合一买入均算） |
| 条件 | 结算后队伍成员兵种集合满足该条「所需同队」；说话人仍在队伍中 |
| 不计 | 出售、换座、仅刷新候选人、重置回滚本身不触发；战斗生成的弱复制不计入 |
| 频次 | **整局 Run 每条台词 id 最多一次**；招募「重置」**不**清除已播标记 |
| 新 Run | 已播标记清空 |

多条同时可触发时：本版按表顺序取**第一条**未播且条件满足的台词；同帧只播一条。

---

## 5. 表现【设计定稿】

| 项 | 定稿 |
|----|------|
| 锚点 | 说话人在招募**上区**的纸片站位上方 |
| 形态 | 纸剪风对话气泡贴图 + 短文案；本版默认用**中号**气泡资源 |
| 交互 | **非模态**；不阻挡招募拖放/点击 |
| 寿命 | 自动淡出（约 2–4 秒）；可被下一条覆盖 |
| 文案 | 人类可读；禁止内部 id、流派/小队标签 |
| 与三合一 | 【建议】等本帧队伍 UI 同步后再挂气泡，避免叠在合成瞬间 |

---

## 6. 数据【设计定稿】

每条台词至少含：`id`、`speaker_unit_id`、`required_unit_ids`、`line`、触发阶段（本版固定招募进队）、`once_per_run`（本版恒 true）。

资源落点：`resources/barks/`；逻辑见 `PartyBarkService`（工作名）；UI 见招募 Arena 气泡控件。

---

## 7. 验收口径（玩家可观察）

1. 招募中招入后队伍同时有**召魂**与**残影**（兵种）时，召魂头顶冒出「你也来了」。  
2. 同 Run 内再招/再凑齐不再播。  
3. 招募重置后同 Run 仍不重播。  
4. 气泡不挡住后续招募操作。

轻量验收：加载烟测通过；效果由用户自验。
