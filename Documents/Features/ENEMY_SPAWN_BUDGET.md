# 层预算抽阵

> 功能规格 · 只谈敌方「按层预算抽人选阵并落座」的规则骨架，不写具体数值 · 2026-10-15  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [地图与节点](./MAP.md) · [角色单位](./UNITS.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：ε / κ / 层中线 P 的定稿曲线与表；单位预算点具体数字；阵型标签权重表；敌池花名册。  
> **【愿景已有】** 敌方按关卡占敌半场座位、开战锁阵中一次出齐；压力来自阵型与越线；Boss 超高单体威胁；出兵时机与生成序见战斗篇。  
> **【用户新共识】** 用「层预算」作**内部尺子**生成敌方阵容；**无**玩家战力 HUD；目标强度 E＝κ×层中线 P；宽带宽＋阵型标签（软约束）；独立敌池；落座近战前排 / 远程后排、同行高血优先与溢位；品阶硬、预算软；失败回退不退纯随机；Boss＝固定位＋剩余预算；精英同生成器更大 κ；开关兼容旧「出兵只数」；功能与数值分离。  
> **【实现】** Run 主路径已接 `EnemyBudgetSpawner` + `SpawnBudgetConfig`（`resources/spawn/default_spawn_budget.tres`）；`enabled=false` 可回旧 `spawn_count` 随机。具体 ε/κ/P 为占位可回调。  
> **【As-Is 兼容】** 关预算开关时：`WaveData.spawn_count` 从敌池按品阶过滤后随机抽只数；可有 `fixed_entries`。

## 1. 这是什么

**层预算抽阵**规定：进入一场战斗类遭遇时，系统如何根据**地图层进度**算出本场敌方强度目标，从**独立敌池**里抽出一队敌方角色，再按规则摆进**敌方角色座位**，供准备阶段预览、开战锁阵一次出齐。

玩家可见结果：敌半场座位上出现一队对手（可预览）。  
玩家**看不见**：预算数字、带宽、κ、层中线 P、抽选失败次数——这些是内部尺子，**不做战力 HUD**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 预算怎么定目标、怎么抽人、怎么落座、失败怎么回退 | **战斗**：何时生成、书写顺序 / 部署技能、行动队列 |
| 普通 / 精英 / Boss 在生成器上的差异 | **地图**：点哪个节点、层是什么 |
| 敌池独立、品阶硬过滤 | **角色单位**：近战 / 远程判定、生命等属性语义 |
| 开关如何兼容旧「出兵只数」 | **战斗关卡**：座位几何、前排 / 后排空间语义 |
| — | **数值**：ε / κ / P 曲线、单位强度分、标签权重（资源填空） |

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 内部尺子与玩家可见边界（无战力 HUD）  
- 目标强度、带宽、阵型标签（软）的功能关系  
- 独立敌池与品阶硬过滤  
- 抽阵主流程与失败回退阶梯（不退纯随机）  
- 落座：近战前排、远程后排；同行高血优先；溢位  
- Boss / 精英相对普通战的生成差异  
- 与旧「出兵只数」的开关兼容  
- 功能与数值分离约定、验收口径  

### 2.2 本版不做

- **不做**按玩家**当前真实队伍**动态加难。  
- **不做**为贴预算去**缩放**已抽出单位的生命 / 攻击等属性。  
- **不做**玩家侧战力评分或战力 HUD。  
- **不做**延时分批刷怪（出兵时机仍见战斗篇：开战一次出齐）。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **层中线 P** | 由当前地图**层进度**查表得到的基准强度；**不是**玩家战力。曲线由生成预算配置填空。 |
| **威胁系数 κ** | 节点类型乘数：普通 / 精英 / Boss；精英用同一生成器、更大 κ。 |
| **目标强度 E** | **E＝κ×层中线 P**。 |
| **带宽 ε** | 允许实际阵容强度总和落在目标附近的宽容差带（软）。 |
| **单位强度分 U** | 内部评估分（生命 / 攻击 / 粗 DPS / 技能系数 / 品阶）；队伍合计 P＝ΣU。公式见实现与数值资源，本文不定稿点数。 |
| **阵型标签** | 抽阵软偏好（如 frontline / skirmish / backline）；不硬锁结构。 |
| **独立敌池** | 专供遭遇抽敌的单位池；与商店 / 招募池数据上分池。 |
| **品阶硬过滤** | 当前进度允许的最高品阶之下才可入抽。 |
| **出兵只数** | 旧路径 `spawn_count` 随机刷怪数量；兼容开关见 §9。 |
| **固定位** | 遭遇预置必出单位（如 Boss）；先占预算与座位，再用剩余预算抽其余。 |

## 5. 目标强度与软约束

```text
层中线 P  ← 生成预算配置（按层）
威胁系数 κ ← 节点类型（普通 / 精英 / Boss）
目标强度 E ＝ κ × P
合法合计区间 ≈ ［E − ε, E ＋ ε］
```

- **普通**：基准 κ。  
- **精英**：同一生成器，更大 κ。  
- **Boss**：固定位优先，再用剩余预算（§8）。  
- **阵型标签**：软偏好；带宽优先于标签；不可破品阶硬过滤。  
- **不读玩家真队**抬高或压低 E。

---

## 6. 独立敌池与品阶硬过滤

1. 抽阵只从配置的**独立敌池**取单位（空池时可回退关卡 `enemy_pool` 并告警）。  
2. 先按进度做**品阶硬过滤**（与现有品阶解锁衔接）。  
3. 过滤后池为空：告警并走最小合法回退；不得默默用商店池冒充主路径。

---

## 7. 抽阵主流程

### 7.1 主路径

```text
1. 计算 E＝κ×P，取带宽 ε、阵型标签（若有）
2. 放入固定位（若有）：计入已用预算
3. 在品阶合法池中拒采样 / 填充，使 ΣU 尽量进入带宽；人数受敌座上限约束
4. 按 §8 落座，输出占座表（书写顺序＝开战生成序）
5. 交给战斗篇：准备可预览；开战按占座表依次生成、一次出齐
```

### 7.2 失败回退（不退纯随机）

| 阶梯 | 做什么 | 仍须遵守 |
|------|--------|----------|
| 1 | 同种子重抽若干次 | 品阶硬；不改属性 |
| 2 | 放宽带宽一档 | 品阶硬 |
| 3 | 降低 / 忽略阵型标签 | 品阶硬 |
| 4 | 有序替换靠近 E | 品阶硬；不引入池外单位 |
| 5 | 贪心保底编队贴近 E | 仍按落座规则；**不是**旧只数无预算乱抽 |

### 7.3 约束硬度

| 约束 | 硬度 |
|------|------|
| 品阶 | **硬** |
| 座位容量 | **硬** |
| 预算合计 | **软** |
| 阵型标签 | **软** |

## 8. 落座规则

与角色单位一致：`projectile_speed > 0` 为远程，否则近战。前排 / 后排仅开战落点（技能 / 索敌不认前后排标签）。

1. **先定行**：近战 → 前排；远程 → 后排。  
2. **同行内**：生命上限高者优先占座。  
3. **破平**：强度分 U，再稳定 id。  
4. **溢位**：近战多于前排 → 溢入后排；远程多于后排 → 溢入前排。  
5. **书写顺序**：建议先前排左→右，再后排；固定位优先生成（利于 Boss 部署时技能）。

## 9. Boss、精英与普通

| 节点 | 生成方式 |
|------|----------|
| **普通** | 全预算生成器；κ＝普通 |
| **精英** | 同一生成器；更大 κ |
| **Boss** | 固定位先入并计入已用预算；再用剩余预算填充 |

|------|------|

## 12. 与战斗三步的衔接

```text
进入战斗 / 精英 / Boss
  →【本篇】按层预算抽阵 → 敌方占座表（可预览）
  →【战斗】准备 → 开战锁阵按占座书写顺序生成 → 观战 → 结算
```

## 13. 验收口径

1. 进入普通战斗：准备阶段可见敌方占座预览；无战力 / 预算 HUD。  
2. 同一种子、同一层、同一节点类型：名单与占座可复现。  
3. 近战主要在前排、远程主要在后排；溢位规则可见。  
4. 精英更压（更大 κ），仍是同一套抽法。  
5. Boss 场固定位保留；其余由剩余预算填充。  
6. 不应出现超进度品阶敌人。  
7. 关掉预算开关后，旧 `spawn_count` 路径仍能开打。  
8. 失败时走回退阶梯，而非无预算纯随机。
