# 队伍强度抽阵

> 功能规格 · 只谈敌方「按玩家队伍强度定目标、抽人选阵并落座」的规则骨架，不写具体数值 · 2026-10-16  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [地图与节点](./MAP.md) · [角色单位](./UNITS.md) · [玩家](./PLAYER.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：κ / 带宽 ε / 层护栏上下限的定稿曲线与表；单位强度分具体公式点数；阵型标签权重表；敌池花名册。  
> **【用户新共识】** 普通/精英：进节点瞬间按**整局队伍强度 S** 定目标 **E＝κ×S**（精英更大 κ），再抽敌并锁名单；准备只预览+换座、开战前不重抽；**层进度**降为品阶硬过滤 + **E 上下限护栏**（非主尺子）；**Boss 不吃**真队目标（固定位 / 既有 Boss 路径）；本版队伍强度**不含增益卡**；不缩放已抽单位属性；无战力 HUD。  
> **【用户新共识 · 人数】** **普通**：敌方人数与**地图层号**绑定——第 1 层 **1～2**、第 2 层 **2～3**、第 3 层 **3～4**，依此类推（第 F 层 ∈ **[F, F＋1]**）；座位上限仍硬封顶。**精英**：＝N 或 **N＋2**（N＝队伍角色数）；**Boss**：**不跟随**人数规则。**第一关**（第 1 层）：精英人数仍 ≤ N；远程最多 1（普通 / 精英）。  
> **【用户新共识 · 敌池契约 A】** 抽阵敌池与可招募友方为**同种类镜像、分资源维护**：每个可招 id 须有对应 `enemy_<id>` 进默认敌池（熔印者不进敌池）；名单同步为内容契约，由测试守卫。  
> **【用户新共识 · 技能预期 · 深】** 单位强度分中的技能系数 α 默认由 **`SkillExpectation`** 按主技能 / 被动的触发时机 × 效果类型结构估算；可选 `skill_alpha_by_unit_id` 覆盖。全池 α **相对分化、均值锚定≈1.0**（不借技能轴整体加难）。熔印者用 **runtime 缝合主技能** 入尺。  
> **【用户新共识 · 层难度】** 整体难度随地图层深入上升：人数层绑定 + **层护栏下限硬夹** + **`floor_threat_growth`**（同队更深一层 E 更高）。  
> **【用户新共识 · 普通加压 · 2026-10-22】** 加强形态为**人数差不多、每个更凶 / 前排更压**（不优先加人）；**全层普通**抬难度，中后期尤甚，前期也略加。本轮手段：抬普通 κ / 层威胁 / 护栏与阵型权重，带宽内**偏向上沿**；**同场已选种类软降权**（尽量换面孔，贴不上 E 时仍允许重复）。**暂缓**：敌方三合一、改普通人数公式。  
> **【用户新共识 · 敌方 2★ · 2026-10-25】** 普通/精英**每一层**直接刷 **2★ 模板**（身体按三份底模加总语义 ≈×3；技能按该兵种 2★ 倍率；**不做**敌方队伍内真三合一）。只数＝进点瞬间整局队伍里**展示为 2★** 的成员数（3★ 不计；熔印者无星不计）；玩家没有 2★ 则敌方全是 1★。可升星座位不够时封顶，首领标记单位不占名额。Boss 节点不升星。返回的强度分 U 按 2★ 身体计。  
> **【用户新共识 · 敌方品阶缓释 · 2026-10-25】** 层解锁 T2/T3 **≠** 敌阵立刻饱和：在引入带内对敌方 **T2/T3 只数**硬封顶，并 **∩ 玩家队内同档人数 + 1**（有队伍时）；空队仍走层表 intro、不做玩家个数绑定。与 §6.2 同表；贴不上 E 走回退阶梯，**默认不**突破只数帽。  
> **【用户新共识 · 敌我攻血匹配 · 2026-10-25】** 「匹配」指 **阵容威胁 E/ΣU**（§2.3），**不是**逐单位把敌方生命/攻击改成与玩家同数字；弱队进深层时 **层护栏下限硬夹**（不因 S 低而低于本层 `floor_e_min`）。  
> **【实现】** Run 主路径 `EnemyBudgetSpawner` + `SpawnBudgetConfig` + `UnitPowerScore` / `SkillExpectation`；`enabled=false` 可回旧 `spawn_count` 随机。  
> **【As-Is 兼容】** 关预算开关时：`WaveData.spawn_count` 从敌池按品阶过滤后随机抽只数；可有 `fixed_entries`。

## 1. 这是什么

**队伍强度抽阵**规定：进入一场战斗类遭遇时，系统如何根据玩家**当前整局队伍**算出本场敌方强度目标，从**独立敌池**抽出一队敌方角色，再按规则摆进**敌方角色座位**，供准备阶段预览、开战锁阵一次出齐。

玩家可见结果：敌半场座位上出现一队对手（可预览）。  
玩家**看不见**：队伍强度分、目标 E、带宽、κ、护栏、抽选失败次数——这些是内部尺子，**不做战力 HUD**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 目标怎么定、怎么抽人、怎么落座、失败怎么回退 | **战斗**：何时生成、书写顺序 / 部署技能、行动队列 |
| 普通 / 精英 / Boss 在生成器上的差异 | **地图**：点哪个节点、层是什么 |
| 敌池独立、品阶硬过滤 | **角色单位**：近战 / 远程判定、生命等属性语义 |
| 开关如何兼容旧「出兵只数」 | **战斗关卡**：座位几何、前排 / 后排空间语义 |
| — | **数值**：κ、ε、层护栏表、单位强度分公式填空 |

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 内部尺子与玩家可见边界（无战力 HUD）  
- 队伍强度 S、目标 E、带宽、阵型标签（软）的功能关系  
- 评估对象与时机（整局队伍；进节点瞬间锁敌）  
- 独立敌池与品阶硬过滤；层进度作护栏  
- 抽阵主流程与失败回退阶梯（不退纯随机）  
- 落座：近战前排、远程后排；同行高血优先与溢位  
- Boss / 精英相对普通战的生成差异  
- 与旧「出兵只数」的开关兼容  
- 功能与数值分离约定、验收口径  

### 2.2 本版不做

- **不做**为贴预算去**缩放**已抽出单位的生命 / 攻击等属性。  
- **不做**玩家侧战力评分 HUD。  
- **不做**延时分批刷怪（出兵时机仍见战斗篇：开战一次出齐）。  
- **不做**开战前按本场入座阵重算或重抽敌阵。  
- **本版**队伍强度**不含**增益卡（当前设计无增益卡；若日后有增益，是否入尺另案）。

### 2.3 敌我攻血「匹配」口径【定稿 · 2026-10-25】

玩家与策划口语里的「每层敌人攻血要和队员匹配」，在本项目里指下面两条，**不**指进场后再改 `max_hp` / `attack` 字段。

| 定稿 | 含义 |
|------|------|
| **A · 阵容威胁匹配** | 进节点快照队伍强度 **S** → **E_raw＝κ×S×(1＋floor_threat_growth×(F−1))** → **E＝clamp(E_raw, floor_e_min, floor_e_max)**；抽敌使 **ΣU** 落在带宽内且**偏向上沿**（§5）。**U** 已含展示生命、攻击、粗输出与技能 α，故敌我「凶度」在内部尺子上对齐，而非卡牌上数字 1:1。 |
| **弱队仍被层托住** | 当 **κ×S×层威胁** 低于本层 **floor_e_min** 时，**E 抬到下限**，不因队伍养得差而整层变软；与人数随 F 增、品阶解锁等叠加。 |
| **敌模板** | 敌池与可招友方 **同 id 镜像**（`enemy_<id>`）；单场敌兵面板来自模板 + 星级模板（§敌方 2★ 共识），**不做**抽出后的属性乘算缩放（§2.2）。 |
| **Boss** | 不吃真队 **S** 定 **E**；不适用本节的「匹配」，走固定位高威胁。 |

**验收（功能）**：同层、同队快照下 E 可复现；弱队高层 E 不低于该层 `floor_e_min`；肥队 E 随 S 上升直至触顶 `floor_e_max`。具体 κ、护栏表、ε 由 `default_spawn_budget.tres` 与数值切片维护。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **队伍强度 S** | 对当前整局队伍每位成员算单位强度分再合计；**不含**站位、生成的代理角色、增益卡。 |
| **威胁系数 κ** | 节点类型乘数：普通 / 精英；Boss **不**用真队 κ 定 E。 |
| **目标强度 E** | 普通/精英：**E＝clamp(κ×S×层威胁乘数, floor_e_min, floor_e_max)**；Boss：不吃真队目标。 |
| **层护栏** | 按地图层进度给出的 E 下限 / 上限；真队定中心，层定护栏。 |
| **带宽 ε** | 允许实际阵容强度总和落在目标附近的宽容差带（软）。 |
| **单位强度分 U** | 内部评估分（生命 / 攻击 / 粗输出 / 技能系数 / 品阶）；友方与敌方同族尺子。公式见实现与数值资源，本文不定稿点数。 |
| **阵型标签** | 抽阵软偏好（如 frontline / skirmish / backline）；不硬锁结构。 |
| **独立敌池** | 专供遭遇抽敌的单位池；与招募池**种类镜像、资源分家**（契约 A）。 |
| **技能预期 α** | 由技能结构估出的强度乘数；标准技能≈1.0，召唤/再动等更高，白板≈0.85。 |
| **层威胁增长** | `E_raw＝κ×S×(1＋growth×(F−1))`；再经层护栏夹紧。 |
| **品阶硬过滤** | 当前进度允许的最高品阶之下才可入抽。 |
| **品阶缓释带** | 层解锁后一段时间内限制敌方 T2/T3 **只数**；见 §6.2。 |
| **玩家同档绑定** | 有队伍时：敌方 T2/T3 只数 ≤ 玩家队内该档人数 + 1。 |
| **出兵只数** | 旧路径 `spawn_count` 随机刷怪数量；兼容开关见 §9。 |
| **固定位** | 遭遇预置必出单位（如 Boss）；Boss 场优先，不吃真队剩余预算逻辑。 |

## 5. 目标强度与软约束

### 5.1 普通 / 精英

```text
队伍强度 S  ← 整局队伍成员（进节点瞬间快照；身体 + 技能预期 α）
威胁系数 κ ← 节点类型（普通 / 精英；精英更大）
层威胁乘数 ← 1 ＋ floor_threat_growth × (F − 1)
E_raw ＝ κ × S × 层威胁乘数
目标强度 E ＝ clamp(E_raw, 本层下限, 本层上限)   ## 下限硬夹，不因弱队软化
合法合计区间 ≈ ［E − ε, E ＋ ε］
```

- **普通**：基准 κ。  
- **精英**：同一生成器、同一套真队尺子，更大 κ。  
- **层难度**：人数随 F 增 + 护栏上下限随层升 + 层威胁乘数；保证越深层整体更难。  
- **阵型标签**：软偏好；带宽优先于标签；不可破品阶硬过滤。可配置权重（本轮前排 / 游走高于后排）。  
- **带宽偏好**：合法合计落在带宽内时，**偏向上沿**（ΣU ≥ E 优先于对称贴中）。  
- **同场软去重**：抽人 / 贪心保底均**优先未选种类**；仅当池内种类不够填满人数时才按降权允许重复。拒采样同误差时面孔更散优先。带宽 / 人数硬约束仍优先。  
- **读玩家真队**：是（仅普通 / 精英目标）。

### 5.2 Boss

- **不吃**真队目标：不按 S 定 E，不按剩余真队预算填杂兵。  
- **不跟随**「人数≈玩家阵容」规则（§5.4）。  
- 固定首领位（及关卡写死的跟班若有）走既有 Boss 路径。  
- 层进度仍可影响品阶过滤等硬约束（若 Boss 池适用）。

### 5.4 敌方人数约束【定稿】

| 节点 | 敌方人数目标 |
|------|----------------|
| **普通** | 与**地图层号 F**绑定：第 F 层在 **[F, F＋1]** 内掷点（第 1 层 1～2、第 2 层 2～3…）。`floor_index`≤0 按第 1 层。**不再**按队伍人数 N 封顶。 |
| **精英** | 以进点瞬间队伍成员数 N 为基准（N≥1；空队保底见实现）：**＝ N** 或 **N＋2** |
| **Boss** | **不跟随**；固定位 / 既有路径 |

人数硬约束优先于「尽量贴满带宽」；**敌方座位上限**仍硬封顶（可裁切掷出人数）。

#### 第一关（地图第 1 层；`floor_index`≤1）特例【定稿】

| 约束 | 规则 |
|------|------|
| **普通人数** | 仍走层绑定（1～2）；不另用 N 封顶 |
| **精英人数** | **不得超过** N（关闭 N＋2） |
| **远程** | 敌方阵容**最多 1** 个远程单位（`UnitPowerScore.is_ranged`；普通 / 精英） |

**非第一关远程上限【用户新共识】**：普通 / 精英在 n≥2 时**禁止全远程**；远程最多 **⌈0.4n⌉**（且 ≤ n−1）。后排阵型标签可偏好远程，但须至少 1 近战。Boss 节点仍不跟随本表人数 / 远程特例。

### 5.3 评估对象与时机【定稿】

| 项 | 约定 |
|----|------|
| **对象** | 整局队伍成员（星级后身体 + 技能预期 α）；熔印者含 runtime 主技能；不含站位、代理、增益卡 |
| **时机** | **进入**战斗 / 精英节点**瞬间**计算 S、抽敌并**锁名单** |
| **准备** | 只预览已锁敌阵；可换己方座位；**不可**改队伍构成；**不可**重抽敌 |
| **开战前** | **不**重算、不重抽 |

## 6. 独立敌池与品阶硬过滤

1. 抽阵只从配置的**独立敌池**取单位（空池时可回退关卡 `enemy_pool` 并告警）。  
2. **内容契约 A**：默认敌池种类集合 ≡ 默认可招募友方集合（`enemy_<ally_id>` 镜像）；熔印者不进敌池；新增可招角色须同步镜像敌资源并挂入两池。  
3. 先按**地图层号**做**品阶硬过滤**（`TierUnlock`：第 1–3 层最高 T1，**第 4 层起 T2**，**倒数 6 层起 T3**；与招募最高档同表）；有真队时还可 ∩ 玩家队伍最高品阶。敌池不过滤最低档（招募倒数档踢 T1 仅作用于候选人池）。  
4. 过滤后池为空：告警并走最小合法回退；不得默默用商店池冒充主路径。

### 6.1 单位强度分与技能预期（功能）

```text
U ＝ 身体项(展示生命 / 攻击 / 粗输出，溅射修正) × α_skill × 品阶因子
α_skill ＝
  显式表 skill_alpha_by_unit_id[id]（敌 id 可回退去 enemy_ 前缀）
  否则 SkillExpectation：触发权重 × 效果族权重 × 目标范围 × 条件可靠度
           → 映射到 α（标准 raw≈1.0 → α≈1.0；夹在约 0.85～1.40）
```

- **锚点**：全池相对分化，标准技能附近 α≈1.0，**不**用技能轴整体抬难度。  
- **熔印者**：身体用有效展示攻血；α 用 runtime 缝合主技能深评分。  
- **点数与权重表**：实现默认见 `SkillExpectation` / `SpawnBudgetConfig`；大调参走数值切片。

### 6.2 敌方 T2 / T3 缓释（只数硬封顶）【定稿 · 2026-10-25】

在 §6 品阶**池过滤**（`pool_ceiling`）之后、拒采样 / 贪心填人时，对**填充单位**（非 `fixed_entries`）统计已选 `tier`，不得超过本场 **有效只数帽**。不削弱 T2/T3 模板攻血；延后的是**出场个数**。

#### 6.2.1 池天花板（不变）

```text
map_max    ← TierUnlock.get_max_unlocked_tier(F, floor_count)
player_max ← 队伍成员 UnitData.tier 最大值（无成员 / 空队时不参与）
pool_ceiling = 有队伍 ? min(map_max, player_max) : map_max
敌候选：tier ≤ pool_ceiling
```

#### 6.2.2 层表只数帽 `cap_layer`

记本场敌方目标人数 **n**（§5.4）、地图层 **F**（1-based）、`F2 = TierUnlock.T2_FROM_FLOOR`（默认 4）、`F3 = floor_count − TierUnlock.LATE_BAND_FLOORS + 1`（默认 15 幕 → 10）。

**T2 只数帽** `t2_layer(F, n)`（`F < F2` 时为 0）：

| 条件 | `t2_layer` |
|------|------------|
| `F == F2` | `1` |
| `F == F2 + 1` | `min(2, n)` |
| `F == F2 + 2` 且 `n ≥ 2` | `min(⌈n/2⌉, n − 1)` |
| `F2 + 3 ≤ F < F3` | `min(⌈0.75·n⌉, n)` |
| `F ≥ F3`（T3 层带已开） | `n`（T2 只数不再单独限；由 T3 帽与池天花板约束） |

**T3 只数帽** `t3_layer(F, n)`（仅 `F ≥ F3` 时可能 > 0；此前为 0）：

| 条件 | `t3_layer` |
|------|------------|
| `F == F3` | `1` |
| `F == F3 + 1` | `min(2, n)` |
| `F == F3 + 2` 且 `n ≥ 2` | `min(⌈n/2⌉, n − 1)` |
| `F ≥ F3 + 3` | `min(⌈0.75·n⌉, n)` |

**精英**：`t2_layer` / `t3_layer` 各 **+1**，再 `min(·, n)`。  
**第一关**（`F ≤ 1`）：`t2_layer = t3_layer = 0`（与远程特例并列）。  
**Boss**：`fixed_entries` / 首领固定位 **不计入**只数、**不受**本节帽（杂兵填充仍受帽）。

#### 6.2.3 玩家同档绑定【定稿】

进点瞬间统计队伍（与算 S 同快照；只看 `UnitData.tier`，不含站位）：

```text
P2 = 队内 tier==2 的人数
P3 = 队内 tier==3 的人数
```

| 队伍 | 有效帽 |
|------|--------|
| **有成员** | `t2_cap = min(t2_layer, P2 + 1)`；`t3_cap = min(t3_layer, P3 + 1)` |
| **空队** | `t2_cap = t2_layer`；`t3_cap = t3_layer`（**仅**走层表 intro，不做 `P+1` 绑定） |

填人时：已选 T2 ≥ `t2_cap` 则候选剔除 `tier==2`；已选 T3 ≥ `t3_cap` 则剔除 `tier==3`。固定位先计入对应 tier 计数。

#### 6.2.4 与预算 / 回退

- 只数帽 **硬**；带宽贴 E、阵型标签、种类软去重 **不得**突破 `t2_cap` / `t3_cap` 与 `pool_ceiling`。  
- 因帽过严导致 ΣU 偏低：按 §7.3 回退（放宽带宽 → 降标签 → 有序替换 → 贪心保底）；**默认**回退阶梯**不**提高 T2/T3 只数帽（数值可配「最后一档 +1 T2」开关，主路径 **关**）。  
- **可选软权重**（实现可后补）：intro 前 3 层内单次 roll 对 T2/T3 乘 `intro_weight`（F2→0.35，F2+1→0.55，F2+2→0.75，其后 1.0）；T3 引入带同理以 `F3` 为起点。硬帽优先于权重。

#### 6.2.5 配置落点（实现时）

`SpawnBudgetConfig` 或 `EnemyTierIntroConfig`：层偏移表、`elite_bonus`、是否启用玩家绑定、空队行为；默认与上表一致。`floor_count` 变化时 `F3` 随 `TierUnlock` 重算。

## 7. 抽阵主流程

### 7.1 主路径（普通 / 精英）

```text
1. 进节点瞬间：读整局队伍 → 算 S → E_raw＝κ×S×层威胁乘数 → 护栏夹紧得 E；取带宽 ε、阵型标签（若有）
2. 放入固定位（若有）：计入已用预算
3. 在品阶合法池中拒采样 / 填充，使 ΣU 尽量进入带宽；遵守 §6.2 T2/T3 只数帽；人数受敌座上限约束
4. 按 §8 落座，输出占座表（书写顺序＝开战生成序）；锁名单
5. 交给战斗篇：准备可预览；开战按占座表依次生成、一次出齐
```

### 7.2 Boss 路径

```text
1. 跳过「真队定 E」
2. 固定位（首领等）优先；不按 S 填剩余杂兵
3. 落座 → 准备预览 → 开战一次出齐
```

### 7.3 失败回退（不退纯随机）

| 阶梯 | 做什么 | 仍须遵守 |
|------|--------|----------|
| 1 | 同种子重抽若干次 | 品阶硬；不改属性 |
| 2 | 放宽带宽一档 | 品阶硬 |
| 3 | 降低 / 忽略阵型标签 | 品阶硬 |
| 4 | 有序替换靠近 E | 品阶硬；不引入池外单位 |
| 5 | 贪心保底编队贴近 E | 仍按落座规则；**不是**旧只数无预算乱抽 |

### 7.4 约束硬度

| 约束 | 硬度 |
|------|------|
| 品阶（池过滤） | **硬** |
| T2/T3 只数帽（§6.2） | **硬** |
| 座位容量 | **硬** |
| 预算合计 | **软**（合法解偏向上沿） |
| 阵型标签 | **软** |
| 同场种类去重 | **软**（降权；不硬禁） |
| 层护栏夹紧后的 E | **硬边界**（目标本身被夹紧） |

## 8. 落座规则

与角色单位一致：`projectile_speed > 0` 为远程，否则近战。前排 / 后排仅开战落点（技能 / 索敌不认前后排标签）。

1. **先定行**：近战 → 前排；远程 → 后排。  
2. **同行内**：生命上限高者优先占座；列序从中间向两侧（5 列标签「53124」，填充中→右→左→远右→远左）。  
3. **破平**：强度分 U，再稳定 id。  
4. **溢位**：近战多于前排 → 溢入后排；远程多于后排 → 溢入前排。  
5. **书写顺序**：先前排再后排（座位索引升序）；Boss 首领落**后排水平居中**。  
6. **友方默认空座**：同一中心向外列序（`SeatLayout` / `DeckState.find_first_empty_seat`）。

## 13. 验收口径

1. 进入普通战斗：准备阶段可见敌方占座预览；无战力 / 预算 HUD。  
2. 同一种子、同一队伍快照、同一节点类型：名单与占座可复现。  
3. 近战主要在前排、远程主要在后排；溢位规则可见。  
4. 精英更压（更大 κ），仍是同一套抽法。  
5. Boss 场不按玩家队伍强度加码；固定首领保留。  
6. 不应出现超进度品阶敌人；T2/T3 只数不超过 §6.2 有效帽（含玩家 `P+1` 绑定）。  
7. 关掉预算开关后，旧 `spawn_count` 路径仍能开打。  
8. 失败时走回退阶梯，而非无预算纯随机。  
9. 进点后换座不改变已锁敌阵；开战前不重抽。
