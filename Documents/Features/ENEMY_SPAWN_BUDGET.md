# 队伍强度抽阵

> 功能规格 · 只谈敌方「按玩家队伍强度定目标、抽人选阵并落座」的规则骨架，不写具体数值 · 2026-10-16  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [地图与节点](./MAP.md) · [角色单位](./UNITS.md) · [玩家](./PLAYER.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：κ / 带宽 ε / 层护栏上下限的定稿曲线与表；单位强度分具体公式点数；阵型标签权重表；敌池花名册。  
> **【用户新共识】** 普通/精英：进节点瞬间按**整局队伍强度 S** 定目标 **E＝κ×S**（精英更大 κ），再抽敌并锁名单；准备只预览+换座、开战前不重抽；**层进度**降为品阶硬过滤 + **E 上下限护栏**（非主尺子）；**Boss 不吃**真队目标（固定位 / 既有 Boss 路径）；本版队伍强度**不含增益卡**；不缩放已抽单位属性；无战力 HUD。  
> **【用户新共识 · 人数】** **普通**：敌方人数尽可能＝玩家阵容人数 N，**偶发 N＋1**；**精英**：＝N 或 **N＋2**；**Boss**：**不跟随**人数规则。  
> **【实现】** Run 主路径 `EnemyBudgetSpawner` + `SpawnBudgetConfig`；`enabled=false` 可回旧 `spawn_count` 随机。  
> **【As-Is 兼容】** 关预算开关时：`WaveData.spawn_count` 从敌池按品阶过滤后随机抽只数；可有 `fixed_entries`。

---

## 1. 这是什么

**队伍强度抽阵**规定：进入一场战斗类遭遇时，系统如何根据玩家**当前整局队伍**算出本场敌方强度目标，从**独立敌池**抽出一队敌方角色，再按规则摆进**敌方角色座位**，供准备阶段预览、开战锁阵一次出齐。

玩家可见结果：敌半场座位上出现一队对手（可预览）。  
玩家**看不见**：队伍强度分、目标 E、带宽、κ、护栏、抽选失败次数——这些是内部尺子，**不做战力 HUD**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 目标怎么定、怎么抽人、怎么落座、失败怎么回退 | **战斗**：何时生成、书写顺序 / 部署技能、行动队列 |
| 普通 / 精英 / Boss 在生成器上的差异 | **地图**：点哪个节点、层是什么 |
| 敌池独立、品阶硬过滤 | **角色单位**：近战 / 远程判定、生命等属性语义 |
| 开关如何兼容旧「出兵只数」 | **战斗关卡**：座位几何、前排 / 后排空间语义 |
| — | **数值**：κ、ε、层护栏表、单位强度分公式填空 |

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 内部尺子与玩家可见边界（无战力 HUD）  
- 队伍强度 S、目标 E、带宽、阵型标签（软）的功能关系  
- 评估对象与时机（整局队伍；进节点瞬间锁敌）  
- 独立敌池与品阶硬过滤；层进度作护栏  
- 抽阵主流程与失败回退阶梯（不退纯随机）  
- 落座：近战前排、远程后排；同行高血优先与溢位  
- Boss / 精英相对普通战的生成差异  
- 与旧「出兵只数」的开关兼容  
- 功能与数值分离约定、验收口径  

### 2.2 本版不做

- **不做**为贴预算去**缩放**已抽出单位的生命 / 攻击等属性。  
- **不做**玩家侧战力评分 HUD。  
- **不做**延时分批刷怪（出兵时机仍见战斗篇：开战一次出齐）。  
- **不做**开战前按本场入座阵重算或重抽敌阵。  
- **本版**队伍强度**不含**增益卡（当前设计无增益卡；若日后有增益，是否入尺另案）。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **队伍强度 S** | 对当前整局队伍每位成员算单位强度分再合计；**不含**站位、生成的代理角色、增益卡。 |
| **威胁系数 κ** | 节点类型乘数：普通 / 精英；Boss **不**用真队 κ 定 E。 |
| **目标强度 E** | 普通/精英：**E＝κ×S**，再经层护栏夹紧；Boss：不吃真队目标。 |
| **层护栏** | 按地图层进度给出的 E 下限 / 上限；真队定中心，层定护栏。 |
| **带宽 ε** | 允许实际阵容强度总和落在目标附近的宽容差带（软）。 |
| **单位强度分 U** | 内部评估分（生命 / 攻击 / 粗输出 / 技能系数 / 品阶）；友方与敌方同族尺子。公式见实现与数值资源，本文不定稿点数。 |
| **阵型标签** | 抽阵软偏好（如 frontline / skirmish / backline）；不硬锁结构。 |
| **独立敌池** | 专供遭遇抽敌的单位池；与商店 / 招募池数据上分池。 |
| **品阶硬过滤** | 当前进度允许的最高品阶之下才可入抽。 |
| **出兵只数** | 旧路径 `spawn_count` 随机刷怪数量；兼容开关见 §9。 |
| **固定位** | 遭遇预置必出单位（如 Boss）；Boss 场优先，不吃真队剩余预算逻辑。 |

## 5. 目标强度与软约束

### 5.1 普通 / 精英

```text
队伍强度 S  ← 整局队伍成员（进节点瞬间快照）
威胁系数 κ ← 节点类型（普通 / 精英；精英更大）
E_raw ＝ κ × S
目标强度 E ＝ clamp(E_raw, 本层下限, 本层上限)
合法合计区间 ≈ ［E − ε, E ＋ ε］
```

- **普通**：基准 κ。  
- **精英**：同一生成器、同一套真队尺子，更大 κ。  
- **阵型标签**：软偏好；带宽优先于标签；不可破品阶硬过滤。  
- **读玩家真队**：是（仅普通 / 精英目标）。

### 5.2 Boss

- **不吃**真队目标：不按 S 定 E，不按剩余真队预算填杂兵。  
- **不跟随**「人数≈玩家阵容」规则（§5.4）。  
- 固定首领位（及关卡写死的跟班若有）走既有 Boss 路径。  
- 层进度仍可影响品阶过滤等硬约束（若 Boss 池适用）。

### 5.4 敌方人数约束【定稿】

以进点瞬间玩家**队伍成员数**为基准 N（N≥1；空队保底见实现）。

| 节点 | 敌方人数目标 |
|------|----------------|
| **普通** | 尽可能 **＝ N**；允许**部分场次 N＋1** |
| **精英** | **＝ N** 或 **N＋2** |
| **Boss** | **不跟随**；固定位 / 既有路径 |

人数硬约束优先于「尽量贴满带宽」；座位上限仍硬封顶。

### 5.3 评估对象与时机【定稿】

| 项 | 约定 |
|----|------|
| **对象** | 整局队伍成员（星级后身体 + 技能系数）；不含站位、代理、增益卡 |
| **时机** | **进入**战斗 / 精英节点**瞬间**计算 S、抽敌并**锁名单** |
| **准备** | 只预览已锁敌阵；可换己方座位；**不可**改队伍构成；**不可**重抽敌 |
| **开战前** | **不**重算、不重抽 |

## 6. 独立敌池与品阶硬过滤

1. 抽阵只从配置的**独立敌池**取单位（空池时可回退关卡 `enemy_pool` 并告警）。  
2. 先按进度做**品阶硬过滤**（与现有品阶解锁衔接）。  
3. 过滤后池为空：告警并走最小合法回退；不得默默用商店池冒充主路径。

---

## 7. 抽阵主流程

### 7.1 主路径（普通 / 精英）

```text
1. 进节点瞬间：读整局队伍 → 算 S → E_raw＝κ×S → 护栏夹紧得 E；取带宽 ε、阵型标签（若有）
2. 放入固定位（若有）：计入已用预算
3. 在品阶合法池中拒采样 / 填充，使 ΣU 尽量进入带宽；人数受敌座上限约束
4. 按 §8 落座，输出占座表（书写顺序＝开战生成序）；锁名单
5. 交给战斗篇：准备可预览；开战按占座表依次生成、一次出齐
```

### 7.2 Boss 路径

```text
1. 跳过「真队定 E」
2. 固定位（首领等）优先；不按 S 填剩余杂兵
3. 落座 → 准备预览 → 开战一次出齐
```

### 7.3 失败回退（不退纯随机）

| 阶梯 | 做什么 | 仍须遵守 |
|------|--------|----------|
| 1 | 同种子重抽若干次 | 品阶硬；不改属性 |
| 2 | 放宽带宽一档 | 品阶硬 |
| 3 | 降低 / 忽略阵型标签 | 品阶硬 |
| 4 | 有序替换靠近 E | 品阶硬；不引入池外单位 |
| 5 | 贪心保底编队贴近 E | 仍按落座规则；**不是**旧只数无预算乱抽 |

### 7.4 约束硬度

| 约束 | 硬度 |
|------|------|
| 品阶 | **硬** |
| 座位容量 | **硬** |
| 预算合计 | **软** |
| 阵型标签 | **软** |
| 层护栏夹紧后的 E | **硬边界**（目标本身被夹紧） |

## 8. 落座规则

与角色单位一致：`projectile_speed > 0` 为远程，否则近战。前排 / 后排仅开战落点（技能 / 索敌不认前后排标签）。

1. **先定行**：近战 → 前排；远程 → 后排。  
2. **同行内**：生命上限高者优先占座。  
3. **破平**：强度分 U，再稳定 id。  
4. **溢位**：近战多于前排 → 溢入后排；远程多于后排 → 溢入前排。  
5. **书写顺序**：建议先前排左→右，再后排；固定位优先生成（利于 Boss 部署时技能）。

## 12. 与战斗三步的衔接

```text
进入战斗 / 精英 / Boss
  →【本篇】按队伍强度（或 Boss 路径）抽阵 → 敌方占座表（可预览）
  →【战斗】准备 → 开战锁阵按占座书写顺序生成 → 观战 → 结算
```

## 13. 验收口径

1. 进入普通战斗：准备阶段可见敌方占座预览；无战力 / 预算 HUD。  
2. 同一种子、同一队伍快照、同一节点类型：名单与占座可复现。  
3. 近战主要在前排、远程主要在后排；溢位规则可见。  
4. 精英更压（更大 κ），仍是同一套抽法。  
5. Boss 场不按玩家队伍强度加码；固定首领保留。  
6. 不应出现超进度品阶敌人。  
7. 关掉预算开关后，旧 `spawn_count` 路径仍能开打。  
8. 失败时走回退阶梯，而非无预算纯随机。  
9. 进点后换座不改变已锁敌阵；开战前不重抽。
