# 角色单位（Feature）

> 功能规格 · 与具体数值分离 · 2026-10-12  
> 胜负与主题以 [GAME_VISION.md](../GAME_VISION.md) 为准；技能积木见 [ABILITIES.md](../ABILITIES.md)；商店见 [SHOP_SYSTEM.md](../SHOP_SYSTEM.md)；增益见 [BUFF_SYSTEM.md](../BUFF_SYSTEM.md)；角色一览（Content）见 [UNITS_ROSTER.md](../UNITS_ROSTER.md)。  
> **本版不定**：攻/血点数、暴击百分比、移动步数表、伤害公式系数（交 `balance-designer` / 战斗 System）。

## 1. 一句话 / 乐趣位置

**角色单位**定义棋盘上一切可战斗实体——玩家可购角色、敌方单位、召唤 token——在 **构筑 → 布阵 → 开战看戏** 中共用的身份、属性、技能槽与流派分类契约。

| 阶段 | 单位贡献 |
|------|----------|
| 构筑 | 可购角色作为商店商品；内建技能与流派标签决定构筑方向 |
| 布阵 | 生命 / 攻击 / 移动画像决定站位价值 |
| 开战 | 普攻循环（攻击方式）与事件联动（技能）两套系统兑现；清波制胜负见愿景 |

深度公式（v1）：单位内建联动 + 站位 + 增益卡；**无羁绊**。

---

## 2. 范围与非范围

### 2.1 In-scope

- 单位三类：可购友方 / 敌方 / token
- 功能属性大类：生命、攻击、移动
- 并列元数据：身份、技能槽、流派标签（设计层）
- 固有底板 vs 牌库成长 vs 战斗临时 的分层
- 召唤关系与 token 最小契约
- 站位空间契约（高层）
- 与商店 / 增益 / 战斗 System 的接口声明

### 2.2 Out-of-scope / 本版不写（延后）

| 项 | 状态 |
|----|------|
| 主题换皮、命名故事、概念包装 | **本版不写**（附录 A） |
| 商店期单位乐趣权重（OnBuy/OnSell 等体验权重） | **延后** |
| 攻击特例实现细节（如特殊命中形状的单位级实现） | **延后**（附录 B） |
| 种族/职业羁绊 | **v1 不做** |
| 装备物品 | **非本 Feature 主轴** |
| 具体数值与平衡表 | **交数值策划** |
| Ability 触发器/目标/效果枚举全文 | **见 ABILITIES** |

### 2.3 相邻边界

| 归属本 Feature | 相邻 |
|----------------|------|
| 单位是什么、有哪些功能属性、三类差异 | **商店**：roll、定价、合并升级流程 |
| 技能槽「必须挂什么」 | **Ability System**：触发×目标×效果积木 |
| 单位可被增益挂载（可购） | **增益**：Buff 规则与附加 UI |
| 上场后参与清波 | **战斗 / 遭遇**：刷怪、tick、胜负判定 |

## 3. 单位三类

| 类别 | 定义 | 进入方式 |
|------|------|----------|
| **可购** | 玩家商店可获得的友方角色 | 商店角色池 → 牌库条目 → 布阵上场 |
| **敌** | 遭遇/波次中的敌方实体 | 刷怪 / 遭遇配置 |
| **Token** | 由技能或效果生成的临时单位 | `SPAWN` 类效果等；默认不入商店、不进牌库成长 |

三类共用同一套生命 / 攻击 / 移动功能骨架；差异见 §5.4 与 §10。

---

## 4. 设计维度总览

```text
元数据：身份 · 技能槽 · 流派标签
战斗大类：生命 · 攻击 · 移动
关系：召唤来源（token）
接口：经济字段（与商店契约，本 Feature 只声明有无）
```

| 维度 | 为何不是「第四战斗属性」 |
|------|--------------------------|
| 身份 | 决定商品边界、阵营、胜负归属，不直接进单次伤害公式 |
| 技能槽 | 事件联动来源，与普攻循环正交 |
| 流派标签 | 设计分类与教学索引，**非**羁绊计数 |

## 5. 属性规格

### 5.1 生命

| 子属性 | 功能定义 | 构筑 / 布阵 / 开战 |
|--------|----------|-------------------|
| **生命上限** | 可承受伤害的上限 | 前排承伤预期；死亡触发链门槛 |
| **当前生命** | 战斗中实时生命 | 仅运行时；上场通常从有效上限开始 |

可被牌库成长与战斗临时修饰（见 §6）。**具体点数未定稿。**

### 5.2 攻击

#### 5.2.1 子属性

| 子属性 | 功能定义 | 说明 |
|--------|----------|------|
| **攻击力** | 伤害侧的**统一数值输入** | 普攻伤害 = **基于攻击力的公式**；具体式子/系数交 balance 与战斗 System，**本版不定** |
| **攻击范围** | 发起普攻所需的空间距离 | 与矩形棋盘、现有战斗距离语义一致；**格数未定稿** |
| **攻击暴击率** | 暴击判定的概率输入 | **百分比未定稿** |
| **攻击方式** | **普攻循环**如何选目标、如何出手 | 与技能槽**分立**（§5.2.2） |

**已取消**：独立「攻击基础伤害」属性。伤害侧不以第二套「基础伤害」字段与攻击力并列。

#### 5.2.2 攻击方式 vs 技能（两套系统）【锁定】

| 系统 | 职责 | 不职责 |
|------|------|--------|
| **攻击方式** | 定义普攻循环：是否普攻、打多远、以何种形态出手 | 不描述事件连锁的完整联动逻辑 |
| **技能槽** | 内建触发 → 效果（可含伤害、召唤、增益等） | 不重新定义「普攻怎么打」 |

技能造成的伤害可以**引用攻击力**（同一输入），但仍属技能系统产出。

#### 5.2.3 攻击方式（高层）

| 模式 | 一句话 |
|------|--------|
| **标准普攻** | 按攻击范围对目标造成基于攻击力的普攻伤害 |
| **无普攻** | 不走普攻循环；输出主要依赖技能等 |
| **特殊攻击形态（扩展槽）** | 改变普攻命中形状或出手时机的扩展位 |

**待定**：「远程」是单独攻击方式，还是「标准普攻 + 更大攻击范围」（见 §13）。  
**本版不写**：特殊形态的单位级实现细则（附录 B）。

### 5.3 移动

| 子属性 | 功能定义 |
|--------|----------|
| **移动方式** | 如何选择目标格与路径形态 |
| **移动距离** | 每行动轮内，移动方式所允许的位移额度（量纲由数值定；**本版无步数表**） |
| **可否移动** | 本场是否执行位移（可为固有，或由规则标记覆盖） |

移动方式与移动距离**正交**：方式决定「怎么走」，距离决定「能走多远」。

#### 5.3.1 移动方式 — 当前设计提案（待确认可升定稿）

下列 6 类为讨论中的**功能有限集提案**。用户尚未口头确认「采用」；**若后续无异议，可升为定稿**（见 §13）。

| 玩法名 | 一句话行为 |
|--------|------------|
| **标准步进** | 沿格逐步靠近目标；每回合能走多远由移动距离约束 |
| **快步进** | 同标准步进，但移动距离相对更大（功能分类，不定具体步数） |
| **滑移** | 沿直线连续占格，直到阻挡或边界 |
| **跳跃** | 忽略中间格，落到规则允许的远格 |
| **传送接近** | 不走路径，直接出现在靠近目标的合法空格 |
| **不可移动** | 本场不执行位移 |

**待定**：滑移是否在本版拆子型（横纵 / 对角 / 全向）（见 §13）。

#### 5.3.2 As-Is 实现参考（非设计定稿）

实现侧存在更细的移动行为拆分（多种步进/滑移/跳跃/传送等）及「每回合移动量」字段。功能规格以 §5.3.1 提案为准做收束；实现映射由程序在定稿后对齐。**勿将代码枚举直接当作设计定稿。**

### 5.4 三类单位适用性

| 大类 / 子项 | 可购 | 敌 | Token |
|-------------|------|-----|-------|
| 身份·类别 | 必填 | 必填 | 必填 |
| 进商店池 | 是 | 否 | 否 |
| 技能槽·主技能 | **必填** | 可选 | 可选 |
| 技能槽·被动 | 可选 | 可选 | 可选 |
| 流派标签 | 建议 ≥1 | 可选 | 可选 |
| 生命 / 攻击 / 移动 | 必填 | 必填 | 必填（可极简） |
| 牌库成长 | **适用** | 不适用 | **默认不适用** |
| 召唤来源 | 可选 | 不适用 | **建议必填** |
| 经济·Tier/cost | 必填（接口） | 不适用 | 不适用 |
| 经济·击杀掉金 | 可选 | 建议有 | 可选 |

## 6. 固有 vs 牌库成长 vs 战斗临时

| 层 | 涵盖 | 生命周期 |
|----|------|----------|
| **固有** | 身份、内建技能挂载、生命/攻击/移动**底板** | 单位模板级 |
| **牌库成长** | 星级、永久属性加成、部分规则标记 | Run 内、牌库条目级；**默认可购适用** |
| **战斗临时** | 本场对攻/血/距/暴击等的修饰 | 单波战斗；结束清空 |
| **规则标记** | 如不可移动 | 常由增益写入条目，开战同步到实例 |

```text
Unit 固有底板
  → DeckEntry 成长 / 增益 / 规则（可购）
    → 战场实例（当前生命 + 战斗临时修饰）
```

星级与经验阈值、升级加成为**牌库条目**规则，详见商店文档；本 Feature 只锁定「成长不在敌/token 默认路径上」。

## 7. 技能槽契约

| 槽 | 规则 |
|----|------|
| **主技能（ability）** | 可购单位**必须**配置；描述以「触发 + 目标 + 效果」可读为准 |
| **被动（passives）** | 可选；额外内建能力 |
| **战斗合并** | 开战监听来自主技能 + 被动（及条目上允许进入战斗的钩子，见增益边界） |
| **积木全文** | 触发器 / 目标选择 / 效果类型 → [ABILITIES.md](../ABILITIES.md)，**本文不重复枚举** |

与 §5.2.2 一致：技能可造成伤害，但不定义普攻循环。

## 8. 流派标签（设计层）

| 约定 | 说明 |
|------|------|
| **归属** | 本 Feature；用于构筑教学、样板流识别、目录索引 |
| **非羁绊** | **禁止**「凑 N 个同标签触发团队增益」 |
| **与愿景样板** | 「坚韧」「冲锋」等为**体验别名**，映射到标签集；不另开战斗属性 |
| **As-Is 参考** | 花名册曾用触发向分类（如受伤、开战、召唤、死亡等）作推断索引；**非资源定稿** |

**待定（见 §13）**：

- 单标签还是允许多标签
- 标签枚举表定稿与「其他」是否取消
- 体验别名与标签的正式映射表

---

## 9. 站位空间契约（高层）

| 契约 | 功能含义 |
|------|----------|
| **共享矩形棋盘** | 友方、敌方、token 占同一网格；每格至多一实体 |
| **攻击范围** | 普攻可达的空间距离（语义与棋盘战斗距离一致） |
| **移动落点** | 受移动方式、移动距离、阻挡与占格约束 |
| **相对方位钩子** | 技能侧可使用「身后」「前/后排」「周围格」等；单位 Feature 承认这些为**布阵可利用的空间语义**，细则在 Ability System |

邻接与距离**不**用六边形或其它体系替代现有棋盘接口（项目约束）。

---

## 10. 召唤与 token

| 项 | 规格 |
|----|------|
| **定义** | 由技能/效果生成的单位实例，默认临时 |
| **最小模板（建议）** | 具备生命 / 攻击 / 移动三类；主技能可空；**建议登记召唤来源** |
| **成长** | 默认不参与牌库星级与增益挂载 |
| **生成时覆盖** | 生成瞬间覆写生命等 → 属**召唤效果契约**，非 token 模板必改项 |
| **胜负 / 占格** | 计入场上实体；影响清波与空间压缩 |

| 接口 | 本 Feature 声明 | 细节文档 |
|------|-----------------|----------|

## 13. 开放问题

1. **移动方式有限集（§5.3.1）**：用户尚未口头确认「采用」。请确认采用 / 增删 / 另提。**若无异议，可将该 6 类升为定稿。**
