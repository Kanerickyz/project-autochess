# 角色单位

> 功能规格 · 只谈规则与结构，不写具体数值 · 2026-10-12  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [技能目录](../ABILITIES.md) · [商店](../SHOP_SYSTEM.md) · [增益](../BUFF_SYSTEM.md) · [角色一览](../UNITS_ROSTER.md)  
> **本版不写**：具体生命/攻击数字、暴击百分比、每回合走几格、伤害公式里的系数、每一级加多少。这些交给数值策划和战斗规则去填。

## 1. 这是什么

**角色单位**规定：棋盘上所有能参与战斗的角色——友方角色、敌方角色、生成的代理角色——在「买卡构筑 → 预布阵 / 战斗补人 → 自动战斗看联动」里共用哪些身份、属性和技能约定。

| 阶段 | 角色单位在做什么 |
|------|------------------|
| 构筑 | 友方角色是商店里能买的卡；自带技能、流派标签和**角色等级**决定你怎么养成 |
| 布阵 | 生命、攻击、移动决定谁适合站前排、谁适合站后排；等级高的通常更耐打、更疼 |
| 开战 | 普通攻击怎么打，和技能什么时候触发，是两套事；清光敌人算赢，己方全灭算输（见愿景） |

第一版的乐趣来自：角色自带技能的组合 + 站位 + 增益卡。**不做**「凑齐若干同族/同职业就触发团队加成」那种羁绊。

## 2. 写什么、不写什么

### 2.1 本文要说清的

- 单位有哪几种：友方角色、敌方角色、生成的代理角色
- 角色有哪些属性：角色等级、生命、攻击、移动，以及身份、技能槽、流派标签
- 角色等级如何作为本体成长（progression）：默认加强哪些属性、哪些故意不随等级变
- 角色生命周期：招募、上场、开战、回合存活、移动、攻击、受伤、死亡、离开队伍等节点
- 哪些是角色本身自带的，哪些跟等级/牌库养成走，哪些只在本场战斗临时存在
- 生成代理角色时最少要约定什么
- 站位和空间上，角色之间怎么互相「用得上」
- 和商店、增益、战斗规则分别接到哪里

| 个别角色很特殊的攻击形状怎么实现 | 以后再说（见文末附录 B） |

## 3. 单位种类

| 种类 | 是什么 | 怎么出现在棋盘上 |
|------|--------|------------------|
| **友方角色** | 玩家能在商店买到、放进自己阵容的角色 | 商店 → 牌库 → 准备预布阵或战斗中 cycle 补人上场 |
| **敌方角色** | 这一关/这一场对面的角色 | 按遭遇或波次配置刷出来 |
| **生成的代理角色** | 技能或效果在战斗里变出来的角色（替身、召唤物等） | 由技能或效果生成；默认不进商店，也不走角色等级养成 |

三种都共用同一套「生命 / 攻击 / 移动」结构；**角色等级**默认只属于友方角色的养成路径。差别见后文适用表和「生成的代理角色」一节。

## 4. 设计时先看哪些面

```text
说明身份的：种类 · 技能槽 · 流派标签
成长相关的：角色等级
战斗用的：生命 · 攻击 · 移动
关系上的：由谁生成（主要针对代理角色）
和商店交接的：品阶、价格、击杀掉落金币等（本篇只说「有没有」，不定价）
```

| 面 | 怎么理解 |
|----|----------|
| 种类与身份 | 决定能不能买、算哪一边、清场谁算赢，不直接算单次伤害 |
| **角色等级** | 友方角色本体进度；升级后角色「本身」更强（见第 5.1 节） |
| 技能槽 | 管「什么时候额外发生什么」，和普通攻击怎么打是分开的 |
| 流派标签 | 方便策划和玩家认「这是什么打法」；**不是**凑数量触发的羁绊 |
| 生命 / 攻击 / 移动 | 战斗与站位直接用到的属性大类 |

## 5. 属性怎么设计

### 5.1 角色等级

| 属性 | 是什么意思 | 玩家什么时候在意 |
|------|------------|------------------|
| **角色等级** | 这一张友方角色在牌库里的本体进度 | 构筑养成、上场预期「更肉 / 更疼」、和同名合并目标 |

#### 它管什么、不管什么

| 是角色本体成长 | 不是（请分开看） |
|----------------|------------------|
| 等级升高后，角色之后上场更强 | **本场临时**：受伤加攻、开战加成等，战斗结束就没了 |
| 默认强化生命上限、攻击力（见下） | **增益卡**：外挂强化，另买另叠，不是「升一级」本身 |
| 跟着牌库里那一张友方角色走 | **敌方强度 / 波次配置**：不是玩家养成条 |
| — | **整局地图上的别的养成**（休息、事件等）：另篇 |

**怎么升到更高等级**（合并、经验、上限档位）由 [商店文档](../SHOP_SYSTEM.md) 写清；本篇把**角色等级定为角色属性**，并约定升级默认改哪些战斗属性。

#### 升级默认强化什么（功能层，无具体数字）

| 随角色等级变强 | 建议 | 说明 |
|----------------|------|------|
| **生命上限** | **主要成长轴** | 等级高 → 更耐打；布阵前排预期清晰 |
| **攻击力** | **主要成长轴** | 等级高 → 普通攻击和「吃攻击力」的技能都更疼；与「伤害只认攻击力」一致 |

| 默认不随角色等级改变 | 为什么 |
|----------------------|--------|
| **攻击方式** | 这是「怎么出手」的身份；升级改方式等于换人 |
| **移动方式** | 这是站位题怎么出的身份；应保持稳定 |
| **流派标签** | 分类与教学用，不是养成条 |
| **攻击范围**（默认） | 一涨就改变「谁能打到谁」；不作人人升级的主轴 |
| **移动距离**（默认） | 一涨就大幅改摸脸速度；不作人人升级的主轴 |
| **攻击暴击率**（默认） | 不宜变成「人人升级都加暴击」；留给个别技能或增益 |

**还没定**（见开放问题）：技能效果强度是否正式算角色成长的并行轴；生成内容是否随等级放大等。

#### 谁拥有角色等级

| 种类 | 角色等级 |
|------|----------|
| **友方角色** | **有**；牌库养成路径上的本体进度 |
| **敌方角色** | **默认没有**；强弱靠遭遇/波次配置 |
| **生成的代理角色** | **默认没有**独立等级进度；强弱跟生成者和生成规则走 |

### 5.2 生命

| 属性 | 是什么意思 | 玩家什么时候在意 |
|------|------------|------------------|
| **生命上限** | 最多能挨多少伤害 | 摆前排、估能不能扛住；**随角色等级提高是默认主轴之一** |
| **当前生命** | 这一场里还剩多少 | 开战过程中；上场时一般从「有效上限」开始 |

牌库养成（含等级）、增益和本场临时效果都能影响生命相关表现（见第 6 节）。**具体数字本版不定。**

### 5.3 攻击

#### 攻击相关属性

| 属性 | 是什么意思 | 说明 |
|------|------------|------|
| **攻击力** | 算伤害时统一用的那个数 | 普通攻击伤害由「基于攻击力的公式」算出；**随角色等级提高是默认主轴之一**；具体数字与公式系数本版不定 |
| **攻击范围** | 普通攻击够得着多远 | 跟矩形棋盘上的战斗距离说法一致；**默认不随等级涨**；具体几格本版不定 |
| **攻击暴击率** | 打出暴击的概率 | **默认不随等级涨**；具体百分比本版不定 |
| **攻击方式** | 普通攻击这一套循环怎么打 | 和技能是两套系统；**不随等级改变** |

**已经拿掉**：单独的「攻击基础伤害」。不要再搞一套和攻击力并列的基础伤害字段。

#### 攻击方式 和 技能：两套系统（已定）

| 系统 | 管什么 | 不管什么 |
|------|--------|----------|
| **攻击方式** | 普通攻击：打不打、打多远、以什么形态出手 | 不负责整条「事件连锁」的技能逻辑 |
| **技能** | 角色自带的触发与效果（可以造成伤害、生成代理角色、加状态等） | 不重新定义「普通攻击怎么打」 |

技能造成的伤害可以**用到攻击力**（同一个数），但那仍是技能打出来的，不是攻击方式本身。角色等级提高攻击力时，这类「吃攻击力」的技能会间接变强；技能自身是否另有「随等级放大」见开放问题。

#### 攻击方式（先定大类）

| 方式 | 一句话 |
|------|--------|
| **标准普通攻击** | 按攻击范围，对目标打出基于攻击力的普通攻击 |
| **没有普通攻击** | 不走普通攻击循环；输出主要靠技能等 |
| **特殊攻击形态（以后再展开）** | 留给「改变命中形状或出手时机」的扩展；本版不写具体实现 |

**还没定**：「打得远」算单独一种攻击方式，还是「标准普通攻击 + 更大的攻击范围」（见开放问题）。  
特殊形态的细则本版不写（附录 B）。

### 5.4 移动

| 属性 | 是什么意思 |
|------|------------|
| **移动方式** | 怎么选格子、怎么挪过去；**不随角色等级改变** |
| **移动距离** | 一轮行动里，这种移动方式最多能动多少；**默认不随等级涨**（具体数字本版不定） |
| **可不可以移动** | 这一场会不会走位（可以是角色自带，也可以被规则临时关掉）；不是等级养成轴 |

方式和距离分开看：方式回答「怎么走」，距离回答「能走多远」。

#### 移动方式——目前的设计提案（还没正式拍板）

下面 6 种是讨论里收束过的说法。你还没口头说「就用这套」；**如果后面没有异议，可以升成定稿。**

| 名称 | 一句话 |
|------|--------|
| **标准步进** | 一格一格靠近目标；一轮能走多远由移动距离限制 |
| **快速步进** | 和标准步进一样走法，但相对走得更远（只分类型，不定步数） |
| **滑移** | 沿一条直线一直滑，直到被挡住或到边 |
| **跳跃** | 中间格子不算阻挡，直接落到规则允许的远处格子 |
| **传送接近** | 不沿路径走，直接出现在靠近目标的合法空格 |
| **不可移动** | 这一场不走位 |

**还没定**：滑移要不要在本版再拆成「只能横竖 / 只能斜 / 都能滑」。

#### 和现在程序里的对照（只作参考，不是设计定稿）

程序里拆得更细（好几种步进、滑移、跳跃、传送等），也有「每回合移动量」一类字段。功能规格以上面的提案为准往回收；程序怎么映射，等定稿后再对齐。**不要把代码里的枚举名直接当成设计定稿。**

### 5.5 三种单位分别要填什么

| 项目 | 友方角色 | 敌方角色 | 生成的代理角色 |
|------|----------|----------|----------------|
| 单位种类 | 必填 | 必填 | 必填 |
| **角色等级** | **有**（牌库养成） | 默认无 | 默认无 |
| 能不能进商店 | 能 | 不能 | 不能 |
| 主技能 | **必须有** | 可以没有 | 可以没有 |
| 额外被动 | 可以有 | 可以有 | 可以有 |
| 流派标签 | 建议至少有一个 | 可以有 | 可以有 |
| 生命 / 攻击 / 移动 | 都要有 | 都要有 | 都要有（可以很简单） |
| 等级默认加生命上限与攻击力 | **会** | — | — |
| 由谁生成 | 一般不用 | 不用 | **建议写清楚** |
| 品阶 / 价格 | 要有（和商店交接） | 不用 | 不用 |
| 被击杀掉落金币 | 可以配 | 建议有 | 可以配 |

## 6. 自带的、等级与牌库养成的、本场临时的

| 层 | 包括什么 | 活多久 |
|----|----------|--------|
| **角色自带** | 种类、挂上的技能、攻击方式、移动方式、生命/攻击/移动的底板 | 跟着角色模板 |
| **角色等级与牌库养成** | **角色等级**；等级带来的生命上限与攻击力强化；其它永久加成与部分规则标记 | 这一整局里、跟着牌库里那一张；**默认只有友方角色** |
| **本场临时** | 这一场战斗里对攻、血、范围、暴击等的临时改动 | 一场战斗；结束清掉 |
| **规则标记** | 例如不可移动 | 常由增益写到牌库条目上，开战时带到场上 |

```text
角色自带的底板（含攻击方式、移动方式）
  → 角色等级 + 牌库养成 / 增益 / 规则（友方角色）
    → 场上这一只（当前生命 + 本场临时改动）
```

**经验怎么攒、最高几级、卖价怎么算**写在商店文档；本篇钉死：

1. **角色等级是友方角色的属性**  
2. **升级默认加强生命上限与攻击力**  
3. **攻击方式、移动方式不随等级变**  
4. **敌方角色和生成的代理角色，默认没有角色等级养成**

## 7. 技能槽约定

| 槽 | 约定 |
|----|------|
| **主技能** | 友方角色**必须**有；写给人看时，最好能读成「什么时候触发 + 对谁 + 发生什么」 |
| **被动** | 可以有，也可以没有 |
| **开战时** | 主技能和被动都会参与监听（生命周期节点见第 8 节；增益若允许带进战斗，边界见增益文档） |
| **与角色等级** | 技能可以间接吃到「等级提高的攻击力」；技能效果是否另有「随等级放大」见开放问题；**升级默认不换主技能、不改攻击方式** |
| **完整积木表** | 触发、目标、效果类型见 [技能目录](../ABILITIES.md)，这里不重复罗列 |

和前面一致：技能可以造成伤害，但不定义普通攻击怎么打。技能挂在下面「角色生命周期」的节点上触发。

## 8. 角色生命周期

角色不只「有属性」，还有一条从进队到离队、从上场到倒下的**时间线**。技能挂在时间线的节点上触发；普通攻击和移动是战斗里的行为节点。

**两条总原则**

1. **攻击方式**只描述「普通攻击怎么打」；**技能**是另一套「在某节点触发后发生什么」。  
2. **角色等级**只属于友方角色的牌库养成；敌方角色、生成的代理角色默认没有这套等级进度。

### 8.1 容易混的词（已定）

| 词 | 定义 | 不要和谁搞混 |
|----|------|--------------|
| **上场时** | 把友方角色**放到棋盘格子上**的那一刻（占格成功：准备预布阵或战斗 cycle 补人） | 不是开战；开战见「开战时」 |
| **开战时** | 战斗**正式开始**的那一刻（场上角色开始按战斗规则行动之前/之初） | 不是摆盘占格 |
| **回合存活时** | 战斗里按**行动轮**结算：一轮行动结束时，该角色**仍然活着** | 不是整波打完还活着；也不是回合刚开始 |
| **离开队伍** | 友方角色从牌库里被移出（主动卖掉、满库替换等） | 不是战斗死亡（死了牌还在） |

### 8.2 谁走哪一段

| 生命周期节点 | 友方角色 | 敌方角色 | 生成的代理角色 |
|--------------|----------|----------|----------------|
| 招募（购买）时 | 有 | 无 | 无 |
| 升级时 | 有（等级提升时） | 无 | 无 |
| 上场时（摆上棋盘） | 有 | 一般无（刷怪出场） | 无（走「被生成时」） |
| 开战时 | 有（若已在场） | 有（若已在场） | 有（若已在场） |
| 回合存活时 | 有（若在场且仍活） | 有 | 有 |
| 移动时 | 有（自身走位时） | 有 | 有 |
| 进行攻击时 | 有（若会普通攻击） | 有 | 有 |
| 受到伤害时 | 有 | 有 | 有 |
| 死亡时 | 有 | 有 | 有 |
| 离开队伍 | 有 | 无 | 无 |
| 被生成时 | 一般无 | 一般无 | 有 |

### 8.3 各节点说明

#### 招募（购买）时

| 项 | 说明 |
|----|------|
| **是什么** | 商店阶段，玩家花金币买进一张友方角色，写入牌库（或同名合并进已有条目）的那一刻 |
| **谁会经历** | 仅友方角色 |
| **典型会发生什么** | 扣费；牌库多一条或同名加经验；可触发「购买时」类技能 |
| **与升级的顺序（已定）** | **先完成购买，再结算升级**。同名合并若使经验够升级：先走完「招募（购买）时」，再进入「升级时」 |
| **边界** | **商店**负责能不能买、价格、满库、同名合并；**技能**可在购买成功后响应 |
| **不是什么** | 不是摆上棋盘；不是开战；不是挂增益卡 |

#### 升级时

| 项 | 说明 |
|----|------|
| **是什么** | 友方角色的**角色等级**实际提升的那一刻 |
| **谁会经历** | 仅友方角色 |
| **典型会发生什么** | 按成长约定提高生命上限与攻击力等；可触发「升级时」类技能 |
| **边界** | 等级是什么、默认加什么见第 5.1 节；经验怎么攒见商店文档 |
| **不是什么** | 不是购买本身（购买在前）；不是开战 |

#### 上场时

| 项 | 说明 |
|----|------|
| **是什么** | 从本波手牌选用友方角色，**成功占住一个空格**的那一刻（准备预布阵或战斗中补人） |
| **谁会经历** | 主要是友方角色 |
| **典型会发生什么** | 格子被占用；场上出现可参战实例（带上等级养成后的生命/攻击等）；一般**还没**开战 |
| **边界** | 布阵规则归流程/牌库；默认不把「上场」当成开战技能大触发点 |
| **不是什么** | **不是开战时**；不是购买 |

#### 开战时

| 项 | 说明 |
|----|------|
| **是什么** | 战斗**正式开始**的那一刻 |
| **谁会经历** | 当时已经在场上的友方 / 敌方 / 代理角色 |
| **典型会发生什么** | 开战爆发、开战增益、开战点伤等「开战时」类技能在此触发 |
| **边界** | 与「上场时（摆盘）」拆开；技能挂在开战，不挂在摆盘 |
| **不是什么** | 不是占格成功；不是每一行动轮的开头 |

#### 回合存活时

| 项 | 说明 |
|----|------|
| **是什么** | 战斗进行中，按**行动轮**：一轮行动结束时，该角色**仍然存活** |
| **谁会经历** | 当时在场且未死亡的友方 / 敌方 / 代理角色 |
| **典型会发生什么** | 可作为「又撑过一轮」的钩子（回复、叠层等）；本身不强制改属性 |
| **边界** | 纯战斗时间线；与「回合开始时」不同（若以后要做轮初钩子，另开名字） |
| **不是什么** | 不是整波打完还活着；不是升级；不是离开队伍 |

#### 移动时

| 项 | 说明 |
|----|------|
| **是什么** | 战斗中该角色靠**自身移动规则**完成一次合法走位（格子变了） |
| **谁会经历** | 三种都可能；不可移动则不会 |
| **典型会发生什么** | 更新所占格子；之后可接普通攻击（若规则允许）；可触发「移动时」类技能 |
| **边界** | 移动方式/距离决定能不能走；技能响应「自己走成功了」 |
| **不是什么** | **由技能触发的瞬时位移（换位、传送拉扯等）不算「移动时」**；也不是布阵时玩家手摆位置 |

#### 进行攻击时

| 项 | 说明 |
|----|------|
| **是什么** | 走**普通攻击**流程：按攻击方式与攻击范围选目标并出手 |
| **谁会经历** | 三种都可能；「没有普通攻击」则跳过 |
| **典型会发生什么** | 用攻击力经统一伤害公式结算；可能暴击；可能接「造成伤害 / 击倒」等后续（细则在技能文档） |
| **边界** | **攻击方式**管普攻怎么打；技能造成的伤害**不叫**「进行攻击时」 |
| **不是什么** | 不是技能砸伤害；不是离开队伍 |

#### 受到伤害时

| 项 | 说明 |
|----|------|
| **是什么** | 生命因伤害结算而减少之后，该角色作为「受伤对象」被通知 |
| **谁会经历** | 三种都可能 |
| **典型会发生什么** | 当前生命下降；可触发「受伤时」类技能；若降到零则进入死亡时 |
| **边界** | 伤害可来自普攻或技能，本节点统一是「我挨打了」 |
| **不是什么** | 不是治疗；不是「被选中但未造成伤害」 |

#### 死亡时

| 项 | 说明 |
|----|------|
| **是什么** | 该角色确认阵亡、离开可作战状态 |
| **谁会经历** | 三种都可能 |
| **典型会发生什么** | 腾出格子；可触发「死亡时」类技能；参与胜负统计 |
| **边界** | 战斗内死亡走战斗与技能；**离开队伍不是死亡** |
| **不是什么** | 不是销毁牌库里的卡。友方角色战斗死亡后，**牌库条目仍在**，下一场/准备阶段仍可再上场（除非玩家之后使其离开队伍） |

#### 离开队伍

| 项 | 说明 |
|----|------|
| **是什么** | 友方角色从牌库里被移出队伍的那一刻。包括：玩家主动卖掉，以及**满库替换**等导致该卡离开牌库的情形 |
| **谁会经历** | 仅友方角色 |
| **典型会发生什么** | 条目离开牌库；按商店规则退款（若适用）；条目上的增益一并消失；可触发「离开队伍」类技能（原「出售时」类效果归到这里） |
| **边界** | 商店管时机与退款；技能在离开队伍流程里响应 |
| **不是什么** | 不是战斗死亡；不是代理角色从场上消失 |

#### 被生成时

| 项 | 说明 |
|----|------|
| **是什么** | 技能或效果在战斗里**生成**代理角色（或同类临时单位）并使其出现在棋盘上的那一刻 |
| **谁会经历** | 主要是生成的代理角色 |
| **典型会发生什么** | 占格；可带生成时数值覆盖；可触发「被生成时」类技能 |
| **边界** | 与招募、上场（玩家摆盘）都不同 |
| **不是什么** | 不是购买；不是准备阶段摆盘 |

### 8.4 技能结果链（不单列成生命周期主节点）

下列更偏「攻击/技能结算后的结果」，细节写在技能文档，本篇不把它们抬成与「招募 / 开战」同级的主节点：

- 造成伤害时、击倒时  
- 友方死亡时（旁观联动）  
- 波次结束时仍存活  

若以后要把其中某一条升成主节点，再单独拍板。

### 8.5 时间线怎么串起来

```text
商店时间线：招募（购买）→ 升级（若本次购买导致升级）→ …… → 离开队伍
准备时间线：上场（摆盘）
战斗时间线：开战时 → 移动 / 普通攻击 / 受伤 / 回合存活（按行动轮）→ 死亡
生成时间线：被生成（代理角色）
```

注意：

- 友方**死亡**腾出格子，但**不销毁**牌库里的卡。  
- **离开队伍**才会让卡从牌库消失。  
- 技能造成的瞬时位移**不走**「移动时」。

普通攻击只出现在「进行攻击时」；技能可以挂在上表节点上，也可以造成伤害而不经过「进行攻击时」。

## 9. 流派标签

| 约定 | 说明 |
|------|------|
| **干什么用** | 帮玩家和策划认出「这是什么打法」，方便做目录和教学 |
| **不是羁绊** | **禁止**「场上凑齐 N 个同标签就给全队加成」 |
| **和愿景里的说法** | 「坚韧」「冲锋」是体验上的别名，映射到标签；不再另开一套战斗属性 |
| **与角色等级** | 标签**不随等级改变** |
| **现状参考** | 角色一览里曾按触发类型（受伤、开战、召唤、死亡等）自动归类；那只是索引，不是资源里的定稿 |

**还没定**（见开放问题）：

- 一个角色只能有一个标签，还是可以有多个
- 标签清单定稿，以及要不要取消「其他」
- 「坚韧 / 冲锋」和标签怎么一一对应

## 10. 站位和空间（先说清楚的部分）

| 约定 | 含义 |
|------|------|
| **同一块矩形棋盘** | 友方、敌方、生成的代理角色占同一张格子；一格最多站一个 |
| **攻击范围** | 普通攻击够得着多远（和棋盘战斗距离说法一致）；默认不靠升级拉长 |
| **移动落点** | 受移动方式、移动距离、阻挡和占格限制；移动方式不随等级变 |
| **相对位置** | 技能里可以用「身后」「前排/后排」「周围格子」等；本篇承认这些是摆阵时用得上的空间说法，细则在技能文档 |

邻接和距离继续用现有矩形棋盘规则，不用六边形或其它体系替换。

## 11. 生成的代理角色

| 项目 | 约定 |
|------|------|
| **是什么** | 技能或效果在战斗里变出来的角色，默认是临时的 |
| **最少要有什么** | 生命、攻击、移动都要有；主技能可以没有；**建议写明是谁/什么效果生成的** |
| **角色等级** | **默认没有**自己的等级养成条 |
| **生命周期** | 入场走「被生成时」；之后可经历开战/移动/攻击/受伤/回合存活/死亡；不走招募、上场摆盘、离开队伍 |
| **生成时改数值** | 生成当下改生命等，算「生成效果」的约定，不必改代理角色模板本身 |
| **胜负和占格** | 算场上的实体；会影响清场和格子够不够用 |

## 12. 和商店、增益、战斗怎么交接

| 交接项 | 本篇怎么说 | 细节看哪 |
