# 角色单位

> 功能规格 · 只谈规则与结构，不写具体数值 · 2026-10-15（回合制依次行动版）  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [玩家](./PLAYER.md) · [Content 角色库](../Content/UNITS_ROSTER.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [角色技能](./UNIT_ABILITIES.md) · [增益](../BUFF_SYSTEM.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：兵种花名册与具体数字（见 Content）；伤害公式系数；每一级加多少。  
> **【现状】** 属性字段在单位属性脚本（`scripts/data/unit_stats.gd` 的「Realtime」组，命名 As-Is）；资源在 `resources/units/realtime/`。资源中仍可能残留 `command_cost`（**【To-Be】删除号令费用**，见玩家篇）。**【移动 To-Be】** 回合内一动：八向格步 + **落格顿步** + 切比雪夫格距（见战斗关卡 / 战斗）；As-Is 为实时并行八向弱滑动。旧动物占位与象棋式走法身份只留在旧网格工具环。

## 1. 这是什么

**角色单位**规定：战场上所有能参战的角色——友方角色、敌方角色、生成的代理角色——共用哪些属性、怎样在回合制自动战中行动、何时触发什么。

| 阶段 | 角色单位在做什么 |
|------|------------------|
| 构筑 | 牌库里的那一张友方角色；角色等级是它的本体进度 |
| 准备 | 从手牌入**角色座位**（见玩家 / 战斗关卡） |
| 开战 | 自己索敌、八向格步靠近、攻击；玩家不能拖动、不能点技能、不能再出牌 |

第一版不做种族/职业羁绊。

## 3. 单位种类

| 种类 | 是什么 | 怎么出现在战场上 |
|------|--------|------------------|
| **友方角色** | 玩家牌库里的角色 | 准备阶段从手牌入角色座位，开战时生成（见 [玩家](./PLAYER.md)） |
| **敌方角色** | 本场遭遇的对手 | 开战时在敌半场一次刷出 |
| **生成的代理角色** | 技能或效果在战斗中生成的临时角色 | 由技能生成（如轻步兵 `death_spawn_pack` → `token_ember`）；不占准备槽 |

三种单位共用同一套属性与战斗行为。友方允许场上多名同一兵种（由队伍构成自然形成）。不做「一张牌一次出一群」的投放设定（生成代理另论）。

## 4. 属性：大类 → 属性 → 模式

长度单位一律用「格」，时间单位用「秒」。括号里是资源字段名。

```text
生命
 └ 生命上限（max_hp）
攻击
 ├ 攻击力（attack）
 ├ 攻击方式 → 近战单体 / 远程投射物单体 / 近战溅射
 ├ 攻击距离（attack_reach）
 ├ 攻击间隔（attack_interval）
 ├ 攻击前摇（attack_windup）
 ├ 投射物速度（projectile_speed）
 ├ 溅射半径（splash_radius）
 └ 暴击率（crit_rate_percent，沿用；本版名单为零）
移动与索敌
 ├ 移动速度（move_speed）— 完成一格步进的节拍
 └ 索敌范围（sight_range）— 切比雪夫格距
体积与占格
 ├ 碰撞体积（body_radius）— 表现/剪影参考；出手判定用格距
 ├ 推挤质量（mass）— 【As-Is】圆推挤；【To-Be】占格冲突改道/短等为主
 └ 部署时间（deploy_time）【To-Be：友方入槽开战不使用】
构筑
 ├ 花费 / 商店金（cost）— 买进牌库
 └ 品阶（tier）— 商店解锁档
```

### 4.1 生命

| 属性 | 功能 | 玩家什么时候在意 |
|------|------|------------------|
| **生命上限**（max_hp） | 最多能承受多少伤害 | 谁扛在前面；随角色等级提高 |
| **当前生命** | 本次上场后还剩多少 | **每次入槽开战都满生命上场**，不跨战斗节点保留 |

### 4.2 攻击

| 属性 | 功能 |
|------|------|
| **攻击力**（attack） | 每次命中的伤害；随角色等级提高 |
| **攻击距离**（attack_reach） | 与目标的**切比雪夫格距**不大于它就能出手（单位：格；与八向一致） |
| **攻击间隔**（attack_interval） | 两次出手之间的时间 |
| **攻击前摇**（attack_windup） | 进入攻击距离、锁定新目标后，到第一次出手之间的等待 |
| **投射物速度**（projectile_speed） | 有值就是远程，伤害在投射物命中时结算；为零就是近战，出手即命中 |
| **溅射半径**（splash_radius） | 有值时以**目标格**为中心、切比雪夫格距 ≤ 该值的敌人受伤；为零就是单体 |

**攻击方式**（本版只有三种；不另设字段，由上面两个字段的组合决定）：

| 模式 | 组合 | 玩家看到 |
|------|------|----------|
| **近战单体** | 无投射物、无溅射 | 贴身打一个目标 |
| **远程投射物单体** | 有投射物、无溅射 | 从远处射出可见的投射物，打中一个目标 |
| **近战溅射** | 无投射物、有溅射 | 贴身打一下，目标周围的敌人一起受伤 |

「远程 + 溅射」本版不用。投射物飞行途中目标已经死亡：投射物消失，不造成伤害。

### 4.3 移动与索敌

| 属性 | 功能 |
|------|------|
| **一动步数**（由移动相关字段表达；As-Is 资源名可能仍为 `move_speed`） | 轮到自己时，本动最多可完成的八向格步数（正步与斜步等价）；越大越容易接敌 |
| **索敌范围**（sight_range） | 切比雪夫格距半径内找最近敌人 |

**【As-Is】** `move_speed` / `attack_interval` 等按实时秒节拍读。**【To-Be】** 主时钟改为行动队列后：移动预算用「一动可走几格」；攻击在一动内最多出手一次（若已在攻距）。具体换算与资源改名交实现 / 数值，本篇定语义。

**选目标与一动内移动规则**（定稿）：

1. 仅在**轮到自己的一动**时选目标、移动与出手（见战斗篇）。  
2. 索敌范围内有敌人：选**格距最近**的敌人作为目标（同距时实现定一种稳定次序）。  
3. 范围内没有敌人：朝**全场格距最近**的敌人前进。  
4. 朝目标做**八方向寻路**；本动按**落格顿步**最多走完一动步数：每步迈向一个邻格，**停稳在格心**后再判「出手或再迈」。  
5. **一格一体**：目标邻格被占则改道；无法前进则提前结束本动移动（见战斗关卡）。  
6. **仅在落稳后**用切比雪夫格距判攻击距离；进入攻距则本动出手并结束移动；锁定该目标至其死亡或离开攻距后，下一次自己的一动再重选。  
7. 用尽一动步数仍不在攻距：本动只移动，不强制空挥。  
8. 距离一律用切比雪夫格距；**不是**欧氏直线距；**禁止**未落稳判攻、禁止无缝连滑多格当一步。

### 4.4 体积与占格

| 属性 | 功能 |
|------|------|
| **碰撞体积**（body_radius） | 剪影/表现参考；**【To-Be】** 不出手判定主轴（出手用格距） |
| **推挤质量**（mass） | 【As-Is】圆推挤；**【To-Be】** 占格冲突以改道/短等为主，质量可作次级并列规则或淡出 |
| **部署时间**（deploy_time） | 【As-Is】资源与模拟仍可能带此字段；**【To-Be】** 友方入槽开战**不使用**部署等待。敌方开战刷出亦立即行动 |

### 4.5 构筑费用

| 属性 | 功能 |
|------|------|
| **花费**（`cost`） | 商店买进构筑库消耗的**金币** |
| **品阶**（`tier`） | 商店解锁档 |

本版**不做**号令费用（`command_cost`）；资源若仍残留该字段，主路径应忽略并择期删除。上场人数由**本场上场人数上限**约束，落点在角色座位上，见玩家篇 / 战斗关卡。

### 4.6 旧网格工具环字段

移动方式（`movement_pattern`）及旧工具环专用的走法身份字段只给旧网格工具环使用。  
主路径「一动可走几格」语义见 §4.3；勿把旧象棋走法身份搬进主路径。  
整数格 `attack_range` 若与 `attack_reach` 并存：主路径以 **`attack_reach` 的格距语义**为准，并应与资源对齐。

## 8. 生命周期（回合制依次行动）

| 节点 | 什么时候 | 谁会经历 | 本版 |
|------|----------|----------|------|
| 招募 / 升级 / 离开队伍 | 商店买卖与合并 | 友方 | 商店占位，主路径没有入口 |
| **上场时** | 入座 / 开战生成成功（或战中补人若回摆） | 友方 | 有 |
| **部署中** | 战中落地后的部署等待（若回摆） | 友方 | As-Is 可能有；To-Be 主路径开战入座无部署等待 |
| **开战时** | 「游戏开始」事件；战中补人上场的单位**不会**经历 | 当时在场的单位 | 有 |
| **自己回合开始** | 行动队列轮到自己、一动开始时 | 全部 | 有（技能可用；见角色技能） |
| **进行攻击时** | 本动出手的那一刻；伤害在命中时结算 | 全部 | 有 |
| **受到伤害时** | 生命被扣之后 | 全部 | 有 |
| **死亡时** | 生命归零；离开战场；之后行动队列跳过该体 | 全部 | 有 |
| **被生成时** | 技能生成代理角色 | 生成的代理角色 | 有（如 `death_spawn_pack`） |
| 移动时（每走一格） | — | — | 主路径**不作为**技能触发点 |
| 全场回合开始 / 回合存活 | — | — | 主路径**不用**；需要时用「自己回合开始」 |

- To-Be 队伍成员战斗死亡不移出队伍；生命不跨场保留，下场满生命再战（见玩家篇）。  
- As-Is 若仍为牌库/手牌中介：友方死亡不销毁牌库条目等旧规则仅作对照，实现回摆以玩家篇为准。

```text
准备：入座 → 开战锁阵生成 → 开战时 → 排出行动队列
自动战斗：轮到自己（自己回合开始）→ 一动内索敌 / 落格顿步 / 出手 → 受伤 / 死亡（队列跳过）
```

## 10. 玩家可观察验收（L0）

1. 战场上每名角色颜色能分清敌我；逻辑上各占一格。  
2. 开战后同一时刻只有当前行动者在动；朝目标沿八方向**一格一顿**靠近；一动步数更高的角色更容易在本动接敌。  
3. 远程角色在落稳且进入攻距后于本动射击；近战在落稳且贴格距内出手（未落稳不出手）；不在攻距则本动可只移动。  
4. 带近战溅射的角色打一下，目标周围格距内的敌人一起掉血。  
5. 同一格不会叠两名存活单位。  
6. To-Be 无战中补人部署等待；若 As-Is 仍有部署表现，不作为本篇验收主轴。  
7. 一名角色死后，它那张牌可以再打出，打出时满生命（若规则允许再出；主路径开战观战见玩家篇）。  
8. Content §6 九人已挂主技能；民兵白板，上场后只打普通攻击。
