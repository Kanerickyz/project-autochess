# 角色单位

> 功能规格 · 只谈规则与结构，不写具体数值 · 2026-10-13（实时战斗版）  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [Content 角色库](../Content/UNITS_ROSTER.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [技能目录](../ABILITIES.md) · [增益](../BUFF_SYSTEM.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：兵种花名册与具体数字（见 Content）；伤害公式系数；每一级加多少。  
> **【现状】** 实时属性字段在单位属性脚本（`scripts/data/unit_stats.gd` 的「Realtime」组）；资源在 `resources/units/realtime/`，由 Run 主路径实时战斗读取。旧动物占位只留在旧网格工具环。

## 1. 这是什么

**角色单位**规定：战场上所有能参战的角色——友方角色、敌方角色、生成的代理角色——共用哪些属性、怎样实时行动、何时触发什么。

| 阶段 | 角色单位在做什么 |
|------|------------------|
| 构筑 | 牌库里的那一张友方角色；角色等级是它的本体进度 |
| 投放 | 准备阶段预布阵、战斗中补人：落点吸附到我半场的格子 |
| 开战 | 自己索敌、移动、攻击；玩家不能拖动、不能点技能 |

第一版不做种族/职业羁绊。

## 3. 单位种类

| 种类 | 是什么 | 怎么出现在战场上 |
|------|--------|------------------|
| **友方角色** | 玩家牌库里的角色 | 准备阶段预布阵，或战斗中从手牌补人 |
| **敌方角色** | 本场遭遇的对手 | 开战时在敌半场一次刷出 |
| **生成的代理角色** | 技能或效果在战斗中生成的临时角色 | 由技能生成；本版名单没有技能，主路径里不会出现 |

三种单位共用同一套属性与实时行为。**一张牌只出一体**（不做一张牌出一群的设定）。

## 4. 属性：大类 → 属性 → 模式

长度单位一律用「格」，时间单位用「秒」。括号里是资源字段名。

```text
生命
 └ 生命上限（max_hp）
攻击
 ├ 攻击力（attack）
 ├ 攻击方式 → 近战单体 / 远程投射物单体 / 近战溅射
 ├ 攻击距离（attack_reach）
 ├ 攻击间隔（attack_interval）
 ├ 攻击前摇（attack_windup）
 ├ 投射物速度（projectile_speed）
 ├ 溅射半径（splash_radius）
 └ 暴击率（crit_rate_percent，沿用；本版名单为零）
移动与索敌
 ├ 移动速度（move_speed）
 └ 索敌范围（sight_range）
体积与部署
 ├ 碰撞体积（body_radius）
 ├ 推挤质量（mass）
 └ 部署时间（deploy_time）
```

### 4.1 生命

| 属性 | 功能 | 玩家什么时候在意 |
|------|------|------------------|
| **生命上限**（max_hp） | 最多能承受多少伤害 | 谁扛在前面；随角色等级提高 |
| **当前生命** | 本次上场后还剩多少 | **每次从手牌打出都满生命上场**，不跨战斗节点保留 |

### 4.2 攻击

| 属性 | 功能 |
|------|------|
| **攻击力**（attack） | 每次命中的伤害；随角色等级提高 |
| **攻击距离**（attack_reach） | 双方碰撞圆**边缘之间**的距离不大于它就能出手 |
| **攻击间隔**（attack_interval） | 两次出手之间的时间 |
| **攻击前摇**（attack_windup） | 进入攻击距离、锁定新目标后，到第一次出手之间的等待 |
| **投射物速度**（projectile_speed） | 有值就是远程，伤害在投射物命中时结算；为零就是近战，出手即命中 |
| **溅射半径**（splash_radius） | 有值时以**目标为圆心**伤害范围内全部敌人；为零就是单体 |

**攻击方式**（本版只有三种；不另设字段，由上面两个字段的组合决定）：

| 模式 | 组合 | 玩家看到 |
|------|------|----------|
| **近战单体** | 无投射物、无溅射 | 贴身打一个目标 |
| **远程投射物单体** | 有投射物、无溅射 | 从远处射出可见的投射物，打中一个目标 |
| **近战溅射** | 无投射物、有溅射 | 贴身打一下，目标周围的敌人一起受伤 |

「远程 + 溅射」本版不用。投射物飞行途中目标已经死亡：投射物消失，不造成伤害。

### 4.3 移动与索敌

| 属性 | 功能 |
|------|------|
| **移动速度**（move_speed） | 每秒能在连续坐标上走多少格 |
| **索敌范围**（sight_range） | 在这个半径内找最近的敌人 |

**选目标规则**（定稿）：

1. 索敌范围内有敌人：选**最近**的敌人作为目标。  
2. 范围内没有敌人：朝**全场最近的敌人**前进，前进过程中持续重新判断。  
3. 目标进入攻击距离：停下攻击，并**锁定**这个目标，直到它死亡或离开攻击距离；之后重新按第 1 步选目标。  
4. 距离一律是战场连续坐标上的直线距离（单位：格），不按格子走路。

### 4.4 体积与部署

| 属性 | 功能 |
|------|------|
| **碰撞体积**（body_radius） | 单位是一个圆；圆和圆不能重叠，攻击距离按圆的边缘计算 |
| **推挤质量**（mass） | 两个圆挤在一起时，质量大的更难被推开；敌我双方都会互相推挤 |
| **部署时间**（deploy_time） | **战斗中落地**后要等这么久才开始移动和攻击 |

部署中的单位：**可以被攻击、可以被推挤、算作己方存活**，但不移动、不攻击。  
准备阶段预布阵的友方角色和开战时刷出的敌方角色，**开战即可行动**，不走部署时间（部署时间是战中补人的代价）。

### 4.5 新主路径不再读取的旧字段

格子攻击范围（`attack_range`）、移动方式（`movement_pattern`）、每回合步数（`steps_per_turn`）只给旧网格工具环使用。

## 5. 角色等级

| 约定 | 内容 |
|------|------|
| 是什么 | 友方角色在牌库里的本体进度；敌方角色和生成的代理角色默认没有 |
| 升级加强 | **生命上限**和**攻击力** |
| 不随等级变 | 攻击方式、攻击距离、攻击间隔、移动速度、索敌范围、碰撞体积、部署时间 |
| 本版 | 商店节点只是占位，主路径**没有升级入口**；角色以起始等级参战 |

## 6. 技能槽（本版结论）

| 槽 | 本版约定 |
|----|----------|
| **主技能** | **允许为空**，三种单位都一样。本版名单全部没有主技能，是纯属性单位 |
| **被动** | 可以为空；本版名单全部为空 |
| 与附魔的关系 | 主技能为空的角色在附魔节点走「新增主技能」分支；附魔本版是占位节点 |

这一条取代旧约定「友方角色必须有主技能」。将来技能要上场，仍然通过 `EffectSpec` + `EffectResolver`，战斗内触发只走 `CombatEventBus`。

## 7. 本版角色名单（职能槽）

正式兵种名、角色定位与数值见 **[Content/UNITS_ROSTER.md](../Content/UNITS_ROSTER.md)**（十名友方基础兵种）。本篇只保留职能骨架，避免与 Content 双写漂移。

美术统一用**圆形色块**：圆的大小和碰撞体积一致，颜色区分敌我，圆上标短名。

| 职能槽 | 攻击方式 | 相对特征（无具体数字） |

| 前排坦克 | 近战单体 | 生命最高档、速度中 |
| 脆皮远程 | 远程投射物单体 | 生命低、射程远、单发偏低 |
| 均衡近战 | 近战单体 | 生命、攻击都中等 |
| 高速杂兵近战 | 近战单体 | 速度快、生命低、廉价 |
| 高速脆皮远程 | 远程投射物单体 | 速度快、生命很低、伤害低 |
| 脆皮远程输出 | 远程投射物单体 | 射程最远、单发较高 |
| 高伤慢攻 | 近战单体 | 单发最高、攻击间隔长 |
| 群伤近战 | 近战溅射 | 生命较高、伤周围一圈 |

## 8. 生命周期（实时版）

| 节点 | 什么时候 | 谁会经历 | 本版 |
|------|----------|----------|------|
| 招募 / 升级 / 离开队伍 | 商店买卖与合并 | 友方 | 商店占位，主路径没有入口 |
| **上场时** | 投放吸附到格子成功（预布阵或战中补人） | 友方 | 有 |
| **部署中** | 战中落地后的部署时间内 | 友方 | 有（只是状态，不是触发点） |
| **开战时** | 战斗正式开始；战中补人上场的单位**不会**经历 | 当时在场的单位 | 有 |
| **进行攻击时** | 每次出手的那一刻；伤害在命中时结算 | 全部 | 有 |
| **受到伤害时** | 生命被扣之后 | 全部 | 有 |
| **死亡时** | 生命归零；腾出人口 | 全部 | 有 |
| **被生成时** | 技能生成代理角色 | 生成的代理角色 | 名单无技能，主路径不出现 |
| 回合存活时 / 移动时 | 依赖「行动轮」和「走成功一格」 | — | 实时路径**不触发** |

- 友方角色战斗死亡**不销毁**牌库里的那一张；它在场上存活期间不能再次打出，**死后可以再打出**，再打出时满生命。  
- 一张牌同时只能有一体在场。

```text
准备：上场（吸附我半场的格子）→ 开战时 → 索敌 / 移动 / 攻击 / 受伤 → 死亡 → 牌可再打出
战中补人：上场（吸附）→ 部署中 → 索敌 / 移动 / 攻击 / 受伤 → 死亡 → 牌可再打出
```

## 10. 玩家可观察验收（L0）

1. 战场上每名角色都是圆形色块，大小和碰撞体积对应，颜色能分清敌我。  
2. 开战后单位**平滑移动**，不按格子跳动；快的角色明显比慢的先接敌。  
3. 远程角色在远处停下，射出可见的投射物；近战角色贴身才出手。  
4. 带近战溅射的角色（如链枷兵）打一下，目标周围的敌人一起掉血。  
5. 单位不互相重叠；体积大、质量大的单位能把小单位推开。  
6. 战中补人的角色落地后有一段可辨认的部署时间，期间不动但能挨打。  
7. 一名角色死后，它那张牌可以再打出，打出时满生命。  
8. Content 名单中的友方角色均无主技能，上场后只打普通攻击。
