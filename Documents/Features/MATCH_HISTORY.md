# 对局记录

> Features · 局外 · **【用户新共识 · 2026-10-28】**

## 是什么

主菜单入口「对局记录」：保存每局 **爬塔 / 无尽** 结束时玩家已看过的 **远征统计**（与 `RunStatsOverlay` 同源 `RunStatsSnapshot`），本地只读、不影响下一局数值。

## 范围

| 记入 | 不记入 |
|------|--------|
| 爬塔 Run 胜/败后的远征统计 | 沙盒、附魔试验场 |
| 无尽 Run 结束后的远征统计 | 单场遭遇战报 |
| 最多 **30** 条，超出删最旧 | 局外奖励 / 跨局养成 |

持久化：`user://run_match_history.json`（`RunMatchHistoryStore` + `RunMatchHistoryCodec`）。

## 玩家操作

1. 主菜单 → **对局记录** → 列表点一条 → 全屏统计（与局内相同布局；主按钮 **返回列表**；可 **复制阵容**）。
2. **清空** 删除全部本地记录。
3. Run 结束链不变；在展示远征统计时自动 append 一条。

## 验收（轻量 + GUI 建议）

1. 完成一局爬塔或无尽并看完远征统计 → 主菜单列表出现对应摘要。
2. 点进详情：历程/战斗/队伍/巅峰与当局结束时一致。
3. 沙盒结束不产生新记录。
4. 主菜单按钮分组间距与胶囊样式一致（含「开始游戏」）。

实现：`scenes/ui/match_history/match_history_screen.tscn`、`scripts/core/run/run_match_history_*.gd`。
