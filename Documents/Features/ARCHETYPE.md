# 流派（内部设计语言）

> 功能规格 · 构筑方向分类与中毒流规则 · 2026-11-09  
> 相关：[游戏愿景](../GAME_VISION.md) · [角色技能](./UNIT_ABILITIES.md) · [战斗状态](./COMBAT_STATUS.md) · [战斗观战反馈](./COMBAT_FEEDBACK.md) · Content [技能库](../Content/UNIT_ABILITIES_ROSTER.md) · [中毒流内容](../Content/POISON_ARCHETYPE.md)  
> **本版不写**：玩家可见流派标签 / 构筑提示名；燃烧状态实装；虚弱流 / 狂暴流独立成簇；羁绊计数。  
> **【定稿】** 内部 **六主轴**；异常流本切片只交付 **中毒簇**。流派名**不对** UI / 卡面 / 教程露出（见 [角色技能](./UNIT_ABILITIES.md) §2.5）。

## 1. 这是什么

**流派**是策划用的内部构筑方向：玩家通过选角与站位，让战斗事件兑现成可认的胜负手感。  
玩家**看不到**流派名；靠技能说明、站位形状与观战因果自己摸索。

构筑深度仍 = 单位内建技能 + 槽位站位 + 增益卡。v1 **不做**种族 / 职业羁绊。

## 2. 六主轴【定稿】

| # | 内部名 | 玩家认路（不对玩家挂名） |
|---|--------|--------------------------|
| 1 | **坚韧** | 挨打才开始变强 |
| 2 | **收割** | 击杀 / 敌亡后滚雪球（承接愿景旧称「冲锋」的样板位） |
| 3 | **退场** | 死了也赚 |
| 4 | **召唤** | 场上变多 |
| 5 | **鼓舞** | 开战 / 回合给邻座加油 |
| 6 | **异常流** | 靠挂在单位身上的战斗状态词条改变胜负 |

- 混搭允许，且是加分；主轴是认路工具，不是互斥标签。  
- **白板身体**仍合法：可只堆身体与增益，不强制挂进某一主轴。  
- **经济**（开战产金、读金加身等）作跨遭遇养成辅轴，不升格为第 7 战斗主轴。  
- **虚弱 / 狂暴**可作零件挂在收割 / 鼓舞等轴上；**本切片不**另立「虚弱流 / 狂暴流」成簇交付。

## 3. 异常流 · 中毒簇【定稿】

### 3.1 一句话体验

这队不靠自己攻血一路飙，而靠给敌人挂上「轮到你就掉血」的中毒，用站位与拖节奏把伤害磨出来，并由受益者在出手时**按毒层打额外伤害**兑现。

### 3.2 规则底座

中毒结算、叠层上限、遭遇结束清空见 [战斗状态](./COMBAT_STATUS.md)（已有）：  
**该单位自己回合开始**先按层数扣生命；不走护甲、不吃虚弱；tick 致死则本动不跑「自己回合开始」技能。

施加 / 驱散走统一效果管线（`APPLY_COMBAT_STATUS` / `REMOVE_COMBAT_STATUS`）。不新开第三套状态系统；不做「场上中毒人数 ≥ N」羁绊。

### 3.3 职能骨架（无数值）

| 职能 | 玩家认路 | 功能 |
|------|----------|------|
| **邻格施加者** | 贴交战带给附近敌军上毒 | 典型：自己回合开始 → 周围一格敌军加中毒层 |
| **命中施加者** | 后排也可参与上毒 | 造成伤害时 → 对事件目标加中毒层 |
| **放大器** | 把毒堆厚或铺开 | 对**已中毒**目标再加层，和 / 或薄层多目标 |
| **毒向受益者** | 「敌人毒越厚，我打它越疼」 | 见 §3.4 |
| **拖拍肉盾** | 让敌方多跳几轮回合 | 自带技能或白板；职责是扛与占位，不是上毒核心 |

具体技能条目与挂载见 Content；本篇只定职能与规则。

### 3.4 毒向受益者【定稿】

| 项 | 规则 |
|----|------|
| **触发** | 对目标**造成伤害时**（含普攻与会走「造成伤害」事件的技能伤） |
| **条件** | 该目标当前中毒层数 **> 0** |
| **效果** | 再造成一段**额外技能伤害**；伤害量与目标**当前中毒层数相关**（玩家语言：多打约等于层数那么多；点数 / 倍率交数值） |
| **层数** | **只读、不消耗、不驱散**；毒层仍留给后续回合 tick 与多次兑现 |
| **防连环** | 该额外伤害**不再**触发「出手上毒」或「再读层数打一段」等连锁；上毒与吃毒分属不同职能技能 |
| **观战** | 走行动内技能 / 结果短标可读；状态层数仍可在长按信息卡查看（见 [战斗观战反馈](./COMBAT_FEEDBACK.md)） |

**【实现 As-Is】** `EffectAction.DamageMode.TARGET_STATUS_STACKS`：额外伤害 = 目标当前状态层数 × `value`（经升星倍率）；条件 `EVENT_TARGET_HAS_COMBAT_STATUS` + `condition_stat_name`。额外 `DEAL_DAMAGE` 仍 suppress「造成伤害」连锁。

### 3.5 站位与节奏

| 杠杆 | 含义 |
|------|------|
| 邻格上毒 | 施加者偏前或贴交战带；太后排则空挥 |
| 拖回合 | 毒伤在敌方回合开始才跳 → 需要扛住前几轮交换 |
| 与速切张力 | 全队秒杀会饿死毒跳次数与受益者读层次数 |
| Boss 斩首 | 拖磨对首领更涩；对清波小怪更甜（克制感，不另开系统） |

### 3.6 一句边界

本切片**只做**中毒簇上述职能与规则。  
本切片**不做**：燃烧单位状态；格子灼烧当中毒替代；虚弱 / 狂暴升格为异常流平行成簇；毒专用羁绊或玩家可见「中毒流」标签。

## 5. 验收口径（文档级）

1. 内部文档与 Content 备注可归入六主轴之一（或白板 / 经济辅轴）；不对玩家 UI 露出主轴名。  
2. 中毒流最小包在 Content 中可指认：邻格施加（已有种子）、命中施加、放大器、毒向受益者四类职能条目（挂载可分步）。  
3. 毒向受益者规则与 §3.4 一致：造成伤害时读层加伤、不耗层、额外段不连锁上毒 / 再读层。  
4. 燃烧与其它异常成簇不出现在本版规格正文展开中。
