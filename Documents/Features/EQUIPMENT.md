## 1. 这是什么

玩家在地图商店购买装备，挂到有空格的友方角色上。装备分两类：**护甲**（挡伤）与**技能类**（战斗自动触发效果）。格子按职业固定且两类混装。短点角色打开详情可卸载到队伍暂存，再挂给别人。

| 本篇负责 | 别处负责 |
|----------|----------|
| 装备种类、共槽、职业固定格数、挂/拒、卸载暂存、合计护甲、技能装「各触发 / 两件两次」、三合一合并 | **地图商店**：货架抽签与购买拖装 |
| — | **角色单位**：行为职业（坦克/近战/远程/刺客）与走打 |
| — | **角色技能**：技能效果内容池、触发与效果管线 |
| — | **数值**：护甲档、技能装售价、暂存格数 |

## 2. 术语

| 术语 | 意思 |
|------|------|
| **装备** | 永久挂在队伍成员上的道具；含护甲与技能类；跨遭遇保留。 |
| **护甲（装备）** | 提供抵挡点数；多件**相加为一条合计护甲**。 |
| **技能类装备** | 携带一条原「角色技能」效果；挂上后按技能规则自动触发。 |
| **装备槽上限** | 由行为职业固定：坦克 **0**、近战 **1**、刺客 **2**、远程 **3**。 |
| **队伍级装备暂存栏** | 卸载与三合一溢出进入；可再挂到有空格的成员。 |
| **合计护甲** | 各件护甲抵挡点数之和；战斗扫读与受伤结算按一条。 |

## 3. 槽位与购买

| 项 | 定稿 |
|----|------|
| 格数 | 见职业固定表；坦克 **故意为 0**（无法挂任何装备） |
| 混装 | 护甲与技能类占用同一套格子 |
| 购买 | 拖商店装备到角色：金够且有空格 → 扣金挂上；否则失败不扣金 |
| 新角色 | 招募 / 买入时**空装**（不自带技能、不自带护甲） |
| 废止 | 拖新装随机覆盖旧装 |

坦克拖装须有明确失败反馈（职业无法挂装）。

---

## 4. 结算

| 项 | 定稿 |
|----|------|
| 多件护甲 | 点数相加为一条合计护甲；头图 / 脚下扫读一条 |
| 技能类 | 每件各自按效果触发；**同一种挂两件则结算两次**（按槽位稳定顺序） |
| 护甲与受伤 | 有剩余护甲时本次不扣血、不触发「受伤时」；伤害先扣护甲；溢出部分也不扣血；装备不销毁；护甲下场战斗开战回满（细则同既有护甲表） |

## 5. 详情、卸载、暂存、阶段

与 2026-11-02 共识相同：短点详情；卸载进队伍暂存；暂存满拒绝卸载；地图商店 / 准备 / 招募可改装；开战只读；手势三分离。技能类与护甲同一暂存栏。

---

## 6. 三合一

参与成员全部装备优先填入产物空槽（不超过产物职业格数）；溢出进队伍暂存。废止「随机只留一件」。

---

## 7. 验收口径

1. 近战/刺客/远程有空格时可买护甲或技能装；坦克拖装失败且不扣金。  
2. 新进队成员空装。  
3. 满格拒买；无随机覆盖。  
4. 同技能装两件战斗中触发两次；多护甲合计一条。  
5. 短点详情可卸载到暂存再挂；开战不可改装。  
6. 三合一填槽、溢出进暂存。
