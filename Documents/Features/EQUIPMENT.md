# 装备

> 功能规格 · 角色装备槽、挂装 / 卸载、队伍级暂存与合计护甲 · 2026-11-02  
> 相关文档：[地图商店](./MAP_SHOP.md) · [玩家](./PLAYER.md) · [战斗观战反馈](./COMBAT_FEEDBACK.md) · [角色单位](./UNITS.md) · [游戏愿景](../GAME_VISION.md)  
> **本版不写**：非护甲装备大类（武器 / 饰品等）；装备单独卖金与退价表；暂存栏具体格数定稿；每名角色槽位数花名册；美术图标定稿。  
> **【用户新共识 · 2026-11-02】** 友方角色装备槽上限 **0～3**；槽满则买不了 / 挂不上；**废除**「拖新装随机覆盖旧装」；多件护甲 **数值相加为一条合计护甲**；**短点**开角色详情（槽位 + 缩略图 + 可卸载）；卸载进入 **队伍级装备暂存栏**，可再拖给有空槽的角色；手势 **短点=详情 / 拖角色=换座 / 长按=百科**。  
> **【边界】** 购买入口在 [地图商店](./MAP_SHOP.md)；本篇管槽模型、详情改装、暂存、合计护甲、三合一溢出与阶段可写边界。招募道具行**不**卖装备。

---

## 1. 这是什么

玩家把护甲类装备挂到友方角色的装备槽上，跨遭遇保留；槽满不能再挂。短点角色打开详情，看见槽位与缩略图，可卸载到队伍级暂存栏，再挪给其他有空槽的角色。战斗中同一角色多件护甲按**一条合计护甲**扫读与结算。

| 本篇负责 | 别处负责 |
|----------|----------|
| 槽上限、挂 / 拒、卸载、队伍暂存、详情改装入口、合计护甲、三合一装备合并 | **地图商店**：货架抽签、定价购买拖装、消耗品 |
| 手势三分离（短点 / 拖换座 / 长按百科）与阶段可写边界 | **战斗观战反馈**：长按百科卡样式、技能播报卡 |
| — | **玩家**：队伍 / 备战（角色板凳，不是装备暂存） |
| — | **数值**：护甲档点数、售价、暂存格数 |

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：装备、装备槽上限、已占用、队伍级装备暂存栏、合计护甲、角色详情（改装）  
- 挂装成功 / 失败条件（含商店购买与暂存挪装）  
- 卸载 → 暂存 → 再挂装  
- 多件护甲加成一条  
- 三合一时装备如何并入产物与溢出  
- 哪些阶段可改装、开战只读  
- 与长按百科、拖换座的分工  

### 2.2 一句边界

本版**做**：护甲装备、0～3 槽、满槽拒绝、详情卸载、队伍暂存再分配、合计护甲。  
本版**不做**：随机覆盖旧装；装备单独出售退金；开战改装；非护甲装备种类。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **装备** | 永久挂在队伍成员上的护甲类道具；跨遭遇保留；本版种类仅护甲分档。 |
| **装备槽上限** | 该成员最多可同时挂着的装备件数，取值 **0～3**（按角色配置；【建议】多数默认 1，花名册另填）。 |
| **已占用** | 该成员当前已挂装备件数。 |
| **空槽** | 已占用 &lt; 装备槽上限时的可挂容量。 |
| **队伍级装备暂存栏** | 整局队伍拥有的装备暂存区（**不是**角色备战区）；卸载与三合一溢出进入此处；可再拖到有空槽的成员。 |
| **合计护甲** | 同一成员所挂各件护甲抵挡点数之和；战斗扫读与受伤结算按**一条**合计护甲。 |
| **角色详情（改装）** | 短点友方角色打开的界面：可见槽位格、各件缩略图、合计护甲、卸载入口。 |

## 4. 槽位与挂装

| 项 | 定稿 |
|----|------|
| 槽上限 | 每名友方角色 **0～3**（资源 / 花名册配置） |
| 挂装条件 | 目标有空槽，且操作合法（见 §7 阶段） |
| 商店购买挂装 | 拖货架装备到角色：金币足够 **且** 有空槽 → 扣金、挂入空槽、货架槽清空；否则 **失败、不扣金、货架保留** |
| 暂存挪装 | 拖暂存栏装备到角色：有空槽则挂上并清空该暂存格；否则失败、暂存保留 |
| **废止** | 拖新装到已满 / 已有装角色时「旧与新随机留一件、另一件消失不退金」 |

0 槽角色永远无法挂装；拖装须有明确失败反馈（不只靠颜色）。

## 5. 角色详情与卸载

### 5.1 短点开详情

| 项 | 定稿 |
|----|------|
| 入口 | **短点抬起**友方角色（未达长按阈值、按下后位移未超拖拽阈值） |
| 主层须见 | 肖像 / 名 / 星；攻血；**装备槽位（按上限展示空/实格）+ 缩略图**；合计护甲（有则显示）；卸载入口 |
| 次要 | 技能短摘或「长按看全文」；主题类名一行 |
| 不做（详情主层） | 完整技能百科正文（归长按）；羁绊凑数效果句 |

### 5.2 卸载

| 项 | 定稿 |
|----|------|
| 操作 | 在详情中卸载某件已挂装备 |
| 去向 | 进入 **队伍级装备暂存栏** 的空格 |
| 暂存已满 | **拒绝卸载**，装备仍留在角色上，并提示 |
| 出售 | **本版不做**装备单独卖金；卸载 ≠ 出售 |

### 5.3 手势三分离【用户新共识】

| 手势 | 结果 |
|------|------|
| **短点**（抬起，未超拖阈值、未达长按） | 开 / 关角色详情（改装） |
| **拖角色**（按下后位移超阈值） | 换座 / 备战往返（写回持久占位；规则见 [玩家](./PLAYER.md)） |
| **长按**（约 0.4s） | [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2 **百科介绍卡**；松手只收卡，**不**改装 |
| 拖货架消耗品 / 装备 | 挂到角色（或失败提示）；与短点详情分离 |
| 拖暂存装备 → 角色 | 挪装（有空槽） |

详情已打开时，【建议】锁棋盘拖座，避免双通道；点空白或关闭收面板。

## 6. 队伍级装备暂存栏

| 项 | 定稿 |
|----|------|
| 归属 | **队伍拥有物**（与角色备战区分：暂存是装备，不是角色） |
| 寿命 | **整局、跨地图节点持久**；失败 / 通关随局清 |
| 容量 | **有上限**；满则不能再卸入、三合一溢出也不能再进（须有失败 / 提示）；**具体格数不定死**（数值填空） |
| 来源 | 详情卸载；三合一放不下的溢出件 |
| 去向 | 拖到有空槽的友方角色；本版**不能**拖回商店货架、**不能**卖金 |
| 呈现 | 功能上须可拖到角色；版式（半场固定行 vs 仅详情旁）实现可择一，验收以「能看见、能拖挂」为准 |

## 7. 阶段：可改装 vs 只读

| 阶段 | 装备 |
|------|------|
| **地图商店** | **可写**：拖货架购买挂装；短点详情卸载；暂存 ↔ 角色挪装；可换座 |
| **准备**（可换座半场） | **可写**：详情卸载、暂存挪装；**不能**买新装备（无货架） |
| **招募** | **可写**：详情卸载、暂存挪装；招募道具行**不**卖装备 |
| **开战观战** | **只读**：若可开详情则仅扫读槽位 / 缩略图 / 合计护甲；**禁止**卸载与挂装 |
| 胜后强化等点选屏 | **只读**；勿与短按写入抢手势 |

开战锁阵后不能改装备，与「纯观战」一致。

## 8. 合计护甲与受伤

### 8.1 多件加成一条【用户新共识】

同一成员挂多件护甲时：各件抵挡点数 **相加** 为 **合计护甲**。  
战斗脚下 / 头图扫读、受伤结算均按**这一条合计护甲**；详情与长按附属可 **分件列出** 各装备，但不得让玩家以为有多条独立护甲条在并行扣减。

### 8.2 护甲与「受伤」（自原地图商店迁入）

护甲在受伤结算中保护生命；**有剩余护甲时本次攻击不扣血**（护甲按受到的伤害扣减，扣到 0 为止；**伤害大于护甲时溢出部分也不扣血**）；**装备不销毁**。护甲仅在**下一场战斗节点开战**时回满，**战斗内不回满**。

| 结算结果 | 「受伤时」类触发 |
|----------|------------------|
| 受击时仍有护甲（含伤害 > 护甲导致护甲归零） | **不**扣血、**不**触发受伤类（仅消耗护甲） |
| 受击时护甲已为 0，扣完仍存活 | 正常扣血；**算**受伤并触发 |
| 受击时护甲已为 0，扣到生命归零 | 只走死亡；**不**触发「受到伤害 / 友方受伤」 |
| 护甲在本场战斗中耗尽 | 本场剩余时间无护甲；**离开战斗节点**时队伍数据回满（地图/招募立即可读）；下场开战仍会同步一次 |

有合计护甲时 UI 显示护甲值图标（格式对齐攻击 / 生命图标）。

## 9. 三合一与装备

触发与产物星级 / 攻血见 [玩家](./PLAYER.md) §4.1。本篇只定装备：

| 项 | 定稿 |
|----|------|
| 输入 | 参与合成的成员各自携带的全部装备 |
| 填入 | 优先填入合成产物的装备槽（不超过产物槽上限） |
| 溢出 | 放不下的件进入 **队伍级装备暂存栏**；暂存已满时的处理须有明确失败 / 提示（【建议】合成仍完成，溢出件在暂存满时拒绝进暂存并提示——实现前可在验收写「暂存须能收下本次溢出或先腾空」） |
| **废止** | 「参与成员装备中随机只留一件挂到产物、其余消失不退金」 |

填入顺序【建议】：高档护甲优先；同档任意稳定序。具体排序不锁平衡。

## 11. 验收口径

1. 有空槽时拖商店护甲到角色：扣金挂上；槽满或 0 槽：不扣金、不挂上，有失败反馈。  
2. **不再**出现「拖新装随机覆盖旧装」。  
3. 短点友方开详情：可见槽位与缩略图；可卸载到队伍暂存；暂存满则卸失败。  
4. 可从暂存拖到有空槽角色；目标满槽则失败。  
5. 拖角色仍换座；长按仍出百科、不改装；三者不互相抢成错误结果（位移超阈值走拖）。  
6. 地图商店 / 准备 / 招募可改装；开战详情只读，不能卸 / 挂。  
7. 多件护甲战斗中按一条合计护甲结算与扫读；有护甲时不扣血、不触发「受伤时」（规则同 §8.2）。  
8. 三合一：装备填满产物槽，溢出进暂存；不再随机只留一件。  
9. 本版不能单独卖装备退金；招募不卖装备。
