# 主题羁绊

> Features · **【用户新共识 · 2026-10-30】**  
> 相关：[角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · Content [UNITS_ROSTER](../Content/UNITS_ROSTER.md) · [GAME_VISION](../GAME_VISION.md)

## 1. 是什么

**主题羁绊**是友方角色的中世纪魔幻**主题包装分类**（七类）。每名可招友方**主归一类**。

本版玩家可见用途：**角色库 / 图鉴按主题筛选**。  
战斗内「同主题人数 → 团队增益」的阈值与效果**另切片定稿**；若落地必须走统一效果管线（`EffectSpec` / `EffectResolver`），禁止另写一套 Buff。

它**不是**「坚韧 / 冲锋」等内部玩法轴，也**不是**招募进队短句（见 [队伍羁绊台词](./UNIT_PARTY_BARKS.md)）。

## 2. 七类

| 主题 | 意象（剪影） |
|------|----------------|
| **亡灵** | 枯骨、殓葬、听亡与退场遗赠 |
| **战士** | 野战佣兵、蛮力与猎踪 |
| **骑士** | 骑乘、军府、王权誓卫与军饷 |
| **工匠** | 工坊器械：铁砧、火器、机括 |
| **军乐队** | 鼓号节拍、随军声色 |
| **秘术** | 咒印、药雾、奥术与影刃 |
| **护卫** | 盾墙与贴身护驾（含禁卫） |

成员名单与资源 id 见 [UNITS_ROSTER](../Content/UNITS_ROSTER.md)「主题羁绊」节。

## 3. 边界

| 要做 | 不做（本篇） |
|------|----------------|
| 每名友方主归一类；资源字段可序列化 | 用主题名代替内部玩法轴备注 |
| 角色库主题筛选 | 本篇不定战斗凑数阈值 / 光环数值 |
| 敌方镜像可同主题（便于对照） | 把队伍羁绊台词改成战斗加成 |

## 4. 验收口径（分类 + 筛选）

1. 可招友方均有主题；角色库可选「全部」或某一主题并刷新列表。  
2. 禁卫主归**护卫**。  
3. 筛选不改变战斗规则与招募经济。
