# 种族 / 职业羁绊（SYNERGY）

> 功能规格 · 团队层凑人规则骨架 · 2026-11-10  
> 相关：[游戏愿景](../GAME_VISION.md) · [流派](./ARCHETYPE.md) · [角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · Content [角色库](../Content/UNITS_ROSTER.md)  
> **本版写**：两套轴、职业词表、与技能/内部流派的边界、效果管线约束。  
> **本版不写**：种族具体词表；各标签人数阈值与团队效果文案；UI 角标样式；实现字段清单。  
> **【愿景定稿】** 构筑深度含种族 / 职业羁绊（**门槛**）与 **徽章**（**团队数值交付**，见 [徽章](./BADGE.md)）；职业词表见下。  
> **【用户新共识 · To-Be】** 羁绊只做凑人门槛 + Tag/计数点亮；**无对应徽章时即使凑齐也没有任何团队数值**；团队数值由**羁绊向徽章**兑现。  
> **【实现 As-Is】** 主路径已有**职业 Tag HUD**（仅已入座友方；**按不同角色 id 计数**，同 id 多份只算 1；无阈值激活 / 无团队数值效果）；徽章未实现。

## 1. 这是什么

**羁绊**是挂在友方角色身上的**玩家可见标签**：已入座凑齐同标签人数后，点亮「已激活」门槛。  
**团队数值 / 规则交付不由羁绊本身给出**，而由玩家持有的**对应羁绊向徽章**兑现（见 [徽章](./BADGE.md)）。无徽章时仅有计数与 Tag 点亮。  
与单卡主技能并行，不互相替代。

玩家靠商店 / 信息卡上的职业（及日后种族）标签认路并主动凑人；**不对玩家挂**内部六主轴名（坚韧 / 收割 / …）。

## 2. 两套轴【定稿】

| 轴 | 词表状态 | 规则 |
|----|----------|------|
| **职业** | **定稿**：坦克 · 战士 · 远程 · 工匠 · 军乐队 · 秘术 | 每名友方角色恰好 **1** 个主职业 |
| **种族** | 愿景已确认「有」；**具体名待拍板** | 与职业并存；各自计数、各自阈值 |

- 一名角色可同时带种族标签与职业标签。  
- 生成的代理角色（随从等）是否计入：**未决**（默认建议不计入，防刷）。  
- 敌方角色是否展示 / 结算己方同套词表：**未决**（本篇先定友方构筑）。

## 3. 职业词表认路【定稿】

| 职业 | 玩家认路（无数值） |
|------|-------------------|
| **坦克** | 偏厚、占前、拖节奏 / 承伤 |
| **战士** | 近战输出、切后、溅射打手（非主坦） |
| **远程** | 远程投射物单体（攻击方式默认落此；**奥术例外见 Content**） |
| **工匠** | 护甲 / 经济等工具感 |
| **军乐队** | 旗号鼓类鼓舞与节奏辅阵 |
| **秘术** | 咒术、状态、召唤赋活等非「弓弩枪」施法感（**奥术**属此类） |

挂载名单（草案→Content）见 [UNITS_ROSTER.md](../Content/UNITS_ROSTER.md) §2「职业」列。

## 4. 效果与边界

| 项 | 规则 |
|----|------|
| **无徽章无数值**【定稿】 | 仅凑齐人数、无对应羁绊向徽章 → **不**施加任何团队数值效果（只保留计数 / Tag 点亮） |
| **交付层** | 团队效果由 [徽章](./BADGE.md) 的羁绊向条目在「已激活」时注册；仍走统一效果管线（`EffectSpec` / `EffectResolver`）；**禁止**另开第二套 Buff / 状态系统 |
| **与单位技能** | 技能可用标签做**目标筛选**；**不等于**羁绊计数（见角色技能篇） |
| **与内部流派** | 六主轴仍是策划认路；不对玩家挂流派名；不把主轴改头换面当职业 |
| **与中毒簇** | 不做「场上中毒人数 ≥ N」式毒专用羁绊；中毒仍走战斗状态（见 [战斗状态](./COMBAT_STATUS.md)、[流派](./ARCHETYPE.md)） |
| **与队伍羁绊台词** | [队伍羁绊台词](./UNIT_PARTY_BARKS.md) 是招募进队**纯表现**短句，**不是**本篇凑人团队效果 |

## 5. 未决（实现前须拍板）

- 计数范围：**本切片定稿 = 仅已入座**（不含备战、不含召唤代理）；含备战等若改口径另开切片  
- **去重**【定稿】：同职业下按 **unit.id** 去重，相同角色多份入座只计 **1**；升星不另加计数  
- 开战中途阵亡或召唤后，羁绊层数是否即时重算（HUD 计数仍只跟座位，不跟场上存活）  
- 种族短词表与各职业 / 种族的人数阈值、团队效果  
- 双职业（若有）  
- 商店筛选 / 角标是否本版要做  

## 6. 验收口径（文档级）

1. 愿景与本文职业词表一致（六类；无法师）。  
2. Content 友方总表可指认每名角色的主职业。  
3. 无对应羁绊向徽章时，凑齐人数也不出现团队数值。  
4. 有徽章且已激活时，团队效果走统一效果管线；与「内部流派不对外」不冲突。
