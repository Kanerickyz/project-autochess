## 1. 这是什么

**Boss 遭遇**是幕终点战斗：流程仍是准备 → 观战 → 结算，胜则**直接通关**（不进招募）。与普通战的差异在**胜负模式、占地、一动策略、对砍例外与推开**，细则见本篇；节点进出见 [地图](./MAP.md) / [循环](./GAME_LOOP.md)。

玩家体验一句话：对面一只 **2×2 召唤统领**，每回合在「召枯骨杂兵 / 挪位推开友方 / 溅射砸人」里**只做一件事**；集火它时不被对砍反伤，**斩首即胜**，残兵溃散。

## 2. Boss 遭遇通则【定稿】

### 2.1 胜负模式：斩首

| 结果 | 条件 |
|------|------|
| **胜** | **首领单位**生命归零（斩首） |
| **败** | 己方场上没有存活单位（含友方代理；与愿景一致） |

斩首成立后：

1. 立即视为本场胜利（不必再清光其余敌方）。  
2. 清除场上**非首领**的敌方单位（含开场跟班若有、及本场召唤的衍生小兵）——称为**溃散**。  
3. 溃散**不视为死亡**：不掉击杀掉金；不触发「死亡时 / 击杀时」等退场类技能事件；从战场与行动队列移除。  
4. 若同一伤害结算批次内首领已死且己方亦全灭：**仍判玩家胜**（斩首优先于全灭）。

普通 / 精英遭遇**仍为清波制**（清光全部敌方才胜）。本例外**仅** Boss 节点。

### 2.2 与「一次出齐」的关系

敌方开战仍按关卡占座**一次出齐**。Boss **回合内召唤**走技能「生成的代理角色」管线，**不是**遭遇延时分批刷怪表。

### 2.3 非目标（一句）

不做「必须先杀信使 / 破盾才可伤 Boss」类解谜；首领**始终可被直接伤害**。

## 3. 足迹单位（2×2）【定稿】

默认战场仍是**一格一体**（见 [战斗关卡](./COMBATLEVEL.md)）。**足迹单位**（本版仅 Boss）例外：

| 项 | 约定 |
|----|------|
| 足迹 | 逻辑占用 **2×2** 共四格；足迹内每格仍禁止第二名单位 |
| 座位锚 | 准备预览 / 关卡配置仍只占 **1 个敌方角色座位**；开战生成后按固定规则展开 2×2 |
| 展开失败 | 越界或与已占格冲突时轮换展开朝向/平移；仍失败则本场降级为 1 格占位（实现须可观测告警） |
| 距离 | 索敌、攻距、是否进入攻距：切比雪夫格距取 **对方占格与本足迹各格之最近格**（非足迹中心欧氏） |
| 移动 | 整块足迹**刚性平移**：一步 = 四格同向移一格；目标四格皆在界内且最终可合法占格（含推开提交后）才可迈 |

普通单位、衍生小兵、友方仍严格一格一体。

## 4. 第一只：召唤统领【定稿】

### 4.1 定位

- **攻击方式**：近战溅射（以主目标格为心；攻距按足迹最近格）。  
- **一动策略（三选一互斥）**：只**召唤** / 只**移动** / 只**出手**。  
- **小兵**：复用友方 **枯骨**（`skeleton`）基础身体，敌方阵营代理；无主技能；不占准备座位；不得再召唤。  
- **开场**：**不带跟班**；关卡固定位仅首领本人。  
- **不做**：每回合自回血 / 自加攻作为本只差异预算。

### 4.2 一动决策（设计语言）

观战应读成「统领挑一件大事」，不是普通单位「靠近并出手」流水线。

```text
若 足迹最近格已对某敌进入攻距 → 出手（近战溅射）
否则若 场上衍生小兵未达上限 且 有合法召唤落点 → 召唤
否则若 存在可迈的一步（含推开友方后合法）→ 移动
否则 → 本动空手结束
```

数值（步数、上限、单次召唤只数、攻距档）交 Content / 数值填空；规则层要求：**场上衍生小兵硬上限**；达上限则本动不选召唤。

### 4.3 召唤

| 项 | 约定 |
|----|------|
| 时机 | 本动选择「召唤」时结算（挂在首领自己的一动内；可用「自己回合开始」类技能时机承载） |
| 额度 | 单次低额度（一只标准弱兵，或一小撮更弱——Content 二选一标注） |
| 落点 | 足迹邻格空位优先 → 再敌半场空格 → 皆无则本动召唤失败（不改选其它策略补做） |
| 队列 | 中途生成体插入行动队列：【建议默认】插在当前行动者之后（与战斗篇开放项一致） |

### 4.4 移动与推开

| 项 | 约定 |
|----|------|
| 谁被推 | 目标足迹将覆盖到的**友方角色**（玩家侧单位） |
| 不推 | 敌方小兵及其它敌方；若己方小兵挡在目标足迹内，该步**不合法**，改选方向或放弃移动 |
| 推往哪 | 沿本次平移方向，挤到**足迹外最近空格**；优先正前，其次斜前 |
| 伤害 | **不**因推开造成伤害 |
| 出界 | **禁止**推出战场；唯一下落在界外则改试侧向空格 |
| 无空位 | **整步移动失败**（首领不重叠友方格）；不做原地碾压秒杀 |
| 多友方 | 按稳定次序逐个推；任一人无法安置 → 整步回滚 |

推开是足迹平移特例，**不**恢复全场圆推挤为主轴。

### 4.5 对砍例外（不对称）

全局对砍规则见 [战斗](./COMBAT.md)。本只额外：

| 情形 | 约定 |
|------|------|
| 友方出手，**主目标＝首领** | 首领**不反打** |
| 首领出手，主目标＝友方 | 若互在攻距，友方**仍可**反打首领（同批结算） |
| 友方打小兵 / 小兵互殴 | 正常对砍 |

溅射次要目标本就不触发反打（沿用战斗篇）。

## 5. 验收（文档 / 实现对照）

1. Boss 节点：首领死亡 → 胜 → 通关；小兵溃散且不炸死亡召唤、不掉该笔击杀金。  
2. 普通 / 精英仍清波，不受斩首影响。  
3. 首领逻辑占 2×2；准备只占一敌座。  
4. 首领一动可见三选一（召 / 动 / 打），不会同动叠满三件。  
5. 友方打首领不对砍；首领打友方仍可能被反打。  
6. 首领移动可推开友方；无空位则该步失败。  
7. 召唤体为枯骨壳敌方代理；开场无跟班。  

**【实现】** 上列规则已接主路径战斗模拟与 Boss 遭遇资源；GUI 观感 / 数值手感待用户轻量验收。
