## 1. 这是什么

**徽章**是一整局里挂在**玩家**身上的全局物品：在「某职业已入座种类数 ≥ N」时兑现团队加成，或提供纯全局规则；类比杀戮尖塔圣遗物。  
不挂在某一名队伍成员上；卖人、替换、三合一**不**带走徽章。

体验骨架：打完胜仗 → **先**免费挑一枚徽章（或跳过）→ **再**进招募花金拿人 → 回地图。先定规则、再选人。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 拥有物语义（挂玩家、跨遭遇、失败清空）  
- 掉落时机与流程（三选一、可跳过、不花金）  
- 两支池：羁绊向 / 纯全局（无占比限制）  
- 羁绊向条件口径（职业 + N）  
- 与羁绊、增益卡、招募道具、地图商店、附魔的分工  
- **UX**：持有条、长按说明、三选一立绘式布局（占位圆优先）  
- 效果管线边界；品阶解锁口径  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 徽章何时获得、如何选择、挂谁、池子两支、阶段 UI | **循环 / 地图**：节点进出、Boss 通关 |
| 羁绊数值**由徽章按 N 交付** | **羁绊**：标签、计数、Tag HUD |
| — | **Content 徽章库**：具体 id / 名称 / N / 点数 |
| — | **招募**：短名单拿人（在徽章阶段**之后**） |
| — | **增益卡 / 药水 / 装备 / 附魔** | 

### 2.3 一句边界

本版**不做**：徽章花金购买；Boss 胜后徽章；失败后徽章；独立卖徽章界面（满员替换除外）；广度条件徽章（见 Content 未收录）。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **徽章** | 整局挂在玩家身上的一件全局规则物 |
| **羁绊向徽章** | 绑定某职业（或放大器）+ 需要种类数 **N**；`count ≥ N` 时兑现 |
| **纯全局徽章** | 不依赖职业凑人门槛的全局增益或条件效果 |
| **徽章三选一** | 胜后展示三枚候选，选一枚加入持有，或跳过 |
| **徽章持有条** | 招募 / 准备 / 战斗底部展示已装备徽章的横排 |

## 4. 玩家拥有（一整局）

| 拥有 | 跨遭遇 | 整局失败 |
|------|--------|----------|
| 已持有徽章列表 | **保留** | **清空** |

- 徽章**不是**队伍成员字段；不占座位、不占备战。  
- 开局默认不送徽章。  

---

## 5. 何时获得、怎么选

| 情况 | 是否进徽章三选一 | 之后 |
|------|------------------|------|
| 普通战斗 / 精英 **胜利** | **是**（每胜必出） | 选完或跳过 → **招募** → 回地图 |
| **Boss 胜利** | **否** | 通关 |
| 任一战斗类 **失败** | **否** | 整局失败重置（徽章清空） |

规则：

1. **不消耗金币**。  
2. **可跳过**：本场不拿新徽章；**不撤销**已持有。  
3. 展示 **三** 枚候选；选一枚加入持有。  
4. **同 id 不可重复持有**；抽到已有则重滚或灰显。  
5. **持有上限**（格数留给数值）：满员时改为替换一件或只能跳过。  
6. 本版**不做**独立卖徽章界面（满员替换除外）。

```text
普通 / 精英 胜 → 徽章三选一（可跳过）→ 招募 → 回地图
```

## 6. 两支池【定稿】

| 支 | 作用 | 占比 |
|----|------|------|
| **羁绊向** | 职业 × N（或放大器）兑现团队交付 | **不设**占比上限 |
| **纯全局** | 不依赖职业凑人 | **不设**占比上限 |

### 6.1 羁绊向条件【定稿】

- 每枚羁绊向徽章自带：**绑定职业** + **种类数 N**（Content 填具体 N）。  
- **计数**：仅已入座、按 `unit.id` 去重（与羁绊篇同口径）。  
- **兑现**：持有该徽章 **且** `count(职业) ≥ N`。  
- **无徽章**：无论 count 多少，**无团队数值**（Tag 仍可显示计数）。  
- 同职不同 N 的徽章可并存，各自判定。  
- 不设「全局某职已激活」布尔作为发奖开关；亮效果 = 持有且 count≥N。

进战斗的效果走统一效果管线；**禁止**另开第三套隐式规则。

## 9. UX【用户新共识 · To-Be】

### 9.1 徽章持有条（招募 / 准备·部署 / 战斗）

| 项 | 规则 |
|----|------|
| **何时显示** | **招募**、**准备（部署）**、**战斗观战**均显示当前已装备徽章 |
| **布局** | 屏幕**底部一条**横排（持有条）；不挡主棋盘操作热区为优先；可与底栏 Dock 分区或叠在其上方安全区，实现时保可读 |
| **图标** | 每枚一格；**本版占位 = 圆**（色块/空心圆均可）；正式纹样另案 |
| **空态** | 无徽章时可隐藏整条，或显示空位提示（二选一实现，须一致） |
| **战斗** | 只读：不可拖卸；观战期仍可长按查看 |

### 9.2 长按说明

| 项 | 规则 |
|----|------|
| **手势** | 长按持有条上某一徽章圆标 → 弹出说明（名、条件「职业 × N」、效果正文） |
| **手感** | 对齐单位长按信息卡口径（见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2）：长按出卡、滑动可切下一枚、松手收卡；不与拖棋盘单位手势冲突 |
| **三选一阶段** | 候选大图亦可长按看全文（与点选领取分流：长按不领取） |

### 9.3 三选一（立绘式，非粗按钮）

对齐招募候选人「**纸片 / 立绘槽**」表现，**禁止**用一排默认系统按钮当唯一候选项。

| 项 | 规则 |
|----|------|
| **构图** | 三枚候选**并排大图位**（竖屏可略叠或等分）；每枚 = **圆形主视觉占位**（优先布局）+ 下方名称 / 条件短句 |
| **参照** | 角色美术立绘或招募纸片的「主体剪影居中、信息在脚」层级；不是 Modal 里三个 `Button` 文本条 |
| **操作** | **点按**某一候选主视觉 = 选中领取；另提供可读的**跳过**（可弱化样式，但仍非唯一交互） |
| **已有 id** | 灰态或角标「已持有」，不可点领（或重滚，见 §5） |
| **本版美术** | 圆占位即可；先把三栏布局与底栏持有条跑通 |

```text
┌─────────┬─────────┬─────────┐
│  ○大圆  │  ○大圆  │  ○大圆  │
│  名称   │  名称   │  名称   │
│ 条件短句│ 条件短句│ 条件短句│
└─────────┴─────────┴─────────┘
        [ 跳过 ]
```

## 10. 验收口径（文档级）

1. 普通 / 精英胜后、进招募前，出现免费三选一（可跳过）；候选为立绘式三栏，非纯按钮条。  
2. Boss 胜 / 失败不进徽章阶段。  
3. 持有徽章跨遭遇保留；失败清空；卖人 / 三合一不丢。  
4. 无徽章时凑齐职业也无团队数值。  
5. 招募 / 准备 / 战斗底部可见持有条；长按圆标可读效果。  
6. 羁绊向按 Content 所写 N 与点数兑现（见 [徽章库](../Content/BADGE_ROSTER.md)）。
