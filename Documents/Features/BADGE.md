## 1. 这是什么

**徽章**是一整局里挂在**玩家**身上的全局物品：改整队规则或在「某羁绊已激活」时兑现团队加成，类比杀戮尖塔圣遗物。  
不挂在某一名队伍成员上；卖人、替换、三合一**不**带走徽章。

体验骨架：打完胜仗 → **先**免费挑一枚徽章（或跳过）→ **再**进招募花金拿人 → 回地图。先定规则、再选人。

---

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 拥有物语义（挂玩家、跨遭遇、失败清空）  
- 掉落时机与流程插入点（三选一、可跳过、不花金）  
- 两支池：羁绊向 / 纯全局（无占比限制）  
- 与羁绊、增益卡、招募道具、地图商店装备 / 消耗品、附魔的分工  
- 效果管线边界；品阶解锁口径  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 徽章何时获得、如何选择、挂谁、池子两支 | **循环 / 地图**：节点进出、Boss 通关 |
| 羁绊数值**由徽章交付** | **羁绊**：标签、计数、「已激活」门槛、Tag HUD |
| — | **招募**：短名单拿人 / 药水 / 旗帜（在徽章阶段**之后**） |
| — | **增益卡**：花金、挂某一名队员 |
| — | **地图商店**：消耗品 / 装备挂队员 |
| — | **附魔**：双献祭熔合 |
| — | **数值**：权重、持有上限格数、效果点数 |

### 2.3 一句边界

本版**不做**：徽章花金购买；Boss 胜后徽章；失败后徽章；单独出售徽章入口（满员替换见 §5）。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **徽章** | 整局挂在玩家身上的一件全局规则物 |
| **羁绊向徽章** | 条件依赖「某职业 / 种族羁绊已激活」，用于兑现或改写该羁绊的团队交付 |
| **纯全局徽章** | 不依赖凑人门槛的全局增益或条件效果（如某伤害类型倍率、经济 / 规则改写） |
| **徽章三选一** | 胜后展示三枚候选，选一枚加入持有，或跳过 |

## 4. 玩家拥有（一整局）

| 拥有 | 跨遭遇 | 整局失败 |
|------|--------|----------|
| 已持有徽章列表 | **保留** | **清空**（回开局默认，通常为空） |

- 徽章**不是**队伍成员字段；不占座位、不占备战。  
- 开局默认不送徽章（若日后「开局赠礼」另开切片）。  

---

## 5. 何时获得、怎么选

| 情况 | 是否进徽章三选一 | 之后 |
|------|------------------|------|
| 普通战斗 / 精英 **胜利** | **是**（每胜必出） | 选完或跳过 → **招募** → 回地图 |
| **Boss 胜利** | **否** | 通关（不进徽章、不进招募） |
| 任一战斗类 **失败** | **否** | 整局失败重置（徽章清空） |

规则：

1. **不消耗金币**。  
2. **可跳过**：本场不拿新徽章；**不撤销**本局已持有徽章。  
3. 展示 **三** 枚候选；选一枚加入持有。  
4. **同 id 不可重复持有**；候选若抽到已持有 id，应重滚或灰显不可选（实现二选一，须保证玩家总能理解「已有」）。  
5. **持有上限**（格数留给数值）：满员时三选一改为「替换一件已有」或只能跳过（须在 UI 可读）。  
6. 本版**不做**独立的卖徽章 / 自由换徽章界面（满员替换除外）。

流程：

```text
普通 / 精英 胜 → 徽章三选一（可跳过）→ 招募 → 回地图
```

## 6. 两支池【定稿】

| 支 | 作用 | 占比 |
|----|------|------|
| **羁绊向** | 读「某标签已激活」后兑现 / 改写团队交付 | **不设**占比上限 |
| **纯全局** | 不依赖羁绊门槛的全局规则 / 增益 | **不设**占比上限 |

三选一每次从已解锁池中抽取；可同屏出现两支的任意组合（由权重决定，权重本篇不写）。

### 6.1 效果形态（功能，无数值）

- **单纯全局增益**：无额外凑人条件即生效（仍可有战斗内触发时机）。  
- **若条件满足则…**：条件为触发时机或其他限制（状态词、击杀、经济等）；**羁绊向**的主条件是「对应羁绊已激活」。  

进战斗结算的效果必须走统一效果管线（与技能 / 羁绊交付同源约定）；**禁止**另开第三套隐式规则。

## 7. 与羁绊的关系【定稿】

对照 [种族 / 职业羁绊](./SYNERGY.md)：

| 层 | 职责 |
|----|------|
| **羁绊** | 标签、入座去重计数、Tag 点亮、「已激活」门槛 |
| **徽章（羁绊向）** | 在已激活时**交付团队数值 / 规则**；无对应徽章则**无团队数值** |

- **无徽章、即使凑齐人数**：只有计数 / Tag 点亮，**没有任何**团队数值效果。  
- 「已激活」与羁绊同口径：**仅已入座**、按角色种类去重对阈值；不含备战、不含召唤代理。  
- 阵亡是否重算：跟羁绊同一未决，徽章**不另开**「场上存活」口径。

## 8. 品阶与出现率

| 轴 | 规则 |
|----|------|
| **品阶（tier）** | 徽章池解锁与**角色品阶解锁同步**（同一套层进度解锁表）；未解锁品阶不进候选 |
| **出现率** | 池内用权重区分常见 / 少见（可对应内部「稀有度」）；**v1 不对玩家再露第二套稀有度名与解锁轴** |

具体权重与点数留给数值。

---

## 9. 验收口径（文档级）

1. 普通 / 精英胜后、进招募前，出现免费三选一（可跳过）。  
2. Boss 胜 / 失败不进徽章阶段。  
3. 持有徽章跨遭遇保留；整局失败清空。  
4. 卖人 / 三合一不丢徽章。  
5. 无羁绊向徽章时，凑齐职业 / 种族也无团队数值（仅 Tag / 计数）。  
6. 候选池可同时出现羁绊向与纯全局，无强制占比。  
7. 战斗内徽章效果走统一效果管线。
