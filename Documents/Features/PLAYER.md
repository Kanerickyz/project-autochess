## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**，以及一场遭遇里牌如何在 **抽牌堆 / 手牌 / 弃牌堆** 之间流动，从而决定何时能把友方角色打到战场上。

战场上的自动战斗、胜负、半场落点见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。本篇只定玩家侧资源与出牌节奏。

借鉴皇室战争的是：**小手牌 + 从自己的库里轮转补手**。不借鉴圣水；也不把构筑库锁死为 8 张——本作构筑库张数可变。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：构筑库、牌库条目、抽牌堆、手牌、弃牌堆、抽牌、打出、入手冷却、手牌宽度

| 本篇负责 | 别的文档负责 |

生成的代理角色**不是**玩家牌库拥有物，不进手牌或弃牌堆。是否计入「己方仍存活」（全灭判定）见 [战斗](./COMBAT.md)（定稿方向：代理算存活）。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **构筑库** | 这一整局里玩家拥有的全部角色牌集合。张数可变，可多于或少于 8。跨遭遇保留；商店等会改它。 |
| **牌库条目** | 构筑库里的一张角色牌（含等级、已挂增益等进度）。抽打轮转的基本单位。 |
| **抽牌堆** | 本场遭遇里「还没抽上手」的牌。开场由构筑库形成（开场洗乱），只在本场内消耗与洗回。 |
| **手牌** | 玩家当前可见、入手冷却结束后可打出的牌。有宽度上限。 |
| **弃牌堆** | 本场已打出、离开手牌的牌所在处。需要抽牌且抽牌堆为空时，弃牌堆洗回抽牌堆。 |
| **抽牌** | 从抽牌堆取牌加入手牌；加入时挂上入手冷却。 |
| **打出** | 选一张已冷却完毕的手牌，在合法落点生成友方角色；该牌进入弃牌堆，再尝试抽牌补手。 |
| **入手冷却** | 牌**进入手牌时**开始的短时不可打出状态。默认 **1 秒**（数值占位，可配置）。 |
| **手牌宽度** | 手牌最多保持几张。默认 **4**（可配置）。 |

「弃牌堆」是玩家规则用语：打出后离开手牌的循环区。它不是与构筑库无关的永久销毁；洗回抽牌堆后仍是同一批牌库条目。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 构筑库（全部牌库条目） | 保留，可被商店等修改 | 回到开局默认 |
| 金币等经济 | 见循环 / 经济约定 | 重置 |
| 手牌 / 抽牌堆 / 弃牌堆 | **不**跨遭遇保留；每场重建 | — |

手牌三区是**遭遇临时**；构筑库是**整局持久**。

## 5. 遭遇内牌流

### 5.1 进入遭遇（无准备阶段）

取消准备预布阵：进入战斗类节点后**直接进入可出牌的战斗**（阶段命名由战斗篇对齐）。

开场顺序：

1. 由当前**构筑库**生成本场**抽牌堆**并**洗乱**。  
2. **弃牌堆**为空；**手牌**为空。  
3. 连续抽牌，直到手牌达到手牌宽度，或抽牌堆与弃牌堆都无法再抽。  
4. 每张进入手牌的牌挂上**入手冷却**（含起手抽到的牌）。  
5. 冷却结束后，玩家可向合法落点打出，生成友方角色。

### 5.2 打出 → 弃牌 → 抽补

1. 只能打出**入手冷却已结束**的手牌。  
2. 打出成功：在战场生成对应友方角色；该牌库条目进入**弃牌堆**；手牌少一张。  
3. 若手牌张数低于手牌宽度：从抽牌堆抽 1 张补上（抽入即再次入手冷却）。  
4. **无人口**限制；不因「场上已有几人」禁止打出。

### 5.3 抽牌堆空时

当需要抽牌且抽牌堆为空：

- 若弃牌堆非空：将弃牌堆**全部洗回**抽牌堆，再抽。  
- 若弃牌堆也空：本下不抽（手牌可以暂时不满）。

### 5.4 入手冷却

| 项 | 规则 |
|----|------|
| 何时挂 | 牌从抽牌堆**加入手牌时**（起手、打出后补抽、洗回后再抽均适用） |
| 默认时长 | 1 秒（占位；其它秒数留给数值，可配置） |
| 冷却中 | 该手牌不可打出；不阻挡其它已冷却手牌打出 |
| 冷却结束 | 可打出 |

### 5.5 场上单位与牌位置

- 打出后，牌在弃牌堆（或已洗回抽牌堆 / 再次上手），与「该次打出生成的单位是否仍存活」**解耦**。  
- 单位死亡**不**单独改牌区位置；牌只按抽打与洗回规则移动。  
- 遭遇结算：手牌 / 抽牌堆 / 弃牌堆解散；牌库条目回到构筑库拥有态（无跨场手牌）。

### 5.6 构筑库张数与手牌宽度

- 构筑库张数 **N 可变**（可大于或小于手牌宽度）。  
- 若 N 小于手牌宽度：起手能抽多少是多少；之后靠打出 → 弃牌 → 洗回再转。  
- 若 N = 0：无牌可抽，无法打出友方（胜负见战斗篇）。

## 6. 相对旧闸门的玩家侧规则

| 旧设定 | 本篇规则 |
|--------|----------|
| 人口硬顶 | **无**。打出只受手牌、入手冷却、落点合法性约束。 |
| 准备预布阵 | **无**。无开战前摆阵步骤；遭遇内直接用手牌往战场打。 |
| 部署时间 | **无**。落地后即可按战斗规则行动（单位 / 战斗篇与此对齐）。 |
| 一张牌同时仅一体 | **取消**。场上允许多名同一兵种；同一牌库条目轮转再次上手并打出后，允许与先前仍存活的生成体并存。 |
| 本波固定抽子集再只在子集内滚 | **改为**整份构筑库进入本场抽打弃循环（张数 = 当前构筑库大小）。 |

## 7. 玩家可观察操作（验收口径）

1. 进战斗遭遇后能看到手牌（目标宽度上满，或库不足则更少）；牌先有短冷却再能打。  
2. 打出后该牌离开手牌进入弃牌堆（或等价提示），并尝试补抽一张入手（再冷）。  
3. 抽光后继续打出，能完成弃牌洗回再抽的一轮循环（库足够小时必现）。  
4. 无「人口已满」拦截；无准备阶段摆阵作为必经步。  
5. 在冷却与手牌约束下可连续打出，且可出现多名相同角色在场。
