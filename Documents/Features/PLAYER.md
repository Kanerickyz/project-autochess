# 玩家

> 功能规格 · 只谈玩家拥有什么、准备阶段如何布阵上场，不写具体数值 · 2026-10-16  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [招募](./RECRUIT.md) · [角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · [增益](../BUFF_SYSTEM.md)  
> **本版不写**：商店买卖细则与定价、扩席如何购买与费用、招募操作细则、座位世界坐标细表、伤害公式、技能花名册、三合一具体点数平衡表。  
> **【To-Be】** 持久拥有物为**队伍**；席位内角色**全体上场**；准备阶段**只调站位**；开战后天**完全观战**。队伍内**同角色同星满三自动三合一**（见 §4.1）。无号令（战令）及号令费用；无遭遇内抽牌 / 手牌 / 弃牌。**【As-Is】** 实时主路径仍为无准备、战中抽打弃 + 号令，且仍以牌库/手牌为中介；**文档 To-Be ≠ 已实现**。

## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**，以及一场遭遇的**准备阶段**里，如何把队伍中的角色摆进战场**角色座位**，从而决定本场站位。队伍在当前**队伍席位上限**内的成员**全部上场**（无「这局不上」的备战勾选，无抽选牌戏）。

战场自动战斗、胜负、座位几何见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。胜后短名单拿人 / 换人见 [招募](./RECRUIT.md)。升级、挂增益、**提高席位上限**等完整养成见商店文档（本篇只定拥有物与准备布阵）。

体验骨架：商店 + 胜后招募养成**队伍** → 进遭遇**准备站位** → 开战观战看结果。主乐趣是队伍换人取舍、养成（升级 / 增益）与座位站位，不是抽牌或战中微操。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：队伍、队伍成员、星级、队伍席位上限、角色座位、入座、开战锁阵、三合一  
- 一整局拥有物与跨遭遇保留  
- **自动三合一**（同角色同星满三）  
- 准备阶段：队伍成员入座 / 换座；席位内全体上场  
- 座位网格与席位上限的关系（座位固定 2×5；最大席位 ≤ 座位数）  
- 开战锁阵与遭遇结算  
- 和相邻文档的分界  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 玩家拥有的队伍、准备入座与站位 | **战斗**：胜负、敌方出兵时机、结算、阶段推进、开战锁操作 |
| 席位上限与座位网格的关系、全体上场 | **战斗关卡**：座位几何（含 2×5）、半场、敌方座位、开战连续移动 |
| — | **角色单位 / Content**：兵种属性与商店花费 |
| — | **角色技能**：触发与生成代理 |
| 队伍作为拥有物；席位上限「会变」的功能存在 | **愿景 / 循环**：商店何时访问、地图选路 |
| 队伍侧三合一规则（何时合、合出什么） | **招募**：招入 / 出售等如何改队伍（触发三合一） |
| — | **商店**：完整货架买卖、增益、扩席等；商店内招入同样遵守本篇三合一 |
| — | **增益**：挂在队伍成员上的效果内容 |

### 2.3 生成的代理角色

生成的代理角色**不是**玩家队伍拥有物，不占准备阶段的角色座位（由技能在战斗中生成）。是否计入「己方仍存活」见 [战斗](./COMBAT.md)。

### 2.4 一句边界

本版**不做**：遭遇内抽牌堆 / 手牌 / 弃牌、准备刷新、备战席（场下不上场的勾选）、号令（战令）及号令费用，以及开战之后的任何出牌 / 补人 / 改座。  
**做**：可成长的**队伍席位上限**（提高方式与费用见商店；本篇不写买法）。不引入利息、玩家经验条决定席位等自走棋整包人口经济——除非商店文档另开需求。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **队伍** | 这一整局里玩家拥有的友方角色集合。成员数 ≤ 当前**队伍席位上限**。跨遭遇保留；商店 / 招募等会改它。 |
| **队伍成员** | 队伍里的一名角色（含**星级**、当前攻血、已挂增益等进度）。入座与上场的基本单位。 |
| **星级** | 队伍成员的养成档位，默认 **1～3**。开局加入多为 1 星；**三合一**后升一档。信息卡与战场可读展示用「星」。 |
| **三合一** | 队伍里同角色、同星级的成员满 **3** 名时，**自动**合成 1 名更高星成员（见 §4.1）。 |
| **队伍席位上限** | 当前最多拥有、且全部上场的人数。可在商店中提高；**最大不超过**友方角色座位数（默认 **10**）。与「座位网格」合一语义上等于上场人数上限：席位内有人即打。 |
| **角色座位**（亦称角色槽） | 战场上看得见的友方站位座位。座位数由战斗关卡几何决定（默认 **2 行 × 5 列 = 10**），**固定不随席位扩展**。 |
| **入座**（入槽） | 把一名队伍成员放到空角色座位；开战时该座生成对应友方并锁阵。 |
| **换座** | 准备阶段调整已入座成员落在哪个座位（含收回后再入另一座）。 |

本版无「构筑库抽选」「手牌宽度」「准备刷新」等遭遇牌区术语。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 队伍（全部队伍成员） | 保留，可被商店 / 招募等修改 | 回到开局默认 |
| 当前队伍席位上限 | 保留，可在商店中提高 | 回到开局默认 |
| 金币等经济 | 见循环 / 经济约定 | 重置 |
| 本场角色座位占用 | **不**跨遭遇保留；每场准备重建 | — |

队伍与席位上限是**整局持久**；座位占用是**遭遇临时**。

开局时玩家拥有一支队伍与一个起始席位上限（具体人数与赠送角色由数值 / 商店约定填空；功能上开局席位 &lt; 最大席位 ≤ 10）。

### 4.1 自动三合一（队伍规则）

只要**整局队伍**里出现 **3** 名**同一角色**且**同一星级**的成员，就**立即自动合成**，无需玩家确认或拖叠。

| 项 | 规则 |
|----|------|
| 触发条件 | 同角色（同一兵种）**且**同星级，计数达到 3 |
| 触发时机 | 队伍构成刚变为满足条件的瞬间（例如招募招入第 3 个同名同星、商店买入等）。准备阶段不改队伍，故准备中不会触发 |
| 合成消耗 | 移除这 3 名成员 |
| 合成产物 | **1** 名同角色成员；**星级 = 原星级 + 1** |
| 攻 / 血 | 产物的**当前攻击**、**当前生命（及生命上限）** = 被合三份各自**当前攻击 / 当前生命（及上限）**的直接加总。具体手感不对再调，本篇不锁平衡表 |
| 技能 | **技能种类不变**（仍用该角色原自带技能；本版不因升星换技能或升技能档） |
| 增益 | 三份成员上已挂的增益**并入**合成体；冲突 / 叠加上限见增益文档，本篇不展开 |
| 星级上限 | **最高 3 星**。三个 3 星同角色**不再**自动合成 |
| 多于 3 只 | **不出现**：第 3 个同角色同星一进队就合掉，不会攒到 4 只同名同星并存 |
| 席位 | 合成后队伍人数 **−2**，立刻腾出空席，可继续招入 / 买入 |

验收要点：招入（或等价改队伍）使某同角色同星从 2 变为 3 时，玩家应立刻看到合成演出与结果（一人、星 +1、攻血为加总）；队伍中不应稳定存在 3 名以上同角色同星未合个体。

## 5. 遭遇内准备（站位）

### 5.1 进入遭遇 → 准备

进入战斗类节点后进入**准备阶段**（不是直接开战）。

开场顺序：

1. 友方角色座位皆空。  
2. 将当前**队伍**中的全部成员视为本场必上场名单（人数 = 队伍成员数 ≤ 当前席位上限）。  
3. 玩家把每位成员**入座**到我半场空座位，或调整已入座成员的座位（换座）。不要求占满全部 10 个座位；空座位用于站位选择。  
4. 准备阶段**不能**买人、卖人、扩席或改队伍构成（改队伍在**招募**或地图商店等完成）。  
5. 至少有 **1** 个座位已入成员时，可点**开始战斗**。不要求占满全部座位。若队伍成员数为 0：无法入座开战（胜负 / 是否禁止进遭遇见战斗篇）。

### 5.2 入座、全体上场与开战锁阵

1. 入座条件：目标为队伍成员、目标座位空、本场未开战；本场已入座人数不得大于队伍成员数（每人至多占一座）。  
2. **全体上场**：开战时，队伍中**每一名**成员都必须已入座。未完成入座前不可开战（或实现等价：开战前自动校验并提示缺座）。不允许留下「不上场」的队员。  
3. 入座成功：该成员占用该座位；记录 / 更新该座的**入座时间**（开战时友方生成序用；见战斗篇）。  
4. 换座：可把已入座成员收回（暂时不占座）再放入另一空座；收回后再入座时，该座入座时间更新为**最后一次成功入座**的时间。收回后若存在未入座成员，仍须在开战前全部入座。  
5. 点开战（生成序、部署时技能、「游戏开始」事件见 [战斗](./COMBAT.md) §6.5）：  
   - 各已占用座位按**入座时间序**依次生成对应友方角色（座位落点）；  
   - 敌方按遭遇配置书写顺序依次生成；  
   - 本场准备结束；  
   - 之后**完全不能改座、不能改队伍**。  
6. 已入座成员在开战后视为本场已部署；单位死亡**不**把该成员移出队伍（队伍仍是整局拥有物；本场只是战斗实例阵亡）。

### 5.3 遭遇结算

座位占用清零。队伍成员与席位上限保留（胜负与整局重置见循环 / 愿景）。

### 5.4 座位与席位上限

| 项 | 定稿默认 | 说明 |
|----|----------|------|
| 角色座位网格 | **2×5 = 10**（几何见战斗关卡） | **固定**；不随席位扩展 |
| 队伍席位上限 | 可成长；**最大 ≤ 10** | 等于当前可拥有且全部上场的人数 |
| 本场上场人数 | = 当前队伍成员数 | 成员数 ≤ 席位上限；开战全体入座 |

- 站位取舍来自：在最多 10 座中为全体队员选落点；席位较小时空座多，席位接近上限时可选空位变少。  
- 敌方占座与人数由关卡配置，**不**自动同步玩家席位上限。  
- 队伍席位上限可在商店中提高；提高方式与费用见商店文档。

## 6. 相对旧方向的玩家侧规则

| 旧方向 | 本篇规则 |
|--------|----------|
| 构筑库 + 准备抽选 / 手牌 / 弃牌 / 刷新 | **删除**遭遇牌区。拥有物改为**队伍**；准备只站位。 |
| 战中号令 + 抽打弃出牌 | **删除**。开战纯观战。 |
| 库可大于上场数、每场勾选谁上 | **改为**席位内全体上场；无备战勾选。 |
| 「无人口」且上场上限整局固定 | **改为**可成长的**队伍席位上限**（如何购买见商店）；最大 ≤ 座位数。 |
| 座位数 = 上场上限（旧设想） | **座位固定 2×5**；席位上限可变且 ≤ 10；空座服务站位。 |
| 无准备、进遭遇直接出牌 | **改为有准备**：布阵站位 → 开战。 |

## 7. 玩家可观察操作（验收口径）

1. 进遭遇后进入准备：可见队伍成员、当前席位上限、角色座位、已入座情况。  
2. 可将队伍成员入座、换座；开战前须全体成员入座。  
3. 准备阶段看不到抽牌 / 手牌 / 刷新；不能在准备阶段改队伍构成或扩席。  
4. 至少 1 人入座且全体成员已入座后可开战；开战后不可再改座。  
5. 无号令条、无号令费用；无备战席「不上场」勾选。  
6. 队伍内同角色同星满 3 会自动三合一（星 +1、攻血加总）；最高 3 星不再合；不会出现 4 只同名同星并存。
