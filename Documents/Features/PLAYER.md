## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**（已入座成员落在哪个友方座位、备战区里有谁），以及一场遭遇的**准备阶段**里如何微调站位、把备战送上场。**已入座**成员全部上场；备战区成员本场不上场（不是旧式「勾选谁上」，而是固定 5 格持久板凳）。

战场自动战斗、胜负、座位几何见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。胜后短名单拿人 / 换人见 [招募](./RECRUIT.md)。商店完整养成另案。

体验骨架：商店 + 胜后招募养成**队伍（上场 + 备战）与占位** → 进遭遇**准备微调站位 / 备战上座** → 开战观战看结果。主乐趣是队伍换人取舍、养成与站位，不是抽牌或战中微操。

### 2.3 生成的随从

生成的随从**不是**玩家队伍拥有物，不占准备阶段的角色座位（由技能在战斗中按次生成，无每角色本场累计上限）。是否计入「己方仍存活」见 [战斗](./COMBAT.md)。

### 2.4 一句边界

本版**不做**：遭遇内抽牌堆 / 手牌 / 弃牌、**准备刷新手牌**、号令（战令）及号令费用，以及开战之后的任何出牌 / 从备战补人 / 改座。  
本版**不做**：把备战格数做成可扩展（备战固定 5）；旗帜只扩**上场席位上限**。  
**做**：整局持久的友方占位与**备战区**；准备阶段可换座、备战与座位双向拖放；**已入座**成员全体上场。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **队伍** | 这一整局里玩家拥有的友方角色集合 = **已入座成员** + **备战区成员**。跨遭遇保留；商店 / 招募等会改它。 |
| **队伍成员** | 队伍里的一名角色（含**星级**、当前攻血、已挂增益、**占用的友方座位或备战格**等进度）。**熔印者**见 [附魔](./ENCHANT.md)。 |
| **星级** | 队伍成员的养成档位，默认 **1～3**。开局加入多为 1 星；**三合一**后升一档。信息卡与战场可读展示用「星」。**熔印者无星级**（不展示星；技能按 1★ 倍率）。 |
| **三合一** | 队伍里（**含备战**）同角色、同星级的成员满 **3** 名时，**自动**合成 1 名更高星成员（见 §4.1）。**熔印者不参与**。 |
| **熔印者** | 附魔节点熔合产物；非 roster 兵种；**无星级**、**无法三合一**；规则见 [附魔](./ENCHANT.md)。 |
| **上场席位上限** | 当前最多**入座上场**的人数。**本版开局为 5**；招募旗帜可扩至硬顶（见招募商店）；**不**等于总拥有上限。 |
| **备战区** | 跨遭遇持久的 **5** 个场下格；成员**不算上场**；准备 / 招募阶段可把备战与座位双向拖放（备战满不能再拖入）。战斗观战期显示但**只读**。 |
| **角色座位**（亦称角色槽） | 战场上看得见的友方站位座位。座位数由战斗关卡几何决定（默认 **4 行 × 5 列 = 20**，铺满半场）。空座用于站位选择。 |
| **持久占位** | 每位**已入座**成员占用哪个友方座位的整局状态。招募上区与战斗准备使用**同一套**占位；准备换座会写回。 |
| **入座**（入槽） | 把一名队伍成员（含来自备战）放到空角色座位；开战时该座生成对应友方并锁阵。 |
| **换座** | 调整已入座成员落在哪个座位；**写回持久占位**。不含「座位 → 备战」。 |
| **落座时间** | 该成员**最后一次成功落到某座**的时间戳；开战友方生成序用（见战斗篇）。准备换座、招募落座、备战上座都会刷新。 |

本版无「构筑库抽选」「手牌宽度」「准备刷新手牌」等遭遇牌区术语。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 队伍（已入座 + 备战全部成员） | 保留，可被商店 / 招募等修改 | 回到开局默认 |
| **友方持久占位**（已入座成员 ↔ 座位） | **保留**；准备换座、招募招入/替换/出售、备战上座会改 | 回到开局默认 |
| **备战区**（最多 5 名未入座成员） | **保留** | 回到开局默认（空或开局配置） |
| 当前上场席位上限 | 开局 5；旗帜可提高；保留该值 | 回到开局默认（仍为 5） |
| 金币等经济 | 见循环 / 经济约定 | 重置 |

队伍、上场席位上限、**备战区**与**友方持久占位**都是**整局持久**。敌方座位仍由每场遭遇配置，不跨场保留。

开局时玩家拥有一支队伍、上场席位上限 **5**、空或配置好的备战区，以及开局赠送成员的默认占位（具体人数与落点由数值 / 开局流程填空；已入座人数 ≤ 上场席位上限）。

**总拥有上限**（功能口径）：已入座人数 ≤ 上场席位上限，且备战人数 ≤ 5；二者之和为当前可拥有的最大人数。备战满且上场满时不能再买人（细则见招募篇）。

### 4.1 自动三合一（队伍规则）

只要**整局队伍**里出现 **3** 名**同一角色**且**同一星级**的成员，就**立即自动合成**，无需玩家确认或拖叠。

| 项 | 规则 |
|----|------|
| 触发条件 | 同角色（同一兵种）**且**同星级，计数达到 3。**熔印者**（`fused_enchant` 等模板）**不计入**、也不作为合成产物 |
| 触发时机 | 队伍构成刚变为满足条件的瞬间（例如招募招入第 3 个同名同星、商店买入等）。准备阶段不改队伍，故准备中不会触发 |
| 合成消耗 | 移除这 3 名成员 |
| 合成产物 | **1** 名同角色成员；**星级 = 原星级 + 1** |
| 攻 / 血 | 产物的**当前攻击**、**当前生命（及生命上限）** = 被合三份各自**当前攻击 / 当前生命（及上限）**的直接加总。具体手感不对再调，本篇不锁平衡表 |
| 技能 | **技能种类不变**（仍用该角色原自带技能）；每次三合一后，技能效果**数值 ×6**（相对合成前星级）：**1★ ×1 / 2★ ×6 / 3★ ×36** |
| 增益 | 三份成员上已挂的增益**并入**合成体；冲突 / 叠加上限见增益文档，本篇不展开 |
| 星级上限 | **最高 3 星**。三个 3 星同角色**不再**自动合成 |
| 多于 3 只 | **不出现**：第 3 个同角色同星一进队就合掉，不会攒到 4 只同名同星并存 |
| 席位人数 | 合成后队伍人数 **−2**，立刻腾出空席，可继续招入 / 买入 |
| **占位** | 合成体占用三只中**落座时间最早**者的座位；另外两座变空 |

验收要点：招入（或等价改队伍）使某同角色同星从 2 变为 3 时，玩家应立刻看到合成演出与结果（一人、星 +1、攻血为加总）；队伍中不应稳定存在 3 名以上同角色同星未合个体。  
**【表现】** 招募主路径：原料残影飞向合成座 → 合成体弹跳闪白 + 星标（Tween）；演出期间锁定招募操作。

### 4.2 改队伍时的占位默认

| 操作 | 占位 / 备战结果 |
|------|----------|
| 点买 / 等价招入（优先上场） | **上场未满** → 落到**第一个空友方座位**；**上场已满且备战未满** → 进入备战区；**上场与备战都满** → 无法购买 |
| 从招募区直接拖到空座 | 扣费后落到目标空座（满上场且无空座则失败或走替换，见招募篇） |
| 满员替换（拖到已占座） | 新人**继承**被替者座位；被替者离开队伍（不退金） |
| 出售（上区或备战） | 该成员离开队伍；若在座位则座位变空；若在备战则腾出备战格 |
| 准备 / 招募：备战 ↔ 座位 | 备战→空座上阵；座位→备战（备战未满）；写回持久状态；刷新落座时间 |
| 准备换座 | 写回持久占位，并刷新该成员的落座时间 |
| 三合一 | 见 §4.1（含备战成员计数） |
| 附魔融合 | 移除 A、B；熔印者继承 **A 的座位**（无座则第一个空座）；见 [附魔](./ENCHANT.md) |

## 5. 遭遇内准备（站位）

### 5.1 进入遭遇 → 准备

进入战斗类节点后进入**准备阶段**（不是直接开战）。

开场顺序：

1. 按整局**持久占位**，把**已入座**成员放到对应友方座位；**备战区**一行展示未入座成员（最多 5）：准备/战斗在**友方半场下方**，招募在**队伍与招募半场中缝**。  
2. 本场必上场名单 = **已入座**成员（人数 ≤ 上场席位上限）；备战不上场。  
3. 玩家可**换座**微调站位；可将**备战拖入空座位**，也可把**座位上的人拖回备战**（备战未满）；均**写回**持久状态。不要求占满全部座位。  
4. 准备阶段**不能**买人、卖人、改席位上限（改队伍在**招募**或地图商店等完成）；但可调整备战 ↔ 座位（双向；备战满则不能再拖入）。  
5. 准备阶段**没有**手牌区、**不能**刷新手牌。  
6. 至少 **1** 名已入座成员时可点**开始战斗**。若已入座为 0：无法开战（胜负 / 是否禁止进遭遇见战斗篇）。备战里可以有人，不阻止开战。

### 5.2 入座、全体上场与开战锁阵

1. 入座条件：目标为队伍成员（可来自备战）、目标座位空、本场未开战；每人至多占一座；已入座人数不超过上场席位上限。  
2. **已入座全体上场**：开战时，只生成**已入座**成员；备战区成员本场不上场。  
3. 换座 / 备战上座成功：更新持久占位；该成员的**落座时间**更新为最后一次成功落座时间（开战友方生成序用；见战斗篇）。  
4. 点开战（生成序、部署时技能、「游戏开始」事件见 [战斗](./COMBAT.md) §6.5）：  
   - 各已占用座位按**落座时间序**依次生成对应友方角色（座位落点）；  
   - 敌方按遭遇配置书写顺序依次生成；  
   - 本场准备结束；  
   - 之后**完全不能改座、不能改队伍、不能从备战补人**；备战行若仍显示则为**只读**。  
5. 已入座成员在开战后视为本场已部署；单位死亡**不**把该成员移出队伍（队伍仍是整局拥有物；本场只是战斗实例阵亡）。

### 5.3 遭遇结算

**不清空**友方持久占位与备战区。队伍成员、上场席位上限、备战与占位保留（胜负与整局重置见循环 / 愿景）。敌方座位占用随本场清场。

### 5.4 座位、上场席位上限与备战

| 项 | 定稿默认 | 说明 |
|----|----------|------|
| 角色座位网格 | **4×5 = 20**（铺满半场；几何见战斗关卡） | 空座用于选站位 |
| 上场席位上限 | **开局 5**；旗帜可扩至硬顶 | 最多入座上场人数 |
| 备战区 | **固定 5 格** | 跨遭遇持久；不算上场；不随旗帜增加 |
| 本场上场人数 | = 当前已入座成员数 | ≤ 上场席位上限 |

- 站位取舍来自：在座位网格中为已入座队员选落点；备战用于囤未上场成员。  
- 敌方占座与人数由关卡配置，**不**自动同步玩家上场席位上限。

## 6. 相对旧方向的玩家侧规则

| 旧方向 | 本篇规则 |

## 7. 玩家可观察操作（验收口径）

1. 进遭遇后进入准备：可见已入座成员按持久占位落在座位上、备战区一行（最多 5）、上场席位上限可读、可换座。  
2. 准备阶段可将备战拖入空座，也可把座位拖回备战（未满）；换座后状态仍在。  
3. 准备阶段看不到抽牌 / 手牌 / 刷新手牌；不能在准备阶段买人/卖人。  
4. 至少 1 人已入座可开战；开战后不可再改座，备战只读。  
5. 无号令条、无号令费用。

7. 已入座人数不超过上场席位上限；备战人数不超过 5。
