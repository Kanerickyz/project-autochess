## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**（已入座成员落在哪个友方座位、备战区里有谁），以及一场遭遇的**准备阶段**里如何微调站位、把备战送上场。**已入座**成员全部上场；备战区成员本场不上场（不是旧式「勾选谁上」，而是固定 5 格持久板凳）。

战场自动战斗、胜负、座位几何见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。胜后短名单拿人 / 换人见 [招募](./RECRUIT.md)。商店完整养成另案。

体验骨架：商店 + 胜后招募养成**队伍（上场 + 备战）与占位** → 进遭遇**准备微调站位 / 备战上座** → 开战观战看结果。主乐趣是队伍换人取舍、养成与站位，不是抽牌或战中微操。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：队伍、队伍成员、入座硬顶、备战区、角色座位、持久占位、入座、换座、开战锁阵、攻/血预算占用  
- 一整局拥有物与跨遭遇保留（含占位、备战、预算）  
- **无**自动三合一（本版取消）  
- 准备阶段：载入持久占位与备战、可换座、可将备战送入空座（预算检查）；已入座全体上场  
- 座位网格与入座硬顶 10、备战 5 的关系  
- 开战锁阵与遭遇结算（结算后永久损队见阵容预算 / 战斗）  
- 和相邻文档的分界  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 玩家拥有的队伍、备战区、持久占位、准备换座与备战上座 | **战斗**：胜负、敌方出兵时机、结算、阶段推进、开战锁操作 |
| 入座硬顶与座位网格的关系、已入座全体上场 | **战斗关卡**：座位几何（含 2×5）、半场、敌方座位、开战连续移动 |
| — | **角色单位 / Content**：兵种属性 |

| 队伍作为拥有物；入座 ≤10；备战固定 5 | **愿景 / 循环 / 阵容预算**：预算占用、开局赠队、三选一 |
| — | **招募**：招入 / 出售（退预算）/ 池份 |

| — | **增益**：挂在队伍成员上的效果内容 |

### 2.3 生成的随从

生成的随从**不是**玩家队伍拥有物，不占准备阶段的角色座位（由技能在战斗中按次生成，无每角色本场累计上限）。是否计入「己方仍存活」见 [战斗](./COMBAT.md)。

### 2.4 一句边界

本版**不做**：遭遇内抽牌堆 / 手牌 / 弃牌、**准备刷新手牌**、号令（战令）及号令费用，以及开战之后的任何出牌 / 从备战补人 / 改座。  
本版**不做**：旗帜扩席、自动三合一、备战格数扩展（备战固定 5）。  
**做**：整局持久的友方占位与**备战区**；**入座占用攻/血预算**；准备阶段可换座、备战与座位双向拖放；**已入座**成员全体上场。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **队伍** | 这一整局里玩家拥有的友方角色集合 = **已入座成员** + **备战区成员**。跨遭遇保留；硬顶 **15**（10+5）。 |
| **队伍成员** | 队伍里的一名角色（当前攻血、已挂增益、**占用的友方座位或备战格**等进度）。**熔印者**见 [附魔](./ENCHANT.md)。 |
| **星级** | **本版取消三合一主循环**后，星级展示可保留为遗留字段；**不做**同名满三合成。熔印者规则见附魔篇。 |
| **三合一** | **本版取消**（见 [阵容预算](./ROSTER_BUDGET.md)）。 |
| **熔印者** | 附魔节点熔合产物；非 roster 兵种；规则见 [附魔](./ENCHANT.md)。 |
| **入座硬顶** | 当前最多**入座上场**的人数。**本版固定 10**；**无旗帜**。 |
| **攻/血预算** | 入座时占用的双池额度；备战不占；见 [阵容预算](./ROSTER_BUDGET.md)。 |
| **备战区** | 跨遭遇持久的 **5** 个场下格；成员**不算上场**、**不占预算**；准备 / 招募可与座位双向拖放（备战满不能再拖入；入座须预算够）。战斗观战期显示但**只读**。 |
| **角色座位**（亦称角色槽） | 战场上看得见的友方站位座位。座位数由战斗关卡几何决定（默认 **2×5 = 10**，半场内垂直居中；空行是视觉留白）。空座用于站位选择。 |
| **持久占位** | 每位**已入座**成员占用哪个友方座位的整局状态。招募上区与战斗准备使用**同一套**占位；准备换座会写回。 |
| **入座**（入槽） | 把一名队伍成员（含来自备战）放到空角色座位；开战时该座生成对应友方并锁阵。 |
| **换座** | 调整已入座成员落在哪个座位；**写回持久占位**。不含「座位 → 备战」。 |
| **落座时间** | 该成员**最后一次成功落到某座**的时间戳；开战友方生成序用（见战斗篇）。准备换座、招募落座、备战上座都会刷新。 |

本版无「构筑库抽选」「手牌宽度」「准备刷新手牌」等遭遇牌区术语。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 队伍（已入座 + 备战全部成员） | 保留，可被商店 / 招募等修改 | 回到开局默认 |
| **友方持久占位**（已入座成员 ↔ 座位） | **保留**；准备换座、招募招入/替换/出售、备战上座会改 | 回到开局默认 |
| **备战区**（最多 5 名未入座成员） | **保留** | 回到开局默认（空或开局配置） |
| 入座硬顶 | 固定 10 | 回到 10 |
| 攻/血预算剩余 | 见阵容预算；跨遭遇保留 | 重置 |
| 金币等经济 | 见循环 / 阵容预算（金不买人） | 重置 |

队伍、入座硬顶、**备战区**、**友方持久占位**与**攻/血预算**都是**整局持久**。敌方座位仍由每场遭遇配置，不跨场保留。

开局：赠送 **6** 只攻击 1 / 生命 3 的骷髅（可全入座，**不消耗**开局预算），剩余可占用预算 **攻 2 / 血 2**；详见 [阵容预算](./ROSTER_BUDGET.md)。

**总拥有上限**：已入座 ≤ 10，且备战 ≤ 5；合计 ≤ 15。备战满且入座满时不能再入手（细则见招募篇）。

### 4.1 自动三合一（本版取消）

**【用户新共识 · 2026-11-11】** **取消**自动三合一。同名角色可在队伍与场上重复并存（仍受池内每角色 **3** 份限制）。旧合成演出与星级倍率规则**不再**作为本版主循环。

### 4.2 改队伍时的占位默认

| 操作 | 占位 / 备战 / 预算结果 |
|------|----------|
| 点买 / 等价招入（优先入座） | **入手不花金**。有空座且预算够 → 首空座并占用预算；否则进备战（不占预算）；入座与备战都满 → 无法入手 |
| 从招募区直接拖到空座 | 预算够则落到目标空座并占用；不够则失败 |
| 满员替换（点选上区成员） | 新人继承被替者座位与占用口径；被替者离队并按出售/替换口径退预算与池份（见招募篇） |
| 出售（上区或备战） | 离队；释放占用（若在座）；**退预算**；池份回库 |
| 准备 / 招募：备战 ↔ 座位 | 入座须预算够并占用；撤座释放预算；备战满不能再拖入；写回持久状态 |
| 准备换座 | 写回持久占位（预算占用随人，换座不改变占用数额） |
| 附魔融合 | 移除 A、B；熔印者继承 A 的座位；预算占用按熔印者基准重算（细则可另切）；见 [附魔](./ENCHANT.md) |

## 5. 遭遇内准备（站位）

### 5.1 进入遭遇 → 准备

进入战斗类节点后进入**准备阶段**（不是直接开战）。

开场顺序：

1. 按整局**持久占位**，把**已入座**成员放到对应友方座位；**备战区**一行展示未入座成员（最多 5）：准备/战斗在**友方半场下方**，招募在**队伍与招募半场中缝**。  
2. 本场必上场名单 = **已入座**成员（人数 ≤ 10）；备战不上场。  
3. 玩家可**换座**微调站位；可将**备战拖入空座位**（预算够），也可把**座位上的人拖回备战**（备战未满、释放预算）；均**写回**持久状态。不要求占满全部座位。  
4. 准备阶段**不能**买人、卖人（改队伍在**招募**完成）；但可调整备战 ↔ 座位（双向；入座受预算约束）。  
5. 准备阶段**没有**手牌区、**不能**刷新手牌。  
6. 至少 **1** 名已入座成员时可点**开始战斗**。若已入座为 0：无法开战（胜负 / 是否禁止进遭遇见战斗篇）。备战里可以有人，不阻止开战。

### 5.2 入座、全体上场与开战锁阵

1. 入座条件：目标为队伍成员（可来自备战）、目标座位空、本场未开战；每人至多占一座；已入座人数 ≤ 10；**剩余攻/血预算足以占用该成员基准面板**。  
2. **已入座全体上场**：开战时，只生成**已入座**成员；备战区成员本场不上场。  
3. 换座 / 备战上座成功：更新持久占位与预算占用；该成员的**落座时间**更新为最后一次成功落座时间（开战友方生成序用；见战斗篇）。  
4. 点开战（生成序、部署时技能、「游戏开始」事件见 [战斗](./COMBAT.md) §6.5）：  
   - 各已占用座位按**落座时间序**依次生成对应友方角色（座位落点）；  
   - 敌方按遭遇配置书写顺序依次生成；  
   - 本场准备结束；  
   - 之后**完全不能改座、不能改队伍、不能从备战补人**；备战行若仍显示则为**只读**。  
5. 已入座成员开战后视为本场已部署；**战斗中倒下不立刻离队**；**胜负结算后**倒下的已入座友方永久离队并退开战前基准预算（见 [阵容预算](./ROSTER_BUDGET.md)）。

### 5.3 遭遇结算

胜（普通/精英）：倒下已入座友方离队退预算 → 三选一 → 招募；未倒下的占位与备战保留。败：整局重置。Boss 胜：通关，不进三选一/招募。敌方座位占用随本场清场。

### 5.4 座位、入座硬顶与备战

| 项 | 定稿默认 | 说明 |
|----|----------|------|
| 角色座位网格 | **2×5 = 10**（半场内垂直居中；空行是视觉留白；几何见战斗关卡） | 空座用于选站位 |
| 入座硬顶 | **10**；无旗帜 | 最多入座上场人数 |
| 备战区 | **固定 5 格** | 跨遭遇持久；不算上场；不随旗帜增加 |
| 本场上场人数 | = 当前已入座成员数 | ≤ 上场席位上限 |

- 站位取舍来自：在座位网格中为已入座队员选落点；备战用于囤未上场成员。  
- 敌方占座与人数由关卡配置，**不**自动同步玩家上场席位上限。

## 7. 玩家可观察操作（验收口径）

1. 进遭遇后进入准备：可见已入座成员按持久占位落在座位上、备战区一行（最多 5）、上场席位上限可读、可换座。  
2. 准备阶段可点备战自动上阵（有空席时），也可拖备战入空座；可把座位拖回备战（未满）；换座后状态仍在。  
3. 准备阶段看不到抽牌 / 手牌 / 刷新手牌；不能在准备阶段买人/卖人。  
4. 至少 1 人已入座可开战；开战后不可再改座，备战只读。  
5. 无号令条、无号令费用。  
6. 队伍内（含备战）同角色同星满 3 会自动三合一（星 +1、攻血加总、占位按 §4.1）；最高 3 星不再合；不会出现 4 只同名同星并存。  
7. 已入座人数不超过上场席位上限；备战人数不超过 5。
