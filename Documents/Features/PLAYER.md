# 玩家

> 功能规格 · 只谈玩家拥有什么、遭遇内牌怎么流与出牌资源，不写具体数值 · 2026-10-14  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · [增益](../BUFF_SYSTEM.md)  
> **本版不写**：商店买卖与定价、半场几何、伤害公式、技能花名册、号令回复曲线与各牌具体费用点数。  
> **【To-Be】** 抽打弃 + **号令**（主闸门）+ 入手冷却弱化；无人口硬顶。**【As-Is】** 代码已有抽打弃与入手冷却（默认约 1 秒），**尚无号令**；部分旧路径仍含准备/人口等。**文档定稿 ≠ 已实现**。

## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**，以及一场遭遇里牌如何在 **抽牌堆 / 手牌 / 弃牌堆** 之间流动，并用 **号令** 决定何时打得起下一张，从而把友方角色打到战场上。

战场上的自动战斗、胜负、半场落点见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。本篇只定玩家侧资源与出牌节奏。

借鉴皇室战争：**小手牌 + 从自己的库里轮转补手**，以及**可自动回复、有上限的出牌资源**（本作包装为「号令」）。不借场上人口硬顶；构筑库张数可变，不锁 8。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：构筑库、牌库条目、抽牌堆、手牌、弃牌堆、抽牌、打出、号令、号令费用、入手冷却、手牌宽度  
- 遭遇内牌流与号令规则  
- 与无人口、无准备预布阵、无部署时间、允许场上多名同一角色相关的**玩家侧**规则  
- 和相邻文档的分界  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 玩家拥有的牌区、号令与出牌节奏 | **战斗**：胜负、刷怪、结算、阶段推进 |
| 打出时「牌去哪、手怎么补、是否扣号令」 | **战斗关卡**：我半场落点与占位 |
| 号令费用挂在角色定义、经牌库条目可读 | **角色单位 / Content**：具体兵种费用点数（数值） |
| — | **角色技能**：触发与生成代理 |
| 构筑库作为拥有物 | **愿景 / 循环**：商店何时改库、地图选路 |
| — | **增益**：挂在牌库条目上的效果内容 |

### 2.3 生成的代理角色

生成的代理角色**不是**玩家牌库拥有物，不进手牌或弃牌堆，**不消耗号令**（由技能效果生成）。是否计入「己方仍存活」见 [战斗](./COMBAT.md)（定稿方向：代理算存活）。

### 2.4 一句边界

本版不做第二条出牌资源，也不做击杀/受伤回号令等额外回复渠道（将来另开修订）。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **构筑库** | 这一整局里玩家拥有的全部角色牌集合。张数可变，可多于或少于 8。跨遭遇保留；商店等会改它。 |
| **牌库条目** | 构筑库里的一张角色牌（含等级、已挂增益等进度）。抽打轮转的基本单位。 |
| **抽牌堆** | 本场遭遇里「还没抽上手」的牌。开场由构筑库形成（开场洗乱），只在本场内消耗与洗回。 |
| **手牌** | 玩家当前可见的牌。须满足入手冷却结束（若有）且号令足够，才可打出。有宽度上限。 |
| **弃牌堆** | 本场已打出、离开手牌的牌所在处。需要抽牌且抽牌堆为空时，弃牌堆洗回抽牌堆。 |
| **抽牌** | 从抽牌堆取牌加入手牌；加入时可挂极短入手冷却。 |
| **打出** | 扣号令 → 在合法落点生成友方角色 → 该牌进入弃牌堆 → 再尝试抽牌补手。 |
| **号令** | 本场战斗中的出牌资源：随时间自动回复，有上限；打出成功时按费用扣除。 |
| **号令费用** | 打出该牌需要消耗的号令数量；由友方角色定义经牌库条目带来，商店养成阶段应可读。 |
| **号令上限** | 号令可积攒的最大值（可配置）。 |
| **入手冷却** | 牌进入手牌后极短不可打出（防误触）。**弱于**号令主闸门。 |
| **手牌宽度** | 手牌最多保持几张。默认 **4**（可配置）。 |

「弃牌堆」是玩家规则用语：打出后离开手牌的循环区。洗回抽牌堆后仍是同一批牌库条目。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 构筑库（全部牌库条目） | 保留，可被商店等修改 | 回到开局默认 |
| 金币等经济 | 见循环 / 经济约定 | 重置 |
| 手牌 / 抽牌堆 / 弃牌堆 / 号令 | **不**跨遭遇保留；每场重建 / 清零 | — |

手牌三区与号令是**遭遇临时**；构筑库是**整局持久**。

## 5. 遭遇内牌流

### 5.1 进入遭遇（无准备阶段）

取消准备预布阵：进入战斗类节点后**直接进入可出牌的战斗**（阶段命名由战斗篇对齐）。

开场顺序：

1. 由当前**构筑库**生成本场**抽牌堆**并**洗乱**。  
2. **弃牌堆**为空；**手牌**为空。  
3. **号令**设为可配置的开场初值（未满上限；可为 0 或其它占位），随后按规则回复。  
4. 连续抽牌，直到手牌达到手牌宽度，或抽牌堆与弃牌堆都无法再抽。  
5. 每张进入手牌的牌可挂**极短**入手冷却（若启用）。  
6. 满足号令与冷却后，玩家可向合法落点打出。

### 5.2 打出 → 弃牌 → 抽补

1. 只能打出同时满足：在手牌中、入手冷却已结束（若有）、**当前号令 ≥ 该牌号令费用**、落点合法。  
2. 打出成功：**扣除号令费用**；在战场生成对应友方角色；该牌库条目进入**弃牌堆**；手牌少一张。  
3. 若手牌张数低于手牌宽度：从抽牌堆抽 1 张补上（抽入可再挂极短入手冷却）。  
4. **无人口**限制；不因「场上已有几人」禁止打出。

### 5.3 抽牌堆空时

当需要抽牌且抽牌堆为空：

- 若弃牌堆非空：将弃牌堆**全部洗回**抽牌堆，再抽。  
- 若弃牌堆也空：本下不抽（手牌可以暂时不满）。

### 5.4 号令（出牌资源）【To-Be · 设计定稿方向】

> 【As-Is】实现尚未包含号令条与扣费；当前节奏仍主要依赖入手冷却等。

号令决定「什么时候打得起下一张」。与抽打弃并存：**抽打弃管手上有哪些牌，号令管现在能否支付打出。**

| 项 | 规则 |
|----|------|
| **回复** | 战斗进行中自动回复；达到上限后不再增加。**【默认占位】** 对齐皇室战争常态圣水：约 **每 2.8 秒回复 1 点**（可配置）。本版不做全局双倍回复。 |
| **上限** | **【默认】** 初始上限 **10**（可配置）。 |
| **扣费** | 打出成功时扣除该牌号令费用；不足则不可打出。 |
| **卡费挂哪** | 属于**友方角色定义**，经牌库条目带到本场；与商店**花费（金币）独立**。同一条目每次打出费用相同（本版不做临场改费）。各兵点数见 [Content 角色库](../Content/UNITS_ROSTER.md)。 |
| **开场** | **【默认占位】** 开场号令 **5**（未满上限）；遭遇结束清零，不跨遭遇保留。 |
| **可见** | 玩家应能看到当前号令与上限（或等价进度），以及手牌是否打得起。 |

#### 与入手冷却的分工

| 闸门 | 职责 |
|------|------|
| **号令** | **主闸门**：攒费、择时、贵贱牌取舍 |
| **入手冷却** | **弱化**：仅极短防误触或错峰（可配置；To-Be 默认可接近 0 或很短占位） |

本版不以长入手冷却、全局出牌硬直作为主节奏。若与号令叠用，冷却不得长到再次主导体验。  
【As-Is】代码中入手冷却默认约 1 秒，待号令落地后改为弱化默认。

#### 与无人口的分工

| 约束 | 职责 |
|------|------|
| **无人口硬顶** | 不因「场上已有几人」禁止打出 |
| **号令** | 用资源节奏限制单位时间内可投下的强度；场上仍可靠费用与空间自然挤兑 |

打出合法性 = 手牌中 + 冷却结束（若有）+ 号令足够 + 落点合法。**没有**「人口已满」拦截。

### 5.5 入手冷却（弱化）

| 项 | 规则 |
|----|------|
| 何时挂 | 牌从抽牌堆**加入手牌时**（起手、打出后补抽、洗回后再抽均适用） |
| 默认时长（To-Be） | 极短占位（可配置；可接近 0） |
| 冷却中 | 该手牌不可打出；不阻挡其它已满足条件的手牌打出 |
| 冷却结束 | 在号令足够时可打出 |

### 5.6 场上单位与牌位置

- 打出后，牌在弃牌堆（或已洗回抽牌堆 / 再次上手），与「该次打出生成的单位是否仍存活」**解耦**。  
- 单位死亡**不**单独改牌区位置；牌只按抽打与洗回规则移动。  
- 遭遇结算：手牌 / 抽牌堆 / 弃牌堆解散，号令清零；牌库条目回到构筑库拥有态。

### 5.7 构筑库张数与手牌宽度

- 构筑库张数 **N 可变**（可大于或小于手牌宽度）。  
- 若 N 小于手牌宽度：起手能抽多少是多少；之后靠打出 → 弃牌 → 洗回再转。  
- 若 N = 0：无牌可抽，无法打出友方（胜负见战斗篇）。

## 6. 相对旧闸门的玩家侧规则

| 旧设定 | 本篇规则 |
|--------|----------|
| 人口硬顶 | **无**。打出受手牌、号令、（弱）入手冷却、落点约束。 |
| 无出牌费用 / 不借圣水 | **改为有号令**（可回复、有上限；包装名，机制即出牌资源）。 |
| 准备预布阵 | **无**。遭遇内直接用手牌往战场打。 |
| 部署时间 | **无**。落地后即可按战斗规则行动。 |
| 一张牌同时仅一体 | **取消**。场上允许多名同一兵种；同一牌库条目可再次打出并与先前体并存。 |
| 本波固定抽子集再只在子集内滚 | **改为**整份构筑库进入本场抽打弃循环。 |
| 入手冷却作主节奏 | **降级**为极短防误触；主节奏交给号令。 |

## 7. 玩家可观察操作（验收口径）

1. 进战斗后可见手牌与号令（或等价进度）；号令未满时随战斗回复，达上限停止。  
2. 号令不足时无法打出高费牌；足够且冷却结束时可打出，打出后号令减少。  
3. 打出后该牌进入弃牌堆，并尝试补抽一张入手。  
4. 抽光后继续打出，能完成弃牌洗回再抽的一轮循环（库足够小时必现）。  
5. 无「人口已满」拦截；在号令与落点允许时可出现多名相同角色在场。  
6. 入手冷却若存在，仅表现为极短不可点，不主导「有号令时的节奏主体验」。
