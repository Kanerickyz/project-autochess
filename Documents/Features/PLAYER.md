# 玩家

> 功能规格 · 只谈玩家拥有什么、遭遇内牌怎么流与准备上场，不写具体数值 · 2026-10-14  
> 相关文档：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [战斗](./COMBAT.md) · [战斗关卡](./COMBATLEVEL.md) · [角色单位](./UNITS.md) · [角色技能](./UNIT_ABILITIES.md) · [增益](../BUFF_SYSTEM.md)  
> **本版不写**：商店买卖与定价、座位世界坐标细表、伤害公式、技能花名册。  
> **【To-Be】** 准备阶段：抽选 →（可刷新）→ 入座上场 → 点开战；开战**完全不能出牌**，只观战。无人口、无号令（战令）及号令费用。**【As-Is】** 实时主路径仍为无准备、战中抽打弃 + 号令；**文档 To-Be ≠ 已实现**。

## 1. 这是什么

**玩家**规定：一整局里玩家**拥有什么**，以及一场遭遇的**准备阶段**里，牌如何在 **抽牌堆 / 手牌 / 弃牌堆** 之间流动，玩家如何把抽到的角色卡放进战场**角色座位**，从而决定本场上场阵容与站位。

战场自动战斗、胜负、座位几何见 [战斗](./COMBAT.md) / [战斗关卡](./COMBATLEVEL.md) / [角色单位](./UNITS.md)。本篇只定玩家侧拥有物与准备牌流。

体验骨架：商店养成构筑库 → 进遭遇**准备布阵** → 开战观战看结果。主乐趣是构筑质量、抽选 / 刷新取舍与座位站位，不是战中微操或攒费出牌。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 术语：构筑库、牌库条目、抽牌堆、手牌、弃牌堆、抽牌、入座、刷新、角色座位、手牌宽度、本场上场人数上限  
- 准备阶段牌流与刷新规则  
- 入座与上场人数上限的关系（座位网格 ≠ 上限）  
- 开战锁阵（不能再出牌）与未入座牌去向  
- 和相邻文档的分界  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 玩家拥有的牌区、准备抽选与刷新 | **战斗**：胜负、敌方出兵时机、结算、阶段推进、开战锁操作 |
| 入座 / 收回时「牌去哪」、上场人数上限 | **战斗关卡**：座位几何（含 2×5）、半场、敌方座位、开战连续移动 |
| — | **角色单位 / Content**：兵种属性与商店花费 |
| — | **角色技能**：触发与生成代理 |
| 构筑库作为拥有物 | **愿景 / 循环**：商店何时改库、地图选路 |
| — | **增益**：挂在牌库条目上的效果内容 |

### 2.3 生成的代理角色

生成的代理角色**不是**玩家牌库拥有物，不进手牌或弃牌堆，也不占准备阶段的角色座位（由技能在战斗中生成）。是否计入「己方仍存活」见 [战斗](./COMBAT.md)。

### 2.4 一句边界

本版**不做**人口系统、号令（战令）系统、号令费用，以及开战之后的任何出牌 / 补人。  
「本场上场人数上限」是遭遇规则参数，**不是**成长式人口条。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **构筑库** | 这一整局里玩家拥有的全部角色牌集合。张数可变。跨遭遇保留；商店等会改它。 |
| **牌库条目** | 构筑库里的一张角色牌（含等级、已挂增益等进度）。抽选与入座的基本单位。 |
| **抽牌堆** | 本场「还没抽上手」的牌。开场由构筑库形成并洗乱。 |
| **手牌** | 准备阶段当前可见的候选角色卡。从中挑选入座。有宽度上限。 |
| **弃牌堆** | 本场已离开手牌、且按规则进入弃区的牌。需要抽牌且抽牌堆为空时，弃牌堆洗回抽牌堆。 |
| **抽牌** | 从抽牌堆取牌加入手牌。 |
| **角色座位**（亦称角色槽） | 战场上看得见的友方站位座位。座位数由战斗关卡几何决定（默认 **2 行 × 5 列 = 10**），**不等于**本场最多上场人数。 |
| **本场上场人数上限** | 本场最多同时占用友方座位的人数。默认 **4**。与座位网格分离。 |
| **入座**（入槽） | 把手牌中的一张牌放到空角色座位；开战时该座生成对应友方并锁阵。 |
| **刷新** | 准备阶段对当前**未入座**手牌重抽：这些牌回抽牌堆并重洗后再抽满手牌宽度（或抽到无法再抽）。每场最多 **3** 次。 |
| **手牌宽度** | 准备阶段手牌最多保持几张。默认 **4**（与上场人数上限同值）。 |

「弃牌堆」是玩家规则用语。洗回抽牌堆后仍是同一批牌库条目。

## 4. 玩家拥有什么（一整局）

| 拥有 | 跨遭遇 | 整局失败重置时 |
|------|--------|----------------|
| 构筑库（全部牌库条目） | 保留，可被商店等修改 | 回到开局默认 |
| 金币等经济 | 见循环 / 经济约定 | 重置 |
| 手牌 / 抽牌堆 / 弃牌堆 | **不**跨遭遇保留；每场重建 | — |
| 本场角色座位占用 | **不**跨遭遇保留 | — |

手牌三区是**遭遇临时**；构筑库是**整局持久**。

## 5. 遭遇内牌流（准备）

### 5.1 进入遭遇 → 准备

进入战斗类节点后进入**准备阶段**（不是直接开战）。

开场顺序：

1. 由当前**构筑库**生成本场**抽牌堆**并**洗乱**。  
2. **弃牌堆**为空；**手牌**为空；友方角色座位皆空。  
3. 连续抽牌，直到手牌达到**手牌宽度**，或抽牌堆与弃牌堆都无法再抽。  
4. 玩家可将手牌中的牌**入座**、从座位**收回到手牌**（在未达上场人数上限且目标为空座时可入座；手牌不得超过手牌宽度——收回时若手牌已满则不可收回，或须先入座/刷新腾位置；实现按「收回优先回到手牌，手牌满则不可收回」即可）。  
5. 玩家可对当前手牌使用**刷新**（见 §5.3），每场最多 3 次。  
6. 至少有 **1** 个座位已入牌时，可点**开始战斗**。不要求填满上限或填满全部座位。

### 5.2 入座与开战锁阵

1. 入座条件：牌在手牌中、目标座位空、当前已占用座位数 **&lt;** 本场上场人数上限、本场未开战。  
2. 入座成功：该牌离开手牌，占用该座位；记录 / 更新该座的**入座时间**（开战时友方生成序用；见战斗篇）；**不**因此自动补抽（手牌可以暂时少于宽度；默认不因入座补抽）。  
3. 已达上场人数上限后：不能再入座；仍可把已入座牌收回手牌后再换人 / 换座。收回后再入座：该座入座时间更新为**最后一次成功入座**的时间。  
4. 点开战（生成序、部署时技能、「游戏开始」事件见 [战斗](./COMBAT.md) §6.5）：  
   - 各已占用座位按**入座时间序**依次生成对应友方角色（座位落点）；  
   - 敌方按遭遇配置书写顺序依次生成；  
   - **未入座的手牌全部回到抽牌堆**（可再洗匀；在双方生成与部署技能结算之后）；  
   - 手牌清空；本场准备结束；  
   - 之后**完全不能出牌、不能改座、不能刷新**。  
5. 已入座的牌在开战后视为本场已使用；单位死亡**不**把该牌送回手牌或抽牌堆。

### 5.3 刷新（上限 3）

| 项 | 规则 |
|----|------|
| 何时可用 | 仅准备阶段；本场已用刷新次数 &lt; 3 |
| 刷新什么 | 当前**仍在手牌、未入座**的全部候选 |
| 旧牌去向 | **回抽牌堆**（与抽牌堆一并洗匀后再抽） |
| 已入座 | **保留**，不被刷新打乱 |
| 新牌 | 从抽牌堆再抽，直到手牌张数回到手牌宽度，或无法再抽 |
| 费用 | **免费**（本版不另扣金币） |
| 手牌已空 | 刷新不可用（例如全部已入座） |

### 5.4 抽牌堆空时

当需要抽牌且抽牌堆为空：

- 若弃牌堆非空：将弃牌堆**全部洗回**抽牌堆，再抽。  
- 若弃牌堆也空：本下不抽（手牌可以暂时不满）。

准备阶段常规路径下，未入座牌刷新时回抽牌堆，**不**进弃牌堆；弃牌堆主要用于其它将来规则或结算清理。开战时未入座牌回抽牌堆后，本场不再使用牌区出牌。

### 5.5 遭遇结算

手牌 / 抽牌堆 / 弃牌堆解散；牌库条目回到构筑库拥有态。座位占用清零。

### 5.6 手牌宽度、座位与上场人数上限

| 项 | 定稿默认 | 说明 |
|----|----------|------|
| 角色座位网格 | **2×5 = 10**（几何见战斗关卡） | 只定站位选择；空座常态 |
| 本场上场人数上限 | **4** | 入座硬顶；默认整局固定（是否随遭遇变化见愿景未决） |
| 手牌宽度 | **4** | 与上场人数上限同值；**不**要求大于座位数 |

- 选人取舍来自：构筑库构成、起手抽选、刷新（≤3）、以及在 10 座中选落点；**不**靠「手牌张数必须大于座位数」。  
- 构筑库张数 **N 可变**。若 N 小于手牌宽度：起手能抽多少是多少。  
- 若 N = 0：无牌可抽，无法入座开战（胜负 / 是否禁止进遭遇见战斗篇）。

## 6. 相对旧方向的玩家侧规则

| 旧方向 | 本篇规则 |
|--------|----------|
| 战中号令 + 抽打弃出牌 | **删除**。开战纯观战。 |
| 人口硬顶 / 成长式人口条 | **删除**。用**本场上场人数上限**约束入座人数；不用人口 UI。 |
| 座位数 = 上场上限 | **改为分离**：座位网格服务站位；上限单独封顶。 |
| 手牌宽度 &gt; 座位数 | **改为**手牌宽度默认 4（可与上限同值）；取舍靠抽选 / 刷新与站位。 |
| 无准备、进遭遇直接出牌 | **改为有准备**：抽选 → 入座 → 开战。 |
| 部署时间 / 入手冷却作节奏 | **不做**为出牌节奏（无战中出牌）。 |
| 一张牌同时仅一体（战中限制） | 本版无战中再出；同名多座由构筑库张数与抽选自然形成。 |

## 7. 玩家可观察操作（验收口径）

1. 进遭遇后进入准备：可见手牌、抽牌堆/弃牌信息（或等价）、角色座位、已入座数 / 上场人数上限、剩余刷新次数。  
2. 可将手牌入座、从座位收回；达上场人数上限后不能再入座（空座仍可见）。  
3. 可通过刷新改变未入座候选；已入座保留。  
4. 刷新最多 3 次：未入座牌回抽牌堆并重抽。  
5. 至少 1 人入座后可开战；不要求上满上限或占满全部座位；开战后不可再出牌、改座或刷新。  
6. 无人口条、无号令条、无号令费用。
