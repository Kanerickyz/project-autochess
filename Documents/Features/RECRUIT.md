## 1. 这是什么

**招募**是战斗类节点（普通战斗 / 精英）在**胜利结算之后、回到爬塔地图之前**的短养成阶段：玩家在「上区按战斗座位看已入座队伍、一行备战区、下区看候选人」的界面里，花金币把角色招进队伍（**点买优先上场空座**；上场满且备战未满则入备战；都满则无法购买），也可直接拖到上区座位、卖掉上区或备战成员换金币、把备战拖上座、刷新候选人、免费撤销本阶段操作、跳过或确认离开。

体验骨架：打完胜仗 → 用刚到手的金币做一次短名单囤人 / 换人 / 腾位整理（同时定下一场站位与备战）→ 回地图选下一路。主乐趣是战后即时取舍，不是完整商店。招募界面：上区队伍 → 中缝备战 → 下区两行（候选 / 道具动作）。

### 2.3 一句边界

本版招募**不做**：勾选式「谁上场」清单、遭遇内抽牌、地图商店式完整货架。  
**做**：短名单招人 / 替换、**出售腾位（正常退金，含备战）**、刷新、重置、跳过、完成；**持久备战区**；点买优先上场；备战可拖上区上阵；上区即战斗占位并写回持久状态；招入可触发队伍三合一（含备战）；**道具行**（药水永久属性、旗帜扩**上场**席位，见招募商店篇）。  
**不做**：Boss 胜后招募；失败后招募；战斗**准备**阶段道具商店；开战从备战补人。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **招募阶段** | 普通 / 精英胜利结算后、回地图前的短养成阶段 |
| **候选人** | 下区第一行展示的可招募角色；本场展示 **5** 个槽 |
| **招募** | 花金币把一名候选人加入队伍：点买优先上场空座；上场满则入备战；也可**拖到上区空座**；**不可**拖到已上场友方身上 |
| **替换** | 拥有已满时：先**点选候选人**再**点选上区成员**换掉；旧成员**离开队伍且不退金**（与「出售」不同）。**拖候选人盖到已占座不再触发替换** |
| **出售** | 将上区或**备战**一名队伍成员卖掉：成员离开队伍，**按正常出售价退金币**（点数见数值；口径与商店「正常退金」一致，本篇不另定薄退） |
| **备战区** | 跨遭遇持久 5 格；招募阶段可显示、可拖上座、可出售；不算上场 |
| **刷新** | 花金币重新随机三个候选人；不改动已进队成员 |
| **重置** | 免费；回到**本场进入招募瞬间**的快照（队伍 + 三人 + 本阶段相关金币） |
| **跳过** | 丢弃本阶段全部改动（等价先重置）后退出，回地图 |
| **完成** | 保留本阶段未重置的改动，退出回地图 |
| **进门快照** | 进入招募阶段瞬间的队伍、**持久占位**、三人候选、金币余额 |
| **出售落点** | 下区用于完成出售的可读落点（见 §6.2 / §8.2） |

## 4. 何时进入

| 情况 | 是否进招募 | 之后 |
|------|------------|------|
| 普通战斗 / 精英 **胜利** | **是** | 招募结束 → 回地图 |
| **Boss 胜利** | **否** | 直接整局通关 |
| 任一战斗类 **失败** | **否** | 整局失败重置 |

线性开发关工具环是否套用本阶段：本篇不定；主模式以爬塔为准。

| | **招募** | **地图商店** |
|--|----------|--------------|
| 时机 | 普通 / 精英胜后、回地图前 | 地图商店节点 |
| 职责 | 短名单拿角色 / 满员替换；**出售腾位**；刷新三人；改持久占位；**小药水 + 旗帜** | 高风险消耗品 + 装备 + 半场换座（见 [地图商店](./MAP_SHOP.md)）；买角色/升级/增益另案 |
| 货架 | 固定候选人 + 道具行 | 见地图商店篇 |
| 替换 | 旧人**不退金** | — |
| 出售退金 | **正常退金**（点数留给数值） | 出售细则见商店（可与招募共用退金口径） |

招募**不取代**地图商店。高风险消耗品与装备在**地图商店**；招募道具行仍仅小药水与旗帜。

## 6. 表现与布局（可读要点）

### 6.1 进出镜头（功能意图）

1. 战斗阶段结束：敌方半场向上移出摄像范围，友方半场向下移出摄像范围。  
2. 招募开始：上区（队伍）自上而下进入，下区（招募）自下而上进入，拼成一整屏。  

具体缓动与时长留给表现实现；本篇只要求玩家能读出「已离开战斗、进入招募」。

### 6.2 分区语义

| 区域 | 内容 | 说明 |
|------|------|------|
| **上区** | 已入座阵容（**友方持久占位**） | 使用与战斗准备**同一套**友方座位几何；成员落在其占位上（招募时画在队伍半场）。可招入落座、换座、接受备战上座（写回持久占位）。不开战 |
| **备战区** | 最多 5 名未入座成员 | **招募阶段**画在**队伍半场与招募半场之间**（逻辑中缝 / midline）；准备 / 战斗阶段仍可在友方半场下方。跨遭遇持久；上场满后点买落入；可与上区双向拖放（满则不能再拖入）；可拖出售 |
| **招募半场第 1 行** | **5** 个角色候选人 | 一行占满宽度（无列间距）；在备战中缝下方 |
| **招募半场第 2 行** | 道具 + **锁定** + **出售** | 与候选人行相邻（y 差为 1）；同一行排布、互不重叠；出售落点须与「拖候选人上场」区分可读（拖入时预览退金） |

常驻可读信息：阶段标题（如「招募」）、上下区 / 备战标签、当前金币、上场占用（已入座 / 上场席位上限）。色盲不单靠颜色分区。

长按上区 / 备战 / 下区角色查看技能等，见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2。

## 7. 候选人池

- 每次进入招募（及每次**刷新**）从池中随机抽出 **3** 个候选人。  
- 池子权重随**角色品阶**与玩家在本幕爬塔的**进度段**变化（例如幕内前 / 中 / 后段逐步偏向更高品阶）。  
- **品阶硬解锁**与敌池最高档同表（`TierUnlock`）：**第 1–3 层最高 T1；第 4 层起可出 T2；倒数 6 层起可出 T3**。  
- **倒数 6 层起**招募池**不再出 T1**（最低 T2）。  
- 进入部署且本层新解锁更高品阶时，居中半透明提示约 2 秒。  
- 每个可招募角色在**本局**卡池里共有 **9** 份。成功招募（空席加入或满员替换）拿走 1 份；只是出现在货架上、刷新换掉、或锁定未买，都不拿走。  
- 同一角色可以同时占多个候选槽，但不超过剩余份数（已拿走的加上当前货架上的）。某个角色 9 份都拿走后，之后的招募和刷新都不再出现该角色。  
- 出售或替换离队**不**把份数退回卡池。本阶段重置退回这一阶段拿走的份数；新开一局重新装满。三合一只合成已经拿走的单位，不另扣、也不退回。  
- **具体权重表**仍由数值填写；本篇定解锁档、每角色 9 份与重复上限。  
- 候选人默认以 **1 星**加入队伍（若数值另定开局星级，以数值为准；三合一仍按玩家篇）。

## 8. 操作规则

### 8.1 招募（扣金币）

1. **点买 / 点击候选人**（未指定座位）：  
   - 备战未满 → 扣费，加入**备战区**；  
   - 备战已满且上场未满 → 扣费，落到**第一个空友方座位**；  
   - 备战与上场都满 → **无法购买**。  
2. **拖到上区空座**：扣费，加入并落到目标空座（上场已满无空座则失败）。  
3. **拖到已占座**：**拒绝放置**（提示拖到空座位）；不扣费、不替换。需要换人时走「点选候选人 → 点选上区成员」或先出售腾位。  
4. 金币不足：不能完成该次招募。  
5. 加入完成后：若队伍（含备战）满足 [玩家](./PLAYER.md) §4.1 三合一条件，**立刻自动合成**。  

招募价见数值 / 单位数据；本篇不写点数。

### 8.2 出售（退金币）

1. 玩家将**上区或备战**一名队伍成员拖到**出售落点**（或等价交互）并松手。  
2. 该成员**离开队伍**；若在座位则座位变空，若在备战则腾出备战格；玩家获得**全额退金**：**1★ = 该角色招募原价**（`UnitData.cost`）；**每多合一星 ×3**（2★ = 3× 原价，3★ = 9× 原价）。  
3. 长按查看信息卡**不**触发出售；按下后移动超过拖拽阈值才进入拖态，松手落在出售落点才成交；可拖回取消。  
4. 出售造成的队伍、占位、备战与金币变动计入本阶段，可被**重置**回滚。  
5. 出售后若不再满足三合一条件，不会「拆开」已合成单位。

上场满员时玩家可先**出售腾位**再招入，也可**点选替换**（不退金）——两条路径并存；**不可**把候选人直接拖到已上场角色身上替换。

上区亦可在招募阶段**换座**；**备战与上区可双向拖放**（与准备阶段同规则；备战满则不能再拖入）。**点备战**有空上场席则自动入首空座（亦可拖到空座）。

### 8.3 刷新（扣金币）

- 花金币重新随机下区三个候选人。  
- **已招进队伍的成员保留**；已付招募费**不**因刷新退回。  
- 只扣刷新费；刷新费数额留给数值。  
- 金币不足时刷新不可用。

### 8.4 重置（免费）

- 回到**进门快照**：队伍、**持久占位**、三人候选、以及本阶段因招募 / 替换 / **出售** / 换座 / 刷新 / 三合一变动的**金币、队伍与卡池已拿份数**全部回滚到进入招募瞬间。  
- 不消耗资源。  
- 可多次使用。

### 8.5 跳过

- **丢弃**本阶段全部改动（等价执行一次重置），然后退出招募 → **回地图**。  
- 与「完成」不同：跳过不保留本阶段购买 / 替换 / 出售。

### 8.6 完成

- **保留**本阶段当前队伍与金币状态（未被重置的改动），退出招募 → **回地图**。  
- 完成时不要求必须招过人。

### 8.7 拥有物边界

- 招募改**整局队伍**（含备战）、**友方持久占位**与**金币**（含本阶段触发的三合一结果）。  
- 上区占位与备战与下一场准备 / 战斗共用；完成招募后保留。  
- 生成的代理角色不是队伍拥有物，不出现在招募上区 / 备战，不可出售。

## 9. 玩家可观察操作（验收口径）

1. 普通 / 精英胜利后进入招募；可见上区按战斗座位摆好的已入座队伍、备战区一行、下区候选人、出售落点、金币、上场占用（x/上限）。  
2. Boss 胜利不进招募，直接通关；失败不进招募。  
3. 点买优先入上场空座；上场满且备战未满则入备战；都满无法购买；可拖到上区空座；**不可**拖到已占座；满员替换靠点选（旧人不退金）；金不够不能招。  
4. 可将上区或备战成员拖到出售落点卖掉并获得正常退金；长按只看信息不卖。  
5. 上区可换座；备战与上区可双向拖放（备战满失败）；点备战可自动上阵（有空席）；完成后进入下一场准备时状态仍在。  
6. 招入后若同角色同星满 3（含备战），立刻自动三合一（见玩家篇验收）。  
7. 可花金刷新候选人；刷新后已进队 / 备战成员仍在。  
8. 可免费重置：队伍、占位、备战、候选人、本阶段相关金币回到进门状态。  
9. 跳过：改动丢弃后回地图；完成：保留改动后回地图。  
10. 旗帜扩的是上场席位上限，不扩备战格数。
