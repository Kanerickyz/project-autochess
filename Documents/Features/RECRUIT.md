## 1. 这是什么

**招募**是开局与每层战后的**主题承诺短名单**养成阶段：玩家先从随机给出的三个主题里选一个（可花金重 roll 主题盘），再在「上区已入座队伍、一行备战、下区候选人」界面里花金币招人（**点买优先上场空座**；上场满且备战未满则入备战；都满则无法购买），也可拖到上区空座、出售腾位、刷新候选人；战后阶段可**跳过**或**完成**，开局阶段**仅可完成**（且须至少 1 名已入座）。

体验骨架：承诺一条主题线 → 短名单囤人 / 换人 / 腾位 → 进入下一层战斗（或开局后进第一层）。主乐趣是主题承诺与即时取舍，不是完整商店。战后顺序见循环篇：先**商店或事件**，再进本阶段。

### 2.3 一句边界

本版招募**不做**：勾选式「谁上场」清单、遭遇内抽牌、商店式完整装备货架。  
**做**：主题三选一（重 roll **2** 金）；锁池短名单招人 / 替换、**出售腾位（正常退金，含备战）**、刷新候选人；开局不可跳过且完成须 ≥1 已入座；战后可跳过或完成；**持久备战区**；点买优先上场；上区即战斗占位；招入可触发队伍三合一；**道具行**（小药水、旗帜）；**远征行囊圣物可在本阶段出售换金**。  
**不做**：开局赠送队；Boss 胜后招募；失败后招募；战斗**准备**阶段道具商店；开战从备战补人；招募货架出售圣物。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **招募阶段** | 开局，或普通 / 精英胜且完成商店或事件之后的主题承诺短名单阶段 |
| **主题三选一** | 进入本阶段时从八主题中随机展示三个，玩家选一作为本阶段锁池承诺 |
| **主题盘重 roll** | 花 **2** 金重新随机三个可选主题；须再选一；候选人按新主题重抽；已进队成员不变 |
| **候选人** | 下区展示的可招募角色；仅**主或辅**匹配所选主题；槽位数见布局 |
| **招募** | 花金币把一名候选人加入队伍：点买优先上场空座；上场满则入备战；也可**拖到上区空座**；**不可**拖到已上场友方身上 |
| **替换** | 拥有已满时：先**点选候选人**再**点选上区成员**换掉；旧成员**离开队伍且不退金**。**拖候选人盖到已占座不再触发替换** |
| **出售** | 将上区或**备战**一名队伍成员卖掉并**按正常出售价退金币** |
| **备战区** | 跨遭遇持久 5 格；可显示、可拖上座、可出售；不算上场 |
| **刷新** | 花金币重新随机候选人（仍受本阶段已选主题锁池约束）；**不**重选主题；不改动已进队成员 |
| **重置** | **【As-Is】** 玩家**无**独立「重置」操作；**跳过**时内部回滚进门快照 |
| **跳过** | **仅非开局**：丢弃本阶段全部改动后退出 → 下一远征层。**开局不提供跳过** |
| **完成** | 保留本阶段改动后退出。开局完成须**至少 1 名已入座**；战后无此硬门槛 |
| **进门快照** | 进入招募阶段瞬间的队伍、**持久占位**、已选主题、候选人、金币余额 |
| **出售落点** | 下区用于完成出售的可读落点（见 §6.2 / §8.2） |

## 4. 何时进入

| 情况 | 是否进招募 | 之后 |
|------|------------|------|
| **开局** | **是**（第一场战斗前；无赠送队；**不可跳过**；完成须 ≥1 已入座） | 完成 → 第 1 层遭遇 |
| 普通 / 精英 **胜利**，且已完成商店或事件二选一 | **是**（可跳过） | 跳过或完成 → 下一远征层 |
| **Boss 胜利** | **否** | 直接整局通关 |
| 任一战斗类 **失败** | **否** | 整局失败重置 |

线性开发关工具环是否套用本阶段：本篇不定；主模式以爬塔为准。

## 5. 与战后商店的分工

| | **招募** | **战后商店**（选商店时） |
|--|----------|--------------------------|
| 时机 | 开局；或店|事之后 | 普通 / 精英胜后二选一的「商店」支 |
| 职责 | 主题三选一 + 锁池短名单；**出售腾位**；刷新；改持久占位；**小药水 + 旗帜** | 高风险消耗品 + 装备 + 半场换座（见 [地图商店](./MAP_SHOP.md)） |
| 货架 | 主题锁池候选人 + 道具行 | 见地图商店篇 |
| 替换 | 旧人**不退金** | — |
| 出售退金 | **正常退金**（点数留给数值） | 见商店 |

招募**不取代**商店。消耗品与装备在**选商店**时购买；招募道具行仍仅小药水与旗帜。

## 6. 表现与布局（可读要点）

### 6.1 进出镜头（功能意图）

1. 战斗阶段结束：敌方半场向上移出摄像范围，友方半场向下移出摄像范围。  
2. 招募开始：上区（队伍）自上而下进入，下区（招募）自下而上进入，拼成一整屏。  

具体缓动与时长留给表现实现；本篇只要求玩家能读出「已离开战斗、进入招募」。

### 6.2 分区语义

| 区域 | 内容 | 说明 |
|------|------|------|
| **上区** | 已入座阵容（**友方持久占位**） | 使用与战斗准备**同一套**友方座位几何；成员落在其占位上（招募时画在队伍半场）。可招入落座、换座、接受备战上座（写回持久占位）。不开战 |
| **备战区** | 最多 5 名未入座成员 | **招募阶段**画在**队伍半场与招募半场之间**（逻辑中缝 / midline）；准备 / 战斗阶段仍可在友方半场下方。跨遭遇持久；上场满后点买落入；可与上区双向拖放（满则不能再拖入）；可拖出售 |
| **招募半场第 1 行** | **5** 个角色候选人 | 一行占满宽度（无列间距）；在备战中缝下方 |
| **招募半场第 2 行** | 道具 + **锁定** + **出售** | 候选人行下方空一行后再排（y 差为 2）；同一行排布、互不重叠；出售落点须与「拖候选人上场」区分可读（拖入时预览退金） |

常驻可读信息：阶段标题（如「招募」）、上下区 / 备战标签、当前金币、上场占用（已入座 / 上场席位上限）。色盲不单靠颜色分区。

长按上区 / 备战 / 下区角色查看技能等，见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2。

### 6.3 候选人脚下数值（表现）

> 【用户新共识 · 2026-10-30 修订】**卡壳 / 拖出溶解已回撤**（shader 资源可保留备用）；本段只约束脚下数值可读。扣费、空座、已占座拒绝、点买去向等规则不变。

| 项 | 玩家读法 |
|------|----------|
| **静置候选人** | 下区＝**纸片角色**（无背景卡壳）；一行五槽仍可点 |
| **脚下数值** | 攻/血同排缩进单格；**价签单独第二行居中**；邻槽不互挡 |

## 7. 主题三选一与候选人池

### 7.1 主题三选一与主题盘重 roll

1. 进入本阶段时，从八主题中**随机展示三个**不同主题，玩家**必须选一**后才出短名单（可先模态）。  
2. 本阶段可**花 2 金重 roll 主题盘**：扣费后重新随机三个主题，玩家再选一；候选人按新锁池重抽；**已进队 / 备战成员保留**。  
3. 候选人**刷新**不重选主题；与主题盘重 roll 是两条操作。  
4. 每层（及开局）进入时重新三选一，**允许换线**；旧主题上场人数浪费即风险。  
5. 主题选择**只过滤货架**，**不**改变主题团队层强度（见 [主题羁绊](./UNIT_THEME_BONDS.md)）。

### 7.2 锁池入池口径

- 本阶段候选人必须满足：其**主主题或辅主题**与所选主题**任一匹配**即可入池。  
- 双标角色可在其主、辅各自被选中的阶段都出现在对应货架。  
- 上场成形仍按主题羁绊篇**主+辅双计**；入池口径 ≠ 成形计数。  
- 熔印者若不挂主题，则**不进**主题锁池货架（本版主循环亦不接入附魔产出）。

### 7.3 抽取与品阶

- 在锁池内，每次进入招募（及每次**刷新** / 主题盘重 roll 后）随机抽出候选人（槽位数见布局；常见为 3）。  
- 池子权重随**角色品阶**与本幕**远征层进度段**变化。  
- **开局招募**进度按**第 0 层**计品阶（与第 1–3 层同档：最高 T1）。  
- **战后招募**进行期间层号＝**刚胜利的那一层**；离开招募后再层号 +1（见远征层进度篇）。  
- **品阶硬解锁**与敌池最高档同表（`TierUnlock`）：**第 0–3 层最高 T1；第 4 层起可出 T2；倒数 6 层起可出 T3**。  
- **倒数 6 层**只计普通/精英进度带；**Boss 层号不计入**该倒数窗口。  
- **倒数 6 层起**招募池**不再出 T1**（最低 T2）。  
- 进入本阶段且本层新解锁更高品阶时，居中半透明提示约 2 秒。
  
- 每个可招募角色在**本局**卡池里共有 **9** 份。成功招募拿走 1 份；仅出现在货架 / 刷新换掉 / 锁定未买不拿走。  
- 同一角色可占多个候选槽，但不超过剩余份数。9 份拿光后本局不再出现。  
- 出售或替换离队**不**退回份数。**跳过**退回本阶段拿走的份数；新开一局重新装满。  
- **具体权重表**由数值填写；本篇定主题锁池、解锁档、每角色 9 份与重复上限。  
- 候选人默认以 **1 星**加入队伍（三合一仍按玩家篇）。

## 8. 操作规则

### 8.1 招募（扣金币）

1. **点买 / 点击候选人**（未指定座位）：  
   - 上场未满（有空友方座位）→ 扣费，落到**第一个空友方座位**；  
   - 上场已满且备战未满 → 扣费，加入**备战区**；  
   - 上场与备战都满 → **无法购买**。  
2. **拖到上区空座**：扣费，加入并落到目标空座（上场已满无空座则失败）。  
3. **拖到已占座**：**拒绝放置**（提示拖到空座位）；不扣费、不替换。需要换人时走「点选候选人 → 点选上区成员」或先出售腾位。  
4. 金币不足：不能完成该次招募。  
5. 加入完成后：若队伍（含备战）满足 [玩家](./PLAYER.md) §4.1 三合一条件，**立刻自动合成**。  

招募价见数值 / 单位数据；本篇不写点数。

### 8.2 出售（退金币）

1. 玩家将**上区或备战**一名队伍成员拖到**出售落点**（或等价交互）并松手。  
2. 该成员**离开队伍**；若在座位则座位变空，若在备战则腾出备战格；玩家获得**全额退金**：**1★ = 该角色招募原价**（`UnitData.cost`）；**每多合一星 ×3**（2★ = 3× 原价，3★ = 9× 原价）。  
3. 长按查看信息卡**不**触发出售；按下后移动超过拖拽阈值才进入拖态，松手落在出售落点才成交；可拖回取消。  
4. 出售造成的队伍、占位、备战与金币变动计入本阶段；**跳过**会一并丢弃（内部回滚进门快照）。  
5. 出售后若不再满足三合一条件，不会「拆开」已合成单位。

上场满员时玩家可先**出售腾位**再招入，也可**点选替换**（不退金）——两条路径并存；**不可**把候选人直接拖到已上场角色身上替换。

上区亦可在招募阶段**换座**；**备战与上区可双向拖放**（与准备阶段同规则；备战满则不能再拖入）。**点备战**有空上场席则自动入首空座（亦可拖到空座）。

### 8.3 刷新候选人（扣金币）

- 花金币在**本阶段已选主题锁池内**重新随机下区候选人。  
- **已招进队伍的成员保留**；已付招募费**不**因刷新退回；**不**重选主题。  
- 只扣刷新费；刷新费数额留给数值。  
- 金币不足时刷新不可用。

### 8.3b 主题盘重 roll（扣金币）

- 花 **2** 金重新随机三个可选主题；玩家须再选一；候选人按新主题重抽。  
- **已进队 / 备战保留**；本阶段已付招募费不退。  
- 金币不足 2 则不可用；可多次重 roll（每次扣 2）。

### 8.4 重置（【As-Is】无玩家操作）

- **【As-Is】** 招募 HUD **不提供**「重置」按钮；本阶段内**不能**在保留界面状态的前提下免费撤销已发生的招募 / 出售 / 刷新 / 换座 / 三合一等改动。  
- **进门快照**仍由实现维护：队伍、**持久占位**、候选人、金币、本阶段卡池已拿份数、旗帜本阶段购买次数等（见招募商店篇）。  
- **跳过**（仅非开局）时内部执行等价 `reset()`：回滚至进门快照，再退出 → **下一远征层**。  
- **开局不提供跳过**；丢弃本阶段改动的唯一路径不存在于开局（只能完成离开）。

### 8.5 跳过

- **仅普通 / 精英战后招募**可用。  
- **丢弃**本阶段全部改动（内部回滚至进门快照），然后退出 → **下一远征层**。  
- 与「完成」不同：跳过不保留本阶段购买 / 替换 / 出售 / 刷新 / 主题盘重 roll / 道具购买等。

### 8.6 完成

- **保留**本阶段当前队伍与金币状态后退出。  
- **开局**：完成 → 第 1 层；**须至少 1 名已入座**，否则完成不可用。  
- **战后**：完成 → 下一远征层；不要求本阶段必须新招过人。

### 8.7 拥有物边界

- 招募改**整局队伍**（含备战）、**友方持久占位**与**金币**（含本阶段触发的三合一结果）。  
- 上区占位与备战与下一场准备 / 战斗共用；完成招募后保留。  
- 生成的代理角色不是队伍拥有物，不出现在招募上区 / 备战，不可出售。

## 9. 玩家可观察操作（验收口径）

1. 开局无赠送队、有开局金（沿用现行 starting_gold）；进入招募后先主题三选一（重 roll **2** 金），再可见短名单；**无跳过**；完成须 ≥1 已入座。  
2. 普通 / 精英胜且完成商店或事件后进入招募；可跳过或完成。  
3. 候选人仅主或辅匹配所选主题；刷新候选人仍受该主题约束；主题盘重 roll 后须再选主题并重抽候选人。  
4. Boss 胜利不进招募；失败不进招募。  
5. 点买优先入上场空座；上场满且备战未满则入备战；都满无法购买；可拖到上区空座；**不可**拖到已占座；满员替换靠点选（旧人不退金）。  
6. 可将上区或备战成员拖到出售落点卖掉并获得正常退金。  
7. 上区可换座；备战与上区可双向拖放；完成后进入下一层准备时状态仍在。  
8. 招入后若同角色同星满 3（含备战），立刻自动三合一。  
9. **【As-Is】** 无「重置」按钮。  
10. 开局完成 → 第 1 层；战后跳过/完成 → 下一远征层；**不**回地图选路。  
11. 旗帜扩的是上场席位上限，不扩备战格数。
