## 1. 这是什么

**招募**是战斗类节点（普通战斗 / 精英）在**胜利结算之后、回到爬塔地图之前**的短养成阶段：玩家在「上区按战斗座位看自己队伍、下区看三个候选人」的界面里，花金币把角色招进队伍（有空席则加入并落到空座，满员则替换或先出售腾位），也可卖掉上区成员换金币、刷新候选人、免费撤销本阶段操作、跳过或确认离开。

体验骨架：打完胜仗 → 用刚到手的金币做一次短名单换人 / 腾位整理（同时定下一场站位）→ 回地图选下一路。主乐趣是战后即时取舍，不是完整商店。

**不做**：Boss 胜后招募；失败后招募；战斗**准备**阶段道具商店。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **招募阶段** | 普通 / 精英胜利结算后、回地图前的短养成阶段 |
| **候选人** | 下区第一行展示的可招募角色；本场展示 **5** 个槽 |
| **招募** | 花金币把一名候选人加入队伍（空席）或替换一名已有成员（满员） |
| **替换** | 满员时用候选人换掉一名队伍成员；旧成员**离开队伍且不退金**（与「出售」不同） |
| **出售** | 将上区一名队伍成员卖掉：成员离开队伍，**按正常出售价退金币**（点数见数值；口径与商店「正常退金」一致，本篇不另定薄退） |
| **刷新** | 花金币重新随机三个候选人；不改动已进队成员 |
| **重置** | 免费；回到**本场进入招募瞬间**的快照（队伍 + 三人 + 本阶段相关金币） |
| **跳过** | 丢弃本阶段全部改动（等价先重置）后退出，回地图 |
| **完成** | 保留本阶段未重置的改动，退出回地图 |
| **进门快照** | 进入招募阶段瞬间的队伍、**持久占位**、三人候选、金币余额 |
| **出售落点** | 下区用于完成出售的可读落点（见 §6.2 / §8.2） |

## 4. 何时进入

| 情况 | 是否进招募 | 之后 |
|------|------------|------|
| 普通战斗 / 精英 **胜利** | **是** | 招募结束 → 回地图 |
| **Boss 胜利** | **否** | 直接整局通关 |
| 任一战斗类 **失败** | **否** | 整局失败重置 |

线性开发关工具环是否套用本阶段：本篇不定；主模式以爬塔为准。

## 5. 与地图商店的分工

| | **招募** | **地图商店** |
|--|----------|--------------|
| 时机 | 普通 / 精英胜后、回地图前 | 地图商店节点 |
| 职责 | 短名单拿角色 / 满员替换；**出售腾位**；刷新三人；改持久占位 | 完整养成：买角色、升级、增益等（席位扩展另案） |

招募**不取代**地图商店；商店另有完整设计时，以商店文档为准扩展货架与养成，不在本篇展开。

## 6. 表现与布局（可读要点）

### 6.1 进出镜头（功能意图）

1. 战斗阶段结束：敌方半场向上移出摄像范围，友方半场向下移出摄像范围。  
2. 招募开始：上区（队伍）自上而下进入，下区（招募）自下而上进入，拼成一整屏。  

具体缓动与时长留给表现实现；本篇只要求玩家能读出「已离开战斗、进入招募」。

### 6.2 分区语义

| 区域 | 内容 | 说明 |
|------|------|------|
| **上区** | 当前队伍阵容（**友方持久占位**） | 使用与战斗准备**同一套**友方座位几何；成员落在其占位上。可在此招入落座、换座微调（写回持久占位）。**不是**敌方半场，也不开战 |
| **下区** | 三个候选人 + **出售落点** | 候选人固定 3 槽；出售落点须与「拖候选人上场」区分可读（独立出售槽，或下区明确「出售」高亮区；拖入时预览退金） |

常驻可读信息：阶段标题（如「招募」）、上下区标签、当前金币、席位占用（已有人数 / 上限 5）。色盲不单靠颜色分区。

长按上区 / 下区角色查看技能等，见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2。

## 7. 候选人池

- 每次进入招募（及每次**刷新**）从池中随机抽出 **3** 个候选人。  
- 池子权重随**角色品阶**与玩家在本幕爬塔的**进度段**变化（例如幕内前 / 中 / 后段逐步偏向更高品阶）。  
- **具体层段切分、权重表、是否允许重复种类**由数值填写；本篇只定「进度越深，高品阶越容易出现」这一功能方向。  
- 候选人默认以 **1 星**加入队伍（若数值另定开局星级，以数值为准；三合一仍按玩家篇）。

## 8. 操作规则

### 8.1 招募（扣金币）

1. 玩家将候选人拖到上区空座或等价交互（也可先点选再指定落点；功能上须完成「加入 + 占座」）。  
2. **有空席**（队伍成员数 &lt; 5）：扣该角色招募费，候选人加入队伍并落到目标空座（未指定则落到**第一个空友方座位**，见玩家篇 §4.2）；刷新落座时间；该候选槽清空或不可再招（实现可选）。  
3. **满员**：必须指定替换一名已有成员；扣招募费；候选人加入并**继承**被替者座位；被替换成员**直接离开队伍、不退金**。  
4. 金币不足：不能完成该次招募。  
5. 加入完成后：若队伍满足 [玩家](./PLAYER.md) §4.1 三合一条件，**立刻自动合成**（人数 −2、星 +1、攻血加总、占位按玩家篇）。  

招募价见数值 / 单位数据；本篇不写点数。

### 8.2 出售（退金币）

1. 玩家将**上区**一名队伍成员拖到**出售落点**（或等价交互）并松手。  
2. 该成员**离开队伍**，其座位变空；玩家获得**正常出售退金**（具体点数留给数值；本篇要求与「正常金币」口径一致，不做刻意薄退）。  
3. 长按查看信息卡**不**触发出售；按下后移动超过拖拽阈值才进入拖态，松手落在出售落点才成交；可拖回取消。  
4. 出售造成的队伍、占位与金币变动计入本阶段，可被**重置**回滚。  
5. 出售后若不再满足三合一条件，不会「拆开」已合成单位。

满员时玩家可先**出售腾位**再招入，也可直接**替换**（不退金）——两条路径并存，由玩家选择。

上区亦可在招募阶段**换座**（写回持久占位），与准备阶段换座同一规则。

### 8.3 刷新（扣金币）

- 花金币重新随机下区三个候选人。  
- **已招进队伍的成员保留**；已付招募费**不**因刷新退回。  
- 只扣刷新费；刷新费数额留给数值。  
- 金币不足时刷新不可用。

### 8.4 重置（免费）

- 回到**进门快照**：队伍、**持久占位**、三人候选、以及本阶段因招募 / 替换 / **出售** / 换座 / 刷新 / 三合一变动的**金币与队伍**全部回滚到进入招募瞬间。  
- 不消耗资源。  
- 可多次使用。

### 8.5 跳过

- **丢弃**本阶段全部改动（等价执行一次重置），然后退出招募 → **回地图**。  
- 与「完成」不同：跳过不保留本阶段购买 / 替换 / 出售。

### 8.6 完成

- **保留**本阶段当前队伍与金币状态（未被重置的改动），退出招募 → **回地图**。  
- 完成时不要求必须招过人。

### 8.7 拥有物边界

- 招募改**整局队伍**、**友方持久占位**与**金币**（含本阶段触发的三合一结果）。  
- 上区占位与下一场准备 / 战斗共用；完成招募后占位保留。  
- 生成的代理角色不是队伍拥有物，不出现在招募上区，不可出售。

## 9. 玩家可观察操作（验收口径）

1. 普通 / 精英胜利后进入招募；可见上区按战斗座位摆好的队伍、下区三人、出售落点、金币、席位占用（x/5）。  
2. Boss 胜利不进招募，直接通关；失败不进招募。  
3. 有空席时可花金招入并落到空座；满员时花金替换且旧人消失不退金、新人继承座位；金不够不能招。  
4. 可将上区成员拖到出售落点卖掉并获得正常退金（座位变空）；长按只看信息不卖。  
5. 上区可换座；完成后进入下一场准备时站位仍在。  
6. 招入后若同角色同星满 3，立刻自动三合一（见玩家篇验收）。  
7. 可花金刷新三人；刷新后已进队成员仍在。  
8. 可免费重置：队伍、占位、三人、本阶段相关金币回到进门状态。  
9. 跳过：改动丢弃后回地图；完成：保留改动后回地图。  
10. 招募界面不能挂增益、不能扩展席位上限。
