## 1. 这是什么

**招募**是战斗类节点（普通战斗 / 精英）在**胜利结算与三选一之后、回到爬塔地图之前**的短养成阶段：玩家在「上区看已入座队伍、一行备战、下区看候选人」的界面里，把角色招进队伍（**入手不花金**；**点买优先入座**且占用预算；否则进备战），也可拖到上区座位、卖掉成员**退预算**、把备战拖上座（预算检查）、花金刷新、**跳过**或**完成**离开。

体验骨架：打完胜仗 → 损队退预算 → 三选一 → 短名单重组站位与备战 → 回地图。主乐趣是预算拼图与战后取舍。

### 2.3 一句边界

## 3. 术语

| 术语 | 意思 |
|------|------|
| **招募阶段** | 普通 / 精英胜利结算后、回地图前的短养成阶段 |
| **候选人** | 下区第一行展示的可招募角色；本场展示 **5** 个槽 |
| **招募** | 把一名候选人加入队伍（**不花金**）：点买优先入座（预算够）；否则入备战；也可**拖到上区空座**（预算检查）；**不可**拖到已上场友方身上 |
| **替换** | 拥有已满时：点选候选人再点选上区成员换掉；旧成员离队并按出售口径**退预算**与池份。**拖候选人盖到已占座不再触发替换** |
| **出售** | 将上区或**备战**一名成员卖掉：离队，**退基准攻/血预算**，池份回库 |
| **备战区** | 跨遭遇持久 5 格；不占预算；可拖上座（预算检查）、可出售；不算上场 |
| **刷新** | 花金币重新随机候选人；不改动已进队成员 |
| **重置** | **【As-Is】** 玩家**无**独立「重置」操作。实现保留进门快照与内部 `reset()`，仅供**跳过**时回滚本阶段改动（见 §8.4） |
| **跳过** | 丢弃本阶段全部改动（内部回滚至进门快照）后退出，回地图 |
| **完成** | 保留本阶段改动，退出回地图 |
| **进门快照** | 进入招募阶段瞬间的队伍、**持久占位**、三人候选、金币余额 |
| **出售落点** | 下区用于完成出售的可读落点（见 §6.2 / §8.2） |

## 4. 何时进入

| 情况 | 是否进招募 | 之后 |
|------|------------|------|
| 普通战斗 / 精英 **胜利** | **是**（先结算离队退池 → 三选一） | 招募结束 → 回地图 |
| **Boss 胜利** | **否**（无三选一） | 直接整局通关 |
| 任一战斗类 **失败** | **否** | 整局失败重置 |

线性开发关工具环是否套用本阶段：本篇不定；主模式以爬塔为准。

## 5. 与地图商店的分工

| | **招募** | **地图商店** |
|--|----------|--------------|
| 时机 | 普通 / 精英胜后（三选一之后）、回地图前 | 地图商店节点 |
| 职责 | 短名单拿角色（不花金）/ 满员替换；**出售退预算**；花金刷新；改持久占位与预算占用；**小药水** | 消耗品 + 装备 + 半场换座（见 [地图商店](./MAP_SHOP.md)）；**不含买人** |
| 货架 | 固定候选人 + 药水行 | 见地图商店篇 |
| 出售 | **退预算** + 池份回库 | 装备/消耗品细则见地图商店 |

招募**不取代**地图商店。高风险消耗品与装备在**地图商店**；招募道具行仅小药水（无旗帜）。

## 6. 表现与布局（可读要点）

### 6.1 进出镜头（功能意图）

1. 战斗阶段结束：敌方半场向上移出摄像范围，友方半场向下移出摄像范围。  
2. 招募开始：上区（队伍）自上而下进入，下区（招募）自下而上进入，拼成一整屏。  

具体缓动与时长留给表现实现；本篇只要求玩家能读出「已离开战斗、进入招募」。

### 6.2 分区语义

招募阶段纵向三段 + 两处空档（从上到下）。**战斗逻辑盘仍为 5×4**；招募用**虚拟行**拉高 arena，**不加**战斗逻辑行。

| 区域 | 逻辑 y（`seat_rows=2`） | 内容 | 说明 |
|------|------------------------|------|------|
| **友方半场** | `0 .. seat_rows-1`（0–1） | 已入座阵容（**友方持久占位**） | 使用与战斗准备**同一套**友方座位几何；招募时画在上区前两行。可招入落座、换座、接受备战上座（写回持久占位）。不开战 |
| **（空档）** | `seat_rows`（2） | — | 友方半场 ↔ 备战之间留白；不放纸片 |
| **备战区** | `seat_rows + 1`（3） | 最多 5 名未入座成员 | **招募阶段**夹在队伍与招募区之间；准备 / 战斗阶段仍在友方半场下方（`row_y=-1` / board 外）。跨遭遇持久；可与上区双向拖放；可拖出售 |
| **（空档）** | `seat_rows + 2`（4） | — | 备战 ↔ 招募区之间留白；不放纸片 |
| **招募区 · 候选人** | `seat_rows + 3`（5） | **5** 个角色候选人 | 一行占满宽度（无列间距）；可落到棋盘外虚拟行 |
| **招募区 · 动作** | `seat_rows + 4`（6） | 道具 + **锁定** + **出售** | 紧贴候选人下一行（y 差 1，招募区内不再另加空行）；同一行排布、互不重叠；出售落点须与「拖候选人上场」区分可读（拖入时预览退金） |

常驻可读信息：阶段标题（如「招募」）、上下区 / 备战标签、当前金币、上场占用（已入座 / 上场席位上限）。色盲不单靠颜色分区。

长按上区 / 备战 / 下区角色查看技能等，见 [战斗观战反馈](./COMBAT_FEEDBACK.md) §7.2。

### 6.3 候选人脚下数值（表现）

> 【用户新共识 · 2026-10-30 修订】**卡壳 / 拖出溶解已回撤**（shader 资源可保留备用）；本段只约束脚下数值可读。扣费、空座、已占座拒绝、点买去向等规则不变。

| 项 | 玩家读法 |
|------|----------|
| **静置候选人** | 下区＝**纸片角色**（无背景卡壳）；一行五槽仍可点 |
| **脚下数值** | 攻/血同排缩进单格；**价签单独第二行居中**；邻槽不互挡 |

## 7. 候选人池

- 每次进入招募（及每次**刷新**）从池中随机抽出 **3** 个候选人。  
- 池子权重随**角色品阶**与玩家在本幕爬塔的**进度段**变化（例如幕内前 / 中 / 后段逐步偏向更高品阶）。  
- **品阶硬解锁**与敌池最高档同表（`TierUnlock`）：**第 1–3 层最高 T1；第 4 层起可出 T2；倒数 6 层起可出 T3**。  
- **倒数 6 层起**招募池**不再出 T1**（最低 T2）。  
- 进入部署且本层新解锁更高品阶时，居中半透明提示约 2 秒。  
- 每个可招募角色在**本局**卡池里共有 **9** 份。成功招募（空席加入或满员替换）拿走 1 份；只是出现在货架上、刷新换掉、或锁定未买，都不拿走。  
- 同一角色可以同时占多个候选槽，但不超过剩余份数（已拿走的加上当前货架上的）。某个角色 9 份都拿走后，之后的招募和刷新都不再出现该角色。  
- 出售或替换离队**不**把份数退回卡池。**跳过**（内部重置）退回本阶段拿走的份数；新开一局重新装满。三合一只合成已经拿走的单位，不另扣、也不退回。  
- **具体权重表**仍由数值填写；本篇定解锁档、每角色 9 份与重复上限。  
- 候选人默认以 **1 星**加入队伍（若数值另定开局星级，以数值为准；三合一仍按玩家篇）。

## 8. 操作规则

### 8.1 招募（扣金币）

1. **点买 / 点击候选人**（未指定座位）：  
   - 备战未满 → 扣费，加入**备战区**；  
   - 备战已满且上场未满 → 扣费，落到**第一个空友方座位**；  
   - 备战与上场都满 → **无法购买**。  
2. **拖到上区空座**：扣费，加入并落到目标空座（上场已满无空座则失败）。  
3. **拖到已占座**：**拒绝放置**（提示拖到空座位）；不扣费、不替换。需要换人时走「点选候选人 → 点选上区成员」或先出售腾位。  
4. 金币不足：不能完成该次招募。  
5. 加入完成后：若队伍（含备战）满足 [玩家](./PLAYER.md) §4.1 三合一条件，**立刻自动合成**。  

招募价见数值 / 单位数据；本篇不写点数。

### 8.2 出售（退金币）

1. 玩家将**上区或备战**一名队伍成员拖到**出售落点**（或等价交互）并松手。  
2. 该成员**离开队伍**；若在座位则座位变空，若在备战则腾出备战格；玩家获得**全额退金**：**1★ = 该角色招募原价**（`UnitData.cost`）；**每多合一星 ×3**（2★ = 3× 原价，3★ = 9× 原价）。  
3. 长按查看信息卡**不**触发出售；按下后移动超过拖拽阈值才进入拖态，松手落在出售落点才成交；可拖回取消。  
4. 出售造成的队伍、占位、备战与金币变动计入本阶段；**跳过**会一并丢弃（内部回滚进门快照）。  
5. 出售后若不再满足三合一条件，不会「拆开」已合成单位。

上场满员时玩家可先**出售腾位**再招入，也可**点选替换**（不退金）——两条路径并存；**不可**把候选人直接拖到已上场角色身上替换。

上区亦可在招募阶段**换座**；**备战与上区可双向拖放**（与准备阶段同规则；备战满则不能再拖入）。**点备战**有空上场席则自动入首空座（亦可拖到空座）。

### 8.3 刷新（扣金币）

- 花金币重新随机下区三个候选人。  
- **已招进队伍的成员保留**；已付招募费**不**因刷新退回。  
- 只扣刷新费；刷新费数额留给数值。  
- 金币不足时刷新不可用。

### 8.4 重置（【As-Is】无玩家操作）

- **【As-Is】** 招募 HUD **不提供**「重置」按钮；本阶段内**不能**在保留界面状态的前提下免费撤销已发生的招募 / 出售 / 刷新 / 换座 / 三合一等改动。  
- **进门快照**仍由实现维护：队伍、**持久占位**、候选人、金币、本阶段卡池已拿份数、旗帜本阶段购买次数等（见招募商店篇）。  
- **跳过**时内部执行等价 `reset()`：上述状态回滚至进入招募瞬间，再退出 → **回地图**。  
- **【历史 To-Be 已收敛】** 曾规格「免费重置、可多次使用」；与当前产品一致口径为 **跳过 = 唯一丢弃本阶段改动的玩家路径**。

### 8.5 跳过

- **丢弃**本阶段全部改动（内部回滚至进门快照），然后退出招募 → **回地图**。  
- 与「完成」不同：跳过不保留本阶段购买 / 替换 / 出售 / 刷新 / 道具购买等。

### 8.6 完成

- **保留**本阶段当前队伍与金币状态，退出招募 → **回地图**。  
- 完成时不要求必须招过人。

### 8.7 拥有物边界

- 招募改**整局队伍**（含备战）、**友方持久占位**与**金币**（含本阶段触发的三合一结果）。  
- 上区占位与备战与下一场准备 / 战斗共用；完成招募后保留。  
- 生成的代理角色不是队伍拥有物，不出现在招募上区 / 备战，不可出售。

## 9. 玩家可观察操作（验收口径）

1. 普通 / 精英胜利后进入招募；可见上区按战斗座位摆好的已入座队伍、备战区一行、下区候选人、出售落点、金币、上场占用（x/上限）。  
2. Boss 胜利不进招募，直接通关；失败不进招募。  
3. 点买优先入上场空座；上场满且备战未满则入备战；都满无法购买；可拖到上区空座；**不可**拖到已占座；满员替换靠点选（旧人不退金）；金不够不能招。  
4. 可将上区或备战成员拖到出售落点卖掉并获得正常退金；长按只看信息不卖。  
5. 上区可换座；备战与上区可双向拖放（备战满失败）；点备战可自动上阵（有空席）；完成后进入下一场准备时状态仍在。  
6. 招入后若同角色同星满 3（含备战），立刻自动三合一（见玩家篇验收）。  
7. 可花金刷新候选人；刷新后已进队 / 备战成员仍在。  
8. **【As-Is】** 无「重置」按钮；本阶段内改动只能通过**跳过**整体丢弃（回进门快照）或**完成**保留。  
9. 跳过：改动丢弃后回地图；完成：保留改动后回地图。  
10. 旗帜扩的是上场席位上限，不扩备战格数。
