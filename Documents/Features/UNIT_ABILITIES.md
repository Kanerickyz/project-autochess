## 1. 这是什么

**角色技能**规定：友方角色（以及将来需要时的敌方角色、生成的代理角色）如何在战斗中**自动**根据战场事件发动效果——玩家不点技能、不拖动已上场单位来施放。

玩家关心的是：

- 买到或编入牌库时，这名角色**有没有**可读的自带技能，还是白板身体；  
- 开战之后，**什么事发生时**它会自动响应；  
- 预布阵与 cycle 补人时，如何用这些自动响应当作节奏杠杆。

第一版不做种族/职业羁绊。流派来自单位技能、站位与增益卡（见愿景深度公式）。

## 3. 技能槽

### 3.1 槽位

| 槽 | 含义 |
|----|------|
| **主技能** | 角色最醒目的一条战斗联动（或为空） |
| **被动** | 可选的额外被动；可以为空。第一版附魔**不改**被动（见地图） |

三种单位种类（友方 / 敌方 / 生成的代理角色）都允许主技能为空；具体谁空、谁绑定，由 Content 填。

### 3.2 自带技能单位与白板单位【定稿】

| 类型 | 规则 | 玩家体验 |
|------|------|----------|
| **自带技能单位** | 配置里**绑定**主技能；买到或编入牌库时即可认读「它会在什么时机干什么」 | 服务清波认人、cycle 下手牌快速决策 |
| **白板单位** | 主技能**为空**仍可购买、可进牌库、可预布阵与补人；上场后只按属性与攻击方式作战，直到获得主技能 | 服务爬塔养成与附魔「新增」分支 |

两者**并存**，不是互斥路线。Content 决定本版哪些兵种自带技能、哪些是白板；本篇不写花名册。

### 3.3 与角色等级

角色等级加强生命上限与攻击力（见角色单位）。**本篇不规定**等级是否缩放技能幅度；若 Content/数值需要缩放，在内容侧约定，不在此定点数。

## 4. 联动模型【定稿】

一条角色技能在玩家侧可理解为：

```text
何时（战斗事件）
  → 对谁（目标：自己、队友、敌人、事件相关对象等）
    → 发生什么（加临时属性、造成伤害、生成代理角色、换位等）
```

| 约定 | 内容 |
|------|------|
| 谁触发 | 持有该技能的单位满足时机时自动发动 |
| 玩家操作 | **不点技能**；不可通过拖动已上场单位来施放 |
| 战斗效果 | 走统一效果管线；战斗内触发只经战斗事件总线 |
| 非目标 | 不靠种族/职业计数凑羁绊；可用标签做**技能筛选目标**（非羁绊） |

愿景中的样板（如受伤时自身变强）属于本模型，不另开系统。

## 5. 触发：玩家可读大类与实时时机

### 5.1 玩家可读触发大类

对玩家与 Content 作者，优先用下列说法（不要堆内部常量名）：

| 大类 | 典型时机（人类说法） | 构筑直觉 |
|------|----------------------|----------|
| **开场类** | 开战时 | 预布阵吃得到；见下节规则事实 |
| **挨打类** | 受伤时；受击前 | 前排、承伤位 |
| **出手类** | 造成伤害时；击杀时；造成暴击时等 | 输出位、收割 |
| **退场类** | 死亡时 | 炮灰、换人节奏 |
| **同伴类** | 友方死亡时；友方被生成时；自己被生成时 | 看队友，不只看自己 |
| **商店类** | 购买时；出售时；升级时 | 战斗外；与上表分开教 |

「攻击时」在规则上归入**出手类**的具体时机（造成伤害、击杀等），本篇不另设笼统「攻击时」一词当唯一触发名。

### 5.2 实时主路径：可用与不用【定稿】

Run 主路径为实时固定步长战斗（见战斗篇）：**没有回合、没有行动顺序**。

| 时机 | 实时主路径 |
|------|------------|
| 开战时、受伤时、死亡时、出手/命中相关、击杀等 | **可用**（与角色单位生命周期对齐） |
| 战中补人：上场、部署中 | 有生命周期状态；**部署中本身不是**技能触发点 |
| **移动时**、**回合开始 / 回合存活** 等依赖「走成功一格 / 行动轮」的时机 | **不进入**实时主路径技能设计（旧网格工具环可另论，不进本篇验收） |

### 5.3 开战时 vs 战中补人【规则事实】

- **开战时**只对「战斗正式开始那一刻已在场」的单位成立。  
- **战斗中从手牌补上的单位不经历开战时**，因此**吃不到**开战类触发。  
- 是否应把开战类做成自带技能的主流：见第 10 节开放问题（需实机测试，本篇**不定论**）。

## 6. 强度评估维度（规则层，无点数）

评估或设计一条技能时，至少按下列维度思考相对强弱。**具体幅度、次数上限、百分比留给 Content / 数值填空**；本篇只定「要比什么」。

### 6.1 触发频率分档【定稿】

频率是强度预算的**维度之一**：频率越高，单次效果通常应更克制。

| 档位 | 玩家直觉 | 典型归入 | 预算原则（相对） |
|------|----------|----------|------------------|
| **一场一次** | 开局放一下 | 开战时 | 单次可以相对醒目；不覆盖整场 |
| **偶尔多次** | 有人退场/进场才响 | 死亡时、友方死亡时、被生成等 | 单次中等；按「一场可预期的几次」估 |
| **高频** | 打架时常常响 | 受伤时、造成伤害时、受击前等 | 单次明显更克制；靠过程叠出感觉 |
| **条件稀有** | 赚到了才响 | 击杀时、暴击时等 | 单次可比纯高频稍甜；**不要**误当成「一场一次」 |
| **战斗外** | 商店里响 | 购买 / 出售 / 升级时 | 不与战斗频率同一把尺子 |

**死亡触发【定稿】**：强度预算按 **偶尔多次** 评估，**先忽略**「死亡后 cycle 再打出导致同一条死亡技可重复」的放大。若日后实机发现被 cycle 刷爆，再单开修订，不在本篇改默认。

### 6.2 其他强度维度【定稿骨架】

| 维度 | 问什么 | 相对强弱直觉 | 填空归属 |
|------|--------|--------------|----------|
| **单次幅度** | 一次触发改变多少攻/血/伤害 | 幅度越大越强 | Content / 数值 |
| **持续范围** | 只影响本场临时，还是写入牌库条目的 Run 持久 | 持久通常强于纯临时 | 规则分类归本篇；数值归 Content |
| **目标广度** | 自己 / 单体 / 小范围 / 全队 / 全场 | 越广通常越强 | Content / 数值 |
| **是否生成单位** | 是否召唤代理角色、分身等 | 额外占场与输出，通常偏强 | Content；人口/占格规则见单位与战斗 |
| **是否改站位** | 是否换位、击退等 | 改变交战几何，需单独评估可读性 | Content；战场规则见战斗关卡 |
| **是否改经济/商店** | 是否掉金、改商店报价等 | 偏构筑层，不单用战斗频率衡量 | 与增益/商店边界对齐 |
| **依赖条件** | 是否要暴击、击杀、特定站位、友方事件 | 条件越严，单次可相对更甜 | Content |
| **与 cycle / 人口交互** | 是否鼓励早死快补、是否吃满人口 | 影响节奏杠杆，未必等于「更强」 | 设计时自检；死亡档默认见 6.1 |

战斗内临时加成随波次/遭遇结束清理；Run 持久随牌库条目保留（见愿景与增益）。**本篇不写具体清理实现字段。**

## 7. 与增益、附魔的边界

### 7.1 增益卡

| | 角色技能 | 增益卡 |
|--|----------|--------|
| 来源 | 单位配置自带或附魔写入主技能槽 | 商店等购买后挂到牌库条目 |
| 职责 | 战斗事件联动 | 永久属性、规则标签、或少量战斗钩子式 Run 效果（如死亡掉金） |
| 商店 | **不再**出售「战斗联动技能卡」 | 出售增益卡 |

细节见 [增益](../BUFF_SYSTEM.md)。增益**不是**本篇意义上的自带技能联动替代品。

### 7.2 附魔（只引用地图）

附魔节点完整流程见 [地图与节点](./MAP.md)。本篇只保留语义：

- 目标**没有**主技能 → **新增**主技能；  
- 目标**已有**主技能 → **更换**主技能（旧主技能不再作为主技能生效）。  

附魔本版可为占位节点；规则实装以地图篇为准。

## 11. 玩家可观察验收（L0）

1. 文档与 UI 表述能区分「自带技能单位」与「主技能为空的白板单位」。  
2. 有主技能的角色在对应战斗事件发生时自动生效，玩家无需点击技能按钮。  
3. 开战后从手牌补上的单位，不会触发「开战时」类效果。  
4. 白板单位在获得主技能之前，上场行为与纯属性单位一致（只普攻与移动）。  
5. 技能说明能归入玩家可读触发大类，并能标到频率档之一（便于学习，不要求露出内部实现名）。  
6. 本版若 Content 名单仍全空：全员表现为白板，本篇规则仍成立，联动暂不可见。
