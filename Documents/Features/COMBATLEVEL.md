# 战斗关卡

> 功能规格 · 战场空间、半场区域、角色座位与投放规则 · 2026-10-16  
> 相关文档：[战斗](./COMBAT.md) · [Boss](./BOSS.md) · [玩家](./PLAYER.md) · [地图与节点](./MAP.md) · [游戏基础循环](./GAME_LOOP.md) · [游戏愿景](../GAME_VISION.md) · [角色单位](./UNITS.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：刷怪只数、一动可走格数定死、占位半径、座位世界坐标默认表；战斗三步与行动队列细则；地图选路；商店与牌库。  
> **【战场 To-Be】** 双方各有可见**角色座位**（默认 2 行 × 5 列）；友方入座受上场人数上限约束（见玩家篇）；敌方占座与人数由关卡配置；开战后在 **9×16 逻辑格网**上走**回合制依次行动**；每一动内**八方向**寻路（**落格顿步**、**一格一体**），可越半场。行动队列见 [战斗](./COMBAT.md)。  
> **【战场 As-Is】** Run 主路径已落地**回合制依次 + 一动内八向格步**（见战斗篇）；座位几何部分已落地。旧线性开发关 `main.tscn` 为旧网格工具环（象棋式走法身份等；**非**本篇主路径规格）。

## 1. 这是什么

**战斗关卡**规定：玩家从地图进入战斗类节点（战斗 / 精英 / Boss）之后，**战场长什么样、友方与敌方分别能落在哪一侧、开战前后空间怎么用**。

它不管「选哪个节点」（见 [地图与节点](./MAP.md)），也不管「准备 → 观战 → 结算」三步怎么走、敌人**何时**出兵（见 [战斗](./COMBAT.md)），也不管抽牌/刷新/上场人数上限细则（见 [玩家](./PLAYER.md)）。本篇只定**进场后的战场空间规格**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 竖屏窄深、我下敌上、中线切半场**区域** | **地图**：点哪个战斗类节点进来 |
| **角色座位**几何（双方座位网格、前后排落点） | **玩家**：上场人数上限（本版 5）、持久占位、准备换座 |
| 准备入座只在我半场座位；敌方按敌半场座位出齐 | **战斗**：准备门槛、出兵时机、胜负与结算 |
| 逻辑格网、一动内八方向寻路、落格顿步、一格一体、开战越线 | **角色单位**：一动可走格数、索敌/攻距（格距）、占格规则；**战斗**：谁何时行动；**Boss**：足迹 2×2 与推开特例 |
| 半场与座位可读表现 | **技术美术 / UI**：相机、缩放、格间步进表现（可短 ease，须落稳） |
| 关卡如何描述敌方占哪些座 | **内容 / 遭遇资源**：具体单位与占座表 |

## 2. 写什么、不写什么

### 2.1 本文要说清的

- 战场朝向与 **9×16 逻辑格网**（功能语言）  
- **两层用法**：准备阶段座位吸附 vs 开战后回合内一动的八方向格步寻路（落格顿步）  
- 硬半场：投放区 vs 开战后全场可走格  
- 双方角色座位网格与前后排落点语义  
- 与战斗三步、地图选路的分工  
- 现状与目标对照  

### 2.2 本版不写

刷怪数量、节奏秒数交给数值；三步流程与胜负见战斗文档；选路见地图；上场人数上限与持久占位见玩家篇。借鉴只借「投放感」，不抄河与塔。

**本版不做**（与「八向格步 + 回合依次」区分开）：象棋式走法身份（车/马/后）、钉座对撞主路径（SAP / 铭刻式不跑图）、六边形棋盘、全场齐步拍（所有人同一拍同时迈步）。  
技能「周围 / 附近」的格点语义见角色技能；本篇只定空间与移动。行动「谁先谁后」见战斗篇。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **战场 / 逻辑格网** | 一场遭遇里双方活动的有界矩形格网；默认 **9 宽 × 16 高**；逻辑位置用格坐标 |
| **格心** | 一格的逻辑代表点；开战占格与寻路以格心为准 |
| **落格顿步** | 每完成一格八向步进后须**停稳在格心**，再判「出手」或「再迈邻格」；未落稳不判攻、不连滑无缝多格（**强棋感**）。表现可有短 ease，但规则提交以落格为准 |
| **八方向** | 可走向正四向与四对角邻格；斜一步与正一步在格距上等价（切比雪夫） |
| **一格一体** | 任一逻辑格同时最多一名存活单位；目标格被占则改道或等待（见角色单位）。**足迹单位**（本版仅 Boss）可同时占用其足迹内多格，足迹内仍禁止第二体，见 [Boss](./BOSS.md) |
| **足迹** | 足迹单位逻辑占用的格集合（Boss 为 2×2）；距离取最近足迹格 |
| **中线** | 把战场上下对半切开的**区域界**（参考高度偶数时对半） |
| **我半场 / 敌半场** | 画面下方 / 上方半区；**投放与出兵**分区用 |
| **硬半场（投放）** | 准备入座只认**我半场角色座位**；敌方出兵只认**敌半场角色座位** |
| **越半场** | **开战之后**单位可在全场逻辑格上移动与交战，可穿过中线 |
| **角色座位** | 半场上的可见站位座位；默认双方各 **2 行 × 5 列**；数量**不等于**上场人数上限 |
| **前排座位 / 后排座位** | 相对中线更近 / 更靠己方底的那一行座位；**仅决定开战落点**，技能与索敌**不**认前后排标签 |
| **合法入座** | 目标为空友方座位、位于我半场、且未达上场人数上限；开战后天不再入座 |
| **投放区感（表现）** | 画面强调上下半场与**可见座位** |

## 4. 战场形状与朝向【设计定稿】

| 项 | 约定 |
|----|------|
| 朝向 | **竖屏窄深**：玩家在**下**，敌方在**上** |
| 逻辑范围 | 有界矩形**格网**；格坐标 `(x, y)`，`x` 横向、`y` 纵向（向上为敌方向） |
| 参考尺寸 | **9 格宽 × 16 格高**；上下各约 8 格高；中线为 **`y = 8` 的区域界**（不单独占「一行格子」） |
| 通行 | 无河、桥、塔；障碍格/地形若将来加入另开切片；本版默认全场可走（受一格一体约束） |
| 六边形 | **不做** |
| 钉座对撞主路径 | **不做**（开战仍跑图寻路，见 §5） |

示意（比例示意，非像素定稿）：

```text
        敌半场（上）· 敌方角色座位
   ┌─────────────────┐
   │  · · · · ·      │  ← 敌前排（更近中线）
   │  · · · · ·      │  ← 敌后排（更靠敌底）
   ├────── 中线 ──────┤
   │  · · · · ·      │  ← 我前排（更近中线）
   │  · · · · ·      │  ← 我后排（更靠玩家底）
   └─────────────────┘
        我半场（下）· 友方角色座位 · 玩家
```

## 5. 格网空间规则【设计定稿】

### 5.1 占格与距离

| 项 | 约定 |
|----|------|
| 占格 | **一格一体**为默认；**足迹单位**占用其全部足迹格，足迹内不可叠第二体 |
| 冲突 | 普通单位：目标邻格已被占 → 改选其他八向邻格，或短时等待后再寻路（细则见角色单位；不回到圆推挤为主轴）。Boss 足迹平移踩到**友方**时按 [Boss](./BOSS.md) **推开**；无合法安置则该步失败 |
| 距离 | 索敌、攻击距离、溅射等用**切比雪夫格距**（`max(|dx|, |dy|)`，单位：格）；与八向一致。涉及足迹单位时取**最近足迹格** |
| 边界 | 逻辑格须落在战场格网内；不能走出战场；Boss 推开**禁止**推出界 |

表现层可用圆形剪影表示体积，但**不**再用欧氏圆边缘作为主路径出手判定。

### 5.2 移动（开战后 · 一动内）【设计定稿】

- 单位只在**轮到自己的一动**时移动与出手（行动队列见 [战斗](./COMBAT.md)）；差异主轴是**一动可走几格**与站位距离，不是象棋走法身份，也不是实时移速抢拍。  
- 朝目标**八方向寻路**，沿邻格推进；一动内最多走完其移动预算格数（见角色单位）。  
- **落格顿步（强棋感）**：一动内每步从当前格心迈向一个八向邻格；步进结束须**停稳在目标格心**，再判「出手」或「再迈下一步」。  
- **未落稳不判攻**：攻击距离判定只在落稳后的逻辑格上进行；禁止边滑边打、禁止无缝连滑多格当一步。  
- 若落稳后已在攻距：本动出手并结束该动的移动（与战斗篇「一动=靠近并出手」一致）。  
- 表现可有短 ease / 插值，但观感应像棋子挪格；**单动演出可压短**，并可随观战加速缩短（见战斗 / 观战反馈）。  
- 玩家**不可**拖动已上场单位，**不可**点技能。  
- **不做**钉座对撞主路径（SAP / 铭刻式不跑图）；开战仍寻路越线。  
- **不做**全场齐步拍（所有人同一拍同时迈步）。

### 5.3 角色座位（双方）【设计定稿】

| 项 | 约定 |
|----|------|
| 网格 | 双方各 **2 行 × 5 列**（共 10 座 / 侧），镜像同构 |
| 落点 | 座位块在各自半场可放置区内**居中**；行与行、列与列之间各空 **1** 格 |
| 前排 / 后排 | 各侧一行前排、一行后排；前排更近中线、后排更靠己方底 |
| 友方 | 准备阶段只许放入**我半场空座位**；入座人数受玩家篇**上场人数上限**约束；空座常态，不要求填满 |
| 敌方 | 占哪些座、上几个由**关卡（遭遇）配置**，可不填满；开战时按配置书写顺序在已配置座位依次生成、一次出齐 |
| 开战后 | 单位从座位所在逻辑格生成后按八向格步移动；座位不再接受新牌 / 新配置 |

友方流程（功能层）：

1. 玩家将手牌拖入 / 点选一个合法空座位（系统记录入座时间；见玩家篇）。  
2. 开战锁阵时，已占用友方座位按**入座时间序**在其座位格依次生成友方单位；生成当下可结算部署时技能（见 [战斗](./COMBAT.md) §6.5）。  
3. 开战后单位在各自一动内按八向格步移动；友方座位不再接受新牌。  

敌方流程（功能层）：

1. 关卡配置本场敌方单位及其目标座位（合法敌半场座位、不重复；表内**书写顺序**即开战生成序）。  
2. 准备阶段可预览已占敌座上的单位；空敌座用淡座位示意即可。  
3. 开战锁阵时按配置书写顺序在对应敌座**依次**生成敌方单位，本场一次出齐（部署时技能见战斗篇）。  

**【前后排规则深度】** 本版前后排**仅**影响开战落点远近。技能、索敌、承伤**不**增加「前排 / 后排」硬标签或同列遮挡规则。

**【As-Is】** 实时并行八向格步 + 一格一体 + 切比雪夫；弱滑动并可边滑边判攻。**【To-Be】** 回合依次 + 一动内落格顿步。

### 5.4 开战前后对比

| 阶段 | 空间怎么用 |
|------|------------|
| 准备 | 友方只与**我半场角色座位**交互；敌方已占座位可预览 |
| 开战后 | 仅当前行动者在一动内按落格顿步更新逻辑格（八向）；可**越半场**；无战中友方投放 |

## 8. 玩家可观察操作与验收（L0）

1. 进入战斗类节点后，战场呈竖向：我在下、敌在上，中线可辨；参考尺度更紧凑（相对旧 18×32）。  
2. 双方半场各可见 **2×5** 角色座位；前排更近中线、后排更靠己方底。  
3. 准备阶段只能把友方放入我半场**空座位**，且不超过上场人数上限；不能放到敌半场或非座位位置。  
4. 开战时敌方在已配置的敌半场座位按配置书写顺序依次生成、一次出齐（生成序见战斗篇）。  
5. 战斗中同一时刻只有当前行动者在动：沿格网八方向**落格顿步**靠近目标并可出手，可越过中线；已上场友方不可被拖换位；**不能再出牌**。  
6. 同一逻辑格不会长期叠两名单位。  
7. 空座位一眼可读；座位数不等于必须上场人数。  
8. 画面强调半场与座位，压力来自阵型对冲与越线；观战能感到「一格一挪」。

**【As-Is】** 验收可能仍落在弱滑动判攻路径上；落格顿步验收待实现后启用。
