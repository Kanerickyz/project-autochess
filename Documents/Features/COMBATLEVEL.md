# 战斗关卡

> 功能规格 · 战场空间、半场区域、角色座位与投放规则 · 2026-10-14  
> 相关文档：[战斗](./COMBAT.md) · [玩家](./PLAYER.md) · [地图与节点](./MAP.md) · [游戏基础循环](./GAME_LOOP.md) · [游戏愿景](../GAME_VISION.md) · [角色单位](./UNITS.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：刷怪只数、移动速度、占位半径、座位世界坐标默认表；战斗三步细则；地图选路；商店与牌库。  
> **【战场 To-Be】** 双方各有可见**角色座位**（默认 2 行 × 5 列）；友方入座受上场人数上限约束（见玩家篇）；敌方占座与人数由关卡配置；开战后天连续平面实时移动。参考尺寸 **9×16**。  
> **【战场 As-Is】** Run 主路径仍为 18×32 半场自由投放 + 战中出牌，**尚无**角色座位几何。旧线性开发关 `main.tscn` 为回合制格子工具环（**非**本篇目标规格）。

## 1. 这是什么

**战斗关卡**规定：玩家从地图进入战斗类节点（战斗 / 精英 / Boss）之后，**战场长什么样、友方与敌方分别能落在哪一侧、开战前后空间怎么用**。

它不管「选哪个节点」（见 [地图与节点](./MAP.md)），也不管「准备 → 观战 → 结算」三步怎么走、敌人**何时**出兵（见 [战斗](./COMBAT.md)），也不管抽牌/刷新/上场人数上限细则（见 [玩家](./PLAYER.md)）。本篇只定**进场后的战场空间规格**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 竖屏窄深、我下敌上、中线切半场**区域** | **地图**：点哪个战斗类节点进来 |
| **角色座位**几何（双方座位网格、前后排落点） | **玩家**：上场人数上限、手牌宽度、入座/刷新规则 |
| 准备入座只在我半场座位；敌方按敌半场座位出齐 | **战斗**：准备门槛、出兵时机、胜负与结算 |
| 连续战场边界、开战越线交战 | **角色单位**：占位圆、移速、索敌、推挤 |
| 半场与座位可读表现 | **技术美术 / UI**：相机、缩放、具体皮肤 |
| 关卡如何描述敌方占哪些座 | **内容 / 遭遇资源**：具体单位与占座表 |

## 2. 写什么、不写什么

### 2.1 本文要说清的

- 战场朝向与有界连续平面（功能语言；参考尺寸可写，不作战斗逻辑格）  
- **两层空间**：投放/座位格网（只帮落点对齐） vs 开战后的连续坐标  
- 硬半场：投放区 vs 开战后全战场可移动区  
- 双方角色座位网格与前后排落点语义  
- 与战斗三步、地图选路的分工  
- 现状与目标对照  

### 2.2 本版不写

刷怪数量、节奏秒数交给数值；三步流程与胜负见战斗文档；选路见地图；上场人数上限与手牌见玩家篇。借鉴只借「投放感」，不抄河与塔。

**本版不作为主路径规格的内容**（仅旧工具环或实现债可能出现）：回合制行动轮、按格邻接寻路、四向/八向步进、一格一人、切比雪夫/曼哈顿格距战斗、技能「周围格子」的格点语义。连续战场上技能的空间说法见技能文档，与格点棋盘脱钩。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **战场** | 一场遭遇里双方单位活动的**有界二维连续平面**（世界坐标）；长度单位用「格」，与参考投放格网同一尺度 |
| **连续坐标** | 开战前后单位圆心所在的 `(x, y)`；开战后位置、距离、碰撞、移动都在此计算 |
| **中线** | 把战场上下对半切开的**区域界**（不是「占一格的中线格」） |
| **我半场 / 敌半场** | 画面下方 / 上方半区；**投放与出兵**分区用 |
| **硬半场（投放）** | 准备入座只认**我半场角色座位**；敌方出兵只认**敌半场角色座位** |
| **越半场** | **开战之后**单位可在全战场移动与交战，可穿过中线进入对方半区 |
| **角色座位** | 半场上的可见站位座位；默认双方各 **2 行 × 5 列**；数量**不等于**上场人数上限 |
| **前排座位 / 后排座位** | 相对中线更近 / 更靠己方底的那一行座位；**仅决定开战落点**，技能与索敌**不**认前后排标签 |
| **投放格网** | 可选参考格（如 9×16）用于对齐座位与关卡编辑；**不**承担开战后寻路 |
| **合法入座** | 目标为空友方座位、位于我半场、且未达上场人数上限；开战后天不再入座 |
| **投放区感（表现）** | 画面强调上下半场与**可见座位**；逻辑仍是连续平面 |

## 4. 战场形状与朝向【设计定稿】

| 项 | 约定 |
|----|------|
| 朝向 | **竖屏窄深**：玩家在**下**，敌方在**上** |
| 平面范围 | 有界矩形区域；世界坐标 `(x, y)`，`x` 横向、`y` 纵向（向上为敌方向） |
| 参考尺寸 | **9 格宽 × 16 格高**（约为此前 18×32 的一半）；上下各约 8 格高；中线为 **`y = 8` 的区域界**（不单独占「一行格子」） |
| 通行 | 平面内无河、桥、塔；障碍格/地形若将来加入，另开切片，本版默认全场可通行 |
| 六边形 / 格点战斗 | **不做**；不开战后的格点邻接体系 |

示意（比例示意，非像素定稿）：

```text
        敌半场（上）· 敌方角色座位
   ┌─────────────────┐
   │  · · · · ·      │  ← 敌前排（更近中线）
   │  · · · · ·      │  ← 敌后排（更靠敌底）
   ├────── 中线 ──────┤
   │  · · · · ·      │  ← 我前排（更近中线）
   │  · · · · ·      │  ← 我后排（更靠玩家底）
   └─────────────────┘
        我半场（下）· 友方角色座位 · 玩家
```

## 5. 连续空间规则【设计定稿】

### 5.1 占位与距离

| 项 | 约定 |
|----|------|
| 占位形状 | 每个单位是一个**圆**（半径见角色单位 `body_radius`） |
| 重叠 | 圆与圆**不应**长期重叠；挤在一起时按质量推挤（见角色单位） |
| 距离 | 索敌、攻击范围、溅射等一律用连续坐标上的**直线距离**（单位：格） |
| 边界 | 圆心应保持在战场有界范围内；贴边行为由实现定义，本篇要求「不能走出战场」 |

### 5.2 移动（开战后）

- 单位在连续平面上**实时**移动，默认**寻路靠近目标**并做简单避障/绕行；差异主轴是**移动速度**（每秒可移动的距离），不是多种「走法身份」。  
- **不**使用格点四向/八向步进、斜穿格缝、象棋式移动图案作为主路径规则。  
- 固定逻辑时间步推进，结果不依赖显示帧率（见战斗文档）。  
- 玩家**不可**拖动已上场单位，**不可**点技能。

### 5.3 角色座位（双方）【设计定稿】

| 项 | 约定 |
|----|------|
| 网格 | 双方各 **2 行 × 5 列**（共 10 座 / 侧），镜像同构 |
| 落点 | 座位块在各自半场可放置区内**居中**；行与行、列与列之间各空 **1** 格 |
| 前排 / 后排 | 各侧一行前排、一行后排；前排更近中线、后排更靠己方底 |
| 友方 | 准备阶段只许放入**我半场空座位**；入座人数受玩家篇**上场人数上限**约束；空座常态，不要求填满 |
| 敌方 | 占哪些座、上几个由**关卡（遭遇）配置**，可不填满；开战时按配置书写顺序在已配置座位依次生成、一次出齐 |
| 开战后 | 单位从座位坐标生成后按连续坐标移动；座位不再接受新牌 / 新配置 |

友方流程（功能层）：

1. 玩家将手牌拖入 / 点选一个合法空座位（系统记录入座时间；见玩家篇）。  
2. 开战锁阵时，已占用友方座位按**入座时间序**在其座位坐标依次生成友方单位（圆心落座）；生成当下可结算部署时技能（顺序与技能分层见 [战斗](./COMBAT.md) §6.5）。  
3. 开战后单位按连续坐标移动；友方座位不再接受新牌。  

敌方流程（功能层）：

1. 关卡配置本场敌方单位及其目标座位（合法敌半场座位、不重复；表内**书写顺序**即开战生成序）。  
2. 准备阶段可预览已占敌座上的单位；空敌座用淡座位示意即可。  
3. 开战锁阵时按配置书写顺序在对应敌座**依次**生成敌方单位，本场一次出齐（部署时技能见战斗篇）。  

**【前后排规则深度】** 本版前后排**仅**影响开战落点远近。技能、索敌、承伤**不**增加「前排 / 后排」硬标签或同列遮挡规则。

**【As-Is】** 友方仍为半场自由格投放 + 战中出牌，无座位对象；敌方仍为敌半场候选格刷出。

### 5.4 开战前后对比

| 阶段 | 空间怎么用 |
|------|------------|
| 准备 | 友方只与**我半场角色座位**交互；敌方已占座位可预览 |
| 开战后 | 只在**连续坐标**上更新位置；可**越半场**；无战中友方投放 |

## 6. 逻辑与表现

| 层 | 约定 |
|----|------|
| **逻辑** | 连续平面 + 圆占位 + 区域半场 + 座位落点；投放格网仅为 snap 与策划对齐尺寸的参考 |
| **表现** | 强调上下半场与可见座位（含空座）；单位移动可格间插值，**不要求**玩家感到在下跳棋 |
| **胜负** | 仍为清光敌方 / 己方全灭（见愿景），不因半场改变 |

## 7. 和相邻文档怎么分

```text
地图选路 → 进入战斗 / 精英 / Boss
  →【本篇】加载本场战场规格（平面范围、半场、双方角色座位）
  →【战斗】准备入座 → 自动战斗观战 → 结算
```

| 问题 | 看哪篇 |
|------|--------|
| 点哪个节点 | 地图 |
| 何时开战、何时出兵、固定步长、胜负 | 战斗 |
| 抽选、刷新、手牌宽度、上场人数上限 | 玩家 |
| 平面范围、半场、座位几何、越线 | **本篇** |
| 移速、索敌、攻击距离、推挤 | 角色单位 |
| 一整局何时进出会合 | 游戏基础循环 |

## 8. 玩家可观察操作与验收（L0）

1. 进入战斗类节点后，战场呈竖向：我在下、敌在上，中线可辨；参考尺度更紧凑（相对旧 18×32）。  
2. 双方半场各可见 **2×5** 角色座位；前排更近中线、后排更靠己方底。  
3. 准备阶段只能把友方放入我半场**空座位**，且不超过上场人数上限；不能放到敌半场或非座位位置。  
4. 开战时敌方在已配置的敌半场座位按配置书写顺序依次生成、一次出齐（生成序见战斗篇）。  
5. 战斗中单位在连续平面上移动，可越过中线交战；已上场友方不可被拖换位；**不能再出牌**。  
6. 空座位一眼可读；座位数不等于必须上场人数。  
7. 画面强调半场与座位，压力来自阵型对冲与越线。

**【As-Is】** 验收仍可能落在自由投放 / 战中出牌路径上；座位验收待实现后启用。

## 10. 已拍板默认

| 项 | 定稿 |
|----|------|
| 主路径空间模型 | **有界连续平面** + 圆占位；**不是**格点战斗棋盘 |
| 朝向 | 竖屏窄深；我下敌上 |
| 中线 | 区域界；偶数参考高度对半 |
| 参考尺寸 | **9×16**（格尺度）；不作为开战后的逻辑格 |
| 角色座位 | 双方各 **2×5**；友方受上场人数上限约束；敌方由关卡占座（开战生成序见战斗 §6.5） |

| 开战后 | 全平面移动；越半场；默认寻路 + 移速；不可拖已上场 |
| 表现 | 投放区感 + 可见座位；不抄河塔 |

## 11. 开放问题（实现前可再拍）

| 问题 | 建议默认 |
|------|----------|
| 准备阶段是否预览敌半场已占座位？ | **要**（与战斗文档预览一致） |
| 投放 snap 是否必须格心，还是允许半格内微调？ | **先格心**；微调若要做另开 |
| 战场边界对圆心还是对整个圆做 clamp？ | 实现定一种并写进模拟层，本篇只要求不出界 |
| 9×16 下 5 列是否过挤？ | 先按 9×16 实现；若实机过挤再议约一半变体（如 10×16） |
