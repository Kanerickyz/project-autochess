# 战斗关卡

> 功能规格 · 战场空间、半场区域、角色槽与投放规则 · 2026-10-14  
> 相关文档：[战斗](./COMBAT.md) · [玩家](./PLAYER.md) · [地图与节点](./MAP.md) · [游戏基础循环](./GAME_LOOP.md) · [游戏愿景](../GAME_VISION.md) · [角色单位](./UNITS.md) · [架构](../ARCHITECTURE.md)  
> **本版不写**：刷怪只数、移动速度、占位半径、槽位具体坐标默认表；战斗三步细则；地图选路；商店与牌库。  
> **【战场 To-Be】** 友方准备入**角色槽**（可见座位；槽数 = 本场上场上限）；敌方仍敌半场一次刷出；开战后天连续平面实时移动。  
> **【战场 As-Is】** Run 主路径仍为 18×32 半场自由投放 + 战中出牌，**尚无**角色槽几何。旧线性开发关 `main.tscn` 为回合制格子工具环（**非**本篇目标规格）。

## 1. 这是什么

**战斗关卡**规定：玩家从地图进入战斗类节点（战斗 / 精英 / Boss）之后，**战场长什么样、友方与敌方分别能落在哪一侧、开战前后空间怎么用**。

它不管「选哪个节点」（见 [地图与节点](./MAP.md)），也不管「准备 → 观战 → 结算」三步怎么走、敌人**何时**刷（见 [战斗](./COMBAT.md)），也不管抽牌/刷新细则（见 [玩家](./PLAYER.md)）。本篇只定**进场后的战场空间规格**。

| 本篇负责 | 别处负责 |
|----------|----------|
| 竖屏窄深、我下敌上、中线切半场**区域** | **地图**：点哪个战斗类节点进来 |
| **角色槽**几何（座位位置与数量可见） | **玩家**：槽位数与手牌宽度关系、入槽/刷新规则 |
| 准备入槽只在我半场槽位；敌一次出齐只刷敌半场 | **战斗**：准备门槛、刷怪时机、胜负与结算 |
| 连续战场边界、开战越线交战 | **角色单位**：占位圆、移速、索敌、推挤 |
| 半场与槽位可读表现 | **技术美术 / UI**：相机、缩放、具体皮肤 |

## 2. 写什么、不写什么

### 2.1 本文要说清的

- 战场朝向与有界连续平面（功能语言；参考尺寸可写，不作战斗逻辑格）  
- **两层空间**：投放格网（只帮玩家落点） vs 开战后的连续坐标  
- 硬半场：投放区 vs 开战后全战场可移动区  
- 与战斗三步、地图选路的分工  
- 现状与目标对照  

### 2.2 本版不写

具体宽×高、刷怪数量、节奏秒数交给数值；三步流程与胜负见战斗文档；选路见地图。借鉴只借「投放感」，不抄河与塔。

**本版不作为主路径规格的内容**（仅旧工具环或实现债可能出现）：回合制行动轮、按格邻接寻路、四向/八向步进、一格一人、切比雪夫/曼哈顿格距战斗、技能「周围格子」的格点语义。连续战场上技能的空间说法见技能文档，与格点棋盘脱钩。

## 3. 术语

| 说法 | 意思 |
|------|------|
| **战场** | 一场遭遇里双方单位活动的**有界二维连续平面**（世界坐标）；长度单位用「格」，与参考投放格网同一尺度 |
| **连续坐标** | 开战前后单位圆心所在的 `(x, y)`；开战后位置、距离、碰撞、移动都在此计算 |
| **中线** | 把战场上下对半切开的**区域界**（不是「占一格的中线格」） |
| **我半场 / 敌半场** | 画面下方 / 上方半区；**投放与刷出**分区用 |
| **硬半场（投放）** | 准备入槽只认**我半场角色槽** |
| **越半场** | **开战之后**单位可在全战场移动与交战，可穿过中线进入对方半区 |
| **角色槽** | 我半场上的友方座位；数量 = 本场最多上场人数；准备阶段牌放入槽位 |
| **投放格网** | 可选参考格（如 18×32）用于对齐槽位与刷怪候选；**不**承担开战后寻路 |
| **合法入槽** | 目标为空角色槽、位于我半场；开战后天不再入槽 |
| **投放区感（表现）** | 画面强调上下半场与**可见槽位**；逻辑仍是连续平面 |

## 4. 战场形状与朝向【设计定稿】

| 项 | 约定 |
|----|------|
| 朝向 | **竖屏窄深**：玩家在**下**，敌方在**上** |
| 平面范围 | 有界矩形区域；世界坐标 `(x, y)`，`x` 横向、`y` 纵向（向上为敌方向） |
| 参考尺寸 | **18 格宽 × 32 格高**（借皇室战争比例）；上下各约 16 格高；中线为 **`y = 16` 的区域界**（不单独占「一行格子」） |
| 通行 | 平面内无河、桥、塔；障碍格/地形若将来加入，另开切片，本版默认全场可通行 |
| 六边形 / 格点战斗 | **不做**；不开战后的格点邻接体系 |

示意（比例示意，非数值定稿）：

```text
        敌半场（上）· 刷出区
   ┌─────────────────┐
   │   连续平面       │
   ├────── 中线 ──────┤
   │   连续平面       │
   └─────────────────┘
        我半场（下）· 投放区 · 玩家
```

## 5. 连续空间规则【设计定稿】

### 5.1 占位与距离

| 项 | 约定 |
|----|------|
| 占位形状 | 每个单位是一个**圆**（半径见角色单位 `body_radius`） |
| 重叠 | 圆与圆**不应**长期重叠；挤在一起时按质量推挤（见角色单位） |
| 距离 | 索敌、攻击范围、溅射等一律用连续坐标上的**直线距离**（单位：格） |
| 边界 | 圆心应保持在战场有界范围内；贴边行为由实现定义，本篇要求「不能走出战场」 |

### 5.2 移动（开战后）

- 单位在连续平面上**实时**移动，默认**寻路靠近目标**并做简单避障/绕行；差异主轴是**移动速度**（每秒可移动的距离），不是多种「走法身份」。  
- **不**使用格点四向/八向步进、斜穿格缝、象棋式移动图案作为主路径规则。  
- 固定逻辑时间步推进，结果不依赖显示帧率（见战斗文档）。  
- 玩家**不可**拖动已上场单位，**不可**点技能。

### 5.3 角色槽与敌方刷出（To-Be）

| 谁 | 落点 |
|----|------|
| 友方准备入槽 | **只许**我半场的**空角色槽**；开战后天不再投放 |
| 敌方刷出 | **只许**敌半场；本场计划敌人**开战时一次出齐**（时机见战斗文档） |

友方流程（功能层）：

1. 玩家将手牌拖入 / 点选一个空角色槽。  
2. 开战时，已占用槽在其座位坐标生成友方单位（圆心落在槽位）。  
3. 开战后单位按连续坐标移动；槽位不再接受新牌。  

刷怪：在敌半场内选取合法位置（可按格心候选 + 占位校验）；实际刷出数受**敌半场内还能放下多少个体**限制。

**【As-Is】** 友方仍为半场自由格投放 + 战中出牌，无槽位对象。

### 5.4 开战前后对比

| 阶段 | 空间怎么用 |
|------|------------|
| 准备 | 友方只与**角色槽**交互；敌方落点可预览 |
| 开战后 | 只在**连续坐标**上更新位置；可**越半场**；无战中友方投放 |

## 6. 逻辑与表现

| 层 | 约定 |
|----|------|
| **逻辑** | 连续平面 + 圆占位 + 区域半场；投放格网仅为 snap 与策划对齐尺寸的参考 |
| **表现** | 强调上下半场与投放区；单位移动可格间插值，**不要求**玩家感到在下跳棋 |
| **胜负** | 仍为清光敌方 / 己方全灭（见愿景），不因半场改变 |

## 8. 玩家可观察操作与验收（L0）

1. 进入战斗类节点后，战场呈竖向：我在下、敌在上，中线可辨。  
2. 准备阶段只能把友方放入我半场**空角色槽**；不能放到敌半场或非槽位置。  
3. 开战时敌方在敌半场一次出齐（数量受敌半场**还能放下多少**限制）。  
4. 战斗中单位在连续平面上移动，可越过中线交战；已上场友方不可被拖换位；**不能再出牌**。  
5. 槽位数量一眼可读，并等于本场最多上场人数。  
6. 画面强调半场与槽位，压力来自半场分区与越线。

**【As-Is】** 验收仍可能落在自由投放 / 战中出牌路径上；槽位验收待实现后启用。
