# 无尽模式

> 功能规格 · 只谈流程与边界，不写具体数值曲线 · 2026-10-26  
> 相关：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [地图与节点](./MAP.md) · [队伍强度抽阵](./ENEMY_SPAWN_BUDGET.md) · [战斗](./COMBAT.md) · [招募](./RECRUIT.md) · [地图商店](./MAP_SHOP.md)  
> **本版不写**：事件 / 附魔 / 未知节点；精英 / Boss；局外永久成长；中途存档；具体 κ / 面板倍率表点数（由数值资源填空）。  
> **【用户新共识】** 无通关；无精英与 Boss；线性普通战斗串 + 稀疏商店；成绩＝地图层号；死在第 N 层记 N；前几层纯战斗后才插店。

## 1. 这是什么

**无尽**是主菜单并列模式：玩家走一条**几乎直线**的普通战斗爬层，敌人随**地图层号**持续变强，没有通关终点；某一场全灭后，成绩是本局到达的地图层深。

| 本篇负责 | 别处负责 |
|----------|----------|
| 无尽入口、线性节点串、层语义、败局成绩、与主爬塔边界 | **循环 / 地图**：主爬塔分叉、精英、Boss、通关 |
| 无尽加压要用的旋钮种类（层威胁、面板、人数封顶后改轴） | **抽阵**：普通遭遇抽人落座细则 |
| — | **招募 / 地图商店**：操作细则不变时可复用 |

## 2. 与主爬塔的边界

| | 主爬塔 | 无尽 |
|--|--------|------|
| 入口 | 主菜单「开始游戏」 | 主菜单「无尽」 |
| 地图 | 分叉选路 + 精英 / Boss | **线性**节点串：普通战斗为主，稀疏商店 |
| 终点 | Boss 胜＝通关 | **无通关**；败则结束 |
| 成绩 | 通关 / 失败 | **到达地图层深**（死在第 N 层 → 记 **N**） |

无尽**不改写**主爬塔定稿。

## 3. 一整局流程

1. 主菜单点「无尽」→ 开局（默认起始队伍；可与主塔相同的开局招募门槛）。  
2. 进入线性路线：主要是**普通战斗**（准备站位 → 开战观战 → 清敌则胜 → **招募** → 继续前进）。  
3. **前若干层只有战斗**；之后在战斗之间**稀疏插入商店**（必经节点；可不买就离开）。  
4. 任一普通战败 → 结局宣告（败）→ 展示本局到达层深（及必要远征统计）→ 再来一局或回主菜单。

```text
开局 → [战斗层1 → 招募] → … → [战斗层K → 招募]
         ↕ 前几层无店；之后偶插商店（不升层）
                              ↘ 败于第 N 层 → 成绩 N
```

## 4. 地图层号

| 约定 | 含义 |
|------|------|
| **一层** | 路线上的下一场**普通战斗**；该战斗节点的地图层号＝成绩与加压用的 **F** |
| **商店** | 夹在战斗之间；**不占层、不升层** |
| **败局成绩** | 正在打的那一场的层号 **N**（未打赢也记 N） |
| **敌压 / 结算金** | 跟本场战斗的 **F** 对齐（与主塔「按层」同一把尺子；无尽可另配增长强度） |

线状路线可随推进继续往前生成（或等价预生成足够长的前缀再拼接），玩家侧表现为「一直有下一层」。

## 5. 节点种类（本版）

| 节点 | 本版 |
|------|------|
| 普通战斗 | **必有**，占绝对多数；胜后招募 |
| 商店 | **稀疏**；前几层不出现；之后隔若干战斗层插入 |
| 精英 / Boss / 事件 / 附魔 / 未知 | **本版不做** |

## 6. 难度随层升高（必须可感知）

无尽的核心可观察变化：**层号越大，普通战越难**。

| 旋钮 | 本版要求 |
|------|----------|
| **层威胁 / 层护栏** | 同队下，更深 F 的目标压力更高 |
| **面板跟队 + 层向面板下限** | 准备预览上敌方攻/血随 F 明显变厚（主手感） |
| **人数跟层** | 早期随 F 增多；达到座位硬顶后**不再加人**，改由面板 / 品阶 / 阵型压迫继续升高 |
| **品阶** | 随 F **单向**逐步放开更高品阶（不用「倒数层」假设） |
| **精英倍率 / Boss 例外** | 本模式不用 |

玩家应能在准备阶段靠**层号展示**与**敌半场预览**感到「比上一层更难」，不依赖精英/Boss 节点图标。

## 7. 复用与胜负

- 遭遇内：准备 → 回合制观战 → 结算；规则同战斗篇普通战。  
- 胜：招募后继续线性前进。  
- 败：整局结束；**不**进入通关支路。  
- 地图商店 / 招募操作复用既有规格；本篇不改其购买细则。

## 8. 验收口径（功能）

1. 主菜单有「无尽」入口，可进入无尽一整局。  
2. 路线为线性；无精英、无 Boss；前几层无商店，其后稀疏出现商店且商店不升层。  
3. 战斗层号随前进递增；败于第 N 层时成绩展示为 N。  
4. 更高层的普通战在准备预览上明显更难（人数至顶前更多和/或敌攻血更高）。  
5. 主爬塔「开始游戏」行为不被本模式改坏。
