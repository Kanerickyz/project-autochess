# 无尽模式

> 功能规格 · 只谈流程与边界，不写具体数值曲线 · 2026-10-26  
> 相关：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [远征层进度](./MAP.md) · [队伍强度抽阵](./ENEMY_SPAWN_BUDGET.md) · [战斗](./COMBAT.md) · [招募](./RECRUIT.md) · [地图商店](./MAP_SHOP.md)  
> **本版不写**：事件 / 附魔；精英 / Boss；局外永久成长；中途存档；具体 κ / 面板倍率表点数（由数值资源填空）。  
> **【用户新共识】** 无通关；无精英与 Boss；线性普通战斗串 + 稀疏商店；成绩＝远征层号；死在第 N 层记 N；前几层纯战斗后才插店。  
> **【与主模式】** 主爬塔自 2026-11-05 起亦为线性远征层，但含战后店|事二选一、精英层表与 Boss 通关；无尽仍无通关、无精英/Boss/事件支。  
> **【用户新共识 · 2026-11-05】** 无尽**复用主题三选一锁池招募**（含开局不可跳过、可花金重 roll 主题盘等招募规则可复用处）；**不**复用店|事二选一（维持稀疏商店、无事件）。
> **【用户新共识 · 敌压 · 2026-10-26】** 无尽敌攻血加压以 **每层每单位 +1/+1** 为主（第 F 层加 (F−1)）；**不做**层向 2★ 保底、**不**再叠层向面板下限抬升（跟队仍开；2★ 仅跟玩家队内）。

## 1. 这是什么

**无尽**是主菜单并列模式：玩家走一条**几乎直线**的普通战斗爬层，敌人随**地图层号**持续变强，没有通关终点；某一场全灭后，成绩是本局到达的地图层深。

| 本篇负责 | 别处负责 |
|----------|----------|
| 无尽入口、线性节点串、层语义、败局成绩、与主爬塔边界 | **循环 / 远征层**：主爬塔主题招募、店|事二选一、精英层表、Boss 通关 |
| 无尽加压要用的旋钮种类（层威胁、面板、人数封顶后改轴） | **抽阵**：普通遭遇抽人落座细则 |
| — | **招募 / 战后商店**：操作细则不变时可复用 |

## 2. 与主爬塔的边界

| | 主爬塔 | 无尽 |
|--|--------|------|
| 入口 | 主菜单「开始游戏」 | 主菜单「无尽」 |
| 进度 | **线性**远征层：主题招募 + 店\|事二选一 + 精英层表 + Boss | **线性**普通战斗串 + 稀疏商店 |
| 终点 | Boss 胜＝通关 | **无通关**；败则结束 |
| 成绩 | 通关 / 失败 | **到达层深**（死在第 N 层 → 记 **N**） |

无尽**不改写**主爬塔定稿。

## 3. 一整局流程

1. 主菜单点「无尽」→ **开局主题招募**（与主塔同：无赠送队、开局金、不可跳过、完成须 ≥1 已入座、主题锁池）。  
2. 进入线性路线：主要是**普通战斗**（准备 → 开战观战 → 清敌则胜 → **主题招募** → 继续前进）。  
3. **前若干层只有战斗**；之后在战斗之间**稀疏插入商店**（必经；不升层；**无**事件支、**无**店|事二选一）。  
4. 任一普通战败 → 结局宣告（败）→ 展示本局到达层深 → 再来一局或回主菜单。

```text
开局主题招募 → [战斗层1 → 主题招募] → … → [战斗层K → 主题招募]
         ↕ 前几层无店；之后偶插商店（不升层；无事件）
                              ↘ 败于第 N 层 → 成绩 N
```

## 4. 地图层号

| 约定 | 含义 |
|------|------|
| **一层** | 路线上的下一场**普通战斗**；该战斗节点的地图层号＝成绩与加压用的 **F** |
| **商店** | 夹在战斗之间；**不占层、不升层** |
| **败局成绩** | 正在打的那一场的层号 **N**（未打赢也记 N） |
| **敌压 / 结算金** | 跟本场战斗的 **F** 对齐（与主塔「按层」同一把尺子；无尽可另配增长强度） |

线状路线可随推进继续往前生成（或等价预生成足够长的前缀再拼接），玩家侧表现为「一直有下一层」。

## 5. 节点种类（本版）

| 节点 | 本版 |
|------|------|
| 普通战斗 | **必有**，占绝对多数；胜后**主题锁池招募** |
| 商店 | **稀疏**；前几层不出现；之后隔若干战斗层插入；**非**店|事二选一 |
| 精英 / Boss / 事件 / 附魔 / 未知 | **本版不做** |

## 6. 难度随层升高（必须可感知）

无尽的核心可观察变化：**层号越大，普通战越难**。

| 旋钮 | 本版要求 |
|------|----------|
| **每层每单位固定加攻血** | **主加压**：第 F 层每名敌 **+(F−1) 攻 / +(F−1) 血**；结算＝**2★ 身体 → 跟队 → flat**（flat 在跟队后加；禁止跟队后再 ×3）；开战须保留结算 |
| **面板跟队** | 跟玩家队均；**层向面板下限增长关闭**（避免与 flat 双叠） |
| **2★ 模板** | **仅跟玩家队内 2★**；无层向保底配额 |
| **人数跟层** | 早期随 F 增多；达座位硬顶后不再加人 |
| **品阶 / 层威胁** | 随 F 缓开（与主塔同量级）；不另做无尽加码 |
| **精英倍率 / Boss 例外** | 本模式不用 |

玩家应能在准备阶段靠**层号**与敌攻血随层 +1/+1 感到变难，不依赖精英/Boss。

## 7. 复用与胜负

- 遭遇内：准备 → 回合制观战 → 结算；规则同战斗篇普通战。  
- 胜：招募后继续线性前进。  
- 败：整局结束；**不**进入通关支路。  
- 地图商店 / 招募操作复用既有规格；本篇不改其购买细则。

## 8. 验收口径（功能）

1. 主菜单有「无尽」入口，可进入无尽一整局。  
2. 路线为线性；无精英、无 Boss；前几层无商店，其后稀疏出现商店且商店不升层。  
3. 战斗层号随前进递增；败于第 N 层时成绩展示为 N。  
4. 更高层的普通战在准备预览上明显更难（人数至顶前更多和/或敌攻血更高）。  
5. 主爬塔「开始游戏」行为不被本模式改坏。
