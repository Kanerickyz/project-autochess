## 1. 这是什么

**远征行囊**是玩家一整局拥有的 **6** 个槽位，用来存放**远征圣物**。圣物挂在**玩家这一整局**上，不挂到某个队伍成员身上；开战后天仍只观战，不能装卸行囊。

体验骨架：路过**事件**三选一攒规矩 → 养队与站位仍是主循环 → **招募**可卖圣物腾槽换金 → 观战看规则兑现。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **远征行囊** | 整局持久的 **6** 格圣物栏；跨遭遇保留；失败整局重置时清空 |
| **远征圣物** | 放入行囊的一件全局被动/规则修饰；有 Tier；效果见 Content 库 |
| **三选一** | 事件内展示至多 3 件候选圣物，玩家选 1 件（或跳过） |
| **换下** | 拿新圣物时指定一件已有圣物离开行囊；**无金**；旧件丢弃 |
| **出售** | 仅在**招募阶段**卖掉行囊中的圣物换金；退金按 Tier 见 Content |

---

## 4. 拥有与槽位

| 项 | 规则 |
|----|------|
| 容量 | 固定 **6**；本版不扩展 |
| 持久 | 跨遭遇 / 跨节点保留；Run 失败重置 |
| 同名 | 默认同 id **不叠层**；行囊内至多一件同 id（三选一去重） |
| 开战 | 战斗阶段行囊**只读**；不能卖、不能换下、不能拿新 |
| 准备 | 不提供行囊交易；圣物效果若影响准备外经济/商店，按各圣物描述 |

队伍成员、备战、席位上限规则不变；行囊是**额外**拥有物。

---

## 5. 获取：事件三选一

1. 进入**事件**节点时，本版最小交付：提供一次**远征圣物三选一**（可与其它事件选项并存或即为此节点主交互；实现可先做「进事件 = 开三选一」）。  
2. 候选按 Content 池与层深偏抽权重抽取；三格独立抽，同 id 去重重抽。  
3. **可跳过**：不拿、不换下，完成节点回地图。  
4. **行囊未满**：可选一件直接入空槽；也可自愿「拿新并指定一件旧件换下」（旧丢无金）。  
5. **行囊已满**：选一件后必须指定一件旧件换下（旧丢无金）；不能静默覆盖。  
6. 拿新成功后该事件的三选一结束（本节点不要求连续多次三选一）。

**本版获取口仅事件**；地图商店、招募货架、精英默认掉落**不**发圣物。

---

## 6. 出售：招募阶段

1. 仅在**招募**阶段可出售行囊中的圣物。  
2. 出售：圣物离开行囊，按 Tier 退金（见 Content）；UI 须与「出售队伍成员」区分可读。  
3. 事件内的换下**不**走退金。

---

## 7. 效果与管线

1. 圣物效果挂在**玩家 Run**，对整场战斗或经济规则生效，不占用队员增益栏 / 装备槽。  
2. **战斗触发 / 战斗增益**类：须可表达为 `EffectSpec` → `EffectResolver`；触发经 `CombatEventBus`（或开战结算点）；禁止圣物专用第二套 Buff。复杂顶（鼓点/邻旗/铁扉/盾回/血宴每回合）允许 `ExpeditionRelicCombatHooks` 听总线，数值仍走 `stat_modifiers` / 战斗扣血管线。  
3. **非战斗规则**（层金加减、商店标价/刷新费、卖人退金加成、事件代价减免）：走经济/商店/事件解析侧（`EventEffectResolver` + `apply_event_gold_loss`），与战斗管线分界写清。  
4. 与主题羁绊：**不得**修改主题人数计数。允许两类弱放大（见 Content）：  
   - **按主题筛选**：开战给带某主题（主/辅）的友方加临时攻/血；可要求该主题已成形。  
   - **成形开关 / 多层**：如「任一主题成形」或「每成形主题一层」（有硬顶）。  
5. 具体点数、硬顶、卖囊退金、事件偏抽见 [远征圣物库](../Content/EXPEDITION_RELICS_ROSTER.md)。

## 8. 分界（防叠床架屋）

| 已有 | 行囊不抢 |
|------|----------|
| 招募药水 / 旗帜 | 即时结算；不进行囊 |
| 地图消耗品 / 护甲 | 挂角色；不进行囊 |
| 增益卡 | 挂队伍成员 |
| 主题羁绊 | 上场凑人团队层；不改计数 |
| 单位技能 | 兵种自带 |

---

## 9. 玩家可观察操作（验收口径）

1. Run 内可见远征行囊至多 6 格及已装备圣物名/效果摘要。  
2. 进事件可开出三选一；可跳过；未满可直接拿或自愿换下；已满拿新必须指定换下。  
3. 招募可卖圣物换金；卖人与卖圣物不混淆。  
4. 开战后天不能改行囊；带战斗向圣物时观战中效果按描述兑现（轻量验收不代验手感）。  
5. 行囊不满 6 或不拿圣物不阻开战 / 不阻离开事件。
