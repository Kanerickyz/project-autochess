# 胜后免费强化（Victory Boost）

> 功能规格 · 普通/精英**胜利结算之后、招募之前**的免费选人加攻血 · 2026-11-01  
> 相关：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [战斗](./COMBAT.md) · [招募](./RECRUIT.md) · [玩家](./PLAYER.md) · [品阶解锁（实现）](../../scripts/core/tier_unlock.gd)  
> **本版不写**：具体敌压预算调参、镜头缓动定死秒数以外的美术定稿、地图商店消耗品细则。  
> **【用户新共识 · 2026-10-31】** 时机 / 整队可选 / 攻血同加档位 / 可跳过 / 落盘后再进招募。  
> **【用户新共识 · UX · 2026-11-01】** 暗场聚焦；上场+备战全体弹到屏中可选阵列；**短按即写入**（无「确认强化」）；长按只看卡；保留「跳过强化」；短反馈后再进招募。

## 1. 这是什么

**胜后免费强化**是普通战斗 / 精英**胜利**后、进入**招募**之前的短一步：战场压暗，整队纸片弹到屏幕中部供点选；玩家短按一名友方角色后，**不花金币**永久提高其攻击与生命上限，短反馈后进入招募；也可**跳过强化**后仍进入招募。

体验骨架：打完胜仗 → 暗场点名加厚 → 再花金做短名单整队 → 回地图。

## 2. 写什么、不写什么

### 2.1 本文要写清的

- 何时出现 / 不出现  
- 与招募、药水的分工  
- 选人范围、永久写入、与三合一 / 出售的衔接  
- 幅度档位如何跟**当前最高已解锁品阶**对齐（点数为定稿草案）  
- 界面：暗场、居中阵列、短按落盘、长按介绍、跳过  
- 验收口径  

### 2.2 和别处怎么分

| 本篇负责 | 别的文档负责 |
|----------|----------------|
| 胜后强化一步的流程与操作 | **循环 / 战斗**：胜负判定、结算发金时机 |
| 免费永久攻血同加规则 | **招募**：短名单拿人 / 出售 / 药水（花金、单维） |
| — | **玩家**：队伍 / 备战 / 三合一定义 |
| — | **增益卡**：商店挂载的另一套永久层 |

### 2.3 一句边界

本版**做**：普/精胜后强制出界面（可跳过）；暗场 + 整队居中纸片阵列；短按即永久 +攻/+血；长按介绍不落盘；短反馈后进招募。  
本版**不做**：Boss 胜后强化；失败后强化；花金币买本步；开局招募套用本步；「确认强化」二次确认；纯列表 / 抽象按钮墙选人；战斗临时随从可选；强化撤销。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **免费强化阶段** | 胜利结算后、招募进门之前的短养成步 |
| **本档幅度** | 本次强化攻与血各加的点数（同加） |
| **最高已解锁品阶** | 与招募 / 敌池同表（`TierUnlock`）：当前地图层下最高可出角色品阶 |
| **跳过强化** | 不改任何成员属性，结束本步并进入招募 |
| **短按落盘** | 短按一名可选成员即写入永久加成（本步一次；无二次确认） |

## 4. 何时进入

| 情况 | 是否进免费强化 | 之后 |
|------|----------------|------|
| 普通 / 精英 **胜利** | **是** | 强化结束（短按落盘或跳过）→ **招募** → 回地图 |
| **Boss 胜利** | **否** | 直接通关（与招募一致） |
| 任一战斗 **失败** | **否** | 整局失败 |
| **开局招募** | **否** | 仅开局短名单，无本步 |

## 5. 与招募 / 药水的分工

| | **免费强化** | **招募药水** |
|--|--------------|--------------|
| 时机 | 胜后、招募前 | 招募道具行 |
| 花费 | **不花金币** | 花金币 |
| 幅度 | 攻与血**同加**一档（见 §7） | 单维 +1 攻或 +1 生命 |
| 次数 | 每场普/精胜 **一次机会**（可跳过浪费） | 有货且金够可多次 |

招募「跳过」（丢弃本阶段改动回地图）**不能**回滚已落盘的免费强化：本步加成在招募**进门快照之前**写入。

---

## 6. 规则

1. **选人范围**：整队——已入座 + 备战区成员；**不含**战斗生成的代理角色。白板、熔印者可选（与药水目标口径一致）。  
2. **队伍为空**：自动跳过本步，直接进招募（若本场应进招募）。  
3. **效果**：对选中成员 **永久** `bonus_attack` 与 `bonus_max_hp` 各加本档点数（实现写入 `DeckEntry`）；跨遭遇保留；出售 / 被替换带走；三合一按玩家篇攻血加总带走，不另乘星。  
4. **不扣金币**。  
5. **跳过强化**：属性不变，仍进招募。  
6. **短按落盘**：属性写入后，界面上可读出本次 +N/+N，**约 0.5 秒**后再切招募（反馈段可提前打断，但玩家须至少能看清加成文案）；落盘后立刻锁输入，防止连点第二人。  
7. **无撤销**：本步不提供「换人选」或撤销已写入强化。

## 7. 幅度档位【用户草案数值 · 定稿意图】

以**当前最高已解锁品阶**定档（与 `TierUnlock.get_max_unlocked_tier` 同尺；无尽用 forward 同刻度）：

| 最高已解锁品阶 | 本档幅度 |
|----------------|----------|
| 1（约第 1–3 层） | **+1 攻 / +1 生命** |
| 2（约第 4 层起） | **+2 / +2** |
| 3（倒数 6 层起 / 无尽约第 10 层起） | **+3 / +3** |

不按「本局第几次强化」计数。

## 8. 界面与交互

**奖励聚焦态**（非招募半场货架复刻）：同一战场上压暗背景，友方整队纸片从原座位 / 备战位弹到屏幕中部成可选阵列。

| 要素 | 约定 |
|------|------|
| 阶段标题 | 「免费强化」（勿写「招募」） |
| 暗场 | 渐变压暗战场（含敌半场 / 残骸）；暗场空白不可点选角色 |
| 角色表现 | **纸牌 / 纸片**形象；禁止纯抽象名单 UI |
| 居中阵列 | **上场 + 备战全体**进入同一中部编排；备战须有可读标签（如「备战」），不只靠颜色区分 |
| 短按 | 抬起短按（未达长按阈值）→ **立即写入**本档 +攻/+血；无「确认强化」按钮 |
| 长按 | 与现网单位信息卡一致；长按达成后松手**只收卡、不落盘** |
| 跳过 | 常驻 **「跳过强化」**（文案须含「强化」）；与选角热区隔离 |
| 可读说明 | 本档 +N/+N；「不花金币」；一句与药水区分（免费攻血同加 vs 花钱单维） |
| 落盘反馈 | 该员纸片上可读 +N/+N（可环光 / 微放大）；其余可选压暗或收回 |
| 切招募 | 暗场收起；标题 / 下区货架 / 底栏换成招募语义；角色落回招募半场座位几何；清掉强化选中态；避免整屏闪黑重建 |

进场动画未完成前：不可短按落盘、不可误触跳过（或跳过可点但进场锁短按——以实现为准，须防误触）。

## 9. 验收口径（玩家可观察）

- 普/精胜后、进招募前必见「免费强化」暗场 + 居中可选阵列；Boss 胜、失败、开局招募不见本步。  
- 上场与备战成员均出现在居中阵列且可短按；备战身份可读。  
- 可见本档 +N/+N 与不花金币；**短按后**该员攻血各 +N，短反馈后再进招募货架；**无确认钮**。  
- 长按只出介绍、松手不强化。  
- 「跳过强化」后仍进招募且属性未变。  
- 招募「跳过」不会撤销已落盘的免费强化。  
- 档位随当前最高已解锁品阶切换（与品阶解锁提示同尺）。
