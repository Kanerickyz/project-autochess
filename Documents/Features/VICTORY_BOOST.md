# 胜后免费强化（Victory Boost）

> 功能规格 · 普通/精英**胜利结算之后、招募之前**的免费选人加攻血 · 2026-10-31  
> 相关：[游戏愿景](../GAME_VISION.md) · [游戏基础循环](./GAME_LOOP.md) · [战斗](./COMBAT.md) · [招募](./RECRUIT.md) · [玩家](./PLAYER.md) · [品阶解锁（实现）](../../scripts/core/tier_unlock.gd)  
> **本版不写**：具体敌压预算调参、镜头缓动定死秒数以外的美术定稿、地图商店消耗品细则。  
> **【用户新共识 · 2026-10-31】** 见下文定稿表。**【As-Is】** 实现前主路径可能尚无本步；**文档定稿 ≠ 已实现**。

## 1. 这是什么

**胜后免费强化**是普通战斗 / 精英**胜利**后、进入**招募**之前的短一步：自动弹出与招募同构的半场界面，玩家从**整队**（已入座 + 备战）点选一名友方角色，**不花金币**永久提高其攻击与生命上限；也可**跳过强化**后仍进入招募。

体验骨架：打完胜仗 → 先免费点名加厚核心 → 再花金做短名单整队 → 回地图。

| 本篇负责 | 别的文档负责 |

### 2.3 一句边界

本版**做**：普/精胜后强制出界面（可跳过）；整队纸牌点选；长按介绍；按品阶档永久 +攻/+血；确认后短停再进招募。

## 3. 术语

| 术语 | 意思 |
|------|------|
| **免费强化阶段** | 胜利结算后、招募进门之前的短养成步 |
| **本档幅度** | 本次强化攻与血各加的点数（同加） |
| **最高已解锁品阶** | 与招募 / 敌池同表（`TierUnlock`）：当前地图层下最高可出角色品阶 |
| **跳过强化** | 不改任何成员属性，结束本步并进入招募 |
| **确认强化** | 对当前选中成员写入永久加成后，短停再进入招募 |

---

## 4. 何时进入

| 情况 | 是否进免费强化 | 之后 |
|------|----------------|------|
| 普通 / 精英 **胜利** | **是** | 强化结束（确认或跳过）→ **招募** → 回地图 |
| **Boss 胜利** | **否** | 直接通关（与招募一致） |
| 任一战斗 **失败** | **否** | 整局失败 |
| **开局招募** | **否** | 仅开局短名单，无本步 |

---

## 5. 与招募 / 药水的分工

| | **免费强化** | **招募药水** |
|--|--------------|--------------|
| 时机 | 胜后、招募前 | 招募道具行 |
| 花费 | **不花金币** | 花金币 |
| 幅度 | 攻与血**同加**一档（见 §7） | 单维 +1 攻或 +1 生命 |
| 次数 | 每场普/精胜 **一次机会**（可跳过浪费） | 有货且金够可多次 |

招募「跳过」（丢弃本阶段改动回地图）**不能**回滚已确认的免费强化：本步加成在招募**进门快照之前**落盘。

---

## 6. 规则

1. **选人范围**：整队——已入座 + 备战区成员；**不含**战斗生成的代理角色。白板、熔印者可选（与药水目标口径一致）。  
2. **队伍为空**：自动跳过本步，直接进招募（若本场应进招募）。  
3. **效果**：对选中成员 **永久** `bonus_attack` 与 `bonus_max_hp` 各加本档点数（实现写入 `DeckEntry`）；跨遭遇保留；出售 / 被替换带走；三合一按玩家篇攻血加总带走，不另乘星。  
4. **不扣金币**。  
5. **跳过强化**：属性不变，仍进招募。  
6. **确认强化**：属性写入后，界面上可读出本次 +N/+N，**约 0.5 秒**后再切招募（可打断与否以实现为准，但玩家须能看清加成）。

## 7. 幅度档位【用户草案数值 · 定稿意图】

以**当前最高已解锁品阶**定档（与 `TierUnlock.get_max_unlocked_tier` 同尺；无尽用 forward 同刻度）：

| 最高已解锁品阶 | 本档幅度 |
|----------------|----------|
| 1（约第 1–3 层） | **+1 攻 / +1 生命** |
| 2（约第 4 层起） | **+2 / +2** |
| 3（倒数 6 层起 / 无尽约第 10 层起） | **+3 / +3** |

不按「本局第几次强化」计数。

## 8. 界面与交互

布局**参照招募**：同一 Arena 拼屏——上区友方座位纸片、中缝备战一行纸片；**下区不要**候选人 / 药水货架，改为强化动作带。

| 要素 | 约定 |
|------|------|
| 阶段标题 | 「免费强化」（勿写「招募」） |
| 角色表现 | **纸牌 / 纸片座位形象**；禁止纯抽象名单 UI |
| 点选 | 点上区或备战成员 → 选中态 + 预览将 +N 攻 / +N 血 |
| 长按 | 与现网单位信息卡一致；长按不误触确认 |
| 主按钮 | **确认强化**（未选人禁用）/ **跳过强化**（文案须含「强化」，勿单独「跳过」） |
| 可读说明 | 本档 +N/+N；「不花金币」；一句与药水区分（免费攻血同加 vs 花钱单维） |
| 切招募后 | 标题、下区货架、底栏一次性换成招募语义；清掉强化选中态 |

---

## 9. 验收口径（玩家可观察）

- 普/精胜后、进招募前必见「免费强化」屏；Boss 胜、失败、开局招募不见本步。  
- 上场纸片与备战纸片均可点；长按出介绍。  
- 可见本档 +N/+N 与不花金币；确认后该员攻血各 +N，短停后再进招募货架。  
- 「跳过强化」后仍进招募且属性未变。  
- 招募「跳过」不会撤销已确认的免费强化。  
- 档位随当前最高已解锁品阶切换（与品阶解锁提示同尺）。
