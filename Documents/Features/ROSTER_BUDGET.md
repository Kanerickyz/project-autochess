## 1. 这是什么

玩家用**攻击预算**与**生命预算**决定谁能**入座上场**；招募入手与备战存放**不扣**预算。战斗中倒下的友方在**胜负结算后**永久离队，并把开战前基准攻血退回预算池。普通/精英胜利后三选一成长，**取代**原按层发金。

核心公式（玩家可读）：

```text
阵容 = 角色 + 角色 + …
角色 = 生命 + 攻击力 + 技能
```

## 2. 预算模型（乙 · 入座占用）

| 动作 | 规则 |
|------|------|
| **入手（招募拿到角色）** | **不扣**预算。须有空备战格或可入座位，且池中该角色仍有剩余份数。点买**优先入座**（预算够且有空座）；否则进备战。 |
| **进备战** | **免费**；**永不占用**预算。备战固定 **5** 格。 |
| **入座** | 按该角色**基准攻/血**占用剩余预算；任一项不足则不能入座。入座最多 **10**（座位网格 2×5）。 |
| **撤座回备战** | 释放占用；人仍在队伍。备战满则不能撤。 |
| **出售** | 离队；若在座先释放占用；再按基准攻/血**加回**剩余预算；池份数回库。 |
| **战斗中倒下** | 仅本场倒下；编制与预算占用暂不变。 |
| **胜负结算后离队** | 倒下的**已入座**友方（非召唤物）统一移出队伍；释放占用；按**开战前基准攻/血**加回剩余预算；池份回库。备战未参战，不因本场离队。 |

**开战前基准**＝锁阵瞬间的展示攻/血（含永久药水等养成；**不含**本场临时增益）。装备随人销毁，不另退金。

**召唤物**：非队伍拥有物，不占预算、不占编制、不退池。

## 3. 开局

| 项 | 【用户新共识】草案数值 |
|----|------------------------|
| 赠送队伍 | **6** 只攻击 **1** / 生命 **3** 的骷髅（可全入座） |
| 开局可占用余额 | 攻击 **2** / 生命 **2** |
| 赠送与预算 | 赠送入座**不消耗**开局 2/2；2/2 只约束之后**额外入座** |
| 赠送离队 | 出售或结算离队时按 1/3 加回剩余预算 |

## 5. 池份

| 项 | 规则 |
|----|------|
| 每角色整局份数 | **3** |
| 入手 | 成功招募扣 1 份 |
| 战死结算离队 / 出售 | 份数**退回**池中 |

## 6. 金币

金币**不**用于招人。本版金币用途：

- 招募刷新
- 招募道具行（生命/力量药水；**无旗帜**）
- 地图商店消耗品 / 装备

## 7. 胜后三选一（取代层金）

普通 / 精英**胜利**且完成结算离队退池后，玩家三选一：

| 选项 | 效果 |
|------|------|
| A | **+5** 生命预算 |
| B | **+2** 攻击预算 |
| C | **+8** 金币 |

然后进入招募。

| 情况 | 三选一 | 招募 |
|------|--------|------|
| 普通/精英胜 | **有** | **有** |
| Boss 胜 | **无** | **无**（通关） |
| 败 | **无**（整局重置；不入账退池） | **无** |

**【建议】顺序**：结算离队退池 → 三选一 → 招募。

## 9. 验收口径（功能）

1. 开局可见 6 只 1/3 骷髅入座，剩余预算显示 2/2。  
2. 备战↔入座：入座检查预算；回备战释放；备战不占预算。  
3. 招募点买优先入座；金不够仍可入手（不花金）；刷新仍扣金。  
4. 道具行无旗帜；席位不经道具扩展。  
5. 取消三合一：三只同名可并存。  
6. 普通/精英胜：倒下者离队退预算与池份 → 三选一 → 招募。  
7. 败局 / Boss 胜：无三选一。
