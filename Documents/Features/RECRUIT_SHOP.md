# 招募阶段道具与角色行

> 功能规格 · 只谈胜后**招募阶段**半场内的角色/道具，不写具体定价点数 · 修订 2026-11-11

> **本版不写**：角色池权重表、药水定价定稿表、美术图标细则。  
> **【用户新共识 · 2026-11-11】** 角色入手**不花金币**；入座占用攻/血预算（见阵容预算）。道具行仅**生命药水 / 力量药水**（花金）；**移除旗帜**。金币另可用于刷新与地图商店。  
> **【边界】** 本功能在**招募阶段**，不在战斗准备阶段。高风险消耗品与装备在 [地图商店](./MAP_SHOP.md)。

## 1. 这是什么

普通 / 精英胜后进入**招募**时，下半场为两行：第一行角色 5 槽，第二行道具。角色入手走预算规则；道具即时扣金。Boss 胜不进招募。

| 本篇负责 | 别处负责 |
|----------|----------|
| 招募半场两行布局、药水购买与即时效果 | **招募 / 阵容预算**：入手、入座占用、出售退预算、池份、三选一衔接 |
| — | **玩家**：队伍、入座硬顶、持久占位 |
| — | **数值**：药水价格与刷新权重 |

## 2. 布局与交互

```text
招募半场（下）
  第一行：角色候选槽 × 5
  第二行：道具槽（生命药水 / 力量药水）— 无旗帜
招募上半场：当前队伍座位（拖药水落到其上）
```

| 操作 | 结果 |
|------|------|
| 点击 / 拖角色到上区 | 入手不花金；点买优先入座（预算够）；否则备战；规则见招募篇 / 阵容预算 |
| 拖角色到「锁定」落点 | 切换该槽锁定；刷新时**保留**已锁角色；完成/跳过后跨下一场招募仍保留；新 Run / 开局招募清空 |
| 点击药水后点上区角色，或拖药水到上区角色 | 金够则扣金，对该成员永久 +生命或 +攻击 |
| 金不足（仅道具/刷新）/ 拥有已满 / 入座预算不足 / 目标非法 | 失败，槽保留 |

买走后本场该槽可空并解除锁定；不要求自动补货。

---

## 3. 道具

| 道具 | 效果 | 目标 | 持久 |
|------|------|------|------|
| **生命药水** | 目标 **+1 最大生命** | 上区一名队伍成员 | 整局永久（抬高开战前基准，影响日后退预算） |
| **力量药水** | 目标 **+1 攻击** | 上区一名队伍成员 | 整局永久 |

**本版不做旗帜**（入座硬顶固定 10）。

---

## 4. 验收口径

1. 招募阶段下半场可见角色 5 槽 + 药水道具行（**无旗帜**）。  
2. 战斗**准备**阶段无此两行道具商店。  
3. 药水即时扣金且效果跨遭遇保留。  
4. 角色入手不扣金币。  
5. 锁定角色刷新不被换走；空槽不可锁。  
6. 锁定跨场保留规则同旧：完成/跳过后下一场仍锁；新 Run / 开局招募清空。
