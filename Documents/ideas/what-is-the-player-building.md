# 玩家在构筑什么？

> 日期：2026-11-02 · 状态：碎碎念 · 待想清楚再升格规格

## 想法

核心问题：**玩家这一局里到底在构筑什么？乐趣来自哪里？**

### 1. 构筑对象（搭什么）

目前感觉至少有两块，第二块还不清楚：

1. **构筑阵容角色** — 谁上场、什么技能联动、站位怎么摆。
2. **构筑加成** — 加成是什么？是否等于指挥官升级？还是主题羁绊、永久增益、装备/消耗品、胜后强化之类？需要单独想清楚「加成」这一层的玩家可读物。

未定：加成是独立养成轴，还是角色养成的附属？

### 2. 构筑方式（怎么搭）

#### 2.1 战后招募 — 扩阵容

- 新角色加入队伍；随 **Tier** 升高，更容易抽到更强角色。
- 待问：
  - 角色分类是否足够？（目前感觉只有三个 Tier）
  - Tier 之间差异是否够大、够可读？
  - 分类除了 Tier，是否还需要主题/兵种/触发时机等玩家能认的标签？

#### 2.2 角色养成 — 目前偏薄

- 现状印象：主要是 **三合一**，以及基础的 **加攻 / 加血**。
- 待问：角色养成还应有哪些杠杆？（技能幅度随星、装备、永久属性、指挥官、胜后强化…哪些算「养成」、哪些算「加成」）

### 3. 什么决定角色强度？

草稿清单（未定稿，仅记账）：

1. **基础数值** — 血量、攻击力（及攻距/出手方式等身体属性？）
2. **被动 / 主技能** — 额外伤害或效果；**触发频率 × 单次数值**
3. **羁绊？** — 兵种/主题类型？例如「5 个同族有加成」这类硬羁绊要不要做？  
   （对照：愿景里有主题羁绊包装；是否做成凑数硬加成，还是软联动，未定。）

### 4. 玩家乐趣在哪里？

1. **不同的构筑方向** — 种类多、效果可辨、能走出不一样的队。
2. **构筑得到的强度** — 养成与联动兑现后的变强感、碾压感、成型瞬间。

待问：乐趣是否还要第三块——**本局约束下的取舍与转型**（抽不到核心时怎么活）？还是先只盯「方向多样性 + 强度兑现」？

### 5. 待回答的清单（下次聊可逐条勾）

- [ ] 「加成」具体指哪些玩家可见物？指挥官升级是否算其中一条？
- [ ] Tier 数量 / 档差 / 招募权重是否够撑「越往后越强」的感觉？
- [ ] 角色分类维度：Tier 以外还要什么？
- [ ] 角色养成除三合一与加减攻血外，还要不要第二条养成轴？
- [ ] 羁绊：硬凑数 vs 软技能联动 vs 仅库内筛选标签？
- [ ] 乐趣验收：玩家一局后能否用一句话说清「我在玩 XX 流」？
