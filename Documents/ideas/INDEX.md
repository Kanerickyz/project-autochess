# Ideas — 随机想法

> 非正式备忘区：灵感、对照、未定问题。**不是** Features / Content 定稿，不默认进实现。

> 相关：[文档索引](../INDEX.md) · [游戏愿景](../GAME_VISION.md) · [养成规范见 DEVELOPMENT_WORKFLOW](../DEVELOPMENT_WORKFLOW.md)

## 怎么用

- 一条想法一个文件，或按主题拆分（如 `roguelike-orthogonality.md`）。
- 文件名：小写、短横线；开头可写日期与一句话摘要。
- 升格为规格前：先对齐愿景与现有 Features，再按工作流写正式文档；当前不做的默认不写进规格。
